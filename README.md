## 使用方法

- **注入任意 AI 助手**：把 SKILL.md 全文作为系统提示或上下文附加给大模型（中文版信息密度更高，英文版便于国际模型理解；六个技能均提供双语版）。
- **注册为技能**：把技能目录放入支持自定义技能的 AI 编程工具（如 Claude Code）的技能目录，即可自动触发。
- **直接阅读**：knowledge/ 下的主题笔记本身是带文号、数字与对比表的速查手册，适合人读。
- **查证与维护**：政策文号与状态查 [knowledge/索引与口径-2026-11.md](knowledge/索引与口径-2026-11.md)；省别问题查 [knowledge/省级市场状态表-2026-11.md](knowledge/省级市场状态表-2026-11.md)；新能源项目的资源、LCOE、机制电价与并网查 [新能源项目开发与并网-2026-11](knowledge/新能源项目开发与并网-2026-11.md)；电价怎么构成、现价文件与用户侧查证步骤，依次查 [制度谱系](knowledge/中国电价制度谱系-2026-11.md)、[现行政策与查证](knowledge/中国电价现行政策与查证-2026-11.md)、[电价史](knowledge/中国电价史-2026-11.md)；跨国比较先用 [方法与模板](knowledge/国际电价比较-方法与模板-2026-11.md) 统一口径；想快速检验回答是否跑偏，用 [knowledge/黄金问答集-2026-11.md](knowledge/黄金问答集-2026-11.md) 逐题对答案；英文读者从 [knowledge/INDEX_EN-2026-11.md](knowledge/INDEX_EN-2026-11.md) 入手。
- **提交前自检**：运行 `node scripts/check-consistency.mjs`（GitHub Actions 也会执行），检查表格前后空行、相对链接、中英文版本号与关键数字是否一致。
