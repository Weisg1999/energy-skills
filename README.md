## 🚀 使用方法

**方式一：作为 ZCode / Claude Code 技能**
把 `skills/electricity-trading-expert/` 整个目录放到用户技能目录（如 `~/.zcode/skills/`），重启后即自动触发；也可在会话中手动 `/skill` 调用。

**方式二：注入任意 AI 助手**
把 `SKILL.md` 全文作为系统提示或上下文附加给任何大模型（ChatGPT / 通义 / DeepSeek 等均可）。

**方式三：人读**

## 🔬 知识是怎么来的

本仓库由一条**三级蒸馏流水线**构建：

```
6 本专业书籍（PDF，其中 3 本为无文本层扫描件）
   │  PyMuPDF 渲染 + Windows OCR（917 页）
   ▼
L1 部件蒸馏 —— 14 个并行 agent，逐段提炼为结构化笔记（90 万字 → 23 份）
   ▼
L2 书级合并 —— 6 个 agent，主题化去重压缩（→ 9 份书级笔记）
   ▼
L3 终稿合成 —— 通读全部书级笔记 + 网络调研，写成 SKILL.md
   ▲
   └── 网络调研层：2 个研究 agent（2026-09-12），补充最新政策/价格/开源工具，
       每条信息标注来源 URL 与日期，未核实项显式标注"待核实"
```

## ⚠️ 重要声明

1. **时效性**：政策类数字（转正名单、机制电价、补贴标准等）截至 **2026-09-12** 调研时点，此后以官方最新文件为准；书本知识的成书时点已逐书标注（碳实务类为 2016 年前后，机制有效、数字需以网络调研层为准）。
2. **原创性**：`knowledge/` 笔记均为对原书的原创性主题化摘要与提炼（非原文复制），书籍版权归原作者所有；本仓库不含任何书籍原文全文。
3. **非投资建议**：所有价格判断与测算框架仅供学习研究，不构成任何投资建议。
4. **口径纪律**：技能内置了"待核实"标注约定与常见误区清单（如 OM 基准线因子误用于用电排放、813 号文误引等），使用前建议阅读 SKILL.md 第 0 章与第 14 章。
