# ⚡ Energy Skills · 电力交易与虚拟电厂技能库

[English](README_EN.md) | 中文

面向 AI 助手的电力市场领域技能（Skill）集合。每个技能是一份可直接注入大模型上下文的 Markdown 手册：加载后，模型会以对应领域的资深从业者身份回答问题，并遵守内置的答题纪律——数字带文号与时点、涉及具体省份先确认、政策类内容给出查证入口、未经交叉验证的数据标注"待核实"。

## 技能

### [电力交易专家 electricity-trading-expert](skills/electricity-trading-expert/SKILL.md)

覆盖电力现货、中长期与电力金融、辅助服务与容量机制、结算计量、省级市场实践、新能源入市（136 号文）、碳市场以及交易策略与风险管理。[英文版](skills/electricity-trading-expert/SKILL_EN.md)。

| 领域 | 覆盖内容 |

| 现货市场 | SCUC/SCED 出清、LMP/SMP/ZMP 定价、三节点算例、负电价、阻塞管理与 FTR、价格帽中外对比、市场熔断 |
| 中长期与金融 | 差价合约（政府授权/市场化）、"六签"、电力期货期权、日前-实时双结算 |
| 辅助服务与容量 | 品种谱系与"两个细则"、调峰的中国特色与现货融合、联合出清定价、容量机制四路径、煤电容量电价（1501/114号文）、电网侧独立储能容量电价 |
| 结算与计量 | 结算九科目、日清月结、三段式结算公式、不平衡资金、15 分钟计量与拟合规则、2026 量差转价差方向 |
| 政策与省级实践 | 9 号文→20 号令文号时间线、2026 年全国统一市场与南方区域市场、至少 11 个省级现货市场转正（截至 2026-10）、首批试点特色 |
| 统一市场与零售 | 国办发〔2026〕4号、南方区域市场（2026-10-24 转正）、2026 现货新规征求意见（拟 2027-01-01）、售电公司退出与批零倒挂、风险防控与信用评价 |
| 新能源入市 | 136 号文机制电价、存量/增量划断（2025-06-01）、各省承接方案与 2026-2027 竞价结果 |
| 碳市场 | 全国碳市场扩围（3680 家/约 83 亿吨）、CEA 2026 价格、CCER、MRV、配额方案、条例修订、CBAM 证书购买时点、绿证年份价差 |

| 虚拟电厂（市场视角） | 入市身份与重复获利禁止、可参与品种与开放顺序、省级准入门槛与 DR 补贴行情、收益结构与零售侧传导、Order 2222 分 ISO 落地；资源聚合与运营细节指向姊妹技能 |

### [虚拟电厂专家 virtual-power-plant-expert](skills/virtual-power-plant/SKILL.md)

覆盖虚拟电厂概念辨析、资源聚合与评估、发展三阶段（邀约型/市场型/自主调度型）、市场参与机制、商业模式与盈利测算、控制优化技术、中国政策（357 号文及各省细则）与国际对标。[英文版](skills/virtual-power-plant/SKILL_EN.md)。与电力交易专家互补：出清、结算、价格帽等市场机制细节查前者，虚拟电厂的落地与运营查本技能。

| 领域 | 覆盖内容 |
|---|---|
| 概念与辨析 | VPP 定义与"正/负电厂"双重角色、与 DR/微电网/能效电厂的判据（逆向潮流、物理与逻辑聚合）、市场稳定判据 |
| 资源侧 | 可调负荷/分布式电源/储能三类资源、A-D 四象限分类、调节能力五要素、行业可调比例与资源家底 |
| 三阶段框架 | 邀约型（补贴驱动）→市场型（价格信号）→自主调度型（跨空间调度）：判据、跃迁条件、并存关系 |
| 邀约型实践 | 江苏模式（尖峰电价资金池+填谷竞价，削峰 402 万 kW）、上海模式（四方运营体系、精准响应、竞价交易） |
| 市场型机制 | 电能量/辅助服务/绿证碳市场参与流程、CVPP 与 TVPP、美国主体谱系（SC/LSE/CSP/MSP）、芬兰聚合商规制经验 |
| 控制与优化 | 四类预测（负荷/出力/价格/灵活性）、三层调控机理、冀北泛电平台架构 |
| 新兴技术 | 通信选型（NB-IoT/LoRa/5G）、区块链选型（联盟链+分布式一致性算法+链外扩容）与应用环节 |
| 商业模式 | 五类收入来源、e2m 佣金模式、尖峰负荷经济学、盈利测算框架、"规模先行、利润后置"现状与 2026 年零售侧传导约束 |
| 政策与实践 | 357 号文（2027/2030 目标）、93 号文、国标三件套（GB/T 47241-2026 已实施）、至少 20 省专项政策与 15 省市场细则（2026 新增辽宁/福建/安徽等，云南为 2025 年建章、2026 年补市场细则）、全国 470 项目/1685 万 kW 官方口径与 2026 媒体 1.2 亿 kW 接入口径、四类容量口径辨析、绿电直连 100 项目/3410 万 kW、DR 补贴行情、车网互动 241 号文 |
| 国际对标 | 德国 Next Kraftwerke 与 aFRR 价格信号、澳洲南澳 VPP 移交 AGL 的反例、美国 Order 2222 分 ISO 实施时间表（CAISO/ISO-NE 2026-11-01）与 DOE 80-160GW 目标、英国 DFS、芬兰聚合商 |

## 使用方法

- **注入任意 AI 助手**：把 SKILL.md 全文作为系统提示或上下文附加给大模型（中文版信息密度更高，英文版便于国际模型理解；两个技能均提供双语版）。
- **注册为技能**：把技能目录放入支持自定义技能的 AI 编程工具（如 Claude Code）的技能目录，即可自动触发。
- **直接阅读**：knowledge/ 下的主题笔记本身是带文号、数字与对比表的速查手册，适合人读。
- **查证与维护**：政策文号与状态查 [knowledge/索引与口径-2026-11.md](knowledge/索引与口径-2026-11.md)；省别问题查 [knowledge/省级市场状态表-2026-11.md](knowledge/省级市场状态表-2026-11.md)；想快速检验回答是否跑偏，用 [knowledge/黄金问答集-2026-11.md](knowledge/黄金问答集-2026-11.md) 逐题对答案；英文读者从 [knowledge/INDEX_EN-2026-11.md](knowledge/INDEX_EN-2026-11.md) 入手。
- **提交前自检**：运行 `node scripts/check-consistency.mjs`（GitHub Actions 也会执行），检查表格前后空行、相对链接、中英文版本号与关键数字是否一致。

## 几点说明

1. **时效性**：政策类数字（转正名单、机制电价、补贴标准、容量电价、碳价等）整理至 **2026-11-01**；2026 年 9-10 月的现货新规、售电公司管理办法、风险防控办法、信用评价指引仍为征求意见稿，正文已标注状态。各书籍的成书时点已在笔记中标注（碳实务类成书于 2016 年前后，机制仍适用、数字以调研层为准）。引用前请以官方最新文件为准。
2. **原创性**：knowledge/ 下的笔记是对原书内容的主题化摘要与提炼，非原文复制；书籍版权归原作者所有。
3. **非投资建议**：文中的价格判断与测算框架仅供学习研究。
4. **口径纪律**：技能内置"待核实"标注约定与常见误区清单（例如用 OM 基准线因子计算用电排放、把 813 号文误当现货基本规则、容量口径混淆等），使用前建议先读 SKILL.md 的第 0 章与推理手册章节。
