# ⚡ Energy Skills · 电力交易与虚拟电厂技能库

[English](README_EN.md) | 中文

面向 AI 助手的电力市场领域技能（Skill）集合。每个技能是一份可直接注入大模型上下文的 Markdown 手册：加载后，模型会以对应领域的资深从业者身份回答问题，并遵守内置的答题纪律——数字带文号与时点、涉及具体省份先确认、政策类内容给出查证入口、未经交叉验证的数据标注"待核实"。

### [现货报价量化专家 spot-bidding-quant](skills/spot-bidding-quant/SKILL.md)

覆盖从数据到报价单的可复现链路：负荷/电价/出力预测、预测残差校正、量价曲线与申报量决策、售电购电组合、竞价仿真与市场结构识别、滚动回测与 T+1 收益归因。[英文版](skills/spot-bidding-quant/SKILL_EN.md)。附**零依赖 Python 参考实现**（`tools/`）与**合成样例数据**（`data/sample/`），`python tools/selftest.py` 可跑通并断言正文指标。与另三个技能互补：规则与结算查电力交易专家，资源聚合与运营查虚拟电厂专家，碳履约与碳金融查碳资产管理专家，本技能只回答"怎么算、怎么报、怎么验证"。

| 领域 | 覆盖内容 |
|---|---|
| 报价空间 | 报价前必须确认的十个规则参数（段数、限价、二次限价、申报充足率、最小出力、合约分解等）、三种报价身份 |
| 数据与防泄露 | 最小数据清单、可得性与披露渠道、清洗规则、特征可得时点表（防未来信息泄露） |
| 负荷预测 | 季节朴素基线 → 相似日（剔除 ±25% 异常日）→ AR/ARIMAX；温度修正；误差的经济价值换算 |
| 电价预测 | 剩余负荷与边际成本机理、端到端学习路线、尖峰与负价单独建模、方向正确率/尖峰召回/分位数损失 |
| 报价理论 | 价格接受者最优报价=边际成本（可证伪）、枢机机组的剩余需求定价、合规红线、合约覆盖与风险偏好 |
| 火电报价 | 成本结构到多段曲线、启停决策、必开必停机组单独建账 |
| 新能源与储能 | 非对称罚则下的申报量决策、储能套利门槛、光储联合报价、收益测算输入契约 |
| 售电与用户 | 预测→购电组合→套餐定价、2026 批零倒挂约束、情景与 CVaR 敞口模拟 |
| 竞价仿真 | 边际出清、报价扫描（枢机区间与归零悬崖）、HHI 集中度、仿真能力边界 |
| 回测与归因 | 滚动起点、样本外残差校正、指标集、T+1 四项归因（预测/报价/执行/规则） |
| 工程与申报 | D-1 时间表、申报校验清单、改单留痕、监控兜底、自建与采购取舍 |

### [碳资产管理专家 carbon-asset-expert](skills/carbon-asset-expert/SKILL.md)

| 领域 | 覆盖内容 |

| 核算与 MRV | 三层核算体系、燃煤排放公式、数据链（计量—台账—凭证—存证）、核查抽样与不符合项、两套口径、8 类高频错误 |
| 履约日历 | 七个节点（1/15 数据封版→3/31 报告→6/30 核查→9/30 缺口→12/31 清缴→次年 1/31 复盘）、倒排法、RACI、风险清单、ICS 导出 |
| 配额盈缺 | 免费配额、缺口、CCER 5% 上限、CEA 采购量、三因素敏感性、罚则与采购成本对比（算例：采购 5,445.3 万元 vs 罚款 1.35 亿元） |

| CCER 测算 | 减排量、NPV、IRR、盈亏平衡价、敏感性、决策规则（算例：NPV −309.5 万元、IRR 6.25%、盈亏平衡 89.61 元/吨） |
| 碳金融 | 质押/回购/远期掉期/基金债券/保险矩阵、质押追保价格（算例 71.25 元/吨）、会计口径、碳期货未上市边界 |

| 产品碳足迹 | ISO 14067/GB/T 24067、五阶段两边界、声明单位/取舍/分配、因子优先级、碳标识认证试点（算例：12.4 kg/kg、抵消 892.8 元） |

## 使用方法

- **注入任意 AI 助手**：把 SKILL.md 全文作为系统提示或上下文附加给大模型（中文版信息密度更高，英文版便于国际模型理解；四个技能均提供双语版）。
- **注册为技能**：把技能目录放入支持自定义技能的 AI 编程工具（如 Claude Code）的技能目录，即可自动触发。
- **直接阅读**：knowledge/ 下的主题笔记本身是带文号、数字与对比表的速查手册，适合人读。
