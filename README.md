# ⚡ Energy Skills · 电力交易与虚拟电厂技能库

[English](README_EN.md) | 中文

面向 AI 助手的电力市场领域技能（Skill）集合。每个技能是一份可直接注入大模型上下文的 Markdown 手册：加载后，模型会以对应领域的资深从业者身份回答问题，并遵守内置的答题纪律——数字带文号与时点、涉及具体省份先确认、政策类内容给出查证入口、未经交叉验证的数据标注"待核实"。

## 技能

### [电力交易专家 electricity-trading-expert](skills/electricity-trading-expert/SKILL.md)

覆盖电力现货、中长期与电力金融、辅助服务与容量机制、结算计量、省级市场实践、新能源入市（136 号文）、碳市场以及交易策略与风险管理。[英文版](skills/electricity-trading-expert/SKILL_EN.md)。

| 领域 | 覆盖内容 |
|---|---|
| 现货市场 | SCUC/SCED 出清、LMP/SMP/ZMP 定价、三节点算例、负电价、阻塞管理与 FTR、价格帽中外对比、市场熔断 |
| 中长期与金融 | 差价合约（政府授权/市场化）、"六签"、电力期货期权、日前-实时双结算 |
| 辅助服务与容量 | 品种谱系与"两个细则"、调峰的中国特色与现货融合、联合出清定价、容量机制四路径、煤电容量电价（1501号文） |
| 结算与计量 | 结算九科目、日清月结、三段式结算公式、不平衡资金、15 分钟计量与拟合规则 |
| 政策与省级实践 | 9 号文→20 号令文号时间线、7 省现货转正名单、首批试点特色（山西熔断、山东容量补偿、四川丰枯分期等） |
| 新能源入市 | 136 号文机制电价、存量/增量划断（2025-06-01）、各省承接方案与竞价结果 |
| 碳市场 | 全国碳市场扩围（钢铁/水泥/铝）、CEA 价格走势、CCER 重启与方法学、MRV 与核查、试点碳价、CBAM 与绿证衔接 |
| 交易策略与风控 | 发电/售电/用户策略、市场力识别指标（HHI/KSI/RSI/TTS）、五类风险防范、入市能力清单 |

### [虚拟电厂专家 virtual-power-plant-expert](skills/virtual-power-plant/SKILL.md)

覆盖虚拟电厂概念辨析、资源聚合与评估、发展三阶段（邀约型/市场型/自主调度型）、市场参与机制、商业模式与盈利测算、控制优化技术、中国政策（357 号文及各省细则）与国际对标。[英文版](skills/virtual-power-plant/SKILL_EN.md)。与电力交易专家互补：出清、结算、价格帽等市场机制细节查前者，虚拟电厂的落地与运营查本技能。

| 领域 | 覆盖内容 |
|---|---|
| 概念与辨析 | VPP 定义与"正/负电厂"双重角色、与 DR/微电网/能效电厂的判据（逆向潮流、物理与逻辑聚合）、市场稳定判据 |
| 资源侧 | 可调负荷/分布式电源/储能三类资源、A-D 四象限分类、调节能力五要素、行业可调比例与资源家底 |
| 三阶段框架 | 邀约型（补贴驱动）→市场型（价格信号）→自主调度型（跨空间调度）：判据、跃迁条件、并存关系 |
| 邀约型实践 | 江苏模式（尖峰电价资金池+填谷竞价，削峰 402 万 kW）、上海模式（四方运营体系、精准响应、竞价交易） |
| 市场型机制 | 电能量/辅助服务/绿证碳市场参与流程、CVPP 与 TVPP、美国主体谱系（SC/LSE/CSP/MSP）、芬兰聚合商规制经验 |
| 控制与优化 | 四类预测（负荷/出力/价格/灵活性）、三层调控机理、冀北泛电平台架构 |
| 新兴技术 | 通信选型（NB-IoT/LoRa/5G）、区块链选型（联盟链+分布式一致性算法+链外扩容）与应用环节 |
| 商业模式 | 五类收入来源、e2m 佣金模式、尖峰负荷经济学、盈利测算框架与"规模先行、利润后置"的行业现状 |
| 政策与实践 | 357 号文（2027/2030 目标）、93 号文、国标三件套、约 20 省专项政策与 15 省市场细则、全国 470 项目/1685 万 kW 官方口径、四类容量口径辨析、DR 补贴行情、车网互动 241 号文 |
| 国际对标 | 德国 Next Kraftwerke 与 aFRR 价格信号、澳洲南澳 VPP 移交 AGL 的反例、美国 Order 2222 分 ISO 落地时间表与 DOE 80-160GW 目标、英国 DFS、芬兰聚合商 |

## 使用方法

- **注入任意 AI 助手**：把 SKILL.md 全文作为系统提示或上下文附加给大模型（中文版信息密度更高，英文版便于国际模型理解；两个技能均提供双语版）。
- **注册为技能**：把技能目录放入支持自定义技能的 AI 编程工具（如 Claude Code）的技能目录，即可自动触发。
- **直接阅读**：knowledge/ 下的主题笔记本身是带文号、数字与对比表的速查手册，适合人读。

## 几点说明

1. **时效性**：政策类数字（转正名单、机制电价、补贴标准等）整理至 2026-09；各书籍的成书时点已在笔记中标注（碳实务类成书于 2016 年前后，机制仍适用、数字以调研层为准）。引用前请以官方最新文件为准。
2. **原创性**：knowledge/ 下的笔记是对原书内容的主题化摘要与提炼，非原文复制；书籍版权归原作者所有。
3. **非投资建议**：文中的价格判断与测算框架仅供学习研究。
4. **口径纪律**：技能内置"待核实"标注约定与常见误区清单（例如用 OM 基准线因子计算用电排放、把 813 号文误当现货基本规则、容量口径混淆等），使用前建议先读 SKILL.md 的第 0 章与推理手册章节。
