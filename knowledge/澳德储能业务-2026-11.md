# 澳德储能业务：大储与工商储（2026-11）

> 数据截止：2026-11-01｜定位：知识模块（海外市场第三站，储能业务专题）
> 适用边界：只覆盖澳大利亚国家电力市场（NEM）五个区域与德国—卢森堡报价区（DE-LU）的电网侧大储（utility-scale）和工商业储能（C&I）。西澳 WEM、北领地、欧洲其他国家市场不在此文范围；澳洲户用电池、德国户用储能只在边界处提一句，不展开。
> 用途：回答“钱从哪来、怎么进场、并网卡在哪、合同怎么签、运维怎么算”五类问题。本文是规则与业务口径整理，不构成法律、税务或投资意见；所有算例均为合成数字（D 级），不能直接作为项目基准。

## 0. 一页看懂

### 0.1 四象限总图

```
                 电网侧大储                          工商业储能
        ┌──────────────────────────┬──────────────────────────┐
澳洲    │ A. NEM 大储               │ B. 澳洲工商储             │
NEM     │ 能量套利 + FCAS + CIS     │ 需量电费 + 分时价差       │
        │ 5 分钟结算、区域价、MLF    │ DNSP 接入、灵活出口       │
        │ 注册：IRP/Generator 等     │ 聚合：VPP/WDRM/FCAS       │
        ├──────────────────────────┼──────────────────────────┤
德国    │ C. DE-LU 大储             │ D. 德国工商储             │
DE-LU   │ 日前/日内套利 + FCR/aFRR  │ 需量电费 + §14a + 动态电价│
        │ /mFRR + 电网费豁免        │ 低压/中压并网、控制盒     │
        │ 2031 年起容量市场         │ 聚合参与平衡市场          │
        └──────────────────────────┴──────────────────────────┘
```

- **澳洲是“能量-only + 辅助服务 + 政府收入保障”**：没有集中容量市场；大储收益靠能量套利、FCAS 和 CIS（容量投资计划）三块，CIS 是竞标获得的收入保障，不是按容量普发的补贴。
- **德国是“电能量市场 + 平衡市场 + 电网费政策”**：大储的短期收益靠日前/日内价差和 FCR/aFRR/mFRR；中期看 §118(6) 电网费豁免；2031 年起才有容量市场。
- **工商储在两边都不是“缩小版大储”**：收入主要来自用户电费账单（需量电费、分时电价、自发自用），并网走配电网而不是输电通道，单体太小必须靠聚合参与批发/辅助服务。
- **同一个电池，四象限的投决逻辑不同**：大储看价差与辅助服务价格、并网成本和合同期限；工商储看客户负荷曲线、需量电费结构和停电/扩容需求。
- **先问五个问题**：收入由谁支付、合同时长与对手方、并网排队与费用、性能如何考核、政策节点何时变化。五个问题有一个答不上来，财务模型就只是算术。

### 0.4 中国对照一句话

- **中国**：独立储能靠容量电价/容量租赁 + 现货/辅助服务；工商业储能靠峰谷价差 + 需量管理。
- **澳洲**：没有容量电价，靠 energy-only 稀缺定价 + FCAS + CIS 收入保障；工商储靠需量电费和分时价差，聚合后可参与 WDRM/FCAS。
- **德国**：没有中国式容量电价，短期靠电能量与平衡市场，中期靠电网费豁免，2031 年起才有容量机制；工商储靠需量电费、§14a 折扣和动态电价。
- **不能直接换算**：三地的电价口径、税费、并网成本和合同结构都不同，中国项目的 IRR 不能平移。

## 1. 澳洲大储（NEM）

### 1.1 市场结构：能量与 FCAS 共同优化

- **energy-only**：NEM 没有集中容量市场，稀缺时段靠高价回收投资；可靠性由 RRO（可靠性保障合同）、RERT（应急储备）和 CIS 兜底。
- **5 分钟 dispatch + 5 分钟结算**：2021-10-01 起 5MS，电池的充放电计划、FCAS 响应和结算都按 5 分钟粒度。
- **区域价**：五个区域阻塞时价格分离；电池所在区域的价差决定套利空间。
- **FCAS 共同优化**：能量与 FCAS 在同一个 dispatch 引擎里出清，电池需要在“卖能量”和“留容量卖 FCAS”之间做机会成本比较。
- **10 个 FCAS 品种**：8 个 contingency（含 1 秒极快、6 秒快速、60 秒慢速、5 分钟延迟，涨/降分开）+ 2 个 regulation（raise/lower）。1 秒极快 FCAS 于 2023-10-09 上线。
- **NEM 时间固定 AEST**：全年不实行夏令时，交易日在 AEST 04:00 切换；做充放电策略和结算对账时先统一时区。

### 1.2 收益堆叠

| 收入项 | 谁支付 | 计价方式 | 关键约束 | 级别 |
|---|---|---|---|---|
| 能量套利 | 批发市场 | 区域价差 × 充放电量 | 5 分钟价、RTE、退化成本 | A |
| FCAS 容量 | AEMO | A$/MW/时段（按品种/方向） | 可调用性、响应速度、MASS 测试 | A |
| FCAS 能量 | AEMO | 实际调用电量 × 价格 | 与套利争用功率/能量 | A |
| CIS 收入保障 | 联邦政府（招标合同） | 按合同条款的差额补偿/容量支付 | 中标价、可用率、COD 期限 | B |
| RERT/RRO | AEMO/政府 | 合同或事件补偿 | 非经常性，不能当基础收入 | A |
| 网络服务 | NSP/市场 | 按合同 | 试点/个案，规模有限 | C |
| 合约对冲 | 交易对手 | ASX 期货、OTC、PPA、tolling | 信用、保证金、结算方式 | A |

- **收益堆叠不是简单相加**：功率和能量在套利与 FCAS 之间互斥；FCAS 可调用时长会压缩可套利电量；频繁切换增加退化。
- **FCAS 价格会被电池自己压薄**：某个区域电池渗透率上升后，FCAS 价格和套利价差同时收窄；建模要按“市场渗透率情景”而不是历史均价。
- **CIS 是收入保障，不是固定补贴**：以招标文件和合同为准，通常设有收入下限和上限分享机制；中标价竞争激烈，不能假设一定能拿到。
- **合约对冲改变的是现金流形态，不改变 dispatch**：ASX 期货和多数 PPA 是金融结算，电池仍按现货价格响应。

### 1.3 准入与注册

- **注册类别**：储能可按 Generator、Market Customer 或 Integrated Resource Provider（IRP）等类别注册。IRP 由 AEMC 2021-12-02 的最终规则引入，允许储能在单一连接点同时提供发电与负荷服务；该规则自 2024-06-03 起实施，具体注册流程和系统改造要求以 AEMO 指南为准。
  - 注意：IESS 是“Integrating Energy Storage Systems”这轮规则改革的名称，不是注册类别；把 IESS 当成注册类别是常见误读。
- **AEMO 注册**：提交注册申请、技术参数、性能标准（performance standards）、SCADA/通信方案、计量方案；通过后进入预调度/调试。
- **NSP 连接**：与输电网或配电网服务商签连接协议，完成连接申请、系统研究、保护定值、调试和并网测试；并网排队时间因州和电压等级差异很大。
- **FCAS 资质**：按 MASS（Market Ancillary Service Specification）完成测试，证明响应速度、精度和持续时间；不同 FCAS 品种测试要求不同。
- **性能标准**：AEMO 会对发电/负荷响应设定性能标准，未达标可能被限制参与或产生考核。
- **CIS 资格**：需满足招标文件的资格、项目规模、COD 期限、本地化/社区条款等；中标后签收入保障协议。

### 1.4 并网与电网费

- **连接成本**：NSP 的系统研究、接入工程、保护/通信改造、计量装置由项目承担；偏远节点可能需要新建/扩建开关站。
- **MLF/IRLF**：发电机侧按边际损失因子（MLF）结算，互联线按区域间损失因子（IRLF）；MLF 每年调整，同一节点不同年份的 MLF 可能明显变化。
- **结算残差**：跨区交易产生结算残差，按规则分配；不要把残差当成项目可控收入。
- **电网费**：作为负荷充电时可能承担 TUOS/DUOS 等网络费用；具体豁免/折扣按 NER、州规则和连接协议，不能默认“储能免电网费”。
- **并网延期是常见风险**：NSP 研究、设备交付、AEMO 注册、MASS 测试任一环节延误都会推迟 COD，进而影响 CIS 期限和融资提款。

### 1.5 合同与融资

| 模式 | 收入确定性 | 典型期限 | 适合对象 | 注意点 |
|---|---|---|---|---|
| Merchant（纯市场） | 低 | 无 | 有交易能力的开发商 | 价差收窄、FCAS 价格下行 |
| Tolling（代运营） | 中 | 5–15 年 | 有承购方的项目 | 容量费/可用率考核、运营边界 |
| PPA/CfD | 中高 | 10–20 年 | 有长期承购需求 | 结算方式、信用、负电价条款 |
| CIS 收入保障 | 中高 | 按招标合同 | 中标项目 | 中标价、可用率、COD 期限 |
| 组合（CIS+PPA+merchant） | 分层 | 混合 | 大多数可融资项目 | 现金流分层、DSCR 测算 |

- **债务规模看 DSCR**：CIS/PPA 覆盖的部分可以支撑更高杠杆，merchant 部分通常按保守价格假设打折。
- **保证金与信用**：AEMO 的 prudential 要求、交易对手信用、PPA 违约条款都会占用资金。
- **汇率与税务**：中国设备出口、澳洲本地 EPC、GST/所得税、预提税和资本弱化规则需要专业顾问；本文不展开。

### 1.6 运维与退化

- **RTE（往返效率）**：AC 侧 RTE 通常低于 DC 侧，建模要扣辅助负荷（空调、消防、控制系统）。
- **可用容量**：注意 DoD、SOC 窗口、退化后的可用容量，不要用铭牌容量直接算收入。
- **退化与质保**：按循环次数/年限的容量保持率质保；关注质保起算点、温度条件、可用率定义和更换责任。
- **增容（augmentation）**：在项目中期增加电池柜/更换电芯，需提前在土地、并网容量和消防设计中留余量。
- **FCAS 可用率**：FCAS 收入依赖可调用性，频繁调用和 SOC 管理不当会降低可用率并触发考核。

### 1.7 合成算例 A：NEM 100 MW / 200 MWh（D 级）

**假设（全部为合成数字）**

| 参数 | 取值 |
|---|---|
| 额定功率/容量 | 100 MW / 200 MWh |
| 可用容量 | 190 MWh（DoD 95%） |
| AC 侧 RTE | 85% |
| 循环 | 1 次/日 × 350 日/年 |
| 充电价 / 放电价 | A$35 / A$125 每 MWh |
| FCAS | 50 MW 可调用，A$24,000/MW/年 |
| CIS 收入保障 | A$3.0m/年 |
| CAPEX | A$70m（A$350/kWh） |
| OPEX | A$1.53m/年（运维 1.5% CAPEX + 保险 0.3% + 资产/计量） |

**计算**

```
年放电量 = 190 MWh × 350 = 66,500 MWh
年充电量 = 66,500 ÷ 0.85 = 78,235 MWh
套利毛利 = 66,500 × 125 − 78,235 × 35
         = 8.3125m − 2.7382m = A$5.574m
FCAS 收入 = 50 MW × 24,000 = A$1.20m
CIS 收入 = A$3.00m
总收入 = 5.574 + 1.20 + 3.00 = A$9.77m
EBITDA = 9.77 − 1.53 = A$8.24m
静态回收期 = 70 ÷ 8.24 ≈ 8.5 年
20 年税前项目 IRR ≈ 10%（未计退化、增容、残值与融资）
```

**读法**：这个算例的收益里，套利约占 57%、CIS 约占 31%、FCAS 约占 12%。把 CIS 拿掉，IRR 会明显下降；把放电价差从 A$90 压到 A$50，套利毛利减少约 A$2.66m，项目接近不可投。**敏感性分析必须做价差和 CIS 两项**。

### 1.8 澳洲大储五个坑

1. **把 FCAS 当稳定高收益**：FCAS 市场容量小，电池渗透率上升后价格快速下行。
2. **忽略 MLF/IRLF**：并网点 MLF 每年调整，结算电量与报价电量不是一回事。
3. **用铭牌容量算收入**：可用容量、RTE、辅助负荷和退化会把可售电量打八折甚至更多。
4. **把 CIS 当普发补贴**：CIS 是竞标制，未中标就没有；中标后还有可用率和 COD 考核。
5. **低估并网与注册成本**：NSP 连接、MASS 测试、SCADA、性能标准都是实打实的 CAPEX/工期。

## 2. 澳洲工商储

### 2.1 谁买单：用户电费账单

澳洲工商业用户的电费通常由三部分组成：

- **需量电费（demand charge）**：按最大需量（kW 或 kVA）计费，是工商储削峰的第一收入来源。
- **电量电费（usage/TOU）**：分时电价，储能做峰谷价差和自发自用。
- **固定费用/网络费用**：部分州按 kVA 或 kWh 计网络费，储能可降低需量从而间接降低网络费。

工商储的价值不是“卖电给市场”，而是**帮客户少交电费**：削峰、填谷、提高光伏自用、避免扩容、提供备用。批发市场和辅助服务收入通常要通过聚合商，且单体项目太小，不能直接注册。

### 2.2 收益堆叠

| 收入项 | 计算口径 | 关键约束 | 级别 |
|---|---|---|---|
| 需量电费削减 | 削减 kW × 需量费率（A$/kW/年或月） | 客户负荷曲线、需量窗口、同时率 | A |
| 峰谷价差 | 放电量 ×（避免的用电价 − 充电价/RTE） | 分时电价结构、RTE、循环次数 | A |
| 光伏自用提升 | 光伏弃光/低价上网电量转为自用 | 光伏容量、负荷匹配、出口限制 | A |
| 出口/扩容延迟 | 避免的变压器增容或出口工程费 | DNSP 规则、负荷增长 | B |
| 聚合 FCAS/WDRM | 聚合商分成 | 聚合规模、通信/计量、可调用性 | B |
| 州级需求响应/能效激励 | 按州政策 | 资格、基线、计量 | B |
| 备用/可靠性服务 | 按合同 | 客户工艺要求、切换时间 | C |

- **不能重复计算**：同一块电池参与需量削减时，可能无法同时满功率放电做价差；收入堆叠要按 15 分钟/30 分钟时段做占用分析。
- **需量电费看“最大需量”而非平均负荷**：削峰价值取决于客户每月最大需量出现的时间和持续时间，必须用 15 分钟或 30 分钟负荷数据建模。
- **光伏自用与价差可能重叠**：白天光伏过剩时充电、晚高峰放电，既提升自用又赚价差，但要看出口限制和电价结构。

### 2.3 准入与并网

- **DNSP 接入申请**：向配电网服务商提交接入申请，完成系统研究、保护设置、计量方案和调试；不同州流程不同。
- **逆变器标准**：并网逆变器需符合 AS/NZS 4777.2（并网逆变器）；储能系统安装需符合 AS/NZS 5139（电池储能系统安装）。
- **灵活出口（flexible export）**：南澳、维多利亚等州的 DNSP 已落地动态出口限制，采用 CSIP-AUS（IEEE 2030.5）接口；储能/光伏的出口能力受动态 operating envelope 约束。
- **计量**：需要适合的计量装置和通信，聚合参与市场时通常要求 5 分钟或更细粒度数据。
- **消防与安装**：锂电池储能需满足当地消防、建筑和电气安全要求；室内安装尤其要看通风、间距和灭火方案。
- **注册边界**：小型发电/储能一般不需要直接注册 NEM，但通过聚合商参与批发或 FCAS 时，聚合商需满足注册/资质要求。

### 2.4 聚合：VPP、WDRM 与 FCAS

- **VPP（虚拟电厂）**：聚合商把多个工商储/柔性负荷打包，参与能量、FCAS 或需求响应；客户获得容量费/收益分成。
- **WDRM（批发需求响应机制）**：2021-10-21 起实施，允许需求侧在批发市场提供“负发电”；直接参与的最小削减量为 MW 级（具体门槛以 AER 指南为准），聚合商可代理更小的资源。
- **FCAS 聚合**：通过聚合商参与，需要满足响应速度、通信和计量要求；工商储的功率通常不足以单独注册，但聚合后可以。
- **州级需求响应**：各州有独立的峰值削减/需求响应计划，规则、补偿和基线不同，不能跨州套用。

### 2.5 合同模式

| 模式 | 客户付什么 | 收益归属 | 适合场景 |
|---|---|---|---|
| 客户自投 | CAPEX | 客户 | 有资金、追求长期收益 |
| 租赁 | 固定租金 | 客户/出租方分成 | 客户不想占资本 |
| EMC（能源管理合同） | 按节省电费分成 | 服务商为主 | 客户零投入 |
| 聚合分成 | 无前期费用 | 聚合商与客户分成 | 参与 FCAS/WDRM |
| 混合 | 低租金 + 分成 | 按合同 | 大多数工商储项目 |

- **客户信用是核心风险**：EMC/租赁的现金流依赖客户持续经营和用电；签约前要查信用、租约期限、搬迁/停产条款。
- **负荷变化风险**：客户扩产、减产、换工艺、上光伏都会改变储能收益；合同里要有基线调整和终止补偿条款。

### 2.6 合成算例 B：澳洲 200 kW / 400 kWh 工厂（D 级）

**假设（合成）**

| 参数 | 取值 |
|---|---|
| 功率/容量 | 200 kW / 400 kWh |
| 可用容量 | 380 kWh |
| RTE | 88% |
| 循环 | 300 次/年 |
| 需量削减 | 120 kW |
| 需量费率 | A$140/kW/年 |
| 平均避免用电价 | A$0.30/kWh |
| 平均充电价 | A$0.10/kWh |
| CAPEX | A$180,000（A$450/kWh） |
| OPEX | A$4,000/年 |

**计算**

```
年放电量 = 380 kWh × 300 = 114,000 kWh
度电成本（充电）= 0.10 ÷ 0.88 = A$0.1136/kWh
价差收益 = 114,000 × (0.30 − 0.1136) = A$21,250
需量收益 = 120 kW × 140 = A$16,800
年收益 = 21,250 + 16,800 = A$38,050
净收益 = 38,050 − 4,000 = A$34,050
静态回收期 = 180,000 ÷ 34,050 ≈ 5.3 年
```

**读法**：需量收益占 44%，价差占 56%。如果客户最大需量只有 60 kW，需量收益减半，回收期拉长到约 7 年；如果分时价差收窄到 A$0.12/kWh，价差收益降到约 A$13.7k，回收期超过 8 年。**先拿 12 个月 15 分钟负荷数据，再谈装机容量**。

### 2.7 澳洲工商储五个坑

1. **用平均负荷估需量**：需量电费看最大需量，必须用 15 分钟数据找峰值。
2. **忽略出口限制**：DNSP 的静态/动态出口限制会限制放电和光伏自用。
3. **把聚合收入算成确定收入**：FCAS/WDRM 价格和调用次数波动大，聚合商还要分成。
4. **客户信用与租约错配**：EMC 期限超过客户租约，客户搬迁时现金流断裂。
5. **忽略安装与消防成本**：室内改造、消防、通风、计量通信可能占 CAPEX 的 15%–25%。

## 3. 德国大储

### 3.1 市场结构：DE-LU + EPEX + 平衡市场

- **DE-LU 报价区**：德国与卢森堡同一报价区，日前/日内价格与邻国耦合。
- **日前市场**：EPEX 日前拍卖，12:00 CET 关闸，pay-as-clear；15 分钟 MTU 已用于日内，日前仍以小时/15 分钟产品规则为准。
- **日内市场**：连续交易，pay-as-bid；2025-10-01 起 15 分钟 MTU，电池可以更精细地调整充放电。
- **价格下限**：SDAC 日前 −€500/MWh，SIDC 日内 −€9,999/MWh；两个下限不同，负电价时要注意产品归属。
- **平衡市场**：FCR（秒级、对称、仅容量付费）、aFRR（自动、容量+能量）、mFRR（手动、容量+能量）；由 TSO 通过 regelleistung.net 招标。
- **再调度 2.0**：2021-10-01 起覆盖 ≥100 kW 的可控资源，储能按充/放方向参与，补偿与调度以电网运营商规则为准。

### 3.2 收益堆叠

| 收入项 | 谁支付 | 计价方式 | 关键约束 | 级别 |
|---|---|---|---|---|
| 日前/日内套利 | EPEX 市场 | 价差 × 电量 | 15 分钟 MTU、RTE、负电价 | A |
| FCR 容量 | TSO | €/MW/4h 产品 | 预资格、1 MW 最小投标、对称 | B |
| aFRR 容量+能量 | TSO | 容量价 + 能量价 | 预资格、自动响应、SOC 管理 | B |
| mFRR 容量+能量 | TSO | 容量价 + 能量价 | 预资格、手动调用 | B |
| 再调度/网络服务 | 电网运营商 | 按规则补偿 | ≥100 kW、可控资源认定 | B |
| 容量市场 | 政府/拍卖 | 2031 年起 | 2026 年招标据报道不含电池储能；2027 年新增容量招标可参与（≥10 小时） | B |
| PPA/tolling | 交易对手 | 合同价 | 信用、期限、负电价条款 | A |

- **套利空间在收窄**：光伏中午大发、负电价时段增多，电池白天充电、晚高峰放电的模式被大量项目复制；建模要用未来渗透率情景。
- **FCR 是容量市场，不是能量市场**：FCR 只付容量费，电量调用不另付；FCR 要求对称、秒级响应，SOC 管理要求高。
- **aFRR/mFRR 容量与能量分开**：容量中标不等于能量一定被调用；能量收入按实际调用结算。
- **电网费豁免是德国大储的“隐形收入”**：§118(6) 对符合条件、在 2029-08-04 前投运的储能让电网费豁免 20 年；这项政策对项目现金流的影响可能大于平衡市场收入。
- **2031 容量市场不能提前计入**：StromVKG 已于 2026-09-02 获欧盟批准，但拍卖规则、产品设计和储能资格仍在落地；据报道 2026 年两轮 4.5 GW 招标不向电池储能开放，储能主要对应 2027 年约 2 GW 新增容量招标（≥10 小时）。

### 3.3 准入与注册

- **MaStR 登记**：所有发电/储能设施需在德国市场主数据登记系统登记，否则无法合法运行和结算。
- **并网标准**：低压 VDE-AR-N 4105、中压 VDE-AR-N 4110、高压 VDE-AR-N 4120、超高压 VDE-AR-N 4130；大储通常接入中压/高压，需要电网运营商的技术连接条件和认证。
- **机组认证（Anlagenzertifikat）**：按并网电压等级和容量要求，提交机组证书/组件证书、仿真模型和保护方案。
- **平衡市场预资格**：FCR/aFRR/mFRR 需通过 TSO 的预资格测试，证明功率、响应时间、通信和计量能力；储能可以单独或通过池（Pool）参与。
- **REMIT 报告**：参与批发市场的参与者需履行 REMIT 交易报告义务；具体登记和报告字段以 ACER/BNetzA 要求为准。
- **计量**：平衡市场和结算需要符合要求的计量装置与通信；大储通常要求 15 分钟或更细的计量数据。

### 3.4 电网费与政策

- **§118(6) EnWG**：符合条件、在 2029-08-04 前投运的储能，电网费豁免 20 年（自投运起）。注意这是“投运截止日”，不是“签约截止日”；项目延期会直接影响资格。
- **AgNes 改革**：BNetzA 于 2026-05-27 更新改革进程，2026-10 发布决定草案，计划 2027-01-01 最终决定、2029 年起适用。大型储能拟改为容量型电网费（约 €4–7/kW/年，不再按电量收费），现有储能按 §118(6) 豁免到期后再适用；低压户用储能暂不设单独电网费。最终规则以 BNetzA 决定为准。
- **§14a 不适用大储**：§14a 针对低压可控负荷（热泵、充电桩、储能等），大储接入中压/高压，适用的是§118(6)、AgNes 和并网协议，不要把 §14a 的 60% 折扣套到大储。
- **负电价与 EEG**：EEG §51 规定负电价时段上网电价为零；与光伏共表计的储能要注意计量归属，避免把市场充电的电量误算成 EEG 电量。
- **电力税/增值税**：储能充电电量的电力税、增值税处理取决于用途和合同结构；不要套用“储能免税”的说法，需税务顾问逐项确认。

### 3.5 合同与融资

| 模式 | 收入确定性 | 典型期限 | 适合对象 | 注意点 |
|---|---|---|---|---|
| Merchant | 低 | 无 | 有交易能力的开发商 | 价差收窄、负电价 |
| Tolling | 中 | 5–15 年 | 有承购方 | 可用率、运营边界 |
| PPA | 中高 | 10–15 年 | 有长期承购 | 负电价条款、信用 |
| 容量市场（2031+） | 待定 | 待定 | 待规则 | 不能提前计入 |
| 组合 | 分层 | 混合 | 可融资项目 | DSCR、现金流分层 |

- **德国大储的融资更依赖合同**：纯 merchant 项目在价差收窄和负电价增多的背景下，银行通常要求更高的权益比例或长期合同。
- **电网费豁免是融资亮点**：20 年豁免可以显著降低 OPEX，但要在财务模型中明确起算点、资格条件和政策变化风险。
- **负电价条款**：PPA/tolling 合同要明确负电价时谁承担成本、是否限制充放电、结算价格如何调整。

### 3.6 运维与退化

- **RTE 与辅助负荷**：德国大储多为集装箱式液冷系统，辅助负荷（冷却、消防、控制）在高温/高负荷时明显。
- **退化与质保**：按循环/年限的容量保持率质保；注意质保是否覆盖调频频繁切换导致的额外退化。
- **可用率考核**：FCR/aFRR/mFRR 对可用率要求高，计划检修要提前申报，否则可能失去容量费。
- **增容**：在并网容量、土地和消防许可中预留增容空间；德国审批周期较长，后期增容可能比澳洲更慢。
- **消防**：锂电池储能的消防方案需符合当地建筑和消防法规，保险条款可能要求特定的探测/灭火系统。

### 3.7 合成算例 C：DE-LU 100 MW / 200 MWh（D 级）

**假设（合成）**

| 参数 | 取值 |
|---|---|
| 功率/容量 | 100 MW / 200 MWh |
| 可用容量 | 190 MWh |
| RTE | 86% |
| 循环 | 1 次/日 × 330 日/年 |
| 充电价 / 放电价 | €25 / €100 每 MWh |
| 平衡市场收入 | €2.5m/年（FCR+aFRR+mFRR 合计） |
| 其他收入 | €0.7m/年（再调度/合约） |
| CAPEX | €60m（€300/kWh） |
| OPEX | €1.23m/年（含运维、保险、资产/计量；电网费按豁免计） |

**计算**

```
年放电量 = 190 MWh × 330 = 62,700 MWh
年充电量 = 62,700 ÷ 0.86 = 72,907 MWh
套利毛利 = 62,700 × 100 − 72,907 × 25
         = 6.270m − 1.823m = €4.447m
平衡市场 = €2.50m
其他收入 = €0.70m
总收入 = 4.447 + 2.50 + 0.70 = €7.65m
EBITDA = 7.65 − 1.23 = €6.42m
静态回收期 = 60 ÷ 6.42 ≈ 9.3 年
20 年税前项目 IRR ≈ 8%–9%（未计退化、增容、容量市场与融资）
```

**读法**：平衡市场收入占 33%，套利占 58%。如果 §118(6) 豁免不适用，按电网费 €2–3/MWh 估算，年成本增加约 €0.15–0.22m，IRR 下降约 1 个百分点；如果平衡市场收入减半，IRR 降到约 6%。**德国大储的投决要同时做“价差、平衡市场、电网费”三因素敏感性**。

### 3.8 德国大储五个坑

1. **把 §118(6) 当永久免税**：2029-08-04 前投运才有资格，豁免期 20 年。
2. **把 §14a 套到大储**：§14a 是低压可控负荷规则，大储走中压/高压并网。
3. **把 2031 容量市场当确定收入**：规则、拍卖和储能资格都还没落地。
4. **忽略负电价与计量归属**：负电价时段充电、光伏共表、EEG 电量划分都可能影响收益和合规。
5. **低估并网认证周期**：VDE-AR-N 认证、机组证书、电网运营商研究可能比设备交付更慢。

## 4. 德国工商储

### 4.1 谁买单：用户电费账单

德国工商业电费通常包括：

- **需量电费（Leistungspreis）**：按最大需量（kW）计费，是削峰的第一收入来源。
- **电量电费（Arbeitspreis）**：分时/动态电价，储能做价差和自发自用。
- **电网费（Netzentgelt）**：由多项组成，§14a 可控负荷可获折扣；大储走§118(6)。
- **税费/附加费**：电力税、增值税、各类附加费；逐项核对，不能只看“电价”。

工商储的价值同样是**帮客户少交电费**：削峰、动态电价套利、提高光伏自用、§14a 电网费折扣、避免扩容。单体容量通常在 30 kW–1 MW 级，参与平衡市场必须通过聚合商组成 ≥1 MW 的池。

### 4.2 收益堆叠

| 收入项 | 计算口径 | 关键约束 | 级别 |
|---|---|---|---|
| 需量电费削减 | 削减 kW × Leistungspreis | 负荷曲线、需量窗口 | A |
| 动态电价套利 | 放电量 ×（避免电价 − 充电价/RTE） | §41a 动态电价、RTE | A |
| 光伏自用提升 | 光伏弃电转为自用 | 光伏容量、负荷匹配 | A |
| §14a 电网费折扣 | 模块一固定折扣/模块二 60% 减免 | 低压、可控负荷、控制盒 | B |
| 聚合平衡市场 | 聚合商分成 | ≥1 MW 池、预资格、通信 | B |
| 扩容延迟/备用 | 避免的变压器扩容费 | 负荷增长、可靠性要求 | B |

- **§14a 是“折扣换可控性”**：客户获得电网费折扣，代价是电网运营商在需要时可以通过控制盒/HEMS 限制取电功率；不是无条件补贴。
- **模块选择影响收益**：模块一固定折扣、模块二按比例减免、模块三时段可变电价；哪种划算取决于客户负荷和当地电网费结构。
- **动态电价需要智能计量**：§41a 动态电价要求智能电表/通信；没有 iMSys 的客户无法充分套利。
- **需量电费与价差可能冲突**：削峰要求高功率短时放电，价差要求按价格信号充放电；需要 EMS 做多目标优化。

### 4.3 准入与并网

- **MaStR 登记**：储能系统需登记；工商储也不例外。
- **并网标准**：低压 VDE-AR-N 4105，中压 VDE-AR-N 4110；按容量和电压等级选择。
- **§14a 合规**：低压可控负荷需具备远程控制能力，通过控制盒（Steuerbox）和 HEMS 接收电网运营商指令；通信协议和接口需符合 BNetzA/行业规范。
- **计量**：需要智能计量系统（iMSys）支持动态电价和 §14a 控制；计量方案由计量点运营商（MSB）实施。
- **消防/安装**：锂电池储能需满足建筑、消防和电气安装要求；室内安装要评估通风、间距和灭火。
- **聚合参与平衡市场**：聚合商需完成预资格，客户侧需满足通信、计量和可调用性要求。

### 4.4 合同模式

| 模式 | 客户付什么 | 收益归属 | 适合场景 |
|---|---|---|---|
| 客户自投 | CAPEX | 客户 | 有资金、长期自用 |
| 租赁 | 固定租金 | 客户/出租方分成 | 客户不想占资本 |
| EMC | 按节省电费分成 | 服务商为主 | 客户零投入 |
| 聚合分成 | 无前期费用 | 聚合商与客户分成 | 平衡市场/动态电价 |
| 混合 | 低租金 + 分成 | 按合同 | 大多数工商储项目 |

- **客户信用与租约**：德国工商业租约通常 5–10 年，EMC 期限不要超过租约；客户搬迁/停产要有终止补偿。
- **电价结构变化**：客户换供应商、换电价套餐、上光伏都会改变储能收益；合同要有基线调整机制。
- **数据与通信**：EMS 需要接入客户负荷、电价、光伏和电网控制信号；数据权属和网络安全要在合同中明确。

### 4.5 合成算例 D：德国 200 kW / 400 kWh 工厂（D 级）

**假设（合成）**

| 参数 | 取值 |
|---|---|
| 功率/容量 | 200 kW / 400 kWh |
| 可用容量 | 380 kWh |
| RTE | 88% |
| 循环 | 280 次/年 |
| 需量削减 | 100 kW |
| 需量费率 | €90/kW/年 |
| 动态电价价差收益 | €9,600/年 |
| §14a 折扣 | €4,000/年 |
| CAPEX | €160,000（€400/kWh） |
| OPEX | €5,000/年 |

**计算**

```
年放电量 = 380 kWh × 280 = 106,400 kWh
需量收益 = 100 kW × 90 = €9,000
价差收益 = €9,600
§14a 折扣 = €4,000
年收益 = 9,000 + 9,600 + 4,000 = €22,600
净收益 = 22,600 − 5,000 = €17,600
静态回收期 = 160,000 ÷ 17,600 ≈ 9.1 年
```

**读法**：需量收益占 40%，价差占 42%，§14a 占 18%。如果客户最大需量只有 50 kW，需量收益减半，回收期拉长到约 11 年；如果 §14a 模块二不适用，回收期约 11 年。**德国工商储的可投性高度依赖需量电费和 §14a，单纯靠价差很难算过账**。

### 4.6 德国工商储五个坑

1. **把 §14a 当补贴**：是电网费折扣换可控性，客户要接受限功率。
2. **忽略控制盒/HEMS 成本**：§14a 合规需要通信硬件和调试，不是软件开关。
3. **用中国峰谷价差套德国**：德国动态电价和需量结构与国内不同，必须用客户实际账单建模。
4. **单体项目直接参与平衡市场**：小于 1 MW 必须聚合，且要满足预资格和通信要求。
5. **忽略客户租约与信用**：EMC 期限超过租约是常见踩坑点。

## 5. 四象限对照与投决模板

### 5.1 四象限对照

| 维度 | 澳洲大储 | 澳洲工商储 | 德国大储 | 德国工商储 |
|---|---|---|---|---|
| 市场/政策 | energy-only + FCAS + CIS | 零售电价 + DNSP 规则 | EPEX + 平衡市场 + §118(6) | 零售电价 + §14a |
| 主要收入 | 套利/FCAS/CIS | 需量/价差/自用 | 套利/FCR/aFRR/mFRR | 需量/价差/§14a |
| 并网门槛 | NSP 连接 + AEMO 注册 | DNSP 接入 | VDE-AR-N + MaStR | VDE-AR-N + MaStR |
| 辅助服务 | 10 个 FCAS 品种 | 聚合参与 | FCR/aFRR/mFRR | 聚合参与 |
| 容量机制 | CIS（竞标收入保障） | 无 | 2031 年起容量市场 | 无 |
| 电网费 | TUOS/DUOS（按规则） | 网络费（按州） | §118(6) 豁免 20 年 | §14a 折扣 |
| 合同期限 | 10–20 年 | 5–10 年 | 5–15 年 | 5–10 年 |
| 最大风险 | 价差收窄/并网延期 | 客户信用/负荷变化 | 政策变化/负电价 | 客户信用/电价结构 |

> 回收期为本文合成算例的量级，不是市场统计；实际项目因节点、合同、成本和融资差异很大。

### 5.2 投决输入契约（对齐储能投资技能）

| 类别 | 输入项 | 单位/口径 | 必须写清 |
|---|---|---|---|
| 技术 | 额定功率、额定容量、可用容量 | MW、MWh | AC/DC 侧、DoD、SOC 窗口 |
| 技术 | RTE、辅助负荷 | %、kW | AC 侧往返效率、冷却/消防 |
| 技术 | 退化率、循环寿命、增容计划 | %/年、次 | 质保条件、增容时点 |
| 收入 | 套利价差 | 本币/MWh | 分时/季节、负电价处理 |
| 收入 | 辅助服务 | 本币/MW/年或/MWh | 品种、方向、可调用时长 |
| 收入 | 容量/收入保障 | 本币/年 | CIS/容量市场、可用率考核 |
| 收入 | 合约 | 本币/MWh 或 /MW/年 | PPA/tolling、期限、信用 |
| 成本 | CAPEX | 本币 | 设备、EPC、并网、开发 |
| 成本 | OPEX | 本币/年 | 运维、保险、资产、计量、电网费 |
| 财务 | 融资比例、利率、期限 | %、年 | 债务条款、DSCR |
| 财务 | 税率、折旧、WACC | %、年 | 当地税制 |
| 风险 | 并网延期、可用率、对手方 | 月、%、评级 | 敏感性区间 |
| 输出 | 税前/税后 IRR、NPV、LCOS、回收期 | %、本币 | 口径与假设 |

- **收入与成本必须同币种、同税率、同时间粒度**：澳洲用 A$，德国用 €，不要混算。
- **LCOS 要包含并网和电网费**：只算设备成本会低估海外项目的真实度电成本。
- **退化和增容要进现金流**：容量保持率下降会减少可售电量，增容会增加 CAPEX 但恢复收入。
- **融资结构影响权益 IRR**：merchant 收入占比高的项目，银行通常要求更高权益比例；CIS/PPA 覆盖的部分可以提高杠杆。

### 5.3 收入堆叠的互斥与占用

| 资源 | 套利占用 | FCAS/平衡占用 | 冲突点 |
|---|---|---|---|
| 功率（MW） | 充/放功率 | 预留上调/下调容量 | 同时满功率放电与上调备用不可兼得 |
| 能量（MWh） | 充电/放电电量 | SOC 窗口 | 备用要求高 SOC，压缩套利深度 |
| 时间 | 峰谷时段 | 可调用时段 | 晚高峰套利与晚间 FCAS 冲突 |
| 可用率 | 计划检修 | 容量费考核 | 检修期间失去容量收入 |
| 退化 | 循环次数 | 频繁切换 | 调频调用增加等效循环 |

- **先做“无冲突”收入，再做“有冲突”优化**：把确定性的需量/容量收入先锁定，再用剩余功率/能量做套利和辅助服务。
- **FCAS/平衡市场的机会成本要按小时建模**：不能只用年平均价格。
- **SOC 管理是核心**：备用容量要求高 SOC，套利要求低买高卖，EMS 要在两者之间做滚动优化。

### 5.4 敏感性检查清单

1. **价差收窄 30%**：项目 IRR 是否仍高于资本成本？
2. **辅助服务价格下降 50%**：收入结构是否还成立？
3. **并网延期 12 个月**：CIS/容量合同期限是否错过？融资提款是否受影响？
4. **RTE 下降 5 个百分点/退化加快**：可售电量减少多少？
5. **政策变化**：CIS 中标价、§118(6) 资格、AgNes 最终规则、容量市场延迟。
6. **汇率/税率**：本币贬值、预提税、增值税对权益现金流的影响。

## 6. 十个坑与中澳/中德对照

### 6.1 十个坑（跨市场）

1. **用中国“容量电价 + 容量租赁”思维套澳洲**：NEM 没有容量电价，CIS 是竞标收入保障。
2. **把 FCAS 当稳定高收益**：市场小、被电池压价，必须按渗透率情景建模。
3. **忽略 MLF/IRLF 和结算残差**：并网点损失因子每年调整，结算电量≠报价电量。
4. **只看铭牌容量**：可用容量、RTE、辅助负荷和退化会把可售电量打八折。
5. **低估并网与注册**：NSP 连接、MASS 测试、SCADA、性能标准都是 CAPEX/工期。
6. **把 §118(6) 当永久免税**：2029-08-04 前投运才有资格，豁免 20 年。
7. **把 §14a 当补贴**：是电网费折扣换可控性，需要控制盒/HEMS。
8. **把 2031 容量市场当确定收入**：2026-09-02 才获欧盟批准，规则待定。
9. **忽略负电价与计量归属**：德国 EEG §51、储能与光伏共表都可能影响收益和合规。
10. **合同与融资错配**：merchant 收入配长期债、CIS/tolling/PPA 现金流分层不清，DSCR 过不了。

### 6.2 中国—澳洲对照

| 维度 | 中国 | 澳洲 NEM |
