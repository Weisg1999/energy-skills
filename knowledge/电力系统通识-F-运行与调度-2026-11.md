## 0. 一页看懂

### 0.1 三句话

- **运行与调度是一条时间链，不是一张计划表**：年前/月度做电量与检修，日前做机组组合与现货出清，日内滚动修正，实时平衡偏差，AGC 秒级跟踪，最后按规则结算。
- **日计划解决"明天大概怎么开"，实时平衡解决"现在差多少"**：前者是优化问题（SCUC/SCED），后者是控制+再调度问题；两者用的模型、时间尺度和目标不同。
- **计划一定会变，关键是"变得可控"**：负荷/新能源/机组/线路/市场都会变；备用、爬坡、滚动、再调度、AGC 和考核机制就是为变化准备的。

### 0.2 关键概念

| 概念 | 含义 | 本文口径 |
|---|---|---|
| 日计划 | 日前安排的机组/联络线/检修/备用 | 通常 24 h、15 min/1 h 颗粒 |
| 机组组合（UC） | 决定机组开/停与出力区间 | 混合整数优化 |
| 经济调度（ED） | 给定开机方式下的出力分配 | 连续优化 |
| SCUC | 安全约束机组组合 | UC + 网络/备用/爬坡约束 |
| SCED | 安全约束经济调度 | ED + 网络/备用约束 |
| 现货出清 | 按报价/成本形成价格与计划 | 日前/实时，规则各异 |
| 安全校核 | 检查潮流/电压/稳定/限额 | N-1、断面、稳定 |
| 实时调度 | 日内/实时的再调度 | 滚动、超短期预测 |
| AGC | 自动发电控制 | 秒级跟踪 ACE/频率 |
| ACE | 区域控制误差 | 频率/联络线偏差 |
| 备用 | 可调用的裕度 | 旋转/非旋转/调频 |
| 爬坡 | 功率变化速率 | MW/min（算例按单时段折算） |
| 结算 | 按规则算钱 | 日前/实时/偏差/考核 |

### 0.3 先记住四个数

三机组合成算例（煤电 300 MW、气电 200 MW、储能 100 MW/200 MWh）：

- **日前净负荷 300 MW：煤电 250 MW、气电 50 MW，成本 97,500 元，火电旋转备用 200 MW**。
- **实时净负荷 360 MW：煤电 300 MW、气电 60 MW，成本 117,000 元，火电旋转备用 140 MW，偏差成本 19,500 元**。
- **AGC 指令 20 MW：煤电已到上限，全部由气电承担，气电升到 80 MW**。
- **气电故障时：煤电 300 MW + 储能 60 MW 可保住 360 MW 负荷，但事故后可调用上调能力只剩 40 MW，距 80 MW 要求缺 40 MW**。

> 口径提醒：上述数字是合成算例的确定性结果，不是任何真实系统的调度结果。真实调度要考虑网络、备用、爬坡、市场规则、机组状态和新能源出力。

### 0.4 本文不做什么

- 不提供真实电网的拓扑、负荷、报价、机组参数、检修计划或调度指令；
- 不实现完整的 SCUC/SCED、交流潮流、N-1、稳定校核或市场出清；
- 不替代调度机构的运行计划、安全校核、实时调度、AGC 或结算；
- 不把三机组算例的结论套到多区域、直流、新能源高渗透系统；
- 不给出"某机组/储能一定能/不能中标"的结论。

## 1. 运行与调度的全景

### 1.1 时间轴

| 时间尺度 | 主要工作 | 输入 | 输出 |
|---|---|---|---|
| 年/多年 | 电源/电网规划、检修计划、燃料/来水 | 负荷预测、规划、政策 | 装机、检修、合同 |
| 月度 | 电量平衡、检修、中长期分解 | 负荷/新能源预测、机组状态 | 月度计划、检修单 |
| 日前 | 机组组合、现货出清、备用、联络线 | 负荷/新能源预测、报价、检修 | 日前计划、价格 |
| 日内 | 滚动修正、超短期预测、再调度 | 最新预测、机组/线路状态 | 滚动计划 |
| 实时 | 偏差平衡、安全校核、再调度 | 实时量测、ACE、故障 | 实时指令 |
| 秒级 | AGC、一次调频、稳定控制 | 频率/联络线/机组 | 功率指令 |
| 事后 | 结算、考核、复盘 | 计量、计划、指令 | 电费、考核、分析 |

### 1.2 三道"计划"

- **发电计划**：机组开停、出力、备用、爬坡；
- **检修计划**：设备停运/复役，影响拓扑和限额；
- **交易计划**：中长期/现货/省间/绿电的曲线分解。

三者要协调：检修会改变限额，交易会改变出力，出力会影响安全校核。**"计划"不是一张表，而是一组相互约束的曲线/状态。**

### 1.3 运行与调度的区别

- **运行**偏"状态"：频率、电压、潮流、备用、稳定；
- **调度**偏"决策"：开哪台、发多少、留多少备用、怎么切换；
- **市场**偏"价格/结算"：谁中标、什么价、怎么偏差考核。

三者是一个整体：没有安全校核的市场出清不可执行，没有市场价格信号的调度不可持续。

## 2. 日计划：明天怎么开

### 2.1 输入

- 负荷预测（96 点/288 点，分区域/母线）；
- 新能源出力预测（风电/光伏，概率/场景）；
- 机组状态（检修、故障、最小/最大出力、爬坡、启停成本）；
- 来水/燃料/供热；
- 联络线/省间交易；
- 备用要求；
- 网络拓扑/检修/限额；
- 市场报价/中长期合约。

### 2.2 机组组合

机组组合决定：

- 哪些机组开/停；
- 每台机的开停时间；
- 出力范围；
- 备用分配；
- 启停成本/空载成本；
- 最小开机/停机时间；
- 爬坡/滑坡；
- 供热/强迫出力；
- 新能源/储能/需求响应。

机组组合是**混合整数优化**：开/停是 0/1 变量，出力是连续变量。大规模系统求解难，工程上会用：

- 分支定界/割平面；
- 拉格朗日松弛；
- 启发式/优先顺序；
- 分解/聚合；
- 机器学习辅助筛选（不替代最终校核）。

### 2.3 经济调度

给定开机方式，经济调度按边际成本/报价分配出力：

```text
min Σ C_i(P_i)
s.t. Σ P_i = Load
     P_min,i ≤ P_i ≤ P_max,i
     ramp constraints
     reserve constraints
```

不考虑网络时是" merit order"；考虑网络时是 SCED，要加潮流/限额/断面约束。

### 2.4 安全校核

日计划要过：

- 潮流/电压/支路限额；
- N-1/N-1-1；
- 断面/稳定限额；
- 短路/保护；
- 备用/爬坡；
- 检修/拓扑；
- 新能源/储能/直流。

校核不通过要调整：

- 再调度；
- 启停机组；
- 调整备用；
- 调整检修；
- 调整交易曲线；
- 限发/弃电。

### 2.5 日计划的输出

- 机组开停/出力曲线；
- 备用/爬坡；
- 联络线/省间计划；
- 检修安排；
- 新能源/储能计划；
- 安全校核结果；
- 日前价格；
- 风险提示。

## 3. 现货出清：价格怎么形成

### 3.1 日前 vs 实时

| 维度 | 日前 | 实时 |
|---|---|---|
| 时间 | 提前一天 | 运行前/实时 |
| 输入 | 预测、报价、检修 | 最新预测、实测量测 |
| 目标 | 机组组合+经济调度 | 偏差平衡/再调度 |
| 价格 | 日前价格 | 实时价格 |
| 结算 | 按日前计划/价格 | 按偏差/实时价格 |

具体规则因省/区域/市场而异，不能一概而论。

### 3.2 SCUC/SCED

- **SCUC**：安全约束机组组合，决定开停+出力+备用；
- **SCED**：安全约束经济调度，给定开停，决定出力+价格；
- 日前通常 SCUC，实时通常 SCED/再调度；
- 网络约束用直流潮流/灵敏度/交流潮流；
- 价格用边际机组/拉格朗日乘子/LMP；
- 阻塞时不同节点价格不同；
- 启停/空载/爬坡成本可能通过 uplift 回收。

### 3.3 LMP 与阻塞

节点电价：

```text
LMP = 能量分量 + 阻塞分量 + 网损分量
```

- 无阻塞时，各节点 LMP 接近；
- 阻塞时，受端价格高、送端价格低；
- 网损分量反映边际网损；
- 不同市场对 LMP 分解/披露不同。

潮流/节点价细节见[《从潮流到节点电价》](潮流阻塞与节点电价-2026-11.md)，出清算法见[《现货出清与价格形成》](现货出清与价格形成-2026-11.md)。

### 3.4 报价与成本

- 市场按报价出清，不是按实际成本；
- 机组可能报"三段式"/启停/空载/爬坡；
- 储能报充/放电/容量；
- 新能源报零价/负价/差价合约；
- 报价策略影响中标/价格/风险；
- 市场力/容量稀缺时价格可能飙升。

### 3.5 出清结果的可执行性

出清结果要能执行：

- 机组实际出力/爬坡/备用是否满足；
- 网络/电压/稳定是否安全；
- 新能源/储能 SOC/限功率是否可行；
- 联络线/省间是否协调；
- 检修/故障是否改变拓扑；
- 市场规则是否允许。

**"出清通过"不等于"物理可执行"**，还要安全校核和实时平衡。

## 4. 实时平衡：现在差多少

### 4.1 实时调度的输入

- 超短期负荷/新能源预测（分钟级）；
- 实测量测（SCADA/PMU）；
- 机组实际出力/状态；
- 线路/变压器/断面；
- 备用/爬坡；
- ACE/频率；
- 市场偏差/指令。

### 4.2 再调度

实时净负荷与日前计划不一致时：

- 调整在线机组出力；
- 启停快速机组；
- 调用储能；
- 调整联络线/省间；
- 需求响应；
- 限发/弃电；
- 必要时切负荷/紧急控制。

再调度要考虑：

- 爬坡/最小/最大；
- 备用；
- 网络/安全；
- 市场/合同；
- 成本/价格；
- 环保/供热。

### 4.3 AGC

AGC 负责秒级—分钟级跟踪：

```text
ACE = ΔP_tie + B × Δf
```

- `ΔP_tie`：联络线功率偏差；
- `B`：频率偏差系数；
- `Δf`：频率偏差；
- AGC 把 ACE 分配到调频机组/储能；
- 要考虑机组爬坡/死区/延时/容量；
- 与一次调频/二次调频/三次调频协调。

AGC/AVC 细节见[《AGC/AVC 与频率电压闭环》](AGC-AVC与频率电压闭环-2026-11.md)。

### 4.4 备用与爬坡

备用分类：

- 一次调频（秒级，自动）；
- 二次调频/AGC（秒—分钟）；
- 旋转备用（在线，可快速增加出力）；
- 非旋转备用（可快速启动）；
- 替代备用/三次备用（分钟—小时）。

备用要满足：

- 容量；
- 爬坡；
- 持续时间/能量；
- 位置/网络；
- 与市场/考核规则一致。

### 4.5 偏差与考核

- 日前/实时偏差按规则结算；
- 新能源/储能/售电公司有偏差考核；
- 两个细则/辅助服务考核；
- 偏差过大可能罚款/限制交易；
- 预测/申报/EMS 闭环很重要。

预测误差与 EMS 闭环见[《预测误差申报与 EMS 闭环》](预测误差申报与EMS闭环-2026-11.md)。

## 5. 安全校核：计划能不能执行

### 5.1 静态校核

- 潮流/电压/支路限额；
- N-1/N-1-1；
- 断面/稳定限额；
- 短路/保护；
- 变压器/线路/母线；
- 检修/拓扑。

### 5.2 动态校核

- 暂态稳定；
- 小干扰/宽频振荡；
- 电压稳定；
- 频率稳定；
- 新能源/储能/直流故障穿越；
- 紧急控制/安稳策略。

动态安全见[《动态安全评估与紧急控制》](动态安全评估与紧急控制-2026-11.md)，宽频振荡见[《宽频振荡与场站阻抗分析》](宽频振荡与场站阻抗分析-2026-11.md)。

### 5.3 校核不通过怎么办

- 再调度；
- 启停机组；
- 调整备用；
- 调整检修；
- 调整交易曲线；
- 限发/弃电；
- 加装/调整稳定控制；
- 最后才考虑切负荷/解列。

### 5.4 校核的"模型/数据"问题

- 状态估计断面不准；
- 模型参数过期；
- 故障集不全；
- 新能源/储能模型不准；
- 拓扑/检修未更新；
- 量测/通信延迟。

**在线安全分析的最大瓶颈通常不是算法，而是模型和数据。** 状态估计见[《状态估计与安全分析》](状态估计与安全分析-2026-11.md)。

## 6. 机构与职责

### 6.1 调度机构

- 国调/网调/省调/地调/县调；
- 负责电网运行、安全校核、实时调度、AGC、稳定控制；
- 与市场运营机构协调；
- 发布调度指令/限额/检修/信息。

### 6.2 市场运营机构

- 现货/中长期/辅助服务出清；
- 结算；
- 信息披露；
- 市场监控；
- 与调度协调安全校核。

### 6.3 市场主体

- 发电企业：报价、检修、运行、考核；
- 售电公司：申报、偏差、结算；
- 储能/虚拟电厂：申报、调用、SOC 管理；
- 用户：需求响应、负荷管理；
- 电网企业：输配电、接入、运行。

### 6.4 信息流

```text
负荷/新能源预测
  → 调度/市场
  → 机组组合/现货出清
  → 安全校核
  → 调度指令
  → 机组/储能/负荷
  → 实时量测
  → AGC/再调度
  → 结算/考核
```

信息流要有时标、质量位、版本、权限和审计。数据链路见[《SCADA 与电力监控数据链路》](SCADA与电力监控数据链路-2026-11.md)，接口见[《EMS 数据接口参考架构》](EMS数据接口参考架构-2026-11.md)。

## 7. D 级合成算例：三机组的日计划与实时平衡

> 本算例为合成数据，仅用于演示日计划、实时再调度、AGC 与事故备用的计算链；不对应任何真实系统、机组或市场。

### 7.1 系统

| 机组 | 最小出力 | 最大出力 | 成本（元/MWh） | 爬坡（MW/时段） |
|---|---:|---:|---:|---:|
| 煤电 | 150 | 300 | 300 | 60 |
| 气电 | 50 | 200 | 450 | 100 |
| 储能 | -100（充） | 100（放） | 0 | 100 |

储能：100 MW/200 MWh，初始 SOC 50%，最小 SOC 10%；煤电、气电均假设在线，气电最小出力 50 MW 为硬约束，本算例不做开停机优化；正常态备用只计火电旋转备用，事故后计入储能剩余功率；另设事故后备用要求 80 MW（教学假设，约实时负荷 360 MW 的 22%）。

### 7.2 日前

净负荷 300 MW：

| 机组 | 出力（MW） |
|---|---:|
| 煤电 | 250 |
| 气电 | 50 |
| 储能 | 0 |
| 合计 | 300 |

成本：

```text
250 × 300 + 50 × 450 = 97,500 元
```

火电旋转备用（不含储能）：

```text
(300 − 250) + (200 − 50) = 200 MW
```

### 7.3 实时

净负荷 360 MW（+60 MW）：

| 机组 | 日前（MW） | 实时（MW） | 变化（MW） |
|---|---:|---:|---:|
| 煤电 | 250 | 300 | +50 |
| 气电 | 50 | 60 | +10 |
| 储能 | 0 | 0 | 0 |
| 合计 | 300 | 360 | +60 |

成本：

```text
300 × 300 + 60 × 450 = 117,000 元
```

偏差成本：

```text
117,000 − 97,500 = 19,500 元
```

火电旋转备用（不含储能）：

```text
(300 − 300) + (200 − 60) = 140 MW
```

爬坡校验（单时段）：煤电 +50 ≤ 60，气电 +10 ≤ 100，满足；真实调度按 MW/min 与时段长度折算。

### 7.4 AGC

AGC 指令 20 MW，按煤电 60%/气电 40% 分配：

- 原始分配：煤电 12 MW、气电 8 MW；
- 煤电已到 300 MW 上限，无法增加；
- 12 MW 转给气电；
- 最终：煤电 0 MW、气电 20 MW；
- 气电从 60 MW 升到 80 MW；
- 未满足 0 MW。

这说明：**AGC 分配不能只看权重，还要看机组上限/爬坡/死区。**

### 7.5 事故备用

气电故障，净负荷仍 360 MW：

| 资源 | 出力（MW） |
|---|---:|
| 煤电 | 300 |
| 气电 | 0 |
| 储能 | 60 |
| 合计 | 360 |

储能 60 MW 持续 1 h，消耗 60 MWh；初始 100 MWh，剩余 40 MWh，SOC 20%，高于 10% 下限。

事故后可调用上调能力（火电剩余 + 储能剩余功率）：

```text
煤电 (300 − 300) + 储能 (100 − 60) = 40 MW
```

事故后备用要求 80 MW（教学假设，功率口径；未规定持续时间），缺 40 MW。储能剩余 40 MWh，若按 40 MW 调用只能持续 1 h；更长的事故需要更多能量或负荷控制。这说明：**"负荷保住了"不等于"备用够了"**；事故后系统仍可能因备用不足而无法应对下一故障。

### 7.6 这个算例说明什么

- 日计划是"预测+优化"，实时是"偏差+再调度"；
- 煤电先到上限，AGC 只能转给气电；
- 储能可以保供电，但能量/备用会被消耗；
- 备用要按"事故后"状态校核，不是只看正常状态；
- 计划/实时/AGC/备用是一个连续链，不能分开看。

### 7.7 这个算例不说明什么

- 不代表真实机组/储能/网络的参数和约束；
- 不覆盖网络阻塞、电压、稳定、新能源预测误差；
- 不覆盖市场报价、出清、结算、考核；
- 不覆盖多区域/直流/省间；
- 不能用于实际调度、交易或投资决策。

## 8. 新能源与储能把什么变难

### 8.1 新能源

- 出力预测误差大，日前/实时偏差；
- 低惯量/弱支撑，频率/电压稳定问题；
- 出力相关性/极端天气；
- 反送/阻塞/弃电；
- 容量信用低，可靠性贡献有限；
- 并网/振荡/保护问题。

### 8.2 储能

- 能量/功率/SOC 约束；
- 充放电效率/衰减；
- 市场申报/调用冲突；
- 备用/能量/套利不能同时卖；
- 高温/低温降额；
- 并网/保护/消防。

### 8.3 运行上的应对

- 滚动预测/场景；
- 备用/爬坡/灵活性；
- 储能/需求响应/可调负荷；
- 省间/区域互济；
- 动态安全/振荡监测；
- 市场机制（容量/辅助服务/稀缺定价）；
- 调度自动化/EMS/AGC 升级。

## 9. 对交易、投资与运营的含义

### 9.1 交易

- 日前/实时价差、偏差考核、阻塞；
- 报价策略要结合机组/储能约束；
- 新能源/储能预测误差影响偏差成本；
- 检修/故障/天气会改变价格；
- 交易员要关注调度/市场信息。

### 9.2 投资

- 机组/储能/新能源的选址/定容要结合运行；
- 备用/辅助服务/容量机制影响收益；
- 调度/市场规则变化影响项目现金流；
- 并网/安全校核/振荡风险要早评估；
- 运行灵活性/爬坡/最小出力影响经济性。

### 9.3 运营

- 机组/储能/新能源要按调度指令运行；
- 备用/AGC/一次调频要可靠；
- 检修/故障/通信/对时要管理；
- 数据/模型/定值要更新；
- 偏差/考核要复盘；
- 与调度/市场/用户的信息流要畅通。

### 9.4 数据与 AI 的边界

AI 可以做负荷/新能源预测、报价辅助、调度辅助、异常检测，但：

- 调度/安全控制是确定性系统，不能由 AI 实时替代；
- 训练数据要覆盖真实运行/故障/市场；
- 模型要可解释/可审计；
- 预测要带置信度/场景；
- "AI 说可行"不能替代安全校核。

## 10. 常见错误（10 条）

1. **把日计划当"最终计划"**：日前只是起点，日内/实时还会变。
2. **把现货出清当"物理调度"**：出清结果还要安全校核/再调度。
3. **只看成本，不看网络/备用/爬坡**：经济调度可行，安全校核可能不过。
4. **AGC 只按权重分配**：机组上限/爬坡/死区会让权重失效。
5. **备用只看正常状态**：事故后备用可能不够。
6. **储能只看功率，不看能量/SOC**：保供电后可能没电/没备用。
7. **新能源只用日前预测**：日内/实时偏差需要滚动修正。
8. **忽略检修/故障对拓扑的影响**：限额/潮流/稳定会变。
9. **计划/市场/调度信息不一致**：结算/考核/执行对不上。
10. **不做复盘**：偏差/考核/故障原因不分析，下一次还犯。

## 13. 速查

### 13.1 六个公式

```text
机组组合：min Σ C_i(P_i, u_i) + 启停成本
功率平衡：Σ P_i = Load
备用：Σ (P_max,i − P_i) ≥ R
爬坡：−Ramp_i ≤ P_i(t) − P_i(t−1) ≤ Ramp_i
ACE = ΔP_tie + B × Δf
LMP = 能量 + 阻塞 + 网损
```

### 13.2 五个必问

1. 这是日计划、日内滚动还是实时指令，时间尺度/目标是什么？
2. 出清结果过安全校核了吗，网络/备用/爬坡/稳定都考虑了吗？
3. 备用是正常状态还是事故后状态，能量/爬坡/位置够吗？
4. AGC 分配是否受机组上限/爬坡/死区限制，储能 SOC 够吗？
5. 偏差/考核/结算规则是什么，预测/申报/EMS 闭环是否一致？

### 13.3 工具

```bash
# 在 skills/ems-dispatch/tools 下
python operations.py                 # 打印日计划、实时、AGC 与事故备用
python operations.py --json          # JSON 输出
python selftest.py                   # 断言本文数字
```

`operations.py` 只做三机组、单时段、线性成本的确定性演示，不是生产级调度/出清程序。
