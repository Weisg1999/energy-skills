# 储能投资与运营：政策、成本与口径底稿（2026-11）

> 数据截止：2026-11-01｜配套技能：[储能投资与运营专家](../skills/storage-investment-operations/SKILL.md)（v1.5）
> 用途：给技能正文提供可核验的政策节点、公开成本区间与指标口径。本文只做事实与口径整理，不构成投资建议；所有价格、成本与收益数字均为公开信息或示例量级，不能直接作为项目基准。

## 1. 政策框架（截至 2026-11）

### 1.1 容量电价：114 号文

- **文件**：《国家发展改革委 国家能源局关于完善发电侧容量电价机制的通知》（发改价格〔2026〕114号），2026-01-30 印发。**A 级**。
- **适用对象**：服务于电力系统安全运行、未参与配储的电网侧独立新型储能电站；实行**清单制**管理，清单外项目不执行。
- **折算公式**：

```
容量电价 = 当地煤电容量电价标准 × 折算比例
折算比例 = min(满功率连续放电时长 ÷ 全年最长净负荷高峰持续时长, 1)
```

- **要点**：国家定规则，省级定标准、分母时长与执行期限；跨省不可套用；容量电费纳入系统运行费用，由工商业用户按用电量比例分摊（B 级解读）。
- **省级落地（截至 2026-10，B/C 级，待核实）**：

| 省份 | 标准 | 分母/口径 | 状态 | 来源级别 |
|---|---|---|---|---|
| 安徽 | 165 元/kW·年（含税） | 暂定 6 h；2 h≈55、4 h≈110、6 h=165 | 2027-01-01 执行（皖发改价格〔2026〕526号，2026-09-30） | A |
| 甘肃 | 330 元/kW·年 | 6 h 基准，执行 2 年 | 2025-07 起（可靠容量补偿） | B |
| 湖北 | 165 元/kW·年 | 清单制，按月考核 | 2025 年底起 | B |
| 青海 | 185 元/kW·年 | 据行业媒体 | 待核实 | C |

- **读法**：2 h 系统在 6 h 分母下只能拿 1/3，4 h 拿 2/3；"长时化"不是技术偏好，而是容量电价的直接结果。清单、考核与可用率任一不满足，容量电费会被扣减甚至取消。

### 1.2 分时电价重构：1656 号文

- **文件**：《电力中长期市场基本规则》（发改能源规〔2025〕1656号），2025-12-17 印发，2026-03-01 施行，有效期 5 年。**A 级**。
- **核心条款**：对直接参与市场交易的经营主体，**不再人为规定分时电价水平和时段**；对电网代理购电用户，仍由政府价格主管部门统筹优化峰谷时段与浮动比例。
- **落地**：截至 2026-01/02，贵州、河北南网、湖北、陕西、吉林、云南、重庆、辽宁、河南等 9 地明确落地；江苏、山西处于征求意见阶段（C 级媒体汇总，以省级文件为准）。
- **对储能的影响**：固定峰谷价差从"政府给定"变成"市场预测"，用户侧储能的纯套利模型失效或收益收窄；项目可研必须从"固定价差 × 循环次数"改为"现货分时预测 + 多市场叠加"。
- **两个可核验的省级样本（B/C 级）**：

| 省份 | 变化 | 对用户侧储能的影响 |
|---|---|---|
| 浙江 | 浙发改价格〔2026〕112号，2026-07-01 执行；取消上午高峰，加权价差约 0.83→0.50 元/kWh（降幅约 28.5%） | 一天通常只能一充一放，回本周期拉长 |
| 江苏 | 2026-10-13《2027年江苏电力零售市场交易工作指引》取消零售套餐固定价格电量比例、现货联动比例与比例分成；峰谷价差约 0.85→0.65 元/kWh（降幅约 25%） | 纯套利回本由约 4 年拉长到 7–10 年（媒体测算，C 级） |

- **纪律**：不要把"取消固定分时电价"说成"取消分时电价"。取消的是政府核定的固定表和固定比例，市场化分时定价仍在，只是定价主体从政府变为市场。

### 1.3 辅助服务：411 号文

- **文件**：《电力辅助服务市场基本规则》（发改能源规〔2025〕411号），2025-04-03 印发。**A 级**。
- **定义**：为维持电力系统安全稳定运行、保证电能质量，除正常电能生产、输送、使用外，由可调节资源提供的调峰、调频、备用、爬坡等服务。
- **对储能**：储能可作为独立主体或聚合主体参与；收益由容量补偿、里程补偿、考核等构成，具体品种、价格与结算以省级规则和"两个细则"为准。
- **注意**：辅助服务收入不是免费增量，会占用功率、能量与 SOC 裕度，必须扣减套利机会成本。

### 1.4 新能源配储与 136 号文

- **文件**：《关于深化新能源上网电价市场化改革 促进新能源高质量发展的通知》（发改价格〔2025〕136号），2025-02-09 印发。**A 级**。
- **与储能相关**：新能源机制电价通过竞价形成，存量/增量以 2025-06-01 划断；配储不再作为并网前置条件的趋势下，独立储能与共享储能成为主要形态。
- **114 号的排除项**：参与配储的电网侧独立储能不执行容量电价；"配储"与"独立"是两种商业模式，不能同时拿两份钱。

### 1.5 两部制与需量：1583 号、500 号

- **文件**：发改办价格〔2016〕1583号、发改价格〔2018〕500号。**A 级**。
- **计费方式**：按变压器容量、按合同最大需量、按实际最大需量（500 号增加）。
- **合同最大需量规则**：
  - 核定值可按月变更，提前 5 个工作日申请；计费方式按季变更，提前 15 个工作日申请；
  - 实际最大需量未超过核定值 105% 的，按核定值计费；
  - 超过 105% 的部分，基本电费**加一倍**收取；
  - 申请核定值低于变压器容量与高压电动机容量总和 40% 的，按 40% 核定；
  - 两路及以上进线分别计算最大需量，累加计收。
- **公式（合同最大需量）**：

```
over = max(实际最大需量 − 1.05 × 核定值, 0)
基本电费 = 需量电价 × (核定值 + 2 × over)
```

- **对用户侧储能**：削峰的价值只在"实际需量超过 105% 核定值"或"下调核定值"时体现；把需量从 105% 以内继续往下削，在合同最大需量模式下并不直接省钱。

## 2. 成本与价格观察（2026-09/10，B 级）

### 2.1 公开中标区间

| 口径 | 区间（元/Wh） | 均价/备注 | 时点 |
|---|---|---|---|
| 2 h 储能系统 | 0.53–0.86 | 加权均价约 0.60 | 2026-09 |
| 4 h 储能系统 | 0.52–0.58 | 加权均价约 0.53 | 2026-09 |
| 2 h 储能 EPC | 0.68–1.50 | 加权均价约 1.02 | 2026-09 |
| 4 h 储能 EPC | 0.69–0.99 | 周均价 0.79–0.99 | 2026-09/10 |
| 近期单体项目 | 0.678–1.199 | 新疆 0.678、宁夏 0.881、青海 0.899、河南 1.054、山西 1.199 | 2026-11-02/04 |

- **口径提醒**：系统价只含电池、BMS、PCS、EMS 等设备；EPC 含设计、施工、并网、土建等，边界差异大。**系统价与 EPC 价不可直接比较**，元/Wh 要注明按直流侧还是交流侧额定能量。
- **分级**：招中标公告为 B 级公开信息，但不是项目基准价；单个项目受规模、时长、构网型、消防、地形、并网条件影响，偏离均价是常态。

### 2.2 成本构成（示意，D 级）

| 科目 | 典型内容 | 测算提醒 |
|---|---|---|
| 电池与 BMS | 电芯、模组、簇级管理 | 占设备成本大头，价格随锂价波动 |
| PCS 与升压 | 变流器、变压器、开关柜 | 构网型、高低电压穿越会增加成本 |
| EMS/SCADA | 监控、调度、通信 | 要含 AGC/AVC 与双网冗余 |
| 消防与安全 | 探测、灭火、泄爆、隔离 | 标准升级会带来改造支出 |
| 土建与并网 | 基础、舱体、集电线路、升压站 | 山地、滩涂、高寒地区差异大 |
| 建设期费用 | 设计、监理、保险、融资 | 常被漏计，需单列 |

### 2.3 运维与运营成本（示意，D 级）

- O&M：按 CAPEX 的 1.5%–3.0%/年做初筛；
- 辅助电源与站用电：按吞吐电量或额定功率估算，不能按零计；
- 保险：财产险 + 第三者责任，按 CAPEX 的 0.2%–0.5%/年；
- 土地/屋顶租金、通信、管理、人工；
- 增容/更换：按 SOH 阈值与 Warranty 条款单列，不能假设"15 年不换电池"。

## 3. 运行指标口径：GB/T 36549-2018

- **标准**：《电化学储能电站运行指标及评价》（GB/T 36549-2018），适用于额定功率不小于 500 kW 且额定能量不小于 500 kWh 的电站，其他规模可参照。**A 级**。
- **指标框架**：

| 类别 | 指标 | 口径 |
|---|---|---|
| 电量 | 上网电量、下网电量、站用电量、运行小时数、等效利用系数 | 关口表/单元计量 |
| 能效 | 综合效率、储能损耗率、站用电率 | 综合效率 = 上网电量 ÷ 下网电量（AC-AC） |
| 可靠性 | 可用系数、非计划停运系数 | 可运行时间/统计时间；停运次数与时长 |

- **2026 年上半年行业数据（中电联，B 级）**：电化学储能电站平均利用率指数 42%，整体可用系数 0.98；非计划停运 901 次，单次平均 31.55 h，电池问题导致的非计划停运次数占比 44.28%。
- **读法**：可用系数高不等于利用率高；综合效率必须扣辅助设备能耗，只算电池或 PCS 效率会高估 3–5 个百分点。

## 4. 投资测算参数清单

### 4.1 技术参数

| 参数 | 单位 | 说明 |
|---|---|---|
| 额定功率/额定能量 | MW/MWh | 注明 AC/DC 侧 |
| 可用能量比例 | % | DoD、SOC 窗口、BOL/EOL |
| 往返效率 RTE | % | AC-AC；单程取平方根 |
| 年循环次数 | 次/年 | 与价差、调度、考核匹配 |
| 可用率 | % | 与容量电价考核口径一致 |
| 辅助电源 | % 或 MWh/年 | 不能漏 |
| 年衰减率 | %/年 | 线性/雨流；与质保条款对应 |
| 寿命/增容计划 | 年 | 是否更换、何时增容 |

### 4.2 收入参数

| 收入 | 关键参数 | 主要风险 |
|---|---|---|
| 峰谷/现货套利 | 充放电价、循环次数、价差持续时长 | 固定分时退出、价差收窄、负价 |
| 容量电价 | 省级标准、分母时长、清单资格、可用率 | 清单未入、考核扣减、政策退坡 |
| 容量租赁 | 租赁价格、租期、履约率 | 新能源配储需求下降、违约 |
| 辅助服务 | 品种、容量/里程价格、K 值、考核 | 规则变化、里程下降、能量占用 |
| 需量管理 | 核定值、实际需量、需量电价 | 生产波动、充电抬高需量 |
| 需求响应/VPP | 补贴标准、调用次数、结算周期 | 补贴退坡、调用不确定 |

### 4.3 财务参数

| 参数 | 常用初筛取值 | 说明 |
|---|---|---|
| 项目折现率 | 6%–8% | 与资本成本、风险匹配 |
| 资本金 IRR 目标 | 8%–10% | 不代表实际可达到 |
| 所得税 | 25% | 注意三免三减半等适用性 |
| 折旧年限 | 10–15 年 | 与会计/税务口径一致 |
| 残值 | 0–5% | 电池残值争议大，宜保守 |
| DSCR | ≥1.2 | 融资方通常要求 |
| 贷款期限/利率 | 8–12 年 / 3.5%–5% | 以实际授信为准 |

## 5. 来源分级与查证入口

| 级别 | 来源 | 本文用法 |
|---|---|---|
| A | 国家发改委、国家能源局、省级发改委/能源局、国家标准全文 | 文号、公式、执行时间、标准指标 |
| B | 交易中心、中电联、招中标公告、行业协会统计 | 价格区间、运行指标、项目案例 |
| C | 行业媒体、券商研报、企业宣传 | 省级落地进度、影响测算；必须标"待核实" |
| D | 本技能基于公开参数的测算 | 算例、敏感性；不得外推为项目收益 |

- **查证入口**：国家发改委价格司、国家能源局政策法规司、各省发改委价格处、电力交易中心信息披露平台、全国标准信息公共服务平台、中国招标投标公共服务平台。
- **纪律**：同一数字在不同来源冲突时，先看计量点、含税口径、统计期与项目边界；不能只比数字大小。
