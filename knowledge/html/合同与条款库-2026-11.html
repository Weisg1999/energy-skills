0. 一页看懂

0.1 条款矩阵怎么用

  1. 签约前：按合同类型进对应小节（§2–§6），对照"条款要点表"逐条过，红线项不满足即暂停签约；
  2. 谈判中：把红线拆成三档——必须拿到（walk-away）、争取拿到（可让步换条件）、可以让（换取其他条款）；让步只发生在第三档；
  3. 签约后：条款与台账联动——偏差责任、保函、调价机制要能在日课（盘前简报/触发线）与结算对账中被执行，否则条款是纸面的；
  4. 争议时：回到条款原文 + 证据链（见《合成案例复盘库》案例 4、10）。

0.2 五类合同一览

合同类型典型主体价格机制主要风险侧关联模块
国内中长期（双边/集中竞价/差价合约）发电、售电、大用户固定价、价差联动、照付不议偏差与曲线风险在售电/用户侧m-risk-credit
绿电 PPA（含绿电交易、直连）新能源、用户/售电电能量 + 环境属性分签出力形状与证书交付m-cross-ppa
零售套餐售电、终端用户固定价/联动/分时套餐批零倒挂在售电侧m-risk-credit
储能容量租赁储能业主、新能源场站固定租金/保底+分成/tolling调用权与考核转嫁m-storage-invest
VPP 聚合协议聚合商、资源业主激励分成/固定补贴基线认定与豁免m-vpp-core

0.3 七条谈判判断

  1. 合同是事前的风控：多数交易损失在签约时已大半确定（见《合成案例复盘库》案例 4、6、7、10）。
  2. 价格条款的第一问不是"多少钱"，而是"价格怎么变"：联动什么参考价、多久调一次、有没有上下限，比初始价差更能决定长期盈亏。
  3. 电量条款的第二问是"曲线"：总量一致但形状不一致，中长期对冲就是假的；峰谷形状偏差是隐性的价格条款。
  4. 偏差与考核责任要和"谁控制变量"对齐：谁控制出力/用电行为，谁承担对应偏差，控制不了的（调度指令、非停）走免责而不是转嫁。
  5. 违约条款的价值在违约前：保函、抵销、催告、证据签收这些"平时用不上"的条款，决定违约后能不能收回钱。
  6. 不可抗力必须写清"政策变动"：规则换版、限价调整、机制电价切换不是自然不可抗力，要在合同里单独安排（动态引用 + 重新谈判触发）。
  7. 环境属性默认不随电量走：绿证/环境价值的归属、交付方式、重复计算禁令必须明写；"卖电送绿证"的默认理解是重复计算与争议之源。

2. 国内中长期

2.1 条款要点

条款常见做法谈判要点
价格固定价、基准价+浮动（挂钩月度/现货指数）浮动挂钩的参考价来源、结算均价口径、封顶保底
曲线年度总量 + 分月分时分解；部分省要求带曲线结算曲线由谁定、调整窗口（月度/旬度）、曲线偏差责任
照付不议用户侧照付不议、发电侧照发不议不可抗力与政策变动是否除外；偏离曲线的计价
偏差超出约定曲线部分按现货/考核规则处理责任对齐"谁控制变量"；考核费用转嫁要有上限
结算按交易中心结算单；差异按异议流程差异处理条款与市场异议时限衔接，不倒签
违约保函/保证金、逾期利息、抵销权保函金额与信用等级联动；抵销权明确
政策变动动态引用现行规则明确"规则换版→参数自动更新→重大变化触发重谈"

2.2 谈判红线（walk-away）

  1. 偏差考核费用 100% 转嫁且无上限、无免责情形——不走；
  2. 参考价来源或结算口径可以由对方单方解释——不走；
  3. 照付不议对己方单向适用、对方不对应承担——不走；
  4. 无保函或保函明显低于敞口（参考信用与保函机制的最低逻辑），且无其他担保——原则上不走；
  5. 规则参数写死为数值且拒绝动态引用——原则上不走。

2.3 常见坑

  • 只谈价不谈曲线：结算时才发现形状偏差吃掉全部价差；
  • "按交易中心结算为准"没有配差异处理程序，争议无抓手；
  • 政策变动条款缺失，换版年参数写死（案例 6）；
  • 违约条款只有"协商解决"四个字，无担保、无抵销、无催告程序。

3. 绿电 PPA

3.1 条款要点

条款常见做法谈判要点
价格电能量价与环境价值分签或分列；固定价 vs 跟发浮动环境价值单独计价，禁止"打包价拆不清"；形状溢价归属
电量与曲线固定曲线（baseload）vs 跟发（pay-as-produced）跟发风险归谁；不足电量的替代采购权与价格
绿证归属证书随电交付或单独交付；交付时间与核销证书归属、交付时点、跨年处理、重复计算禁令四件齐
结算电能量按市场结算，环境价值按证书交付结算证书未按期交付的违约金与替代采购
不可抗力极端天气减产的处理出力不足是商业风险不是不可抗力；写清减负机制
政策变动补贴/机制电价/证书规则变化的传导动态引用 + 重谈触发

3.2 谈判红线（walk-away）

  1. 环境价值不单独计价、证书归属不明——不走；
  2. 允许对方对同一环境属性重复主张（绿证 + CCER + 自愿声明混用）——不走（重复计算禁令见《绿证、CCER 与 CBAM 衔接与重复计算边界》）；
  3. 出力不足时用户被要求按固定曲线全量照付、且无替代采购安排——原则上不走；
  4. 证书交付时间与核销机制缺失——不走。

3.3 常见坑

  • "卖电送绿证"口头默认：证书市场价值波动后争议；
  • 24/7 匹配需求未写进条款（小时级匹配、存储/时移规则），结算时无法支撑 Scope 2 主张；
  • 跨境使用未确认证书互认（GO/REC/LGC 与中国绿证的边界见 m-cross-ppa）；
  • 电站未来加装机组的证书归属未约定。

4. 零售套餐

4.1 条款要点

条款常见做法谈判要点
价格固定价、联动价（参考现货/挂牌/代理购电）、分时套餐联动参考价、调整频率、上下限；一口价要有再定价机制
保底封顶联动价设封顶保护用户、保底保护售电封顶触发时的处理（降比例/暂停联动）
电量各户电量估计与实际差异的处理超用/少用的计价；大户排产变化的通知义务（案例 3）
偏差转嫁偏差考核费用按约定分摊转嫁比例上限、免责情形、计算依据可核
结算电费构成分项披露（电能量、输配、基金附加、服务费）分项披露是义务也是信任基础；口径可核
违约拖欠电费的违约金、停限电程序程序合规（通知期限、恢复供电路径）；服务费独立于电费
政策变动目录电价/代理购电变化传导动态引用；调价通知期

4.2 谈判红线（walk-away）

  1. 无联动机制的一口价长周期套餐 + 无止损安排（售电侧视角）——原则上不走（案例 7）；
  2. 偏差考核全转嫁无上限、计算依据不可核——不走；
  3. 违约金、停限电程序与监管规则冲突的条款——不走；
  4. 电费构成不披露、不允许对账——不走。

4.3 常见坑

  • 用户侧只看单价比价，忽略联动上限与偏差转嫁的真实成本；
  • 售电侧压力测试只测价跌不测价涨（案例 7）；
  • "电费+服务费"打包后服务费随欠费被一起违约处理，程序瑕疵导致停限电无效；
  • 大户排产变化无通知条款，偏差责任无法追偿。

5. 储能容量租赁

5.1 条款要点

条款常见做法谈判要点
租金固定租金（元/kW·年）、保底+超额分成、tolling（付固定容量费获调用权）结构选择决定风险分担（§9 算例）；调价窗口
容量与电量租赁容量（MW）与可用电量（MWh）、时长分开写可用率定义、考核口径（如按调度考核结果）
调用权出租方自用 vs 承租方调用权（或优先调用时段）调用时段收益归属；调用挤占出租方套利的补偿
考核转嫁并网考核/调度考核费用的分担转嫁有上限；因承租方指令导致的考核归承租方
退化循环次数/可用容量的衰减处理租期内容量下限；衰减补足责任
违约单方解约补偿、容量替代采购权解约补偿与剩余租期挂钩方式
不可抗力调度指令、电网事件的免责免责不等于免租（或写明减免比例）

5.2 谈判红线（walk-away）

  1. 可用率与考核口径不定义、扣减依据不可核——不走；
  2. 调用权与收益归属留白（"具体另行协商"）——不走；
  3. 全部并网考核无上限转嫁——不走；
  4. 退化无容量下限，租期末尾可用容量严重缩水无救济——原则上不走。

5.3 常见坑

  • 只谈租金单价不谈调用收益归属，储能真赚钱的部分（交易收益）与租金脱节；
  • "容量租赁"与"融资租赁/设备租赁"混称，权利义务完全不同；
  • 考核费用转嫁无上限，一次电网考核吃掉全年租金；
  • tolling 结构套用海外模板时，忽略本省现货规则对调用与结算的约束（海外 tolling 见 m-cross-ppa §5）。

6. VPP 聚合协议

6.1 条款要点

条款常见做法谈判要点
能力口径铭牌容量、实测可调、申报能力三层（案例 9）申报值定义 = 实测 × 同时率 × 可用率，折减留痕
激励与分成按认定响应量计费；聚合商与业主分成分成基数（毛/净）、考核扣减先扣谁
基线按本省基线口径核定基线复算权、异常日剔除的事前确认
豁免生产班次冲突、检修期的豁免豁免申请程序、时限、替代资源义务
数据负荷曲线、遥测数据共享数据用途限定、保密、断数处理
代理关系聚合商代理参与市场的授权范围唯一代理还是多家；代理行为的责任归属
违约资源未响应的考核分担聚合商先行承担对外考核、对内按协议追偿

6.2 谈判红线（walk-away）

  1. 申报值定义留白、基线口径不可核——不走；
  2. 资源未响应的对外考核 100% 转嫁给业主且无豁免程序——不走；
  3. 数据授权无用途限定（可任意商用）——原则上不走；
  4. 多家聚合同一资源且无优先顺序约定——原则上不走。

6.3 常见坑

  • "理论可调能力"直接进协议附件当申报值（案例 9）；
  • 豁免条款缺失，用户一次生产高峰吃掉全年分成；
  • 分成基数是"净额"但净额口径由聚合商单方计算；
  • 规则变化（基线算法、认定门槛调整）没有协议调整程序。

7. 绿证与环保属性归属（专节）

  • 默认规则由合同改写：证书/环境属性不必然随电量交付；归属、交付方式、交付时间、跨期处理、核销责任五项必须明写。
  • 分签原则：电能量合同与环境价值合同分开（或同文分列计价），价格可拆、违约可分；绿电交易与绿证交易分开的部分按各自市场规则执行。
  • 重复计算禁令：同一环境属性只能主张一次——绿证、CCER、绿色电力消费声明不得对同一 MWh 叠加；合同要写禁止性条款与违约后果（边界见《绿证、CCER 与 CBAM 衔接与重复计算边界》）。
  • 跨境边界：中国绿证与 GO/REC/LGC 的互认现状决定合同能否支撑境外 Scope 2 主张；不确认互认就签约，是 PPA 谈判最高频的坑（证书对照见 m-cross-ppa §3，24/7 匹配见 §6）。
  • 与政策联动：机制电价、绿电交易规则的年度调整影响环境价值定价；合同用动态引用 + 重谈触发，不写死证书价格。

8. 谈判流程与让步结构

  1. 清单先行：按 §1 矩阵逐维度过一遍，输出"条款差距表"（我方版本 / 对方版本 / 差距 / 属于哪一档）；
  2. 三档分级：必须拿到（walk-away）→ 争取拿到 → 可以让；让步只发生在第三档，且每次让步换取对等条件（价格 ↔ 期限 ↔ 数据权 ↔ 考核上限）；
  3. 红线演练：walk-away 条款在授权矩阵（SOP §1.2）中明确"谁有权放弃红线"——原则上没有人有权在谈判桌上放弃 walk-away；
  4. 落纸纪律：口头共识 48 小时内落入文本；谈判记录归档；
  5. 签约后联动：条款要点（联动参考价、考核上限、保函、豁免程序）进台账与日课，能被执行的条款才是风控。

9. D 级合成算例：储能容量租赁两种结构对比

设定（全部 D 级合成，仅示范风险分担逻辑，不构成定价建议）：储能电站 A（100 MW/200 MWh）向新能源场站 B 出租 100 MW 容量（满足 B 的配储租赁需求），租期〔5〕年。A 的年交易净收益（现货套利+辅助服务，扣运维与退化）三个情景：悲观 1,200 万元 / 期望 2,400 万元 / 乐观 3,600 万元。年并网考核费用期望 60 万元。

结构价格机制悲观年 A 实收期望年 A 实收乐观年 A 实收考核承担风险分担逻辑
A：纯固定租金150 元/kW·年 → 1,500 万元/年1,5001,5001,500A（出租方）B 付固定价，A 担全部交易风险与考核
B：保底+超额分成保底 120 元/kW·年（1,200 万）+ 交易净收益中超过 1,200 万部分的 25% 归 A1,2001,5001,800A 先对外承担，可按协议向调用指令追偿B 保下限换上行分成，A 让渡部分上行换下限保护

要点读法：

  1. 两结构期望值相同（1,500 万），差别全在风险分布：结构 B 把 A 的悲观年从 1,500 拉到 1,200（−300 万），把乐观年抬高到 1,800（+300 万）——B 用"下行让利"换"上行分成"；
  2. 谈判的真正标的不是单价，是参考量与分成基数：本例的"交易净收益"口径（是否扣退化、扣哪些运维）每改一项，分成结果就变；口径必须可核；
  3. 考核归属独立于价格结构单独谈：转嫁比例、调用指令导致的考核归 B，是两条红线；
  4. 若 B 要求优先调用权（挤占 A 套利），应对 A 的机会成本补偿计价，或折算进分成比例；
  5. 结论：结构没有对错，风险承担方要拿到与风险对称的对价，且口径可核、考核有上限。

10. 常见坑十二条

  1. 只谈价格不谈价格怎么变（联动、封顶、调整窗口）；
  2. 只谈总量不谈曲线，形状偏差吃掉价差；
  3. 偏差考核无上限转嫁，且计算依据不可核；
  4. 规则参数写死数值，换版年全线违约或被动（案例 6）；
  5. 环境属性归属留白或"卖电送绿证"默认（§7）；
  6. 同一环境属性被两份合同重复主张；
  7. 保函/保证金缺失或与敞口严重不匹配（案例 10）；
  8. 违约条款只有"协商解决"，无催告、担保、抵销程序；
  9. 不可抗力不区分自然事件与政策变动，调度/非停免责边界不清；
  10. 调用权与收益归属留白"另行协商"；
  11. 数据授权无用途限定，聚合/租赁期满后数据权利不清；
  12. 条款签完进抽屉，不进台账与日课，无法执行（联动 §8.5）。
