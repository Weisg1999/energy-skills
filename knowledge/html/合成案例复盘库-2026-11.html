0. 一页看懂

0.1 怎么用案例训练

  1. 先遮住答案：只读"设定 + 时间线 + 决策点"，独立写下你会怎么做；
  2. 对照决策点：比较你的选择与案例主人公的选择，重点看"当时有哪些信息、缺哪些信息"；
  3. 读错误做法：逐条问自己"我们台里有没有这个动作或习惯"；
  4. 导出检查单：把可复用清单合并进台内日课（见《交易台日课与异常处置 SOP》），或触发线，或合同条款（见《合同与条款库》）；
  5. 复盘复用：真实事件发生后，回到结构最像的案例，逐项对照差异。

案例训练的价值在决策点不在结局：结局由行情决定，决策点暴露的是流程与判断习惯。

0.3 五条判断

  1. 多数事故不是算错，而是流程缺位：十个案例里没有一个是"模型精度不够"单因造成的，都有检查单、触发线或合同条款的缺位。
  2. 决策点的信息永远不完备：训练目标是"在信息不完备时做出可辩护的选择并留痕"，不是"事后看起来全对"。
  3. 损失通常可以切断在第一步：断→判→行→报的顺序（SOP §4.2）在案例 5、8、10 里反复出现——先止损路径，再分析。
  4. 合同条款是事前的风控：案例 4、6、7、10 的损失大小，在签约时就已经大半确定。
  5. 复盘要把差异归到环节：预测 / 报价 / 执行 / 规则 / 合同，归因不到环节的复盘等于没复盘。

1. 案例 1：负电价日——光伏聚合商满发申报

D 级合成设定：某省级现货市场，五一假期低负荷日叠加光伏大发；一家聚合分布式光伏的运营商持有〔200〕MW 等效容量，报量不报价（价格接受者），叠加机制电价差价结算。

时间线

时间事件
D-2气象预报显示假期晴天、气温偏凉，负荷预期偏低；台内无人调阅负价历史分布
D-1 上午预测显示午间光伏出力高峰；按 P50 满发申报，未设负价时段动作
D-1 出清午间 11:00–14:00 出清价深度为负（示意：−80 元/MWh）
D 日光伏按申报满发；负价时段照常发电
T+1 结算午间段电能量收益为大额负值；叠加机制差价后仍为净亏损

决策点

  1. D-1 看到晴天+低负荷组合时，是否查本省负价时段历史并预判？——没有查；
  2. 是否评估"负价时段减出力/停机"的账（少发的机制差价损失 vs 免掉的负电价支出）？——没有算；
  3. 是否把负价时段单独设申报/执行预案并留触发线？——没有设。

错误做法

  • 把"报量不报价"理解成"什么都不用做"，默认价格接受者没有盘中动作空间；
  • 满发申报没有按价格区间分段考虑（负价时段照常满发）；
  • 没有把"负价小时数"作为例行盘前简报风险源（模板 A 第 1 栏）；
  • 事后把亏损归因于"行情极端"，没有归因到"没有预案"这一环节。

正确做法

  • 盘前简报固定看负价风险：节假日 + 大发 + 低负荷三者叠加即列入今日风险源；
  • 事前算清停机账：负价时段每少发 1 MWh，省下的负价支出与损失的机制差价、辅助服务分摊比较，得到本省的"负价动作门槛"（D 级示例：出清价低于〔−X〕元/MWh 时减出力）；
  • 在执行层设触发线：出清价低于门槛 → 降出力至〔Y〕%，动作写入异常处置预案；
  • 若合同允许，优先通过调整申报曲线表达负价时段意愿，而不是事后承受。

可复用清单

  • [ ] 盘前简报含"负价风险"栏（节假日/大发/低负荷三信号）；
  • [ ] 台内存有本省负价时段历史分布与"负价动作门槛"测算；
  • [ ] 负价时段有单独预案与触发线，且演练过；
  • [ ] 机制差价、辅助服务分摊与负价支出进入同一张账比较；
  • [ ] 复盘时负价时段单独归因，不与全天混算。

关联：《量化报价与交易风控》（价格接受者的动作空间）、《气象与电力交易》（大发与负荷的天气驱动）。

2. 案例 2：尖峰缺电日——煤电平价卖空、尖峰无货

D 级合成设定：某省夏季晚峰，温控负荷激增叠加两台机组非停；一台 600 MW 煤电的交易员在日前市场按均价预期卖空全部可用容量，另在日内以低价签出部分电量。

时间线

时间事件
D-1日前价预期温和；交易员按均价预期申报满发并中标，另与相邻主体签日内低价合同〔100〕MWh
D 日白天系统供需趋紧的信号（联络线受限、检修公告）未引起注意
D 日晚峰两台机组非停 + 空调负荷新高，实时价冲顶（示意：1,200 元/MWh）
晚峰时段本机组容量已被日前与日内合同占满，只能按合同价交付，无法在实时市场兑现高价
T+1复盘发现：全天加权售电均价显著低于当日晚峰出清价，机会成本大额为正

决策点

  1. D-1 是否为晚峰保留一定比例的"自留容量"（不提前卖死）？——没有留；
  2. 白天看到趋紧信号时，是否回购日内合同或调整执行？——没有动作；
  3. 检修与非停公告是否进入盘前简报的对手侧信息？——没有进入。

错误做法

  • 把"卖空全部容量"当成稳健策略，没有区分"基荷部分可锁"与"峰段部分应留弹性"；
  • 日内低价合同没有设价格联动或回购条款；
  • 对手侧信息（全网检修、非停、联络线受限）不在信息面清单里；
  • 复盘只看"赚了多少"，没有算"当日晚峰的机会成本"。

正确做法

  • 申报结构按时段分层：基荷段锁价、峰段留出可调整比例（D 级示例：晚峰留〔20〕% 容量不提前锁死）；
  • 日内合同加回购/联动条款，或在合同库中标注该条款为红线（见《合同与条款库》§2）；
  • 信息面七类（SOP §2.1）加入"对手侧检修与非停"，简报会通报；
  • 复盘表增加"机会成本"科目：当月各尖峰时段的机会成本与锁价收益并列展示。

可复用清单

  • [ ] 申报按峰谷分层，峰段保留可调比例；
  • [ ] 日内/短期合同有联动或回购条款；
  • [ ] 对手侧检修、非停、联络线受限进入盘前简报；
  • [ ] 复盘含尖峰时段机会成本科目；
  • [ ] 极端趋紧情景有压力测试与对应的执行预案。

关联：《量化报价与交易风控》（合约覆盖与情景）、《省间与跨区交易》（联络线受限的跨区传导）。

3. 案例 3：偏差考核——售电公司月度偏差超阈

D 级合成设定：某省对零售用户组合实行偏差考核（阈值、算法按该省现行规则）；一家售电公司代理〔40〕家工商业用户，月度申报电量与实际用电偏差超出考核区间。

时间线

时间事件
月初用上月各户实际用电的算术平均做本月预测，未做分时形状
月中两家大户调整排产（示意：合计减〔15〕%），公司未及时调整申报
月下旬发现累计偏差逼近阈值，临时在二级市场高价补量
月末结算补量成本 + 偏差考核费用显著侵蚀毛利；分时形状错配另产生偏差结构问题

决策点

  1. 预测方法是否区分"总量"与"分时形状"、是否纳入大户排产计划？——都没有；
  2. 月中得知大户减产时，是否立即调整申报并评估补量路径？——拖延到下旬；
  3. 是否事先与大户约定"排产变化提前〔N〕日通知"的合同条款？——没有约定。

错误做法

  • 用"上月均值"当预测，忽略负荷形状与用户结构变化；
  • 大户排产信息没有纳入信息面（它比价格预测更可控）；
  • 补量拖到下旬，被动接受高价；没有月中滚动偏差监控；
  • 偏差考核参数（阈值、算法、方向）没有在台内口径表里登记。

正确做法

  • 预测分两层：总量 + 96 点形状；大户用户单独建模并纳入其排产计划；
  • 与大户合同约定排产变化提前通知义务与偏差责任分担（合同库 §4 红线）；
  • 月内滚动监控"累计偏差/阈值"使用率，超过〔50〕% 即启动预案（补量/调申报/通知用户错峰）；
  • 复盘时把偏差拆成"预测偏差"与"行为偏差"（用户实际用电偏离告知计划）分别归因。

可复用清单

  • [ ] 每户有总量+形状两层预测，大户含排产信息；
  • [ ] 大户合同含排产变化通知条款；
  • [ ] 月内偏差使用率有滚动监控与预案触发点；
  • [ ] 偏差考核参数（本省口径）在台内口径表登记并随规则更新；
  • [ ] 复盘区分预测偏差与行为偏差。

关联：《电力市场风险、信用与结算》（偏差考核口径）、《售电零售与风险》技能（客户组合管理）。

4. 案例 4：结算争议——只对总额、错过异议时限

D 级合成设定：某售电公司月度结算单与自算结果差约 0.5%（示意：〔18〕万元）；公司按总额对账，未做科目拆解，口头向交易机构反映，未走正式异议流程。

时间线

时间事件
D+1结算数据可得；财务按总额核对"大概一致"，未出科目级差异桥
D+5结算单正式下发，财务发现总额差 0.5%，微信口头询问客户经理
D+15口头答复"系统口径问题"；公司未立案、未提交书面异议
异议期届满按《电力市场风险、信用与结算》的异议时限流程，逾期差异被视为确认
季度复盘重出科目级差异桥：差异集中在偏差费用一个科目（申报量口径错位），早可立案

决策点

  1. D+1 是否出科目级差异桥？——没有，只对总额；
  2. 发现差异后是否走书面异议并附证据链？——只口头沟通；
  3. 申报回执、出清结果、结算单是否按同一 ID 归档可对齐？——回执散落在邮箱。

错误做法

  • 只对总额不对科目，差异被"平均"掩盖；
  • 口头沟通不留痕，没有时间戳与书面记录；
  • 不知道/不跟踪异议时限，把"在问了"当成"已主张权利"；
  • 三单（申报回执、出清结果、结算单）没有对齐机制。

正确做法

  • 结算初核固定出科目级差异桥（七科目分桶，方法见《现货报价量化专家》§13.3），任一科目超阈值当日立案；
  • 异议一律书面提交并留存受理凭证；台账记录"提交日、受理日、答复期限"；
  • 三张模板（简报/复核单/事件单）与回执按批次号当日归档对齐（SOP §3.3、§8），这是争议证据链的底座；
  • 与交易机构的沟通双轨：技术支持渠道问原因，异议流程保权利。

可复用清单

  • [ ] 结算初核出科目级差异桥，阈值触发立案；
  • [ ] 异议时限在台内日历登记，逾期即失去追调权利；
  • [ ] 三单按批次 ID 归档对齐；
  • [ ] 对外沟通全部书面留痕；
  • [ ] 争议包结构固定：差异科目 + 证据编号 + 时间线 + 诉求。

关联：《电力市场风险、信用与结算》（5/8/10 时限与异议流程）、《现货报价量化专家》§13.3（差异桥与争议包）。

5. 案例 5：极端天气——台风路径突变、免考材料缺失

D 级合成设定：沿海某省风电场（〔300〕MW），台风季一次路径突变导致出力骤降与送出线路跳闸；交易台既没有天气情景预案，也没有按规则提交免考/减考材料。

时间线

时间事件
D-2台风生成，路径预测分歧大；台内按"影响不大"处理，未做情景集
D-1预测仍按正常风资源申报
D 日路径西折，出力骤降（示意：预测 P50 与实际的 MAE 达〔38〕%），送出线路跳闸停机〔6〕小时
D 日盘中执行层无预案，未及时调整；通信短时中断，无降级申报通道
T+1偏差与考核费用落地；免考/减考材料因未在规定渠道与时限内提交，未被采纳

决策点

  1. D-2 是否启动极端天气情景集并调整申报？——按"影响不大"忽略；
  2. 线路跳闸后是否按涉网事件流程处置并同步留存证据？——只做了抢修，未同步交易侧；
  3. 免考申请所需的调度指令、事件记录、出力曲线证据是否事前知道清单？——不知道。

错误做法

  • 天气预警没有分级响应（多大预警触发什么动作，无对照表）；
  • 情景集只做了一个"中位"情景，没有下行情景；
  • 安全处置与交易处置脱节：抢修信息没有同步给申报/考核岗位；
  • 免考材料的证据清单与提交时限事前不清楚。

正确做法

  • 天气预警分级表：预警等级 → 预测修正幅度 → 申报调整 → 备用通道启用，四列写死并演练（气象驱动见《气象与电力交易》）；
  • 情景集至少含一个下行情景（P10），申报与之对齐；
  • 涉网事件双线同步：调度/运维线处置，交易线同步记录事件时间线并按规则提交免考材料；
  • 事前整理免考证据清单（调度指令、故障录波、出力曲线、通信记录）与提交渠道、时限。

可复用清单

  • [ ] 天气预警分级响应表已建立并演练；
  • [ ] 极端天气情景集含下行情景；
  • [ ] 涉网事件交易线同步留痕；
  • [ ] 免考证据清单与提交时限在台内口径表；
  • [ ] 通信中断有降级申报通道。

关联：《气象与电力交易》（极端天气保供与误差考核）、《并网运行考核与两个细则》（免考情形）。

6. 案例 6：政策切换——换版年沿用旧模板

D 级合成设定：某省中长期规则换版并叠加机制电价竞价切换；一家发电企业的交易台未跟踪换版节奏，沿用旧申报模板与旧参数。

时间线

时间事件
T-3 月新规则发布征求意见稿；台内"等正式稿再说"，未启动对照
T-1 月正式稿印发，设施行日；台内无人登记施行日与字段变化
施行日申报模板字段变化（新增分时字段）、限价参数更新；台内沿用旧模板申报
施行周两次申报因格式与参数不符被退回；一次竞价窗口因按旧时限错过
复盘换版日历、参数表、模板对照三件事都没有人负责

决策点

  1. 征求意见稿阶段是否先做"差异预对照"（哪些字段/参数可能变）？——没有；
  2. 正式稿到施行日之间是否排换版日历与演练？——没有；
  3. 谁是换版负责人？——没有指定。

错误做法

  • 把"等正式稿"理解成"什么都不做"，正式稿印发到施行的窗口被浪费；
  • 规则文本没有版本管理，参数表（限价、时限、字段）没有随版本更新；
  • 竞价窗口、退改窗口等时间锚点没有集中日历；
  • 合同与内部制度没有"政策变动"应对条款（如参数更新的生效顺序）。

正确做法

  • 规则版本是一等公民：文号、发布日、施行日、适用范围四要素登记；草案与正式稿分开存放（草案不得当现行）；
  • 每次换版做三件套：参数对照表（旧→新）、申报模板 diff、时间锚点日历；
  • 换版负责人单一指定，施行前用新模板做一次空跑演练；
  • 对外合同中涉及规则参数的引用改为"按现行规则动态引用"，避免写死旧值。

可复用清单

  • [ ] 规则版本台账（文号/发布日/施行日/范围）在维护；
  • [ ] 换版三件套（参数对照、模板 diff、日历）成为标准动作；
  • [ ] 换版负责人已指定；
  • [ ] 施行前完成一次空跑演练；
  • [ ] 合同中规则参数引用方式为动态引用。

关联：《量化报价与交易风控》（规则版本管理）、《省级政策列表》与各省模块（文号与施行日）。

7. 案例 7：批零倒挂——零售套餐没有联动与止损

D 级合成设定：某售电公司以"一口价"年度套餐签下〔2,000〕户中小用户；次年季度现货均价持续高于套餐折价，批零价差倒挂，毛利转负。

时间线

时间事件
签约期一口价套餐定价参考上年均价，无现货联动条款；公司内部压力测试只做了 ±10% 价格情景
Q1现货价温和上行，毛利收窄；公司按"季节性波动"处理
Q2现货均价持续高于套餐折价，倒挂扩大；无止损线、无转售/调价机制
Q3现金流承压，个别用户提出提前解约；解约条款含糊，争议成本上升
年末全年毛利为负；复盘发现压力测试的下行情景方向错了（只测了价跌，没测价涨）

决策点

  1. 套餐定价是否含价格联动/调价机制？——没有；
  2. 是否设"毛利为负即触发动作"的止损线？——没有；
  3. 用户结构是否与现货价格形态匹配（高负荷用户占比过高放大倒挂）？——没有评估。

错误做法

  • 压力测试只测了对己有利的方向（价跌），没测价涨；
  • 一口价套餐把全部价格风险留在售电侧，且无任何再定价机制；
  • 没有止损线：亏损扩大时没有"停止新增签约/启动调价谈判"的预设动作；
  • 解约与转售条款含糊，用户流失时无合同抓手。

正确做法

  • 套餐结构分层：部分固定价 + 部分联动（联动比例、参考价、封顶在下文合同库 §4 展开）；
  • 压力测试双向：价涨情景（倒挂）与价跌情景（客户流失）都要做，并给出对应动作；
  • 止损三件套：毛利警戒线、动作清单（停新签/调价谈判/对冲/回购）、触发权限；
  • 合同预埋解约与转售条款、价格调整通知机制（合同库 §4）；
  • 用户组合按负荷形态分层定价，高波动用户配联动套餐。

可复用清单

  • [ ] 压力测试双向（价涨/价跌）且有对应动作；
  • [ ] 套餐含联动或调价机制；
  • [ ] 止损线与动作清单事先写死；
  • [ ] 解约、转售、调价通知条款在签约时预埋；
  • [ ] 用户组合按负荷形态分层。

关联：《电力市场风险、信用与结算》（零售风险与退出）、《售电零售与风险》技能（套餐定价）。

8. 案例 8：储能 SOC 用尽——见价就放、尾峰无货

D 级合成设定：独立储能电站（〔100〕MW/〔200〕MWh，可用〔180〕MWh）参与现货套利；某日午间低价充满后，全天按"见价就放"执行，晚峰（真实高价段）SOC 已空。

时间线

时间事件
午间光伏大发低价段充满；运行策略按"价差够即放"无保留
午后出现次高价段（示意：500 元/MWh），放掉〔60〕% 电量
傍晚晚峰真实高价段到来（示意：900 元/MWh），SOC 仅剩〔18〕%
晚峰时段可放电量远小于申报，偏差进实时结算；且失去调频预留
T+1 复盘全天价差收益低于"保留至晚峰"的对照策略；退化成本未进放行门槛

决策点

  1. 执行策略是否设 SOC 保留线（为晚峰保留最低电量）？——没有；
  2. 放行门槛是否计入退化成本（而不是只看即时价差）？——没有；
  3. 次高价段是否评估"后面的峰更高"的概率（价格形状预判）？——没有。

错误做法

  • 把"价差够"当唯一放行条件，忽略形状预判与保留策略；
  • 退化成本不进放行门槛，导致高频次浅放循环，收益被退化吃掉；
  • 充放计划与申报曲线脱节，偏差全部进结算；
  • 调频预留被套利挤占，没有容量分区（可交易/预留/备用）。

正确做法

  • 按 96 点价格形状做全天计划：低价段充电 + 保留线（晚峰最低 SOC）+ 高价段集中放电；
  • 放行门槛 = 即时价差 − 退化成本 − 运维分摊；门槛不足不放（公式与参数见《储能投资与运营》）；
  • 容量分区：套利 / 调频预留 / 备用三区，分区间的占用与释放有台账；
  • 申报曲线与执行计划同源，执行偏离申报触发盘中预警（SOP 触发线）。

可复用清单

  • [ ] 全天按形状做计划，晚峰设 SOC 保留线；
  • [ ] 放行门槛含退化成本；
  • [ ] 容量分区（套利/调频/备用）与占用台账；
  • [ ] 申报与执行同源，偏离有预警；
  • [ ] 复盘对照"保留策略"的机会收益。

关联：《储能投资与运营》（退化与门槛）、《储能 EMS 优化调度》（SOC 约束与多市场堆叠）。

9. 案例 9：VPP 基线争议——理论能力当申报值

D 级合成设定：负荷聚合商聚合〔30〕家工商业用户参与需求响应快速响应事件；以"理论可调能力"申报，事件实际响应不足，认定失败并进入争议。

时间线

时间事件
事前台账可调能力 = 各户设备铭牌容量之和 ×〔1.0〕同时率，未实测、未剔除异常日基线
邀约按理论能力〔12〕MW 申报（无预测试）
事件时段部分用户正值生产班次无法响应；基线（5+3 日剔除规则口径）高于预期，核定响应〔6.8〕MW
认定响应率低于认定门槛，激励打折并触发考核
争议聚合商主张"用户客观原因"，但无事前排产沟通与替代资源调度记录

决策点

  1. 申报值是理论能力还是"可验证能力"（实测 × 同时率 × 可用率）？——理论值；
  2. 事件前是否做预测试（小范围真实调用）？——没有；
  3. 是否与用户约定"事件时段的生产豁免与替代资源"？——没有约定。

错误做法

  • 铭牌容量直接当可调能力，没有同时率与可用率的实测折减；
  • 基线算法口径（剔除规则、样本日）没有在台内落地复算，事前无法预估核定值；
  • 申报与用户生产计划脱节，无豁免名单与替代资源池；
  • 无预测试，第一次真实调用就是考核事件。

正确做法

  • 能力分三层登记：铭牌 → 实测可调（预测试折算）→ 申报值（× 同时率 × 可用率），层级间折减留痕；
  • 基线复算工具化：按本省基线口径事前算"核定值预期"，申报与预期对齐；
  • 用户协议约定：事件时段生产豁免条件、提前告知义务、替代资源义务（合同库 §6）；
  • 每季度至少一次预测试，测试结果更新能力台账；
  • 争议证据包：邀约单、用户通知回执、基线复算、遥测曲线四件齐备。

可复用清单

  • [ ] 能力三层登记（铭牌/实测/申报）且折减留痕；
  • [ ] 基线按本省口径可复算、事前有预期值；
  • [ ] 用户协议含豁免与替代资源条款；
  • [ ] 季度预测试常态化；
  • [ ] 争议证据包四件套齐备。

关联：《虚拟电厂：聚合、调度与商业模式》（CBL 与认定）、《需求响应、车网互动与灵活性资源》（基线与考核）。

10. 案例 10：对手违约——集中度过高、担保不盯

D 级合成设定：某售电公司〔65〕% 的批发电量从同一对手采购；该对手因经营恶化逾期未结算，随后进入退出程序，公司应收与保函处置仓促。

时间线

时间事件
T-6 月行业传出该对手亏损扩大的媒体信息；公司未调其信用台账，继续扩大敞口
T-2 月该对手按《电力市场风险、信用与结算》的信用与保函机制出现保函减额迹象；公司未察觉
T-0对手逾期未结算；公司才发现无逐日盯市记录、保函覆盖率不足
T+1 月对手进入退出程序；公司仓促主张担保，部分证据（对账单签收、催告函）缺失
复盘集中度、盯市、证据链三个洞同时存在

决策点

  1. 负面信息出现时是否立即重估对手敞口并设上限？——没有；
  2. 是否按机制逐日盯市并核保函覆盖？——没有；
  3. 违约发生时是否按流程主张（催告、担保、抵销）并保全证据？——仓促且不全。

错误做法

  • 对手集中度无上限，单一对手损失可放大到影响公司存续；
  • 不盯信用等级与保函变化，风险信号全部错过；
  • 对账、签收、催告等证据平时不留，主张权利时缺件；
  • 把"合作多年"当信用，替代制度性监控。

正确做法

  • 对手集中度限额（D 级示例：单一对手敞口 ≤〔30〕%），纳入限额台账与盘前简报；
  • 按机制做逐日盯市与保函覆盖率核对；信用等级变化触发敞口复核；
  • 违约流程预案：催告函模板、担保主张路径、抵销与诉讼备选、证据清单，事前备好；
  • 台账纪律：结算对账单定期签收归档，催告一律书面。

可复用清单

  • [ ] 对手集中度限额在台账并与简报联动；
  • [ ] 逐日盯市 + 保函覆盖率核对常态化；
  • [ ] 违约预案（催告/担保/抵销/证据清单）事前备好；
  • [ ] 对账签收与催告书面化归档；
  • [ ] 信用等级与负面信息进入盘前信息面。

关联：《电力市场风险、信用与结算》（信用评价、保函、违约退出）、《合同与条款库》（违约与担保条款红线）。

11. 案例库使用与维护

  • 案例库是训练素材：新员用案例做上岗前判断训练；老台员每季度抽 2 个案例做"盲答"对照；真实事件复盘时优先对照结构最像的案例。
  • 案例不承载现行规则值：阈值、时限、算法一律指向对应模块（上表"主关联模块"），案例内数字仅示意。
  • 新增案例的标准：真实复盘中反复出现的错误模式，且现有案例未覆盖 → 按同一结构（设定/时间线/决策点/错误/正确/清单）增写并保持 D 级合成。
  • 与《交易台日课与异常处置 SOP》的接口：案例导出的检查单合并进 SOP §2/§3/§4 的对应清单；案例不直接改 SOP 正文，由 SOP 版本评审统一吸收。
