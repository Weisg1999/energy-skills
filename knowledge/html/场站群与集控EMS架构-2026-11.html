0. 一页看懂

0.1 三句话

  • 集控不是单站 EMS 放大：单站优化各自最优，加起来可能全局冲突（送出断面越限、共享储能争用、申报打架）。集控解决的是多场站协调，是分层优化问题，不是把单站模型复制 N 份。
  • 架构由分级授权与时间尺度决定：设备级（ms）→站级 EMS（s）→群级集控（s–min）→调度主站（min–15 min），各层控制权限、闭环周期、数据粒度不同。越往上越慢、越全局；越往下越快、越局部。
  • 通信与安全是架构的硬约束：拓扑（星型/环型/分层）、协议（IEC 104/61850）、时延预算、时钟同步、横向隔离/纵向认证，决定了群级控制能不能闭环、敢不敢闭环。

0.2 关键数字与口径

概念含义来源与级别
站级 EMS单场站闭环控制，秒级工程架构，A
群级集控多场站协调，秒–分钟级工程架构，A
调度主站电网调度，分钟–15 分钟级调度规程，A
群调群控统一接收调度令、分解到站、协调执行运行机制，A
共享储能池多场站共用储能，按净出力配置工程方法，B
同时率多场站峰值不同时出现的折减系数统计/实测，B
横向隔离/纵向认证电力监控安全防护边界安全防护规定，A

本文所有算例为 D 级合成数据，容量、时延、节省比例均为教学假设，不对应任何真实场站群。

1. 为什么需要集控

1.1 单站各自最优 ≠ 全局最优

风光储多场站若各跑各的 EMS：

  • 送出断面冲突：各站满发叠加可能超共用送出断面限额；
  • 共享储能争用：多站共用一套储能时，各自调用指令打架；
  • 申报不一致：分站申报与集控统一申报口径冲突，偏差考核翻倍；
  • 互补性浪费：风光出力互补本可平滑净出力，各自配储则重复投资。

1.2 集控的价值

  • 协调：统一功率分配、断面协调、共享储能调度；
  • 规模效应：共享储能池按净出力配置，小于各自配储之和（§7 算例）；
  • 统一接口：对调度主站一个接口、统一申报，降低考核与运维成本；
  • 全局优化：跨站边际成本/预测精度排序，全局弃电最小。

1.3 与 VPP 聚合的区别

维度场站群集控VPP 聚合
资源物理相邻/同业主的风光储场站地理分散、多业主的可调资源
控制直接控制（自有场站）合约调用（非自有资源）
通信专用通道、强实时公网/专网混合、弱实时
优化物理潮流/断面约束强基线/合约约束强

两者架构思想相通（分层、聚合），但控制权限与约束结构不同。VPP 见 虚拟电厂聚合调度与商业模式 §4。

2. 分级调度架构

2.1 四层分层

层级时间尺度职责控制权限
设备级msBMS/PCS/风机变流器闭环设备保护、就地控制
站级 EMSs单站功率跟踪、SOC 管理、就地优化站内设备调度
群级集控s–min多站协调、断面管理、共享储能、统一申报站间功率分配
调度主站min–15 min电网安全、AGC/AVC、调度令下达群级/站级指令

2.2 分级授权

调度令自上而下分解：调度主站 → 群级集控（接收总指令）→ 分解到各站 → 站级 EMS 执行 → 设备级闭环。每一层只在自己权限内闭环，越权控制是安全事故。群级集控不能绕过站级直接控设备，站级不能拒绝调度令。

2.3 时间尺度匹配

  • 站级闭环（秒级）跟踪群级下发的功率设定点；
  • 群级协调（秒–分钟级）按断面/共享储能状态分配功率；
  • 调度级（分钟级）按电网安全下达 AGC/计划曲线。

越级时间尺度错配（如用分钟级调度令做秒级调频）会导致控制振荡或失稳。单站 EMS 时间尺度与 MPC 见 储能 EMS §6。

3. 通信拓扑与协议

3.1 拓扑选型

拓扑特点适用
星型各站直连集控，简单、单点风险场站少、距离近
环型冗余路径、可靠性高场站多、可靠性要求高
分层区域子站→集控→调度，可扩展大型场站群、跨区

3.2 协议

  • IEC 60870-5-104：调度/集控远动，TCP/IP，广域；
  • IEC 61850：站内/站间互操作，MMS/GOOSE/SV；
  • Modbus/DL/T 634：设备级采集。

协议选型、点表与数据契约见 SCADA 与电力监控数据链路 §2、§3。

3.3 冗余与可靠性

群级集控是单点，需双机/双网冗余；通信通道主备切换；关键指令确认与回读。冗余设计见 SCADA §7。

4. 群调群控与功率分配

4.1 统一功率分配

群级集控接收总功率指令后，按以下原则分解到站：

  • 边际成本/弃电成本排序：弃电代价高的站优先满发；
  • 预测精度：预测可靠的站承担更多调节；
  • 网络约束：考虑各站到送出断面的电气距离与潮流分布（见 潮流阻塞与节点电价）；
  • 储能 SOC 均衡：共享储能按各站需求与 SOC 状态分配充放。

4.2 断面协调

共用送出断面压限时，群级集控统一削减/储能吸收，而非各站独立越限。这是集控相对单站的核心增量——单站看不到断面全局。

4.3 共享储能池

多站共用一套储能，群级集控统一调度，按净出力波动配置容量（§7）。共享储能的产权/分成/调度优先级需在协议里写清，避免争用。

4.4 优化分解

群级全局优化可分解为主从结构：群级主问题分配功率/储能，站级子问题就地优化跟踪。大规模可用交替方向乘子法（ADMM）等分布式分解，但工程上常用集中式 MILP（场站数有限时）。单站数学模型见 储能 EMS §3 与 微网 EMS §3。

5. 数据链路与时延预算

5.1 闭环时延分解

采集(设备->站级) + 上送(站级->群级) + 群级决策 + 下发(群级->站级) + 站级执行
= 群级控制闭环总时延

每一段都要有预算。群级控制周期必须 > 闭环总时延，否则指令打架。采集频率、时延与时间同步见 SCADA §4。

5.2 时钟同步

多站数据对齐依赖统一时钟（北斗/GPS/NTP/PTP），时钟漂移会导致功率分配基于错位数据。群级集控对时钟同步要求高于单站。

5.3 数据质量

群级决策依赖各站上送数据的质量（坏数据/缺失/时标错）。需数据校验、状态估计与坏数据辨识，否则全局优化建立在错误输入上。数据治理见 SCADA §5。

6. 安全与授权

6.1 电力监控安全防护

遵循"安全分区、网络专用、横向隔离、纵向认证"：生产控制大区与管理信息大区横向隔离，上下级纵向认证。群级集控跨站通信必须满足防护要求。详见 SCADA §8。

6.2 控制权限分级

  • 调度令校验（来源/权限/范围）；
  • 群级→站级指令确认与回读；
  • 防误操作（双重确认、闭锁逻辑）；
  • 紧急情况下站级就地保护优先于群级指令。

6.3 等保与验收

集控系统按等级保护定级备案，并网前做安全防护评估与涉网试验。涉网验收见 并网测试与涉网验收实务清单。

7. 合成算例（D 级）：共享储能池的规模效应

7.1 场景

风电场 100 MW、光伏电站 50 MW，同业主、共用送出断面，需配储平滑出力波动。

7.2 独立配储 vs 共享池（D 级假设）

配置功率（MW）能量（MWh）说明
风电独立配储2050平滑风电波动
光伏独立配储2030平滑光伏波动
独立合计4080两套储能
共享储能池3060风光互补，同时率折减
节省10（25%）20（25%）集控规模效应

7.3 为什么共享更省

风电夜间大、光伏午间大，出力互补，净出力波动小于两者波动之和。共享储能按净出力波动配置，而非各自波动之和；多站峰值不同时出现（同时率 < 1），进一步折减容量需求。

7.4 读图与边界

  • 25% 节省是教学假设，实际节省取决于风光相关性/互补性、负荷曲线与断面约束，须用实测时序仿真校核，不能直接套比例。
  • 若风光出力高度正相关（同升同降），互补性弱，共享节省有限甚至不如独立。
  • 共享池需群级集控统一调度，产权/分成/优先级协议是落地前提（§4.3）。

8. 常见错误（10 条）

  1. 把集控当单站 EMS 复制 N 份，忽略全局协调。
  2. 各站满发叠加超送出断面，单站看不到断面全局。
  3. 越级控制（群级绕过站级直控设备），权限错配。
  4. 时间尺度错配（分钟级调度令做秒级调频），控制振荡。
  5. 群级控制周期 ≤ 闭环时延，指令打架。
  6. 多站时钟不同步，功率分配基于错位数据。
  7. 共享储能无产权/分成/优先级协议，争用打架。
  8. 把共享储能 25% 节省当普适比例，不做时序仿真。
  9. 忽略横向隔离/纵向认证，跨站通信不满足安全防护。
  10. 群级决策不做坏数据辨识，全局优化建立在错误输入上。
