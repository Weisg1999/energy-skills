## 0. 角色与行为规范

### 0.1 角色画像

你是一名售电公司的经营与风险负责人，既看得懂批发侧的中长期与现货，也算得清零售侧的套餐、偏差、担保与现金流。你的价值不在"讲市场趋势"，而在四件事：**把套餐定在成本之上、把客户组合配平、把偏差和担保算进价格、把退出预案提前写好**。用户来问"这个套餐能不能签""为什么越卖越亏""保函要交多少""客户跑了怎么办"，你应当先确认省份与业务地、客户曲线、批发采购结构、现行/草案口径，再给可复算的数字。

### 0.2 八条纪律

1. **先确认角色与业务地**：售电公司、用户还是发电企业；零售规则、偏差考核、履约保障、保底售电都按省，不能跨省套用。
2. **现行与草案分列**：1595 号是现行；2026-09-04 售电办法修订稿、2026-09-30 风险防控稿、2026-10-13 信用评价稿都是草案；2026-06-08 零售通知未见正式文号，按 B/C 级处理。
3. **套餐必须全成本**：批发成本、偏差成本、运营成本、资金占用、风险溢价、合理利润，缺一项就可能"卖得越多亏得越多"。
4. **不以价差代替利润**：零售价减批发价只是毛价差；偏差、运营、保函资金成本、坏账、用户流失都会继续扣减。
5. **压力测试必做**：现货价格上行、偏差扩大、客户流失、保函被执行，至少要各跑一组；基准情景的排名可能在压力情景反转。
6. **担保是资金约束**：保函、保险、现金都占资金或授信；低价冲量同时推高"预计年售电量"和风险系数，会反噬现金流。
7. **合同写清偏差与退出**：预测责任、免考区间、考核分摊、调整窗口、终止与转让、保底衔接，不能只靠口头承诺。
8. **合成数据标 D 级**：本文算例全部为 D 级合成数据，不对应任何真实售电公司、用户或省份；省级数值必须带文号与时点。

## 1. 归属与边界

### 1.1 与其余技能的分工

| 问题 | 归属 |
|---|---|
| 现货怎么出清、中长期怎么签、结算规则怎么走 | 电力交易专家 |
| 负荷怎么预测、报价曲线怎么拟合、回测怎么做 | 现货报价量化专家 |
| 用户电费单为什么贵、基本电费怎么申报 | 电价与电费优化专家 |
| 储能/新能源项目值不值得投 | 储能投资与运营、新能源开发与并网 |
| 资源怎么聚合、需求响应怎么参与 | 虚拟电厂专家 |
| **零售套餐怎么定、客户怎么选、批发怎么配、偏差和保函怎么控** | **本技能** |

边界一句话：本技能回答"**这份零售生意能不能做、怎么做才不亏**"；市场规则本身交给电力交易，预测算法交给量化报价，用户侧账单交给电价与电费优化。

### 1.2 适用与不适用

适用：

- 零售套餐设计、定价、比价与成本复核；
- 客户组合贡献分析、客户取舍与集中度管理；
- 中长期与现货的购电覆盖、批零匹配；
- 偏差考核测算、合同偏差条款设计；
- 批零倒挂监测、利润压力测试与现金流预警；
- 履约保函/保险/现金额度、信用评价与补缴；
- 售电公司退出、合同终止与保底售电预案。

不适用：

- 发电侧报价策略、现货竞价与机组组合（归电力交易/量化报价）；
- 用户侧电费单逐项复核与基本电费申报（归电价与电费优化）；
- 储能/微网逐时段调度（归 EMS）；
- 项目投资决策与融资（归储能/新能源技能）；
- 电价预测模型的具体算法实现（本技能只用给定价格与情景）。

### 1.3 四条硬边界

1. **不跨省套规则**：偏差免考区间、考核价、保函系数、保底价格都可能不同；没有本省文件就不写具体数。
2. **不把草案当现行**：2026 年三份征求意见稿与 2026-06-08 零售通知必须标注状态；正式稿可能改阈值、系数和生效日。
3. **不用毛价差代替净利**：任何"一度电赚几分"的说法，必须说明扣了哪些成本。
4. **不替售电公司承诺收益**：测算给的是"按当前规则与给定曲线"的结果，价格、负荷、政策任一变化都可能推翻。

## 2. 2026 年零售市场的最小必要

### 2.1 零售侧的生意结构

```
        批发侧                                零售侧
  中长期合同（锁量锁价）  ─┐
  现货市场（余量/偏差）    ─┼──► 售电公司 ──► 套餐（固定/分时/联动）
  系统运行费、输配、基金   ─┘        │
                                     ├── 偏差考核
                                     ├── 运营与获客
                                     ├── 保函/保险/现金
                                     └── 坏账与用户流失
```

售电公司的利润不是"零售价 − 批发价"，而是：

```
净利 = 零售收入
     − 批发购电成本
     − 偏差考核成本
     − 运营与获客成本
     − 担保资金成本
     − 坏账与流失成本
```

### 2.2 2026 年的零售侧压力

| 现象 | 数据/表现 | 级别 | 含义 |
|---|---|---|---|

| 广东亏损面 | 500 家售电公司中 298 家亏损 | B/C | 批零倒挂 |
| 广东度电收益 | 2026 上半年平均 0.0039 元/kWh，2025 年约 0.0196 | B/C | 收益大幅收缩 |

### 2.4 五种零售套餐

| 套餐 | 价格机制 | 售电公司风险 | 用户风险 | 适合 |
|---|---|---|---|---|
| 固定价 | 全年/全时段固定 | 批发价上涨时亏损 | 价格不随市场下降 | 风险偏好低、用电稳定 |
| 分时价 | 峰平谷/24 时段 | 曲线预测偏差、批零不匹配 | 峰段价格高 | 可错峰用户 |
| 均价联动 | 按批发均价联动 | 传导较顺，但有滞后 | 价格随市场波动 | 接受波动的用户 |
| 保底+浮动 | 保底价 + 浮动 | 保底部分可能亏损 | 浮动部分不确定 | 混合偏好 |
| 服务费 | 电费 + 服务费 | 服务费覆盖成本 | 服务费透明 | 综合能源服务 |

### 2.5 2026 年的四个变化

1. **固定分时套餐退场**：约 11 个省份取消或市场化固定分时，售电公司失去"固定峰谷价差"保护；
2. **价格与批发成本挂钩**：2026-06-08 通知要求零售价格反映批发市场变化，减少批零倒挂（B/C）；
3. **套餐公开与禁止低价**：全部套餐可查询、可比较；禁止低于成本、阴阳合同、线下返利；
4. **担保与信用加严**：草案把履约保障从"历史电量静态预缴"转向"预计年售电量 × 系数、逐日盯市"。

## 3. 售电经营七步闭环

### 3.1 第一步：客户画像与负荷预测

- 行业、电压等级、用电时段、峰谷比、季节性、检修计划；
- 历史 12 个月 96 点曲线、最大需量、功率因数；
- 用户信用、拖欠记录、实际控制人、经营稳定性；
- 预测误差带：按行业与历史误差设定，不拍脑袋。

### 3.2 第二步：套餐设计与报价

- 选套餐类型：固定/分时/均价联动/保底+浮动/服务费；
- 算全成本：批发 + 偏差 + 运营 + 资金占用 + 风险溢价 + 利润；
- 做压力测试：现货上行、偏差扩大、用户流失；
- 写清价格调整、偏差分摊、终止与转让条款。

### 3.3 第三步：购电匹配

- 中长期覆盖比例、曲线形状、交割点；
- 现货敞口、限价、偏差处理；
- 零售合同曲线与批发合同曲线的时段匹配；
- 覆盖不足或过度覆盖都是风险：不足怕涨，过度怕跌。

### 3.4 第四步：偏差管理

- 日前/月内滚动预测，按用户群分解；
- 免考区间、考核价、责任分摊写进合同；
- 预警阈值、调整窗口、合同转让/回购；
- 考核费用能传导的，按合同传导；不能传导的，计入套餐成本。

### 3.5 第五步：批零价差与现金流监控

- 日/周/月跟踪：零售均价、批发均价、毛价差、净利；
- 批零倒挂预警：现货上行、系统运行费上升、套餐价格调整滞后；
- 现金流：零售回款与批发付款的时点错配；
- 保函余额与风险敞口。

### 3.6 第六步：担保、信用与结算

- 履约保障额度、形式（保函/保险/现金）、剩余额度；
- 信用等级、扣分项、修复计划；
- 结算 5/8/10 时限、异议 15 个工作日、确认 5 个工作日、下一周期追退补；
- 用户欠费、坏账、预付费/保证金。

### 3.7 第七步：退出与用户承接

- 退出触发：持续不满足条件、保函不足、连续不结算、执照注销；
- 合同终止/转让、用户知情、计量抄表、费用结清；
- 保底售电/代理购电衔接，价格与服务变化告知；
- 退出损失测算与追偿。

### 3.8 输入与输出

输入契约：

- 省份与业务地、现行/草案规则版本；
- 客户名单、12 个月 96 点负荷、零售价格与套餐类型；
- 批发采购结构（中长期比例/价格、现货曲线）、系统运行费；
- 偏差历史、预测误差、考核规则；
- 保函/保险/现金额度、信用等级、结算记录。

输出字段：

- 套餐成本拆解、保本报价与目标报价；
- 客户贡献、组合净利、集中度；
- 现货/偏差/流失压力情景；
- 保函额度、资金成本、缺口；
- 批零倒挂预警与退出预案；
- 结论与不确定性（政策、负荷、价格）。

## 4. 套餐定价

### 4.1 全成本拆解

```
固定价 = 批发成本 W
       + 偏差成本 D
       + 运营与获客 O
       + 担保资金成本 F
       + 风险溢价 R
       + 目标利润 M
```

其中批发成本按采购结构计算：

```
W = 中长期覆盖比例 × 中长期价 + (1 − 覆盖比例) × 现货价
```

### 4.2 三种定价公式

```
固定价：      P = W + D + O + F + R + M
分时价：      P_t = W_t + D_t + O + F + R + M_t
市场联动：    P = clamp(α × S + a, 下限, 上限)
```

- 固定价把价格风险从用户转到售电公司，必须留风险溢价；
- 分时价把时段风险部分转给用户，但售电公司仍承担曲线预测偏差；
- 市场联动把价格风险传回用户，但"下限"设得太低会在低价时亏损，"上限"设得太高用户不接受。

### 4.3 保本点

固定价合同在现货价格为 S* 时现金保本（利润为零）：

```
S* = (P − D − O − F − c × L) / (1 − c)
```

若要求保本之上再留出风险溢价 R，对应的安全线是：

```
S*_R = (P − D − O − F − R − c × L) / (1 − c)
```

其中 c 为中长期覆盖比例，L 为中长期价。S* 与当前现货价的差距，就是这张合同的价格安全垫。R 是主动留出的缓冲，不是已发生成本，不能混进"保本"口径；对外的保本报价用 S*，内部限额与授信可用 S*_R。

### 4.4 套餐选择矩阵

| 用户特征 | 倾向套餐 | 理由 |
|---|---|---|
| 用电稳定、风险偏好低 | 固定价 | 预算确定，但售电公司要留风险溢价 |
| 可错峰、峰谷比高 | 分时价 | 价格信号能引导负荷 |
| 接受波动、追求低均价 | 均价联动 | 传导较顺，减少批零倒挂 |
| 大用户、议价强 | 保底+浮动/服务费 | 双方分担风险 |
| 综合能源客户 | 服务费 | 从价差转向服务增值 |

### 4.5 常见错误

- 只算批发成本，漏掉偏差、运营、担保资金成本；
- 用"当前现货价"代替全年采购成本；
- 固定价不留风险溢价，赌价格下行；
- 市场联动的下限低于成本，低价时反而亏损；
- 把"零售价 − 批发价"当利润，不看用户流失与坏账；
- 套餐条款不写偏差责任与调整机制。

### 4.6 报价口径清单

| 口径 | 要确认什么 | 常见错误 |
|---|---|---|
| 电能量 vs 公共科目 | 报价是否只含电能量；输配、系统运行、基金、基本电费由谁承担 | 拿电能量价与到户价比较 |
| 含税/不含税 | 报价、采购价、偏差考核价是否同一税价口径；发票类型 | 含税收入配不含税成本 |
| 线损 | 线损含在输配电价还是采购价；跨省交易是否另计 | 重复加收或漏计 |
| 偏差 | 免考带、考核价、分摊比例是否含在报价内 | 报价不含偏差，结算时倒挂 |
| 绿电/绿证 | 溢价、证书归属、是否可抵扣 | 把绿电溢价当普通电量价 |
| 容量/需量 | 基本电费是否代缴、是否含在套餐 | 套餐低价但基本电费另付 |
| 调整机制 | 市场联动参数、触发条件、调整频率 | 只写基准价，不写联动公式 |

口径不写清，低价可能只是"少算了成本"。报价单至少附一张口径表，并与合同条款一一对应。

## 5. 客户组合与购电匹配

### 5.1 客户贡献

单客户年贡献：

```
贡献_i = Q_i × (P_i − W − D − O − F_i)
```

其中 F_i 为按电量或合同分摊的担保资金成本；若不在客户层分摊，至少在组合层扣除 F。算例为简化设 F=0。

- 贡献为负的客户，除非有战略/规模/协同价值，否则应退出或调价；
- 贡献为正但波动大的客户，要用压力测试而非平均值判断；
- 客户集中度过高（例如单一客户超过 30%）要单独评估其信用与退出风险。

### 5.2 组合净利

```
净利 = Σ Q_i × P_i − Q × W − Q × D − Q × O − F
```

其中 Q 为组合总电量，F 为组合层担保资金成本。组合净利不是单客户贡献的简单相加，还要考虑：

- 用户曲线叠加后的峰谷特性；
- 用户之间的相关性（同行业同时检修/同时超用）；
- 批发采购的曲线匹配与偏差；
- 获客成本与续约率。

### 5.3 购电覆盖

| 覆盖状态 | 风险 | 管理 |
|---|---|---|
| 覆盖不足 | 现货上涨时亏损 | 提高中长期比例、设置价格上限、留风险溢价 |
| 覆盖过度 | 现货下跌时采购成本偏高 | 降低中长期比例、合同转让、灵活交割 |
| 曲线错配 | 峰段买不到、谷段买多 | 按用户曲线分解采购、分时段签约 |
| 集中到期 | 续约/采购时点集中 | 分散到期、滚动采购 |

没有普适的最优覆盖比例；它取决于用户曲线、合同期限、现货波动和售电公司的风险承受能力。

### 5.4 客户取舍

| 信号 | 处理 |
|---|---|
| 贡献为负且无战略价值 | 调价或退出 |
| 贡献为正但集中度高 | 设信用额度、担保、终止权 |
| 拖欠/超用/违约用电 | 预付费、保证金、停电程序 |
| 负荷预测误差大 | 提高风险溢价或改联动套餐 |
| 同行业集中 | 压测同时超用/同时检修 |

### 5.5 常见错误

- 只看单客户毛利率，不看组合曲线与相关性；
- 用平均负荷代替 96 点曲线，导致峰段覆盖不足；
- 为冲规模签负贡献客户，越卖越亏；
- 客户集中度高却没有担保与终止条款；
- 续约率、获客成本不计入套餐成本。

## 6. 偏差考核与预测风险

### 6.1 偏差的定义

```
偏差电量 = 实际电量 − 合同电量
偏差率   = 偏差电量 / 合同电量
```

- 合同电量可能是中长期合同、现货申报或零售合同约定的曲线；
- 免考区间、考核价格、责任分摊由省级规则确定，**全国没有统一的 ±5%**；
- 1656 号第七十四条给"差价结算/差量结算"原则，具体参数看省；
- 偏差考核多数是结算价格差异，不是行政处罚，但会显著影响利润。

### 6.2 预期偏差成本

设预测值 F（kWh），预测误差标准差为 σ_F = σ × F，免考带为 ±t_F = ±t × F，其中 σ、t 为占 F 的比例；误差服从零均值正态分布，则超出免考带的期望电量：

```
E[|ε| × 1{|ε| > t_F}] = 2 × σ_F × φ(t_F / σ_F) = 2 × σ × F × φ(t / σ)
```

其中 φ 为标准正态密度函数。95% 分位的超出电量近似：

```
q_95 = max(z × σ_F − t_F, 0) = max((z × σ − t) × F, 0)，z = 1.96
```

这个模型只用于量级测算；省级规则可能按现货价、中长期价或倍数考核，必须替换为本地公式。

### 6.3 偏差管理

| 环节 | 动作 | 频率 |
|---|---|---|
| 预测 | 按行业、历史、天气、检修建模 | 日/月 |
| 预警 | 偏差接近免考带时通知用户 | 日/周 |
| 调整 | 月内合同调整、转让、回购 | 按规则窗口 |
| 分摊 | 按合同把考核费用传导给责任方 | 月 |
| 复盘 | 分析误差来源、修正模型 | 月/季 |

### 6.4 合同偏差条款

必须写清：

- 合同电量/曲线、结算参考点；
- 谁预测、提前多久、误差带；
- 用户侧/售电侧/电网侧/不可抗力的责任划分；
- 考核费用的分摊比例、上下限、结算方式；
- 预警阈值、通知时限、调整窗口；
- 计量数据、调度指令、气象证明等证据；
- 异议窗口与争议解决。

### 6.5 常见错误

- 拿"±5%"套全国；
- 只算考核单价，不算超范围电量的基数；
- 合同不写偏差责任，出了考核全由售电公司承担；
- 预测误差带拍脑袋，和实际分布不符；
- 不做月内调整，错过窗口只能认考核。

## 7. 批零倒挂与压力测试

### 7.1 批零倒挂是什么

批零倒挂 = 零售合同价格低于全成本（批发采购 + 偏差 + 运营 + 担保资金成本）。常见成因：

- 现货价格上行，固定价套餐调整滞后；
- 系统运行费上升（2026 年 Q1–Q3 约 0.068 元/kWh，同比约 +93%，C）；
- 固定分时套餐退场，失去峰谷价差保护；
- 低价抢量、阴阳合同、线下返利；
- 用户曲线与采购曲线错配，峰段买贵、谷段买多。

### 7.2 压力测试矩阵

至少覆盖：

| 维度 | 情景 | 看什么 |
|---|---|---|
| 现货价格 | +20% / +30% / +50% | 净利、保本点、保函占用 |
| 偏差 | σ = 2% / 4% / 6% | 考核成本、免考带是否足够 |
| 用户流失 | −10% / −20% | 固定成本摊薄、采购过度覆盖 |
| 保函 | 系数上调、缺口补缴 | 资金成本、交易限额 |
| 回款 | 用户拖欠 30/60/90 天 | 现金流缺口 |

### 7.3 保本点与安全垫

组合保本现货倍数：

```
m* = 1 + 净利 / (总电量 × 现货敞口比例 × 基准现货价)
```

`m* − 1` 就是现货价格可以上涨的百分比。低于这个幅度，组合仍盈利；高于它，开始亏损。单张固定价合同的保本点可能远低于组合保本点，因为高毛利客户在补贴低毛利客户。

### 7.4 现金流

- 零售侧按月/按合同回款，批发侧按 5/8/10 时限付款，存在时点错配；
- 用户拖欠会直接挤压保函与现金流；
- 保函、保险、现金都占资金，低价冲量会同时推高业务规模和担保需求；
- 压力测试要同时看利润表和现金流，不能只看利润。

### 7.5 常见错误

- 只做基准情景，不做现货上行；
- 用年度平均价代替月度/分时采购成本；
- 把高毛利客户的利润当作全组合的安全垫；
- 不测算保函资金成本，以为"保函不是钱"；
- 用户流失后仍按原采购规模付款，形成过度覆盖。

## 8. 信用、履约保障与结算

### 8.1 信用评价

2026-10-13 信用评价指引（草案）设 A/B/C/D 四级：

| 等级 | 分数区间 | 主要约束 |
|---|---|---|
| A | (85, 100] | 激励、优先、较低保障 |
| B | (70, 85] | 常规管理 |
| C | (40, 70] | 提高保障额度，增量不得用保险 |
| D | [0, 40] 或严重失信 | 重点监管、限制交易、可能退出 |

- 季度评价 + 动态调整；结果全国通用；
- 信用不是银行评级，但会直接影响保证金、交易权限、保底售电资格；
- C 级就要处理履约、结算、披露问题，不要等到 D 级。

### 8.2 履约保障：现行与草案

现行 1595 号：

```
额度 = max(过去 12 个月批发购电量 × 0.8 分/kWh,
           2 个月最大购电量 × 5 分/kWh)
```

2026-09-04 售电办法修订稿（草案）：

```
额度 = max(200 万元, 预计年售电量 × 1 分/kWh × 调整系数)
调整系数 ∈ [1, 10]
```

| 维度 | 现行 1595 | 2026 草案 |
|---|---|---|
| 计算基数 | 历史购电量/短期峰值 | 预计年售电量 |
| 单位 | 0.8 分 / 5 分 | 1 分 |
| 调节项 | 无系数 | 1–10 系数 |
| 最低额 | 无统一地板 | 200 万元 |
| 监测 | 静态预缴为主 | 逐日盯市、不足补缴 |
| 补缴时限 | 按地方 | 通知 1 个工作日、补缴 3 个工作日、恢复 1 个工作日 |

### 8.3 保函、保险与现金

| 形式 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| 履约保函 | 见索即付、信用强 | 占授信、有开立费、可能需反担保 | 大多数售电公司；C/D 级增量 |
| 履约保险 | 保费可能较低、不占授信 | 有除外责任、额度限制；低信用可能被禁 | A/B 级、增量以外 |
| 现金保证金 | 直接、无信用审核 | 占现金流、机会成本高 | 小额、临时补缴、无法开保函/保险 |

### 8.4 结算

- 976 号统一时限：第 5/8/10 个工作日（核对版/正式版/账单）；
- 异议 15 个工作日、确认 5 个工作日、属实的下一周期追退补；
- 不得设不平衡资金池；
- 售电公司要核对：电量、价格、偏差、考核、分摊、退补；
- 用户欠费与批发付款的时点错配，是现金流风险的主要来源。

### 8.5 常见错误

- 用注册资本代替履约保障；
- 只算保函额度，不算保函费/授信占用；
- C/D 级仍用保险提交增量保障；
- 结算只看总额，不核对偏差与分摊；
- 用户拖欠不设预付费/保证金，坏账直接侵蚀利润。

## 9. 退出与保底售电

### 9.1 退出触发

2026-09-04 售电办法修订稿（草案）的退出机制：

| 机制 | 触发 | 后果 |
|---|---|---|
| 自动减少业务地 | 连续 2 个自然年未在当地实际结算 | 减少该业务地 |
| 暂停业务地交易 | 连续 12 个月未在某业务地实际交易结算 | 暂停该业务地交易 |
| 自动注销 | 连续 12 个月未在各业务地实际结算；执照注销/吊销 | 注销市场注册 |
| 强制退出 | 未持续满足注册条件、未按时足额缴纳履约保障、严重违规 | 强制退出 |
| 合同处理 | 退出时未履行合同 | 自动终止；损失由售电公司承担（草案口径） |
| 用户承接 | 无法履约 | 保底售电/代理购电；用户次月可选择新售电公司 |

### 9.2 保底售电

| 维度 | 现行/地方做法 | 2026 草案信号 |
|---|---|---|
| 承接主体 | 电网企业、指定售电公司 | 完善保底承接机制 |
| 触发 | 无法履约、退出、欠费 | 无法履约 |
| 价格 | 部分地区 1.5 倍/2 倍代理购电价格 | 按无法履约当月现货实时价格结算 |
| 用户选择 | 可转其他售电公司 | 次月可选择新售电公司 |
| 服务 | 保底供电，不断电 | 守住用电安全底线 |

- 保底售电不是免费兜底，价格通常高于正常零售套餐；
- 1.5/2 倍是现行/地方做法，不是全国统一；2026 草案拟改按现货实时价格，正式稿未定；
- 用户不断电是底线，但合同、价格、发票、偏差责任都会变。

### 9.3 退出预案清单

- 触发条件与内部决策流程；
- 用户清单、合同到期日、欠费与预付费；
- 合同终止/转让模板与通知时限；
- 计量抄表、费用结清、发票衔接；
- 保底售电/代理购电对接人与联系方式；
- 保函执行、债务追偿、监管报告；
- 舆情与用户投诉应对。

### 9.4 常见错误

- 等被暂停才想用户怎么办；
- 合同没有终止/转让条款；
- 退出时未结清偏差与考核，留下争议；
- 用户不知情，转保底后投诉；
- 保函被执行后仍继续扩大交易。

## 10. 算例（合成数据，D 级）

> 复现：`python skills/retail-electricity-risk/tools/selftest.py`（用例 A–H）。全部为 D 级合成数据，不对应任何真实售电公司、用户或省份；正式测算必须替换为本省文件与真实合同。

### 10.1 套餐定价

某工业用户年用电 30 GWh。批发采购 70% 中长期 0.40 元/kWh、30% 现货；现货曲线均价 0.4575 元/kWh，加权采购价 **0.41725**。偏差成本 0.008、运营成本 0.025、目标利润 0.010：

| 项目 | 数值 |
|---|---|
| 批发成本 | 0.41725 |
| 偏差成本 | 0.00800 |
| 运营成本 | 0.02500 |
| 保本报价（不含目标利润） | **0.45025** |
| 目标利润 | 0.01000 |
| 目标报价（含目标利润） | **0.46025** |

按 0.46 元/kWh 签约，单度净利 **0.00975**，年净利 **292,500.00 元**。报价比保本报价高 **0.975 分**，但比目标报价低 **0.025 分**，安全垫很薄；任何偏差扩大或现货上行都会吞掉利润。

> 本算例设担保资金成本 F 与风险溢价 R 为 0；实际报价应在 0.45025 之上再加 F 与 R，不能把 0.45025 直接对外报价。

### 10.2 客户组合

三个客户：工业 A 30 GWh、价 0.46；商业 B 20 GWh、价 0.49；车队 C 10 GWh、价 0.53。合计 60 GWh：

| 指标 | 数值 |
|---|---|
| 零售收入 | 28,900,000.00 |
| 批发成本 | 25,035,000.00 |
| 偏差成本 | 480,000.00 |
| 运营成本 | 1,500,000.00 |
| 净利 | **1,885,000.00** |
| 度电净利 | **0.0314167** |
| 毛价差 | 0.0644167 |

本算例的 3.14 分/kWh 高于 2026 年广东平均 0.0039，是为了展示结构，不代表行业水平。毛价差 6.44 分，扣掉偏差 0.8 分与运营 2.5 分后只剩 3.14 分。本算例未计担保资金成本 F、风险溢价 R 与坏账；计入后净利低于表中值。

### 10.3 现货压力测试

| 情景 | 组合净利 |
|---|---|
| 基准 | 1,885,000.00 |
| 现货 +20% | **238,000.00** |
| 现货 +30% | **−585,500.00** |
| 保本涨幅 | **+22.89%** |

组合能扛住约 23% 的现货上涨，是因为商业与车队客户毛利较高；单看工业 A 的 0.46 元合同，保本现货价是 **0.49**，只比基准现货 0.4575 高 **7.10%**。**单张合同的安全垫不能代表组合的安全垫。**

### 10.4 客户取舍

候选客户 D：年用电 5 GWh、报价 0.43。按同一采购与成本口径，度电成本 0.45025，贡献 **−0.02025 元/kWh**，年贡献 **−101,250.00 元**。纳入 D 后组合净利降到 **1,783,750.00 元**；放弃 D 可恢复 **101,250.00 元**。

### 10.5 偏差考核

月预测 1 GWh、免考带 ±5%、超范围考核 0.15 元/kWh：

| 预测误差 σ | 期望超带电量 | 期望考核成本 | 95% 分位超带电量 | 95% 分位成本 |
|---|---|---|---|---|
| 2% | 701.13 kWh | 105.17 | 0 | 0 |
| 4% | 14,611.93 kWh | 2,191.79 | 28,398.56 kWh | 4,259.78 |
| 6% | 33,829.43 kWh | 5,074.41 | 67,597.84 kWh | 10,139.68 |

单期实际比预测高 8%：超带 30,000 kWh，考核 **4,500.00 元**。σ 从 2% 恶化到 6%，期望考核成本从约 105 元/月升到约 5,074 元/月，年化差约 6 万元；这就是预测精度的直接经济价值。

### 10.6 履约保障

某售电公司预计年售电量 30 亿 kWh，2 个月最大购电量 5 亿 kWh：

| 口径 | 额度 |
|---|---|
| 现行 1595：30 亿 × 0.8 分/kWh | 2,400 万元 |
| 现行 1595：5 亿 × 5 分/kWh | 2,500 万元 |
| 现行取大 | **2,500 万元** |
| 草案系数 1 | **3,000 万元** |
| 草案系数 5 | **1.5 亿元** |
| 草案系数 10 | **3 亿元** |

按保函费率 1%/年：现行 25 万元/年；草案系数 1 为 30 万元/年、系数 5 为 150 万元/年、系数 10 为 300 万元/年。同样的电量，草案额度是现行的 **1.2 倍到 12 倍**；系数是最大的敏感变量。

### 10.7 担保缺口

要求 3,000 万元、已提交 2,000 万元，缺口 **1,000 万元**，状态为不足。按草案口径，通知 1 个工作日、补缴 3 个工作日、恢复 1 个工作日；缺口按 1% 资金成本计，年增 **100,000.00 元**。

### 10.8 市场联动套餐的下限

市场联动套餐 100% 传导 + 0.01 元/kWh 加价、下限 0.40、上限 0.55。下表按 70/30 组合加权采购成本计：基准现货 0.4575 时 W = 0.7×0.40 + 0.3×0.4575 = 0.41725；现货降到 0.40 时，若中长期仍锁在 0.40，W = 0.40。

| 现货价 | 零售价 | 加权采购成本 | 度电净利 |
|---|---|---|---|
| 0.4575（基准） | 0.4675 | 0.41725 | 0.01725 |
| 0.40 | 0.41 | 0.40 | **−0.02300** |

下限 0.40 是零售价下限；现货 0.40 时公式价 0.41 高于下限，下限并未触发。即使按 0.41 销售，扣 0.40 采购、0.008 偏差与 0.025 运营后仍亏 2.3 分。**下限要按成本定，不能按市场价定**：本例现货 0.40 时的保本零售价为 **0.433**；若下限写成现货价，需按 P = αS + a ≥ 0.433 反推。

### 10.9 读法

- 套餐报价先算全成本，再看价差；毛价差不是利润；
- 组合能扛的现货涨幅可能远高于单张合同，不要用组合安全垫掩盖单客户风险；
- 负贡献客户要调价或退出，冲规模不等于增利润；
- 偏差是概率问题，用期望与分位数看，不要只看一个月；
- 担保额度与系数直接占资金，低价冲量会同时放大业务与担保需求；
- 市场联动的下限必须覆盖成本，且要写清是零售价下限还是现货价下限，否则低价时反而亏损；
- 所有数字都是 D 级合成数据，不能直接用于真实公司。

## 11. 合规、台账与红线

### 11.1 合规要点

- 套餐全部公开、可查询、可比较；
- 零售价格反映批发成本变化，不做低于成本的不正当竞争；
- 禁止阴阳合同、合同外返利、线下协议；
- 禁止虚假套餐、强制搭售、隐瞒偏差责任；
- 按规则披露批发/零售电量、价格、套餐签约与价差；
- 信用评价、履约保障、结算与退出按现行/草案要求执行。

### 11.2 台账

| 台账 | 内容 | 频率 |
|---|---|---|
| 套餐台账 | 套餐类型、价格、成本、披露记录 | 每次变更 |
| 客户台账 | 合同、曲线、信用、担保、欠费 | 月 |
| 采购台账 | 中长期/现货、覆盖比例、曲线 | 日/月 |
| 偏差台账 | 预测、实际、考核、分摊 | 月 |
| 担保台账 | 额度、形式、剩余、补缴 | 日 |
| 结算台账 | 账单、异议、追退补 | 月 |
| 退出预案 | 触发、用户清单、承接 | 季/触发 |

### 11.3 P0：影响正确性

| 检查项 | 通过标准 |
|---|---|
| 省份与业务地 | 规则、系数、保底价格来自本地 |
| 现行/草案 | 标注状态与生效日 |
| 套餐成本 | 批发+偏差+运营+资金+风险+利润 |
| 报价口径 | 电能量/公共科目、含税/不含税、线损、偏差与绿电归属已写清 |
| 采购结构 | 与零售合同曲线、期限匹配 |
| 偏差口径 | 免考带、考核价、责任分摊与省一致 |
| 保函公式 | 现行/草案分开算 |
| 结算时限 | 5/8/10 与 15/5 已核对 |
| 信用等级 | 与保障额度、保险限制一致 |
| 用户同意 | 合同、转让、退出有证据 |

### 11.4 P1：影响可维护性

| 检查项 | 通过标准 |
|---|---|
| 参数外置 | 价格、系数、考核标准不硬编码 |
| 版本管理 | 每次测算保存规则版本与输入快照 |
| 情景分析 | 至少现货/偏差/流失三组 |
| 可复现 | 同样输入得到同样净利 |
| 审计线索 | 每个数字能追到合同或账单 |
| 退出预案 | 用户承接、合同转让、保底衔接齐全 |

### 11.5 红线

- 不把草案写成已执行；
- 不用外省规则替代本省；
- 不做低于成本的报价；
- 不签阴阳合同、不做线下返利；
- 不隐瞒偏差责任与退出条款；
- 不挪用保证金；
- 不替售电公司承诺"一定赚钱"；
- 不篡改负荷、偏差与结算数据。

## 13. 常见问答

**Q1：售电公司说"一度电只赚几厘"，怎么判断真假？**
几厘是毛价差还是净利？要扣批发成本、偏差、运营、担保资金成本、坏账。本文算例毛价差 6.44 分、净利 3.14 分；2026 年广东行业平均净利约 0.39 分（B/C）。只报毛价差，等于没有回答。

**Q2：固定价套餐还能不能签？**
能，但要三件事：全成本定价、压力测试、限额对冲。单张工业合同在现货 0.49 元就保本，而基准现货 0.4575；现货上涨 7.10% 就吃掉利润。固定价不是不能做，是不能不留风险溢价。

**Q3：市场联动套餐是不是把风险都转给用户了？**
不完全是。用户承担价格波动，售电公司仍承担曲线偏差、用户流失、下限设置不当的风险。本例现货 0.40 时公式价 0.41，扣全成本后反而亏 2.3 分；保本零售价至少 0.433，且要写清下限是零售价还是现货价。

**Q4：保函要交多少？**
现行按"12 个月批发购电量 × 0.8 分"与"2 个月最大购电量 × 5 分"取大；2026 草案按"预计年售电量 × 1 分 × 系数（1–10），最低 200 万元"。30 亿 kWh 的例子里，现行 2,500 万元，草案系数 1/5/10 分别是 3,000 万/1.5 亿/3 亿元。草案不是现行法。

**Q5：客户跑了/公司退出，用户怎么办？**
用户转保底售电或代理购电，次月可选择新售电公司；价格、合同、发票、偏差责任都会变。现行/地方保底价格常见 1.5/2 倍代理购电价格，2026 草案拟按无法履约当月现货实时价格结算，正式稿未定。
