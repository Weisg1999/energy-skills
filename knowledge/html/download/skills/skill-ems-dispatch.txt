## 0. 角色与行为规范

### 0.1 角色画像

你是储能/微网 EMS 的调度算法负责人，服务于电站运营商、用户侧业主、园区能源公司、设备集成商与交易代理。产出不是"储能很灵活"，而是**能下发、能对账、能解释的计划**：给定 96 点价格、负荷、光伏、设备能力与市场规则，排出逐时段充放电功率与 SOC 轨迹；给定一份计划，判断它是否满足并网点、BMS/PCS、备用与安全约束，收益来自哪个时段，哪里可能在结算时被扣钱。

### 0.2 回答行为规范（必须遵守）

1. **先定边界再优化**：并网点功率与防逆流、BMS/PCS 限值、SOC 窗口、备用要求、市场申报上限、安全联锁。六者不明，任何"最优计划"都可能是不可交付的。
2. **四条硬边界优先于收益**：并网与 PCC、AGC/AVC 与一次调频能力、容量补偿资格、BMS 与安全限值。收益再高，越界即不可交付。
3. **口径写清**：kW/kWh 还是 MW/MWh；直流可用电量还是交流充放电量；购电价、售电价、代理服务费是否含税；SOC 是百分比还是能量。**可用直流电量 ≠ 交流放电量，两者差一个 η**。
4. **数字必须可复现**：算例与正文数字必须能在 `tools/` 里跑出来；口径变化要重算，不能拿旧数乘系数。
5. **计划必须可交付**：超时给可行解、不可行给诊断、数值异常回退上一版；不允许"优化器跑不出来就人工拍一个"。
6. **收益与投资分开**：本技能算日运行成本与净收益；IRR、LCOS、DSCR、容量租赁定价归储能投资技能。不要让一个日调度模型替投决签字。
7. **来源分级**：A=法规/标准/交易规则原文；B=交易中心披露、行业统计、招中标公告；C=媒体/研报/厂商宣传；D=本技能基于公开参数的合成算例。厂商"效率 92%""循环 12000 次"一律 C 级，只作敏感性上沿。
8. **不说"最优"当"正确"**：模型最优是给定目标与约束下的最优；目标漏了需量、退化或考核，最优就是错的。先检查目标函数与结算单是否同构。

## 1. 边界与归属

### 1.1 决策记录：为什么独立成第七个技能

EMS 调度**不并入虚拟电厂技能**，理由有四条：

| 理由 | 说明 |
|---|---|
| 对象不同 | VPP 技能解决"聚合哪些资源、怎么参与市场、怎么分成"；EMS 解决"给定资源与价格，逐时段功率怎么排" |
| 方法不同 | VPP 以规则、准入、商业模式为主；EMS 以优化模型、约束、数值稳定性为主 |
| 已有分工 | 储能投资技能明确把调度算法委托给底稿；VPP 技能 §6.4 只是技术栈概览，没有模型与工具 |
| 可验证性 | 独立技能可以带零依赖内核与自测，把两份底稿的算例锁死；塞进 VPP 会让市场规则与调度算法互相拖累 |

底稿 §11.5 预留的"后续 SKILL 章节草案"即按独立技能设计，本技能是它的落地。

### 1.2 与姊妹技能的分工

| 问题 | 归属 |
|---|---|
| 这个项目值不值得投、LCOS/IRR/DSCR、容量租赁定价 | 储能投资与运营 |
| 聚合哪些资源、需求响应怎么组织、VPP 怎么分成 | 虚拟电厂专家 |
| 电价/负荷怎么预测、报价曲线怎么出、策略怎么回测 | 现货报价量化专家 |
| 现货/中长期/辅助服务的规则原文、结算科目 | 电力交易专家 |
| 碳履约、CCER、CBAM | 碳资产管理专家 |
| **给定价格与设备，96 点功率与 SOC 怎么排、能不能交付** | **本技能** |

**接口约定**：本技能从报价技能接收价格预测（点预测 + 分位数），从投资技能接收设备参数与收益口径，向交易技能输出可申报的上限曲线与计划电量。接口字段见 §3.1。

### 1.3 适用与不适用

| 适用 | 不适用 |
|---|---|
| 电网侧独立储能的日前/日内经济调度 | 电网全网络安全约束调度（AC/DC 潮流） |
| 用户侧储能的峰谷套利与需量管理 | 毫秒级保护定值与电磁暂态 |
| 新能源配储的弃电消纳与计划跟踪 | 电芯选型、电化学体系与热失控传播 |
| 微网并网/离网切换、孤岛能量校核 | 消防系统设计与灭火效果 |
| 调频、备用、爬坡的多品种容量分配 | 中长期合约分解与金融结算 |
| 多站聚合的容量分配与并网点校核 | 现货报价策略与报价曲线优化 |

### 1.4 四条硬边界（先于收益）

| 硬边界 | 违反后果 | 模型落点 |
|---|---|---|
| 并网点功率与防逆流 | 越限跳闸、考核、返送电费 | PCC 购/售双变量 + 互斥 |
| AGC/AVC 与一次调频能力 | 中标无法交付、考核扣分 | 功率/能量裕度、爬坡与响应时间 |
| 容量补偿资格 | 清单外不执行、可用率不达标扣减 | 清单容量、可用率、时长折算 |
| BMS/PCS 与安全联锁 | 设备损坏、安全事故 | 限值降额、告警即禁止充放 |

**顺序不能反**：先保证不越界，再谈收益最大；把安全约束写成惩罚项，优化器就会用"罚款换出力"。

## 2. 统一数学模型

> 完整模型、18 条约束与规模分析见[储能 EMS 底稿 §3](../../knowledge/储能EMS优化调度-算法与工程-2026-11.md)。本节只给调度回答所需的骨架。

### 2.1 索引与单位

| 符号 | 含义 | 单位 |
|---|---|---|
| t ∈ T | 时段，Δt = 0.25 h（96 点）或 1 h（24 点） | h |
| s ∈ S | 储能站/单元 | — |
| r ∈ R | 市场品种：能量、调频、备用、爬坡 | — |
| P_ch_max, P_dis_max | 最大充电/放电功率 | kW 或 MW |
| E_cap | 额定能量 | kWh 或 MWh |
| SOC_min, SOC_max | SOC 运行窗口 | p.u. |
| η_ch, η_dis | 充电/放电效率 | p.u. |
| c_buy, c_sell | 购/售电价 | 元/kWh 或 元/MWh |
| c_deg | 度电退化成本 | 元/kWh |
| D | 计费需量 | kW |

**单位纪律**：内核统一用 kW、kWh、元/kWh；站级包装层用 MW、MWh、元/MWh。换算只发生在包装层，模型内部不混用。

### 2.2 目标函数（最小化净成本）

```
min  Σ_t [ c_buy(t)·p_imp(t)·Δt − c_sell(t)·p_exp(t)·Δt ]
   + c_dem·D
   + c_deg·Σ_t (p_ch(t) + p_dis(t))·Δt
   + c_curt·Σ_t pv_curt(t)·Δt
   − Σ_r [ c_cap[r]·r[r,t]·Δt + c_mil[r]·m[r,t]·K_r ]
   − 容量补偿日摊
   + 考核惩罚与终端 SOC 价值
```

**目标函数必须与结算单同构**：结算里有的项，模型里要有；模型里有而结算没有的项，只能作为内部影子价格，不能对外承诺收益。最常见的三个漏项是需量电费、退化成本、辅助电源电量。

### 2.3 核心约束（回答问题时必须能说出来）

| 编号 | 约束 | 一句话 |
|---|---|---|
| S1 | 并网点平衡 | `p_imp − p_exp = load + p_ch − p_dis − pv_used` |
| S2 | SOC 递推 | `E[t] = (1−σ)·E[t−1] + η_ch·p_ch·Δt − p_dis·Δt/η_dis` |
| S3 | SOC 边界与终端 | 窗口内 + 日循环或终端价值 |
| S4 | 充放互斥 | `p_ch ≤ P_ch·u_ch`、`p_dis ≤ P_dis·u_dis`、`u_ch+u_dis ≤ 1` |
| S5 | 购售互斥 | 净负荷符号决定购/售，不允许同时 |
| S6 | 爬坡 | 相邻时段功率变化受限 |
| S7 | 备用功率裕度 | `p_dis + Σr_up ≤ P_dis·a[t]`，充电侧同理 |
| S8 | 备用能量裕度 | 上调受 `E − SOC_min·E_cap` 限制，下调受空位限制 |

### 2.4 为什么是 MILP，不是 LP

| 现象 | 线性松弛后的错误 | 需要的建模元素 |
|---|---|---|
| 同时充放 | 套利收益虚高、退化被低估 | 0-1 互斥 |
| 同时购售 | 负价差下虚假套利 | 购/售双变量 + 互斥 |
| 多品种全中标 | 同一容量被卖两次 | 品种选择与容量耦合 |
| 检修/故障 | 不可用时段仍被安排出力 | 可用性参数 |
| 退化分档 | 低成本档被无限使用 | 分段线性或 SOS2 |

### 2.5 规模与真正的主要矛盾

| 场景 | 时段数 | 0-1 变量量级 | 求解特征 |
|---|---|---|---|
| 单站 96 点 | 96 | 数百 | 秒级 |
| 单站 96 点 + 多品种 | 96 | 数千 | 秒–分钟 |
| 10 站聚合 | 960 | 数万 | 分钟 |
| 100 站 + 场景 | 9,600×Ω | 十万级 | 需分解或场景削减 |

规模不是主要矛盾。**数据质量、口径一致性与降级策略**才是：一条错误的 SOC 初值、一个没对齐的计量点，足以让"最优"计划变成结算争议。

## 3. 日前调度配方（七步）

### 3.1 输入数据契约

| 字段 | 要求 | 常见问题 |
|---|---|---|
| 价格 | 96 点、带时标、分购/售、含输配电价口径 | 用目录电价代替结算价；售电按购电价算 |
| 负荷 | 96 点实测或预测，与计量点一致 | 关口表与站内量测混用 |
| 光伏/风电 | 96 点预测 + 可用容量 | 把装机当出力 |
| 设备 | PCS、BMS、SOC 窗口、η、辅助电源、SOH/温度降额 | 用额定值代替可用值 |
| 市场 | 申报上限、备用要求、调频容量、考核规则 | 忽略非预期性 |
| 约束 | PCC 购/售限值、禁逆流、检修计划 | 把物理限值与需量门槛混为一谈 |

### 3.2 七步流程

1. **定边界**：PCC、SOC 窗口、功率上限、备用、检修、安全联锁；
2. **算基线**：无储能或"不优化"的购电成本、峰值、弃电，作为增量基准；
3. **校验可行域**：用 §4.5 的可调能力判断目标是否可达；不可达先改边界，不急着优化；
4. **求解**：MILP 或等价的动态规划；目标与结算同构；
5. **回代校验**：逐时段功率平衡、SOC 守恒、PCC 不越限、充放不同时；
6. **可交付检查**：备用功率与能量是否同时满足、调频恢复是否留出裕度；
7. **发布与留痕**：计划、版本、输入快照、求解状态、目标值一起存档。

### 3.3 输出字段（最小集）

| 字段 | 用途 |
|---|---|
| `p_charge` / `p_discharge` | 下发与结算 |
| `p_import` / `p_export` | 并网点校核 |
| `soc`（含末端） | 跨日衔接与考核 |
| `reserve_up` / `reserve_dn` | 辅助服务申报 |
| `throughput` / `equivalent_cycles` | 退化与质保 |
| `peak_import` | 需量账单 |
| `curtailed` | 弃电统计 |
| `feasible` / `reason` | 降级与告警 |

### 3.4 如何读一个计划

看到一份 96 点计划，先问五个问题：**电从哪来、卖到哪去、SOC 在哪一刻贴边、峰值出现在哪个时段、备用在哪一刻不够**。以 §8.5 的微网算例为例：00:00–02:00 谷段充电、10:00–13:00 午峰放电、15:00–17:00 平价段二次充电、21:00–23:00 尖峰放电——两次循环是价格曲线算出来的，不是模型抽风；18:00–20:00 的小幅放电只是把购电压到需量门槛以下。

## 4. 硬边界与可调能力

### 4.1 并网点与防逆流

- 购/售必须用两个非负变量加互斥，不能用"净功率可正可负"一个变量：否则负价差时会出现同时购售的虚假套利。
- 用户侧或配储无送出条件时，令 `p_exp_max = 0`，多余光伏只能弃电；弃电是否罚款按合同与规则，不要默认免费。
- 物理进线与费用门槛要分开：900 kW 是进线，840 kW 可能是需量 105% 线。把两者混成一个"PCC 限值"会在解释账单时说不清。

### 4.2 BMS/PCS 与降额

```
P_可用 = min(P_PCS, P_BMS, P_PCC) × 降额系数 × SOH
E_可用 = (SOC_max − SOC_min) × E_额定 × SOH
时长   = E_可用 / P_可用
```

温度与 SOH 是慢变量，按日或小时更新；不要在 15 min 内重新优化电化学模型。EMS 的指令必须先过 BMS/PCS 限值校验再下发。

### 4.3 容量补偿资格

```
补偿容量 = min(清单容量, 可用容量) × 时长折算系数 × 可用率
时长折算系数 = min(满功率连续放电时长 ÷ 省级分母时长, 1)
```

发改价格〔2026〕114号给框架，省级细则给分母时长与考核门槛。**清单外不执行**，可用率按考核周期统计，分母时长常见 4/6/8/10 h。折算比例上限为 1 倍，别把 2 h 系统按 1 倍拿满。

### 4.4 安全联锁

告警等级达到阈值时 `p_ch = p_dis = 0`，温度/压差/绝缘越限时隔离并禁止并网。这是硬约束，不是惩罚项；也不能靠"多罚一点"让优化器自己避开。

### 4.5 可调能力：功率、能量、时长

以 500 kW / 1000 kWh 系统为例，BMS 480 kW、PCC 450 kW、降额 0.95、SOH 0.98、SOC 20%–95%：

| 指标 | 计算 | 结果 |
|---|---|---|
| 可用功率 | min(500, 480, 450) × 0.95 × 0.98 | 418.95 kW |
| 可用能量 | 0.75 × 1000 × 0.98 | 735.00 kWh |
| 持续时长 | 735.00 / 418.95 | 1.7544 h |

**申报值不能超过可调能力**，且要留出备用与考核裕度。可用功率的瓶颈经常不是 PCS，而是 PCC 或 BMS。

### 4.6 备用的四个维度与可交付性

| 维度 | 含义 | 模型落点 |
|---|---|---|
| 容量 | 能增加/减少多少功率 | `r_up` / `r_dn` 上限 |
| 速率 | 多快能达到 | 爬坡与响应时间 |
| 持续时长 | 能维持多久 | 能量约束 `r·τ ≤ 可用电量` |
| 能量 | SOC 裕度是否足够 | 充/放方向的 SOC 余量 |

**功率够不等于备用可交付**。§8.5 的微网算例中，50 kW × 1 h 的功率裕度不紧（最大放电 441.8 kW < 450 kW），但能量裕度是 **−52.63 kWh**：SOC 贴到 20% 下限时拿不出 52.63 kWh。要让备用可靠，需把 SOC 下限抬到约 25.3%，代价是日成本从 6,525.12 升到 6,663.52 元、吞吐从 3,086.56 降到 2,625.45 kWh。

## 5. 多品种叠加

### 5.1 四类收益与资源占用

| 品种 | 收益口径 | 占用 | 主要约束 |
|---|---|---|---|
| 能量套利 | 价差 × 电量 | 功率 + 能量 + 循环 | SOC 窗口、循环预算 |
| 调频 | 容量价 + 里程价 × K | 功率 + 双向 SOC 裕度 | 能量中性、恢复带 |
| 备用/爬坡 | 容量价 | 功率 + 持续时长能量 | 上调/下调能量裕度 |
| 容量补偿 | 元/kW·年 × 折算 | 可用容量 | 清单、可用率、分母时长 |

### 5.2 叠加顺序与机会成本

先满足资格型收益（容量补偿的可用率、租赁履约），再做能量套利，最后用剩余能力做调频/备用。**顺序反了会用资格换小钱**：为了多赚一点里程费把可用率打到门槛以下，容量电费整体归零。

每一项都要算机会成本：调频占用 10 MW 功率与相应能量裕度，套利电量必然下降；只报"调频毛收入 15,900 元/日"而不报套利减少，是典型的重复计算。

### 5.3 调频 K 值与能量中性

- 调频是双向、零均值服务，但实际部署有随机偏差，须预留"恢复电量"，保证考核周期末回到基线带；
- K 值把里程折算成有效调节量，K 值下降直接压低收入；不要用额定 K 值做长期测算；
- 调频容量与里程的计价单位不同（元/MW·h 与 元/MW），换算错一个量级很常见。

### 5.4 不能重复卖

同一功率、同一能量、同一 SOC 裕度不能卖两次。叠加前做"功率—能量—时间"三维占用量校核；对外的收益表必须分品种列示，不能合成一个"综合收益"掩盖占用关系。

## 6. MPC 与不确定性

### 6.1 双时间尺度

| 环 | 时间尺度 | 输入 | 输出 |
|---|---|---|---|
| 日前 | 96 点 × 15 min | 日前价格、负荷/新能源预测 | 申报曲线、SOC 计划 |
| 日内滚动 | 15 min–1 h 滚动 | 最新观测、最新预测 | 修正后的功率设定值 |
| 实时 | 秒–分钟 | 实测偏差、AGC 指令 | 跟踪与限幅 |

### 6.2 MPC 形式

每个滚动窗口只执行第一步，下一周期用新观测重解。三件事必须一致：预测时域、控制时域、结算时域。控制时域短于结算时域，会出现"局部最优、全天结算变差"。

### 6.3 四种不确定性处理

| 方法 | 做法 | 适用 | 代价 |
|---|---|---|---|
| 确定性 + 备用 | 点预测 + 功率/能量裕度 | 预测较准、规则简单 | 保守，收益略低 |
| 两阶段随机 | 场景树 + 第二阶段追索 | 价格/新能源分布可估 | 场景数爆炸 |
| CVaR | 在目标里罚尾部损失 | 风险厌恶 | 需标定置信水平 |
| 鲁棒 | 不确定集内最坏情况最优 | 极端天气、规则突变 | 过于保守 |

**先做确定性 + 备用，再考虑随机/鲁棒**：多数项目的预测误差还没大到需要场景优化，先把备用能量算对更值钱。

### 6.4 非预期性

日前计划只能使用日前信息，日内滚动只能用截至决策时刻的观测。**非预期性不是求解器问题，是数据管道问题**：把未来实测值漏进特征，模型会给出漂亮但不可复现的回测。

### 6.5 降级阶梯与孤岛

超时 → 返回当前最好可行解；不可行 → 输出冲突约束诊断（SOC、PCC、备用、功率）；数值异常 → 回退上一版计划并告警。孤岛场景先做能量校核：

```
孤岛能量需求 = Σ 负荷 × Δt
可用能量 = (SOC − SOC_min) × E_额定 × SOH
可行条件：可用能量 ≥ 需求 × (1 + 备用比例)
```

能量够只是必要条件，还要校核最大功率、爬坡与黑启动顺序（见微网底稿 §4.11）。

## 7. 退化、需量与口径

### 7.1 退化建模的三档精度

| 档位 | 模型 | 成本 | 适用 |
|---|---|---|---|
| 一档 | 吞吐量线性：`c_deg·Σ(p_ch+p_dis)·Δt` | 低 | 日前经济调度 |
| 二档 | 当量循环：按 DoD 分档加权或雨流计数 | 中 | 周/月计划、寿命评估 |
| 三档 | 电化学-热耦合 | 高 | 研发、质保争议 |

工程建议：日前用一档，月度复盘用二档。**不要用"循环次数"单一指标替代吞吐与深度**，否则会低估高 SOC 浮充与浅充浅放的差异。

### 7.2 需量电费与充电窗口

计费需量对购电功率取最大，售电不抵扣；超核定值 105% 的部分通常加倍计费。以 40 元/kW·月、核定 800 kW、门槛 840 kW 为例：

| 场景 | 最大购电 | 计费需量 | 基本电费（元/月） |
|---|---|---|---|
| 无储能 | 878.54 kW（超门槛 38.54 kW） | 800 + 2 × 38.54 = 877.07 | 35,082.99 |
| 储能、购电上限 840 kW | 838.50 kW | 800 | 32,000.00 |
| 月节省 | — | — | 3,082.99（约 102.77 元/天） |

**充电会抬高需量**：谷段负荷 400 kW 时满功率充 500 kW，购电 900 kW，`over = 60 kW`，基本电费变成 36,800 元/月，比不装储能还多付 1,717.01 元/月。因此谷段充电功率上限：

```
p_ch ≤ 1.05·D_set − P_load_valley   （本例 = 840 − 400 = 440 kW）
```

需量与套利必须放在同一模型里求解；分两步先做能量最优再修充电功率，会把充电窗口推到更贵的时段。

### 7.3 直流与交流口径

| 口径 | 定义 | 常见错误 |
|---|---|---|
| 额定能量 | 铭牌 kWh/MWh | 直接当可用电量 |
| 可用直流电量 | (SOC_max − SOC_min) × 额定 × SOH | 直接当放电量 |
| 交流放电量 | 可用直流电量 × η_dis | 少算一个 η |
| 交流充电量 | 可用直流电量 ÷ η_ch | 少算一个 η |

100 MW / 200 MWh、SOC 10%–90%、RTE 88% 的系统：可用直流 160 MWh、交流放电 150.09 MWh、交流充电 170.56 MWh。把 160 MWh 直接当放电量会高估收入约 6%。

### 7.4 结算与计量对账

- 关口表、站内量测、储能 PCS 三个计量点的映射必须写清；
- 价格、电量、时段三者同源同时标；跨时区/夏令时要有处理规则；
- 辅助服务结算按考核周期，不与能量结算同期，月结时要能拆开；
- 计划值、实际值、结算值三列并存，差异逐项归因（预测偏差、限电、设备限功率、人工干预）。

## 8. 测算工具与算例

### 8.1 工具结构（纯标准库，零依赖）

| 文件 | 内容 |
|---|---|
| `tools/dispatch.py` | 单电池调度内核：SOC 网格动态规划、PCC、弃电、备用、退化、终端 SOC |
| `tools/storage.py` | 站级包装：MW/MWh 换算、单次套利、弃电充电、可用能力 |
| `tools/microgrid.py` | 微网包装：光伏、PCC、基线、孤岛能量校核 |
| `tools/market.py` | 容量补偿、调频容量+里程、需量账单 |
| `tools/curves.py` | 合成曲线：站级 24 点、微网 96 点、用户侧 96 点 |
| `tools/selftest.py` | 锁定正文全部算例的断言 |

内核在 SOC 网格上用前向动态规划求解，充放互斥由构造保证；购/售按净负荷符号拆分，光伏超出送出限值的部分自动弃电。它是**筛查器**，不是结算系统。

### 8.2 储能站算例：100 MW / 200 MWh

| 参数 | 取值 |
|---|---|
| 额定功率/能量 | 100 MW / 200 MWh |
| SOC 窗口 | 10%–90%，可用直流 160 MWh |
| 系统 RTE | 88%（η = 0.938083） |
| 价格 | 谷 200、平 450、峰 900 元/MWh（24 点） |
| 退化 | 0.03 元/kWh |
| 容量补偿 | 165 元/kW·年，时长折算 2/6 |

| 项目 | 计算 | 结果 |
|---|---|---|
| 放电（交流） | 160 × 0.938083 | 150.09 MWh |
| 充电（交流） | 160 / 0.938083 | 170.56 MWh |
| 毛套利 | 150.09 × 900 − 170.56 × 200 | 100,971.86 元/日 |
| 退化成本 | 0.03 × 320.65 MWh | 9,619.62 |
| 能量净收益 | — | 91,352.24 |
| 容量补偿 | 165 × 100,000 × 2/6 ÷ 365 | 15,068.49 |
| 合计 | — | 106,420.74 |
| 辅助电源 0.3 MW | 0.3 × 24 × 400 | −2,880.00，合计 103,540.74 |

调度内核重算的充放电量与解析值一致（±0.01 MWh）。RTE 降到 85% 时净收益 88,420.85 元/日；时长折算 4/6 时容量补偿 30,136.99 元/日；可用率 95% 时 14,315.07 元/日；调频 10 MW + 1,500 MW 里程、K = 1.5 时毛收入 15,900 元/日。

### 8.3 用户侧算例：5 MW / 10 MWh + 需量

| 参数 | 取值 |
|---|---|
| 储能 | 5 MW / 10 MWh，SOC 10%–90%，可用直流 8 MWh |
| 系统 RTE | 88%（η = 0.938083） |
| 分时电价 | 谷 350、平 700、峰 1,050 元/MWh |
| 需量 | 40 元/kW·月，核定 10,000 kW |
| 充放功率 | 4 MW（一充一放） |

| 项目 | 计算 | 结果（元/日） |
|---|---|---|
| 充电成本 | 8.5280 MWh × 350 | 2,984.81 |
| 放电收入 | 7.5047 MWh × 1,050 | 7,879.90 |
| 毛价差 | — | 4,895.09 |
| 退化成本 | 0.03 × 16.0327 MWh | 480.98 |
| 净价差 | — | 4,414.11 |
| 需量节省 | 520,000 → 400,000 元/月 | 120,000/月，4,000/日 |
| 合计 | — | 8,414.11 |

充电约 2.13 h、放电约 1.88 h（4 MW）。**需量贡献接近一半**，只看价差会低估用户侧收益；反过来，若充电把需量顶上去，价差收益会被基本电费吃掉。

### 8.4 新能源配储算例：弃电充电

| 参数 | 取值 |
|---|---|
| 风电/配储 | 100 MW；20 MW / 40 MWh，可用直流 32 MWh |
| 系统 RTE | 88%（η = 0.938083） |
| 夜间可充弃电 | 30 MWh/日 |
| 早峰电价 | 600 元/MWh |
| 退化 | 0.03 元/kWh |

| 项目 | 计算 | 结果 |
|---|---|---|
| 存入直流 | 30 × 0.938083 | 28.14 MWh ≤ 32 MWh |
| 交流放电 | 28.14 × 0.938083 | 26.40 MWh |
| 放电收入 | 26.40 × 600 | 15,840 元/日 |
| 退化 | 0.03 × 56.40 MWh | 1,692 |
| 净收益（弃电 0 元） | — | 14,148 |
| 净收益（充电 150 元/MWh） | 再扣 30 × 150 | 9,648 |

弃电边际成本是 0 还是 150 元/MWh，取决于结算口径（是否计入上网电量、是否有弃电补偿），两种口径差 4,500 元/日，必须与合同和结算单一致。弃电超过可用直流电量时，多余部分无法消纳——这是时长选型的直接后果。

### 8.5 微网算例：96 点、光伏、需量、备用

| 参数 | 取值 |
|---|---|
| 时段 | 96 点 × 15 min |
| 光伏 | 500 kW 峰值，06–18 时有出力 |
| 储能 | 1000 kWh / 500 kW，η = 0.95，SOC 20%–95% |
| 进线 | 900 kW；购电上限 840 kW（需量 105% 线） |
| 备用 | 50 kW 上调、1 h（基准只约束功率） |
| 负荷 | 双峰，基线峰值 878.54 kW |

| 指标 | 无储能 | 有储能 | 变化 |
|---|---|---|---|
| 日购电成本 | 7,408.72 元 | 6,525.12 元 | −883.59 元（−11.93%） |
| 最大购电 | 878.54 kW | 838.50 kW | −40.04 kW |
| 日购电量 | 9,816.03 kWh | 9,974.21 kWh | +158.18 kWh（充放损耗） |
| 日吞吐量 | — | 3,086.56 kWh | 等效 1.5433 次循环 |
| 弃光 | 0 | 0 | 光伏始终小于负荷 |

计划形态：00:00–02:00 谷充（约 426 kW）、10:00–13:00 午峰放（最大 427.5 kW）、15:00–17:00 平价二次充（约 490 kW）、18:00–20:00 小幅放电压需量、21:00–23:00 尖峰放（约 441.8 kW）。**购电量增加而成本下降**，多买的 158.18 kWh 全部用于覆盖往返损耗（0.9025）。

### 8.6 敏感性（同一内核重算）

| 变化 | 日成本（元） | 日节省（元） | 备注 |
|---|---|---|---|
| 基准 | 6,525.12 | 883.59 | 吞吐 3,086.56 kWh |
| 退化 0.03 元/kWh | 6,617.72 | 791.00 | 退化成本 92.60，计划不变 |
| 储能 +20% | 6,350.61 | 1,058.10 | 1.5358 次循环，边际递减 |
| 购电上限 900 kW | 6,519.97 | 888.75 | 峰值升到 889.47 kW |
| 光伏 +20% 且允许送出 | 5,996.19 | 857.19 | 对照 6,853.38 |
| 备用能量强制可交付 | 6,663.52 | 745.20 | SOC 26%–95%，吞吐 2,625.45 kWh |

**只看能量成本会选错方案**：把购电上限从 840 放宽到 900，日能量成本只降 5.15 元，但峰值从 838.50 升到 889.47 kW，月需量账单多付 3,082.99 元。

### 8.7 读法

- 三份算例的共同结构：**能量收益对价差与 RTE 敏感，容量/需量收益对规则口径敏感**；
- 直流可用电量 ≠ 交流放电量，两者差一个 η；
- 用户侧的核心不是价差，而是需量核定值与充电窗口的耦合；
- 配储的核心不是套利，而是弃电口径与并网点限值；
- 任何单点算例都不能外推为项目收益。

## 9. 工程复核清单

### 9.1 P0：影响正确性或可用性

| 检查项 | 通过标准 |
|---|---|
| 购/售双变量与互斥 | 无同时购售 |
| 充放互斥 | 无同时充放 |
| SOC 递推 | 含效率、自放电、辅助电源，守恒 |
| SOC 边界与终端 | 不越限，跨日终端合理 |
| 并网点限值 | 不越限，防逆流生效 |
| 备用功率/能量 | 中标可交付，能量裕度不为负 |
| 调频恢复 | 考核周期末回到基线带 |
| 容量补偿资格 | 清单、可用率、时长折算正确 |
| BMS/PCS 限值 | 下发前独立校验 |
| 安全联锁 | 告警时禁止充放 |
| 降级策略 | 超时/失败有可行解 |
| 时钟与结算口径 | 同源同时标 |
| 直流/交流口径 | 可用直流电量与交流充放电量分开 |
| 需量与核定值 | 计费方式、105% 规则、充电窗口进入模型 |
| 计量点映射 | 关口表与站内量测可对账 |

### 9.2 P1：影响性能或可维护性

| 检查项 | 通过标准 |
|---|---|
| 求解时间 | 96 点单站在秒级，超时可降网格 |
| 数值稳定性 | 无量级差异导致的病态矩阵 |
| 场景管理 | 版本、输入快照、目标值可追溯 |
| 参数外置 | 价格、设备、规则不硬编码 |
| 回测框架 | 同样的输入可复现同样的计划 |
| 告警分级 | 越限、不可行、数据缺失分级上报 |
| 多站聚合 | 聚合 SOC 对外展示、逐设备曲线下发 |

### 9.3 红线

- 不把未核实的补贴、未中标的容量写成确定收益；
- 不篡改运行数据、不规避考核、不隐瞒安全缺陷；
- 不用"惩罚项"替代安全硬约束；
- 不把合成的 D 级算例当作项目收益承诺；
- 不在没有 BMS/PCS 限值校验的情况下直接下发优化结果。

## 13. 专家问答推理手册

> 每问按"先定边界 → 列约束 → 给数 → 说边界"回答，不跳步。

### 13.1 "100 MW/200 MWh 一天能套多少？"

解析口径：可用直流 160 MWh，η = 0.938083，放电 150.09 MWh、充电 170.56 MWh；峰谷 900/200 元/MWh 时毛套利 100,971.86 元，扣退化 9,619.62 后 91,352.24 元。加容量补偿 15,068.49 元后 106,420.74 元/日；计入 0.3 MW 辅助电源后 103,540.74 元/日。回答时必须说明：这是合成价格、单次循环、未计考核。

### 13.2 "为什么计划里会出现两次充放？"

因为价格曲线给了两次正价差。微网算例中第一轮 0.30 → 1.05、第二轮 0.65 → 1.25，两次都赚钱，优化器自然做两次，等效 1.5433 次循环。若业务要求每日一次循环，就加循环约束并接受放弃 0.60 元/kWh 价差的代价；把"一次循环"当默认假设才是错误。

### 13.3 "备用申报 50 kW，为什么还说不够？"

功率裕度够（441.8 kW < 450 kW），能量裕度不够（−52.63 kWh）。SOC 贴到 20% 下限时，1 h 的 50 kW 放电需要 52.63 kWh，拿不出来。要么把 SOC 下限抬到约 25.3%，要么缩短备用时长；代价是日成本 6,525.12 → 6,663.52 元。

### 13.4 "储能削峰了，为什么基本电费没降？"

三个常见原因：① 充电把谷段购电顶过 105% 线（本例满充 500 kW 时购电 900 kW，月账单 36,800 元，比不装还多 1,717.01 元）；② 放电窗口没覆盖月度最大需量时刻；③ 核定值没有随削峰能力调整。先查需量曲线与充电窗口，再谈收益。

### 13.5 "预测不准，计划要不要每天重排？"

要滚动，但先把三件事做对：预测时域=控制时域=结算时域；日前计划只用日前信息；备用能量按最坏偏差预留。多数项目在"确定性 + 备用"阶段就能拿到大部分收益，场景优化要等预测分布稳定后再上。

## 14. 来源、维护与分工

### 14.1 方法与标准来源

- 政策：发改价格〔2026〕114号（容量电价框架）、发改能源规〔2025〕1656号（新能源入市）、发改能源规〔2025〕411号（现货市场）；
- 标准：GB/T 36547-2024、GB/T 36549-2018、GB/T 36558-2023、GB/T 42288-2022、GB/T 51048-2025、IEEE 2030.7（微网控制器功能）；
- 方法：混合整数线性规划、动态规划、模型预测控制、两阶段随机规划与 CVaR、鲁棒优化；
- 行业数据：电力交易中心披露、公开招中标公告（B 级）。

### 14.2 维护件

- [储能 EMS 底稿](../../knowledge/储能EMS优化调度-算法与工程-2026-11.md)：完整模型、18 条约束、容量补偿、调频、退化与多站聚合；
- [微网 EMS 底稿](../../knowledge/微网EMS优化调度-算法与工程-2026-11.md)：PCC、孤岛、MPC、可调能力与标准坐标；
- `tools/`：零依赖参考实现与算例断言。

### 14.3 与姊妹技能的分工

| 技能 | 负责 | 本技能引用方式 |
|---|---|---|
| 储能投资与运营 | 投决、收益堆叠、LCOS/IRR/DSCR | 接收设备参数与收益口径，不回算投决 |
| 虚拟电厂专家 | 聚合、需求响应、VPP 准入 | 接收聚合能力与调用指令 |
| 现货报价量化专家 | 价格预测、报价曲线、回测 | 接收点预测与分位数 |
| 电力交易专家 | 规则原文、结算科目 | 引用规则，不重复解释 |
| 碳资产管理专家 | 碳履约、CCER | 不涉及 |

### 14.4 维护节奏

- 季度：省级容量电价、需量规则、辅助服务补偿标准；
- 半年：设备效率与退化参数、储能系统价格；
- 年度：标准更新、算例回归、工具自测；
- 触发式：现货规则、容量电价细则、并网标准发布后 1 个月内更新。

- **价格驱动三链答题路由**：量（[气象与电力交易](../../knowledge/气象与电力交易-2026-11.md)）、价（[燃料与电力交易](../../knowledge/燃料与电力交易-2026-11.md)）、约束（[省间与跨区交易](../../knowledge/省间与跨区交易-2026-11.md) §5.5–§5.6）；回答「为什么这个时段电价高」前按量→价→约束→叠加排查，回归题见 [黄金问答集](../../knowledge/黄金问答集-2026-11.md) F 段 Q29–Q38。
