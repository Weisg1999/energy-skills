0. 一页看懂

0.1 三句话

  • 电不按合同路径走，按阻抗走：潮流分布由网络电抗决定，不由"谁卖给谁"决定。这是阻塞价差的物理根源。
  • 节点价 = 能量分量 + 阻塞分量 + 网损分量：参考节点的能量价全网共享，阻塞和网损把各节点价格拉开。没有阻塞、忽略网损时，全网一个价。
  • 出清价 ≠ 结算价：国内现货普遍按节点价出清（安全约束经济调度 SCED），但结算侧有的省按节点、有的省按统一加权或分区口径。报价前必须先确认所在省的结算口径，否则预测对了出清价也算错了收益。

0.2 关键数字与口径

1. 物理底座：潮流为什么这样流

1.1 直流潮流近似

高压输电网电阻远小于电抗（R ≪ X），电压幅值近似恒定，潮流主要由相角差驱动。直流（DC）潮流把交流潮流线性化：

P_ij = (theta_i - theta_j) / x_ij
  • P_ij：节点 i 到 j 的有功潮流（MW 或标幺）
  • theta_i：节点 i 的电压相角
  • x_ij：线路 i-j 的电抗（标幺）

每个节点满足功率平衡（KCL）：注入 = 流出之和。整个网络是一组线性方程，给定注入就能解出各线路潮流。

1.2 并联路径按电抗反比分流

两点之间若有多条路径，潮流按路径总电抗的反比分配，而不是平均分配，更不是按合同分配。

  • 路径 A 电抗 0.1、路径 B 电抗 0.3 → A 承担 0.3/(0.1+0.3) = 75%，B 承担 25%。
  • 这意味着：即使你"买的是隔壁电厂的电"，潮流也可能绕远路经过一条重载线路，把它压到限额。

1.3 环流与平行路径问题

环网中，一笔交易会沿所有并联路径分流。某条线路可能因为别人的交易而过载——这就是平行路径潮流（loop flow），也是阻塞管理难按"谁引起谁付费"简单切分的原因。省间交易里的穿越潮流同理，见 省间与跨区交易。

2. 节点电价分解：能量 + 阻塞 + 网损

2.1 定义

节点边际电价（LMP）= 在该节点增加 1 MW 负荷、系统重新最优调度后的边际供电成本。它天然分解为三部分：

LMP_i = lambda_energy + congestion_i + loss_i
  • 能量分量 lambda_energy：参考节点的边际能量价，全网相同。
  • 阻塞分量 congestion_i：输电约束被压限时，为守住限额而再调度产生的额外成本，按节点对约束的灵敏度（PTDF）分摊。
  • 网损分量 loss_i：该节点注入功率引起的边际网损成本。

2.2 参考节点

出清模型选一个平衡节点（reference / slack bus）作为能量分量的锚。参考节点本身的阻塞分量定义为零，其他节点的阻塞分量是相对它的差。换参考节点不改变任意两节点的价差，只改变各节点价格的"绝对锚"。

2.3 什么时候全网一个价

  • 没有任何输电约束压限（阻塞分量全为 0）；
  • 且忽略网损（或网损因子全网一致）。

此时 LMP 退化为统一系统边际价。国内部分省份结算侧采用的"统一加权价"，可以理解为对节点价做了事后平均，不是出清时没有阻塞。

3. 阻塞与断面约束

3.1 断面与输电限额

  • 断面：一组输电线路的集合，潮流之和受一个稳定限额约束（如"某送出断面 ≤ 8,000 MW"）。限额常由热稳定、暂态稳定、N-1 校核中最严者决定。
  • N-1：任一线路/变压器断开后，剩余网络不能过载。因此正常运行时的断面限额往往低于物理热极限，留出事故裕度。
  • 阻塞不一定发生在单条线路，也可能发生在整个断面；断面约束压限时，断面内各节点价格被一起拉开。

3.2 阻塞如何改写出清

无约束时，便宜机组多发、贵机组少发。一旦某断面压限：

  1. 便宜侧机组被压低出力（back down），即使它报价低；
  2. 贵侧机组被抬高，承担本可由便宜机组供的负荷；
  3. 系统总成本上升，上升的边际成本就是阻塞分量。

3.3 阻塞租金

阻塞租金 = sum(LMP_load × 负荷) - sum(LMP_gen × 出力)
         = sum(约束影子价格 × 约束限额)
  • 阻塞租金是负荷侧多付、电源侧少收形成的" merchandising surplus"。
  • 在成熟市场，这部分通过金融输电权（FTR）/ 输电权拍卖分配或返还；国内输电权机制仍在演进，具体以各省规则为准（见 §10 待核实）。
  • 阻塞租金为正，说明存在被压限的约束；它的大小直接反映"该断面值多少钱"。

3.4 日前与实时阻塞

日前出清按预测潮流校核断面，实时按实际潮流再校核。预测偏差、机组跳闸、新能源骤变都会让实时阻塞与日前不同，产生日前-实时价差。这也是 量化报价与交易风控 里两结算差异桥的物理来源之一。

4. 网损：边际网损不是平均网损

4.1 两个口径

  • 平均网损率：网损电量 ÷ 供电量，是个统计比例（如 5%）。
  • 边际网损：某节点多注入 1 MW 引起的网损增量，随潮流分布变化，可正可负、可大于平均网损率。

节点价里的网损分量用的是边际网损，不是平均网损率。重载断面附近，边际网损可能远高于平均值；轻载或反送潮流的节点，边际网损甚至为负。

4.2 网损因子

工程上常用网损因子（loss factor）把节点注入折算到参考节点：

等效注入_i = 注入_i × (1 - 边际网损因子_i)

出清模型据此修正节点平衡。不同省份/市场是否显式建模网损、网损因子如何发布，口径不一，报价前需确认（见 §10）。

5. 国内实践：出清侧与结算侧分开看

5.1 出清侧

国内现货试点普遍采用安全约束机组组合（SCUC）+ 安全约束经济调度（SCED），出清按节点价形成，模型内含断面/线路约束与网损处理。这是"节点价出清"的机制基础，见 101 问 B 出清结算。

5.2 结算侧（分省，必须查证）

结算口径与出清口径可以不同，常见三类：

结算口径含义对主体的影响
节点价结算按主体所在节点 LMP 结算选址直接决定收益，阻塞价差真实落袋
统一加权价全省节点价按电量加权平均后结算单主体无法独享节点价差，选址影响被稀释
分区价若干价区，区内统一介于两者之间，跨区价差保留

口径纪律：具体某省采用哪一类、发电侧与用户侧是否一致、新能源/储能是否有特殊结算口径，逐省不同且会调整。本文不锁定省份结论，查证入口见 省级市场状态表 与各省模块（如 山东、山西、广东、蒙西）。回答"某省储能按什么价结算"时，先确认结算口径，再谈价格水平。

5.3 与海外对照

海外成熟市场（PJM、ERCOT、CAISO、NEM 等）节点价/分区价 + FTR 是标配；阻塞管理四法（节点价、分区价、再调度、金融输电权）的横向对照见 电力系统经济学原理 与 101 问 A。海外储能缓解拥堵的接入优先见 海外并网与合规。

6. 价差交易与对冲含义

6.1 节点价差是信号，不是套利保证

  • 节点价差反映阻塞的位置与强度：长期高价差节点意味着断面紧张，适合布局储能/需求响应缓解阻塞；但结算口径若是统一加权价，单主体吃不到这个价差。
  • 价差会随网架加强、电源投产、规则调整而收敛，不能把当前价差当永久收益。

6.2 中长期合约的曲线分解

中长期合约通常约定电量与价格，但现货结算要落到节点 + 时段曲线。合约分解到哪个节点、哪条曲线，决定了合约与现货的偏差暴露。分解口径见 电力交易专家 与合同条款库。

6.3 金融输电权（FTR）

FTR 是对"两点价差"的金融头寸，用于对冲阻塞引起的价差风险。国内输电权/金融输电权机制仍在试点与演进，是否可用、如何拍卖、是否覆盖日前-实时价差，以各省现行规则为准（§10 待核实）。

6.4 负价与阻塞的关系

负价常出现在新能源大发、送出断面压限的节点：便宜电源被阻塞"困"在局部，供过于求把节点价压到负。负价复盘见 合成案例复盘库 案例 1（山东午间负价）。负价是阻塞 + 供给过剩的合成结果，不是单纯"电太多"。

7. 合成算例（D 级）：三节点阻塞价差手算

7.1 网络与参数

三节点环网，电抗标幺：A-B = 0.1，B-C = 0.1，A-C = 0.2。

节点角色边际成本（元/MWh）出力上限（MW）
A便宜电源200300
C贵电源400300
B负荷 300 MW——

输电约束：线路 A-B 潮流 ≤ 150 MW。忽略网损。

7.2 潮流分布（并联分流）

A 供 B 有两条路径：A-B 直连（电抗 0.1）与 A-C-B（0.2+0.1=0.3）。直连承担 0.3/(0.1+0.3) = 75%，绕行承担 25%。

C 供 B 也有两条：C-B 直连（0.1）与 C-A-B（0.2+0.1=0.3）。C-B 直连承担 75%，经 A-B 的绕行承担 25%（方向 A→B）。

因此线路 A-B 潮流：

Flow_AB = 0.75 × g_A + 0.25 × g_C

7.3 无约束 vs 有约束出清

  • 无约束：全由便宜电源 A 供，g_A=300、g_C=0 → Flow_AB = 225 MW > 150，压限。
  • 有约束：g_A + g_C = 300，且 0.75 g_A + 0.25 g_C = 150。代入 g_C = 300 − g_A：
0.75 g_A + 0.25 (300 - g_A) = 150
0.5 g_A + 75 = 150  ->  g_A = 150, g_C = 150

便宜电源 A 被压到 150 MW，贵电源 C 抬到 150 MW。

7.4 节点价（再调度边际成本法）

节点价 = 在该节点 +1 MW 负荷、守住约束的最便宜再调度成本。

  • 节点 A：+1 MW 由 A 本地多发，注入- withdrawal 同点，不改潮流 → 成本 200。
  • 节点 C：+1 MW 由 C 本地多发，同样不改 A-B 潮流 → 成本 400。
  • 节点 B：+1 MW 若全由 C 供，会使 Flow_AB +0.25 → 越限。须 A 减 0.5、C 增 1.5（净 +1，潮流变化 0.75×(−0.5)+0.25×1.5 = 0）→ 成本 = −0.5×200 + 1.5×400 = 500。
节点LMP（元/MWh）能量分量阻塞分量
A（参考）2002000
B（负荷）500200+300
C（电源）400200+200

7.5 阻塞租金核对

负荷付费 = 500 × 300 = 150,000 元/h
电源收入 = 200 × 150 + 400 × 150 = 90,000 元/h
阻塞租金 = 150,000 - 90,000 = 60,000 元/h

约束影子价格 μ = 400 元/MWh（每 MW 限额），μ × 限额 = 400 × 150 = 60,000 元/h，与上式一致。

7.6 读图

  • B 与 A 价差 300 元/MWh，是 A-B 断面紧张的价格信号。
  • 若网架加强使 A-B 限额提到 225 MW 以上，阻塞消失，三节点同价 200，价差归零——价差收益依赖约束持续存在。
  • 储能若装在 B（负荷节点），放电可缓解 A-B 潮流、压低阻塞分量；但是否能拿到这个收益，取决于 §5.2 的结算口径。

8. 对储能、新能源与 VPP 的含义

8.1 选址

  • 储能：装在阻塞断面的受端/负荷节点，放电缓解阻塞、充电吸收过剩，理论上捕获节点价差；装在送端新能源节点则主要做时移。选址收益必须用该节点价格序列测算，不能用全省均价。
  • 新能源：捕获价（capture price）= 实际结算均价，受节点阻塞与同时率影响，常低于全省平均价。捕获价 ≠ 捕获率：捕获率是捕获价 ÷ 基准价的比值，两者口径不同，见 储能收益建模与数据源 与口径字典。
  • VPP/可调负荷：聚合资源分散在多节点，结算口径决定能否按节点优化；统一加权价下，节点级优化价值被稀释。

8.2 报价

  • 预测对象要分清：预测出清节点价还是结算口径价。两者在统一加权/分区结算省份不同。
  • 阻塞高发时段（新能源大发 + 断面紧张）节点价波动剧烈，报价与 CVaR 约束应针对该节点而非全省，见 量化报价与交易风控。

9. 常见错误（10 条）

  1. 以为"电按合同路径走"，忽略并联分流与环流。
  2. 把出清节点价直接当结算价，不确认所在省结算口径。
  3. 用平均网损率代替边际网损进价格测算。
  4. 把当前节点价差当永久套利空间，忽略网架加强会收敛价差。
  5. 用全省平均价测算某节点储能/新能源收益（捕获价口径错）。
  6. 把捕获价与捕获率混为一谈。
  7. 认为负价只是"电太多"，忽略阻塞把便宜电源困在局部。
  8. 忽略 N-1 裕度，用物理热极限当断面限额。
  9. 换参考节点后以为价差变了（价差不随参考节点改变）。
  10. 把日前出清价当实时结算价，忽略日前-实时阻塞差异。

10. 待核实与未定事项

事项状态查证入口

  • 本文：潮流物理 → 节点价分解 → 阻塞/网损 → 选址报价含义，是"价格从哪来"的地基。

速查

口径铁律：出清价 ≠ 结算价；捕获价 ≠ 捕获率；平均网损 ≠ 边际网损
