0. 一页看懂

0.1 三句话

  • 宽频振荡不是"某一个谐波"：它是电力电子设备与电网在几 Hz 到数千 Hz 范围内的动态交互，频率会随运行方式、控制参数和电网强度漂移。
  • 阻抗分析把"控制系统会不会把扰动越放越大"变成"看阻抗的实部和虚部"：实部为负表示有能量注入，虚部过零表示谐振；负电阻频带是风险地图，不是判决书。
  • 整定是权衡，不是找唯一最优：PLL 带宽、电流环、虚拟阻抗、滤波器和构网型控制各有代价；必须多工况扫描、电磁暂态验证、现场实测，再形成可运维的定值。

0.2 关键概念

0.3 先记住四个数

35 kV 合成场站算例（100 MVA 基准）：

  • 电网串联谐振 180 Hz；叠加变流器电感后，总阻抗谐振 160.997 Hz。
  • 谐振点总电阻 −0.02998 pu，阻尼比 −0.00931，负电阻频带 98.8—221.2 Hz：典型"有谐振、又有负阻尼"的风险组合。
  • 把总电阻抬到 +0.03 pu 需要约 0.05998 pu 的虚拟电阻；示例选择 PLL 带宽 30 Hz + 虚拟电阻 0.04 pu。
  • 整定后谐振点总电阻 +0.03003 pu，阻尼比 +0.00933，负电阻频带消失；但这是单工况、单正序、理想限幅的合成结果。

口径提醒：上述数值是教学模型的确定性输出，不是任何真实风机、光伏、储能或电网的阻抗。真实阻抗随频率、功率、电压、控制版本和电网拓扑变化，必须实测/仿真。

0.4 本文不做什么

  • 不提供真实场站的集电网络、变压器、串补、风机/光伏/储能控制参数；
  • 不实现完整的三相电磁暂态、谐波线性化、频率耦合或多机阻抗聚合；
  • 不替代并网检测、阻抗扫描试验、振荡源定位或调度机构的稳定分析；
  • 不把单正序阻抗判据当作所有振荡问题的充分条件；
  • 不给出"某型号变流器一定能/不能并网"的结论。

1. 宽频振荡是什么

1.1 频率坐标

以 50 Hz 为同步频率，工程上常把振荡分成：

名称相对工频典型关注频段常见来源
次同步振荡低于 50 Hz几 Hz—50 Hz串补、轴系、风机控制、弱网
超同步振荡高于 50 Hz50 Hz—数百 Hz滤波器、电流环、网络谐振
高频振荡数百 Hz—数千 Hz数百 Hz—数千 Hz开关频率、滤波器、MMC 控制
宽频振荡覆盖多个频段几 Hz—数千 Hz多设备、多控制环节交互

这些边界不是标准定义，不同文献、标准和厂家可能不同。关键不是背频段，而是知道"哪个频段、哪个设备、哪种机理"。

1.2 三种容易混淆的"次同步"

  • SSR（次同步谐振）：串联补偿线路的 LC 谐振与汽轮机轴系扭振耦合。振荡频率由串补度和轴系模态决定，可能损坏轴系。
  • SSTI（次同步 torsional 相互作用）：HVDC、FACTS 或调速/励磁控制与轴系扭振耦合。控制器可能给扭振模态注入负阻尼。
  • SSCI（次同步控制相互作用）：风电场/光伏/储能变流器控制与串补或弱网交互。没有汽轮机轴系参与，振荡频率由控制与网络共同决定，频率容易漂移。

三者的共同点是"次同步"，但机理、模型、抑制措施不同。把 SSCI 当 SSR 去加阻波器，或把 SSR 当 SSCI 去调 PLL，都是常见误判。

1.3 为什么会发生

宽频振荡需要两个条件同时满足：

  1. 有谐振/低阻尼路径：网络电感与电容（串补、电缆、滤波器）形成谐振，或控制系统本身在某个频段呈现负阻尼；
  2. 有能量注入/扰动源：故障、开关操作、功率指令变化、风速波动、电网电压畸变，或控制器的自激。

只有谐振没有负阻尼，扰动会衰减；只有负阻尼没有谐振，振荡可能表现为控制模态；两者叠加，才容易出现持续/发散振荡。

1.4 新能源为什么更容易遇到

  • 变流器是快速控制器，响应时间从毫秒到几十毫秒，控制带宽与次/超同步频段重叠；
  • PLL、电流环、直流母线、外环、滤波器多时间尺度耦合；
  • 故障期间限流/模式切换，使阻抗随电压、电流变化；
  • 弱电网短路比低，电网阻抗大，设备与电网的交互更强；
  • 多机并联、多品牌、多控制版本，聚合阻抗难以用单机代表；
  • 串补、电缆、柔性直流、SVG 等引入新的谐振路径；
  • 振荡频率会漂移，保护/监测难以按固定频率设置。

1.5 与暂态稳定的区别

《动态安全评估与紧急控制》讲的是大扰动后的首摆/多摆稳定；宽频振荡更多是小干扰/控制交互问题：

  • 暂态稳定：大扰动、非线性、看 CCT/能量裕度；
  • 小干扰振荡：小扰动、线性化、看阻尼/特征值/阻抗；
  • 宽频振荡：可能由小扰动激发，也可能由控制自激，频段更宽；
  • 两者会互相影响：故障期间的限流/模式切换可能激发振荡，振荡又可能影响故障后恢复。

2. 阻抗分析基础

2.1 小信号线性化

阻抗分析把系统在运行点附近线性化：

Δv = Z(jω) Δi

Z(jω) 是频域阻抗，实部为电阻，虚部为电抗。它假设：

  • 系统在运行点附近近似线性；
  • 三相平衡、正序为主；
  • 扰动足够小，不触发限幅/保护/模式切换；
  • 频率耦合可以忽略或另行处理。

这些假设在真实变流器上经常不成立，所以阻抗判据是"风险筛查 + 机理理解"，不是万能判决。

2.2 源—荷互联与回比

把电网等效为 Zg，场站等效为 Zc，公共连接点串联：

Z_total = Zg + Zc

也可以用回比：

L(jω) = Zg(jω) / Zc(jω)

按 Nyquist 判据，1 + L(jω) 的轨迹是否包围临界点决定闭环稳定性。符号约定、电流方向、阻抗/导纳定义必须先写死，否则结论会反号。工程报告里常见"用导纳比还是阻抗比""源和荷谁在分子"的混乱。

2.3 谐振与阻尼

串联谐振：

X_total(ω) = 0

并联谐振：

abs(Z_total(ω)) 最大

在谐振点附近，阻尼比可用：

ζ ≈ R_total / (ω dX_total/dω) = R_total / (f dX_total/df)
  • R_total > 0：正阻尼，扰动衰减；
  • R_total < 0：负阻尼，扰动可能增长；
  • R_total = 0：临界，需看非线性/限幅/高次项。

2.4 负电阻频带

负电阻频带是 R_total(f) < 0 的频率区间。它告诉你有风险，但不告诉你一定会振荡：

  • 需要足够大的负阻尼（不只是"小于零"）；
  • 需要激励/扰动；
  • 需要谐振/相位条件；
  • 限幅、饱和、保护可能把发散变成极限环；
  • 多机系统可能在不同频段相互抵消或放大。

"扫描到负电阻"是红灯，"负电阻带宽很宽、幅值很大、又正好覆盖谐振"才是高风险。

2.5 无源性与 Nyquist

  • 无源性：Re{Z(jω)} ≥ 0 对所有频率成立，是并网稳定的充分条件（对无源电网），但很保守；
  • Nyquist：对线性时不变系统，回比轨迹不包围临界点是充要条件；
  • 阻抗和差：Zg + Zc 的零点/右半平面极点分析，适合串联互联；
  • 增益/相位裕度：可给出相对稳定裕度，但要对多频段分别看。

工程上常把三者组合：先用无源性/负电阻扫出风险频段，再用 Nyquist 看临界点，再用时域/EMT 验证。

2.6 短路比不是全部

短路比：

SCR = S_short / S_rated

低 SCR 表示电网弱、阻抗大，变流器与电网交互强。但：

  • 同样的 SCR，X/R 不同，阻抗频率特性不同；
  • 多机并联时，单机看到的等效 SCR 可能更低；
  • 串补/电缆会改变谐振频率；
  • 控制参数（PLL、电流环）可能比 SCR 更关键。

SCR 是入口指标，不是稳定判据。

3. 场站阻抗建模

3.1 电网侧阻抗

至少包括：

  • 输电线路/电缆的 R、L、C，频率相关；
  • 主变/场站变的漏抗、励磁、分接头；
  • 串联补偿电容（如果有）；
  • 并联电容/电抗、SVG/STATCOM；
  • 负荷（静态 ZIP + 电动机）；
  • 其他新能源场站、HVDC/FACTS；
  • 接地方式与序网络。

电网侧阻抗应随拓扑/检修/开机方式变化，不能只用一个"典型值"。

3.2 变流器阻抗

跟网型变流器的正序阻抗通常由以下环节共同决定：

环节对阻抗的影响常见问题
PLL在次/超同步段引入负电阻/相位偏移带宽过高或过低都可能失稳
电流环决定中高频段阻抗带宽与采样/开关频率冲突
直流母线引入低频动态直流电容/电压环耦合
外环（功率/电压）低频段阻抗与电网频率/电压控制交互
滤波器（L/LC/LCL）高频谐振/衰减谐振峰、相位滞后
前馈/解耦改变阻抗相位电压前馈不完整
限幅/饱和非线性故障/大扰动下阻抗变化
频率耦合正/负序、谐波耦合单正序模型不够

3.3 多机聚合

场站内多台变流器经集电线路并联，阻抗不是简单相加：

  • 各机运行点不同（风速/光照/荷电状态）；
  • 集电线路/箱变引入阻抗与谐振；
  • 不同厂家/型号/控制版本可能相互激发；
  • 单机等值可能低估或高估负阻尼；
  • 多机并联可能改变谐振频率和阻尼。

工程上要做"单机—集电—场站—电网"的分层扫描，并用 EMT 验证聚合等值。

3.4 频率耦合

三相变流器在不对称/谐波扰动下会产生正序、负序、零序耦合，单一正序阻抗可能不够：

  • 负序控制、锁相环、直流母线波动会引入耦合；
  • 谐波线性化可得到多输入多输出阻抗矩阵；
  • 序阻抗扫描要区分正序/负序注入；
  • 不对称故障、单相重合闸、不平衡负荷会激发耦合。

本文的演示只用单正序、单频点，属于最小教学模型。

3.5 模型来源与校验

来源用途风险
厂家 EMT 模型控制/限流/保护细节黑箱、版本不一致、参数保密
厂家阻抗模型/扫描数据频域分析运行点/工况覆盖不足
并网检测报告FRT、AGC/AVC、一次调频不含全部振荡工况
现场阻抗测量校验模型测试条件、注入幅值、安全风险
PMU/录波事后校验采样率/时同步/安装位置

模型校验的核心是同一运行点、同一控制版本、同一拓扑下对比幅值/相位/谐振点，不是只看"趋势像"。

4. 扫描、判据与现场测量

4.1 扫描怎么做

  1. 确定频率范围：至少覆盖次同步、超同步和关注的开关/滤波频段；工程上常见几 Hz—数千 Hz。
  2. 确定频率分辨率：窄带谐振需要更细步长，可对数扫描 + 局部加密。
  3. 确定运行点：功率、无功、电压、SCR、开机台数、集电线路方式。
  4. 对每个频点注入小扰动，测电压/电流响应，算阻抗幅值/相位。
  5. 改变运行点重复，形成"工况—阻抗"矩阵。
  6. 用 Nyquist/负电阻/阻尼指标判稳，再用 EMT 时域验证。

4.2 扫描的四种"坑"

  • 只扫一个工况：轻载/满载、容性/感性无功、单机/多机，阻抗可能完全不同；
  • 分辨率太粗：漏掉窄带谐振峰；
  • 注入幅值太大：触发限幅/非线性，测到的不是小信号阻抗；
  • 忽略频率耦合：单正序扫描看不到负序/谐波耦合。

4.3 判据怎么读

指标读法局限
负电阻频带越宽、越深、越靠近谐振，风险越高不证明一定振荡
谐振频率X=0 或 \Z\
阻尼比负值/接近零表示低阻尼依赖线性化与谐振识别
Nyquist 距离轨迹离临界点多远需要正确回比与模型
相位裕度关键频段的相位余量多频段需分别看
时域仿真是否出现持续/发散振荡依赖模型/扰动/时长

4.4 现场测量

  • 阻抗分析仪/注入法：在并网点注入电压/电流扰动，测宽频阻抗；要注意安全、幅值、频率范围和对电网的影响。
  • 宽频监测：PMU/宽频录波/专用监测装置，采样率和抗混叠要覆盖关注频段。
  • 开关操作/扰动试验：用小扰动（无功阶跃、功率阶跃）观察阻尼，但要做好安全预案。
  • 数据同步：多测点时标误差会严重影响相位/阻抗计算。

4.5 标准与并网要求

  • GB/T 19963.1-2021《风电场接入电力系统技术规定 第 1 部分：陆上风电》对风电场的次/超同步振荡专题研究、监测和抑制提出要求；具体条款以标准原文和并网协议为准。
  • GB/T 19963.2-2024《风电场接入电力系统技术规定 第 2 部分：海上风电》增加了海上风电场的宽频振荡分析与防控要求（以正式文本为准）；海上风电经柔直送出时，控制交互更复杂。
  • GB/T 47968-2026《构网型变流器通用技术规范》为构网型设备提供通用技术框架；构网型不是"消除振荡"的万能药，仍需阻抗/时域校核。
  • 并网检测报告、厂家模型和调度要求是项目层面的最终依据；标准只给原则，不给某个场站的具体定值。

4.6 扫描结果怎么进并网报告

一份可复核的阻抗分析至少包含：

  • 模型来源、版本、参数、校验数据；
  • 电网拓扑/运行方式/短路比/串补/电缆；
  • 场站单机/集电/聚合模型；
  • 扫描范围、分辨率、注入幅值、正/负序；
  • 阻抗曲线、谐振点、负电阻频带、Nyquist 图；
  • 多工况敏感性；
  • 抑制措施与整定依据；
  • EMT 时域验证；
  • 现场测试/监测计划；
  • 结论的边界与未定项。

只有一张"阻抗曲线"不够。

5. 参数整定

5.1 整定对象

对象作用主要代价
PLL 带宽决定与电网同步速度/相位特性太快/太慢都可能失稳
电流环带宽决定中高频阻抗受采样/开关频率限制
直流电压环低频动态/能量平衡与电网频率/功率耦合
虚拟阻抗（R/X）增加阻尼/改变谐振压降、损耗、动态响应
有源阻尼针对特定频段依赖模型/参数，可能漂移
滤波器/陷波器抑制特定谐振相位滞后、参数漂移
构网型/下垂控制提供电压源/惯量限流、能量、故障电流
附加阻尼控制（POD）针对机电/次同步模态需要测量/通信，可能误动

5.2 PLL 带宽的两难

  • 带宽高：同步快、动态好，但在弱网/次同步段可能引入负电阻；
  • 带宽低：相位更稳，但响应慢，弱网下可能失去同步/低频振荡；
  • 没有"通用最佳值"：取决于 SCR、X/R、功率、电流环、外环和电网谐振；
  • 厂家默认值不一定适合你的场站，必须做多工况扫描。

5.3 虚拟阻抗的代价

虚拟电阻 Rv 可以抬高总电阻、增加阻尼，但：

  • 会产生额外压降/损耗（如果实现为实际阻抗）；
  • 影响电压调节和无功分配；
  • 可能降低动态响应/故障穿越能力；
  • 在控制中实现的虚拟阻抗可能改变 X 而不只是 R；
  • 过大的 Rv 可能让变流器在弱网下不稳定或限流。

虚拟阻抗是"用稳态/动态性能换阻尼"，不是免费的。

5.4 整定流程

建模/校验
  → 多工况阻抗扫描
  → 识别谐振点、负电阻频带、敏感参数
  → 单参数灵敏度（PLL/电流环/虚拟阻抗/滤波器）
  → 约束下的折中（动态响应、FRT、损耗、限流）
  → EMT 时域验证（小扰动/大扰动/故障）
  → 现场小扰动试验/监测
  → 形成定值与运维边界

5.5 约束与目标

整定不是"把阻尼调到最大"，而是在约束下找可行点：

  • 稳定：关键工况下阻尼/裕度为正；
  • 动态：PLL/电流环响应满足并网/控制要求；
  • 故障穿越：限流/无功支撑/恢复斜率合格；
  • 稳态：电压/无功/损耗在允许范围；
  • 鲁棒：参数漂移、出力变化、电网拓扑变化下仍稳定；
  • 可运维：定值可理解、可复核、可复现。

5.6 构网型能做什么、不能做什么

构网型变流器以电压源方式运行，可提供：

  • 电压/频率参考；
  • 惯量/阻尼（控制模拟）；
  • 弱网支撑；
  • 黑启动/孤岛能力。

但它不能：

  • 消除所有谐振（控制交互仍存在）；
  • 无限提供故障电流（受限于功率器件/限流）；
  • 替代电网规划/同步机；
  • 保证多机/多品牌并联稳定（需整体研究）。

构网型与跟网型的对比见《储能技术路线安全与构网型并网》。

6.2 基准扫描

量数值
电网单独串联谐振180.0 Hz
总阻抗谐振（X=0）160.997 Hz
谐振点电网电阻+0.02000 pu
谐振点变流器电阻−0.04998 pu
谐振点总电阻−0.02998 pu
谐振点阻尼比−0.00931
负电阻频带98.8—221.2 Hz

读法：

  • 电网本身的谐振在 180 Hz，变流器电感把总谐振拉到 161 Hz；
  • 谐振点总电阻为负，说明变流器在这个频段向振荡注入能量；
  • 负电阻频带覆盖 99—221 Hz，宽约 122 Hz，属于需要重点关注的组合；
  • 但这只是小信号、单正序、单工况结果，不能直接说"一定会振荡"。

6.3 需要多少虚拟电阻

目标：把谐振点总电阻抬到 +0.03 pu（示例阻尼门槛，不是标准值）。

Rv_required = R_target − (Rg + Rc)
            = 0.03 − (0.02 − 0.04998)
            = 0.05998 pu

约 0.06 pu。注意：虚拟电阻抬高 R，不改变 X，所以谐振频率仍约 161 Hz。

6.6 这个算例说明什么

  • 谐振频率由网络和变流器电抗共同决定，不只是电网自己的 180 Hz；
  • 负电阻频带比单个谐振点更能描述风险范围；
  • 虚拟电阻可以抬阻尼，但需要付出稳态/动态代价；
  • PLL 带宽与负电阻幅值的权衡需要多工况校核；
  • 整定后还要用 EMT 验证小扰动、大扰动和故障穿越，不能只看频域曲线。

6.7 这个算例不说明什么

  • 不代表真实变流器的 PLL/电流环/外环/限幅/频率耦合；
  • 不覆盖多机并联、集电线路、不同厂家、不同控制版本；
  • 不覆盖不对称故障、负序、谐波耦合；
  • 不给出真实场站的定值、阻尼门槛或并网结论；
  • 不能用"负电阻频带消失"替代现场试验和长期监测。

7. 现场诊断与应急处置

7.1 先确认"是不是宽频振荡"

现象可能包括：

  • 功率/电压/电流持续振荡，频率不是工频；
  • 振荡频率漂移，或出现多个峰；
  • 变流器/风机/光伏逆变器反复告警/脱网；
  • 场站/电网保护动作，但故障录波没有常规短路；
  • 汽轮机/轴系扭振报警（如果是 SSR/SSTI）；
  • 相邻场站/线路同时出现振荡。

7.2 诊断步骤

  1. 保录波：高采样率录波、PMU、变流器日志、SCADA、开关变位、保护动作。
  2. 定频率/模态：FFT/时频分析，区分工频、次同步、超同步、高频、多模态。
  3. 定范围：是个别变流器、整个场站、集电线路、送出线路还是电网侧。
  4. 定机理：强制振荡（谐振/扰动）还是自激（负阻尼）？是否与串补/电缆/柔直/弱网相关？
  5. 查变化：最近是否改控制软件、滤波器、PLL 参数、开机台数、无功策略、电网拓扑？
  6. 做扫描/仿真：用现场工况复现，比较阻抗/谐振/阻尼。
  7. 定措施：调整控制/虚拟阻抗/滤波器/运行方式，必要时限功率/解列。
  8. 复盘：更新模型、定值、监测和运维规程。

7.3 应急处置的优先级

  • 先保安全：防止设备损坏、越级跳闸、大面积脱网；
  • 再保证据：不要一上来就切机/清日志；
  • 小步调整：降低出力、调整无功/电压、改变控制模式、投退滤波/阻尼；
  • 必要时解列/切机：作为最后手段，按调度规程执行；
  • 不要盲目重合闸：振荡期间重合可能加剧冲击；
  • 记录操作：时间、指令、响应、保护动作，供复盘。

7.4 振荡源定位

常用方法：

  • 比较各测点振荡相位/能量流方向；
  • 逐台/逐组投退，观察阻尼变化（要安全）；
  • 阻抗扫描 + 模型复现；
  • 能量/耗散分析；
  • 机器学习/模式识别（辅助，不替代机理）。

"振荡最大的地方"不一定是"源"：可能是谐振点/薄弱环节，源可能在别处。

8. 对交易、投资与运营的含义

8.1 并网与投决

  • 宽频振荡分析是并网研究的一部分，不是"额外可选"；
  • 弱网、串补、柔直、多机汇集的项目要更早做阻抗/EMT 研究；
  • 厂家模型/控制版本/参数保密会影响尽调，要在合同中约定交付与校验；
  • 抑制措施（虚拟阻抗、滤波器、构网型、附加阻尼）有投资和运行成本；
  • 并网延迟、限功率、弃风弃光、考核罚款要进投决模型。

8.2 设备与合同

  • 采购技术协议应包含：阻抗/振荡研究责任、模型交付、现场测试、性能保证、软件升级后的复核；
  • 不能只看"单机认证"，要看"场站+电网"系统级研究；
  • 多品牌/多版本混装要明确接口与责任；
  • 备品备件、控制板卡、软件版本管理要可追溯；
  • 保险/免责条款要覆盖振荡导致的停机/损坏。

8.3 运营与市场

  • 振荡可能导致出力受限、AGC/AVC 考核、两个细则罚款；
  • 阻尼/惯量/电压支撑可能成为辅助服务，但规则因省而异，不能假设有收益；
  • 储能/构网型可以提升稳定性，但也可能引入新的交互，必须做系统研究；
  • 振荡事件后的停运、检修、发电损失要进风险模型；
  • 交易员要关注调度发布的振荡/限发/检修信息，价格尾部可能与此相关。

8.4 数据与 AI 的边界

AI 可以做振荡检测、模态识别、源定位、参数辨识，但：

  • 训练数据要覆盖真实振荡形态，不能只用仿真；
  • 采样率/时标/安装位置决定可观测性；
  • 保护/紧急控制不能由 AI 实时替代；
  • 模型可解释性和审计要求高；
  • "检测到振荡"不等于"知道原因"，仍需机理分析。

9. 常见错误（10 条）

  1. 把宽频振荡当单一谐波：频率会漂移、多模态，固定滤波器可能失效。
  2. 只扫一个工况：轻载/满载、容性/感性、单机/多机阻抗差异很大。
  3. 用单机模型代表场站：集电线路、多机、多品牌、控制版本会改变谐振/阻尼。
  4. 只看 R<0，不看幅值/带宽/谐振：负电阻很浅、很窄，风险可能有限；很深、很宽又覆盖谐振才危险。
  5. 把阻抗判据当万能：线性化、正序、小信号假设在限幅/故障/不对称下不成立。
  6. 忽略频率耦合/负序：单正序扫描可能漏掉负序/谐波交互。
  7. 只调 PLL，不看电流环/外环/滤波器：阻抗是多环节共同结果。
  8. 用现场试错代替建模：盲目改参数可能掩盖问题、触发新振荡。
  9. 忽略限幅/饱和/FRT：大扰动下阻抗与 Small-signal 不同，故障穿越可能激发振荡。
  10. 一上来就切机/清数据：丢失证据，可能误判源，甚至扩大事故。

12. 速查

12.1 六个公式

Z_total(f) = Zg(f) + Zc(f) = R_total(f) + jX_total(f)

串联谐振：X_total(f) = 0

ζ ≈ R_total / (ω dX_total/dω) = R_total / (f dX_total/df)

负电阻频带：R_total(f) < 0

SCR = S_short / S_rated

回比：L(jω) = Zg(jω) / Zc(jω)，Nyquist 看 1 + L 是否包围临界点

12.2 五个必问

  1. 这次扫描覆盖了哪些工况、哪些频段、正序还是负序，分辨率够不够？
  2. 谐振点是网络谐振还是控制谐振，负电阻频带有多宽、多深？
  3. 模型/参数/控制版本与现场一致吗，用什么数据校验过？
  4. 整定改变了哪些阻抗环节，代价是什么，EMT/现场验证了吗？
  5. 现场振荡的源在哪，是强制振荡还是负阻尼自激，应急措施会不会掩盖证据？

12.3 工具

# 在 skills/ems-dispatch/tools 下
python oscillation.py                 # 打印阻抗扫描、负电阻频带与整定
python oscillation.py --json          # JSON 输出
