2. 服务矩阵与可借鉴点

服务客户问题可借鉴的方法不可照搬的部分
产品碳足迹（PCF）客户要数、碳标识、CBAM 前置按 ISO 14067/GB/T 24067 定声明单位、边界、取舍、分配；输出热点与敏感性厂商的"平均碳足迹""减排百分比"无基线，不能当行业值
组织温室气体盘查合规、ESG、集团合并法人/设施边界、活动数据台账、因子版本锁定不能与产品层混算
碳中和/零碳工厂园区、工厂、品牌声明量化→减排→抵消→报告→声明→核查的层级链；CNMP"零碳"不等于"碳中和"，更不能替代减排
供应链碳数据范围三、客户审核最小字段集、供应商分级、方法学映射"平台已接入 N 家供应商"不等于数据可核查
CBAM 应对出口欧盟产品规则、隐含排放、前体材料、默认值与核查厂商工具输出不能直接当申报表
DPP/电池护照欧盟合规产品身份、材料、碳足迹、循环性、访问控制二维码/标签不等于 DPP
碳数据跨境数据出境合规分类分级、最小必要、路径选择、合同与留痕园区试点是服务案例，不是法律豁免
碳金融对接碳资产融资碳账户/碳绩效 → 银行授信授信额度与利率由银行决定，厂商不兜底

4. 值得写进技能的三条方法线

4.1 从"报告"转向"数据产品"

厂商把 PCF 做成可复用的数据产品：一次建模，多场景输出（客户审核、碳标识、CBAM 前置、DPP 字段）。技能采纳其数据结构化思路，但不采纳"一键生成即合规"的暗示：

  • 声明单位、边界、取舍、分配四项必须显式落库；
  • 因子带来源、年份、地域、技术、版本五个属性；
  • 每个输出都保留"数据 → 因子 → 计算 → 报告 → 声明"的追溯链（§12.6）。

4.2 碳数据增信：从"有数据"到"能授信"

"碳数贷"一类产品的实质，是银行把可核验的碳绩效作为授信参考，而不是把配额或 CCER 当抵押物。技能把它拆成三种结构（§9.6）：

结构增信基础风险点
碳数据增信碳账户、碳足迹、能耗与减排记录数据真实性、口径一致性、可追溯性
碳挂钩贷款利率与碳绩效指标挂钩指标可达性、第三方核验、调整机制
碳资产质押配额/CCER 作为质押物价格波动、质押率、追保与处置

4.3 跨境数据"场景化"而不是"打包出境"

临港试点的可借鉴处是按场景做数据地图：先明确"什么数据、给谁、为什么、到哪里"，再做分类分级与最小必要，最后选安全评估/标准合同/认证/豁免路径。技能把它固化为七步流程（§11.10），并明确园区试点不构成法律豁免。

5. 不能当基准的宣称（复核清单）

常见宣称为什么不能用正确写法
"已服务 N 家企业/N 个产品"口径含试用、重复、未核查项目如必须引用，写"厂商自称，截至某月"
"平均碳足迹 X kg"产品、边界、声明单位不同，不可平均按产品类别与边界分别列示
"帮助客户减排 X%"无基线年、无边界、无核查只引用经第三方核查的绝对量
"一键生成 CBAM 报告"CBAM 需按产品规则核算并核查工具只能辅助，申报责任在授权申报人
"零碳/碳中和"未区分减排、抵消与声明层级按 ISO 14068:2026 的六步链判断
"上链即可信"只证明防篡改，不证明真实计量、凭证、现场核查缺一不可
"园区试点=数据可自由出境"试点是服务机制，不是豁免逐单评估，法务确认

厂商公开定位级别
碳阻迹（Carbonstop）碳核算软件、碳管理平台、碳足迹数据库C：官网与公开报道
易碳数科工业产品碳足迹、LCA 与 CBAM 相关工具C

中创碳投碳市场咨询、碳核算与培训C
碳管家企业碳管理 SaaS 与咨询服务C

结论：国内碳管理服务已从"写报告"分化出三条路线——软件/数据产品（碳衡、碳阻迹、易碳数科）、园区/城市平台（碳启城）、碳资产开发与交易咨询（宝碳、中创碳投）。技能不评价厂商优劣，只吸收其数据结构、证据链与场景拆分方法。

7. 待核实

  • 碳衡科技工商全称、注册资本、股权结构与最新融资轮次，需以国家企业信用信息公示系统为准；
  • "碳数贷"的授信额度、利率区间、风险分担与违约处置，公开信息不足；
  • 临港试点截至 2026-04 的"330 次咨询、32 家企业、34 个场景"为园区/厂商口径，缺少主管部门统计原文；
  • 富华、报喜鸟、南大智慧城、上海冠华各项目的边界、核查机构、证书编号与数据是否公开，未逐项核验；
  • 青钥·Cyacle 的功能清单、计费方式与数据托管地点，未见完整公开文档；
  • 同类厂商的客户数、减排量、市场占有率等数字均为企业口径，本笔记不收录。
