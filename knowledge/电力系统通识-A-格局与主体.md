# 电力系统通识 A · 格局与主体：谁在发电、谁在送电、谁在定规则

> 用途：给没有电力背景的读者一张"行业人员表"。读完应当能回答：我家属于哪家电网、这家电厂归谁、为什么同一个省的电价和隔壁省不一样、交易中心和调度是什么关系。
> 数据截止：2026-11-01。公司股权、装机、供区范围会变，**引用具体数字前请按文末入口核对**；本文只给结构与判据，不给"最新排名"。
> 读法：第 1 节看全景，第 2~3 节看电网与发电，第 4~6 节看配套单位与机构，第 7 节是速查表，第 8 节是常见误解。

---

## 1. 三十秒建立全景

电从一次能源到插座，要经过五个环节（下一份笔记 B 会展开）：**发电 → 输电 → 配电 → 变电 → 用电**。围绕这条链，站着五类主体：

| 主体 | 干什么 | 收入从哪来 |
|---|---|---|
| 电网企业 | 建设和运营输配电网，提供"过路"服务 | 输配电价（政府核定）+ 部分政府性基金 |
| 发电企业 | 建电厂、卖电 | 上网电价（计划或市场） |
| 调度机构 | 下指令决定哪台机组发多少 | 不直接收费，隶属电网 |
| 交易机构 | 组织买卖、出清、发布价格 | 交易服务费 |
| 监管部门 | 定规则、核价、处罚 | 财政 |

一句话记住三者的区别：**交易机构管"钱和量"，调度机构管"电和物理安全"，监管机构管"规则和价格"**。三者分开，是 2015 年新一轮电改的核心安排之一。

中国电力行业还有一个别处少见的特点：**电网不是一张网，而是三张**（国家电网、南方电网、蒙西电网），发电侧则是"五大 + 四小 + 一批地方与新能源公司"的格局。

## 2. 电网：两网加一个"蒙西"

### 2.1 三家电网企业的分工

| 企业 | 供区 | 特点 |
|---|---|---|
| 国家电网有限公司 | 26 个省（自治区、直辖市），约占国土面积 88% | 全球最大公用事业企业；下辖六大分部（华北、华东、华中、东北、西北、西南）与省级电力公司 |
| 中国南方电网有限责任公司 | 广东、广西、云南、贵州、海南 5 省区 | 与国网平级，不是国网子公司；南方区域电力市场 2026-10-24 转入正式运行 |
| 内蒙古电力（集团）有限责任公司（俗称"蒙西电网"） | 内蒙古西部 8 个盟市 | 全国唯一独立于两大电网的省级电网企业；蒙西是 2017 年首批 8 个现货试点之一 |

补充两点容易被忽略：

- 内蒙古东部 4 个盟市（赤峰、通辽、呼伦贝尔、兴安）由**国网蒙东电力**供电，不属蒙西电网。所以"内蒙古的电"在市场上要分东西两套规则看。
- 西藏由国网西藏电力供电，但电网联系与调度体制有特殊性；新疆、青海等西部省份同样属国网，但网架薄弱、新能源占比高，市场设计差别很大。

### 2.2 蒙西为什么能独立

蒙西电网的独立，是 2002 年厂网分开时形成的格局：当时内蒙古西部电网没有并入国家电网，而是保留为自治区属企业。这个历史原因带来两个后果：

1. **它是唯一可以独立设计省级市场规则、又有独立调度权的电网**，蒙西现货市场因此在试点中推进较快；
2. **它是"省网即独立电网"的样本**：跨省交易要按点对网、网对网的方式与国网、南网衔接，输电通道与省间规则是它绕不开的约束。

### 2.3 电网企业的业务边界

电网企业是**自然垄断环节**，监管方式是"准许成本 + 合理收益"的输配电价核定：政府核定它每年可以收多少过网费，而不是让它按市场价卖电。这也是为什么电改的口号是"管住中间、放开两头"——中间（输配电网）管住，两头（发电、售电）放开竞争。

需要注意：**电网企业本身不参与竞争性售电**（具体限制以现行监管规定为准），售电公司是独立市场主体。

## 3. 发电：五大、四小、地方与新能源

### 3.1 五大发电集团

| 集团 | 组建/沿革 | 特点 |
|---|---|---|
| 国家能源投资集团 | 2017 年由神华集团与中国国电集团合并 | 煤电、煤炭、铁路港口一体化，"煤电运"协同；旗下有龙源电力（风电） |
| 中国华能集团 | 1985 年华能国际电力开发公司起步 | 最早的市场化发电企业之一，火电、水电、新能源并举 |
| 中国大唐集团 | 2002 年厂网分开时组建 | 火电为主，近年加码新能源 |
| 中国华电集团 | 2002 年厂网分开时组建 | 火电、水电、新能源；旗下华电新能专注新能源 |
| 国家电力投资集团 | 2015 年由中电投与国家核电技术公司重组 | 核电（CAP 系列）、光伏装机规模居前 |

**格局含义**：五大集团合计装机长期占全国四成以上（比例逐年变化，引用前查中电联年度统计）。对市场而言，这意味着发电侧集中度不低，**市场力监测**是各省规则里的固定内容——这也是《现货报价量化专家》只做市场力"识别"、不做"利用"的原因。

### 3.2 "四小"是历史称谓，别当现行分类

常说的"四小豪门"指**国投电力、华润电力、中广核、国华电力**。但这个说法有两个坑：

1. **国华电力已随神华并入国家能源集团**（2017 年），不再独立于五大之外；
2. 近年来国投电力、华润电力、中广核的装机与业务早已超出"小"的范围，中广核更是核电主力。

所以写作时应说"'四小'（历史称谓）"，或者干脆改称"其他中央发电企业与大型地方发电企业"。

### 3.3 地方能源集团

省级政府通常有自己的能源投资平台，它们既是本地电源的重要持有者，也是地方能源政策的执行者：

| 类型 | 例子 |
|---|---|
| 省级能源集团 | 浙能集团（浙江）、广东能源集团、京能集团（北京）、申能集团（上海）、晋能控股（山西）、内蒙古能源集团 |
| 省级投资平台 | 皖能、豫能、赣能、川投能源等 |
| 城市燃气/综合能源 | 深圳能源、广州发展等 |

地方集团的重要性在于：**它们常常是本省现货市场里"既懂规则又是本地国企"的一类主体**，在省内平衡、供热、保供上承担政策性任务。

### 3.4 新能源运营商

"五大"之外，新能源装机还有几支独立力量：三峡能源（海上风电、光伏）、中广核新能源、华电新能、龙源电力，以及大量民营与外资电站。它们的特点是**资产新、负债高、对电价与消纳政策敏感**——136 号文（新能源上网电价市场化）对这类企业的影响最大。

## 4. 设备与二次系统：电厂的"硬件"和电网的"神经系统"

普通人容易只关注发电集团，但电力和所有重资产行业一样，**装备与自动化厂商决定了系统的能力边界**。

| 类别 | 代表企业 | 作用 |
|---|---|---|
| 一次设备（发电与变电） | 东方电气、上海电气、哈尔滨电气；特变电工、平高电气、中国西电 | 发电机、汽轮机、变压器、开关（GIS）、换流阀 |
| 二次设备（保护与自动化） | 南瑞集团（国电南瑞）、许继电气、四方股份、长园深瑞、国电南自 | 继电保护、调度自动化、变电站自动化、稳定控制 |
| 新能源制造 | 金风科技、远景能源、明阳智能；隆基绿能、通威股份、晶科能源 | 风机、组件 |
| 储能 | 宁德时代、比亚迪、阳光电源、华为数字能源 | 电芯、PCS、系统集成 |

**南瑞为什么总被提到**：它是国网电科院（国网电力科学研究院）旗下的产业集团，做的是调度自动化系统、变电站自动化、继电保护和电力市场技术支持系统——也就是本仓库三个技能里反复出现的"交易中心系统"和"出清系统"的主要供应商之一。理解这一点，就能理解为什么"规则变更"往往同时是一次"系统改造"（见《现货报价量化专家》第 10.4 节）。

## 5. 科研、标准与行业组织

| 机构 | 隶属/性质 | 干什么 |
|---|---|---|
| 中国电力科学研究院（中国电科院） | 国家电网直属 | 电力系统分析、仿真、标准制定、试验检测 |
| 国网电力科学研究院（国网电科院，与南瑞集团一体化运作） | 国家电网 | 二次系统、自动化、市场技术支持系统 |
| 南方电网科学研究院（南网科研院） | 南方电网 | 南方区域电网运行与市场仿真、直流输电研究 |
| 各省电力科学研究院 | 省级电力公司 | 本省试验、检测、技术监督 |
| 电力规划设计总院（电规总院） | 中国能建 | 电力规划、评审、政策研究 |
| 水电水利规划设计总院（水规总院） | 中国电建 | 水电与新能源规划 |
| 中国电力企业联合会（中电联） | 行业协会 | 统计、标准、行业报告（很多数字的原始出处） |

**怎么用**：需要"权威数字"时，先想到中电联与国家能源局的统计；需要"技术边界"时，想到电科院与设计总院；需要"行业惯例"时，想到中电联的团体标准。

## 6. 三类机构：交易、调度、监管

### 6.1 交易机构

- **国家级**：北京电力交易中心（服务国家电网经营区、省间交易）、广州电力交易中心（服务南方区域）；
- **省级**：各省（区、市）电力交易中心，负责省内中长期、现货、辅助服务的组织与结算；
- **性质**：2015 年后要求"交易机构相对独立"，多数已完成股份制改造，电网公司不再是唯一股东，但调度仍隶属电网。

交易中心发布的**规则、公告、出清结果**，是判断一个省市场成熟度的第一手材料。

### 6.2 调度机构

中国实行**五级调度**：国家调度（国调）— 网调 — 省调 — 地调 — 县调。调度机构隶属电网企业，负责：

- 安排开机方式与检修；
- 执行日前/实时出清结果，保证发用电实时平衡；
- 事故处理与黑启动。

所以行业里有句话：**"交易决定价格，调度决定能不能发"**。报价策略再优，若机组检修、爬坡或断面约束不允许，也无法执行——这是《现货报价量化专家》第 12 章申报校验的现实来源。

### 6.3 监管机构

| 机构 | 管什么 |
|---|---|
| 国家能源局及派出机构（各能源监管局） | 市场准入、交易行为、辅助服务、电力安全 |
| 国家发展改革委（价格司） | 电价政策、输配电价核定、容量电价 |
| 国家市场监督管理总局 | 价格违法、反垄断（市场力滥用可能同时触发） |
| 地方政府（发改/能源局） | 省级实施方案、补贴、项目核准 |

## 8. 五个常见误解

1. **"国家电网管全国"**——错。南网 5 省区、蒙西 8 盟市不在国网供区。
2. **"南方电网是国家电网的子公司"**——错。两家是平行的中央企业，供区互不重叠。
3. **"五大发电就是全部发电"**——错。还有四小（历史称谓）、地方能源集团、新能源运营商、自备电厂与分布式电源。
4. **"交易中心就是电网的一个部门"**——改制后交易机构相对独立，但调度仍在电网，两者不能混为一谈。
5. **"电科院都是一家"**——中国电科院（国网直属）与国网电科院/南瑞（产业与研究院一体化）是两回事，南网科研院又是一家。
