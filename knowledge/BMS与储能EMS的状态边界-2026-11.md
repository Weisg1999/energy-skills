# BMS 与储能 EMS 的状态边界：SOC/SOH/SOP、均衡与安全联锁（2026-11）

> 数据截止：2026-11-19｜定位：知识库模块（储能与 EMS·电池状态与安全边界）

## 0. 一页看懂

### 0.1 三句话

- **BMS 管"电芯能不能干"，EMS 管"整站怎么干"**：BMS 给出 SOC/SOH/SOP、温度、电压、绝缘、故障等级；EMS 在这些边界内做功率分配、能量管理、市场申报和运行方式切换。
- **SOC 不是"读出来的"，是"算出来并校正的"**：安时积分会漂，OCV 校正有平台区，EKF/UKF 依赖模型；没有校正的 SOC 在长期运行后可能偏差很大。
- **SOP 不是额定功率**：它同时受 SOC、温度、电压、电流、能量预算和 PCS 能力约束；EMS 如果把 SOP 当常数，调度计划会在高温/低 SOC 时不可执行。

### 0.2 关键概念

| 概念 | 含义 | 本文口径 |
|---|---|---|
| SOC | 荷电状态，剩余电量占比 | 0—100%，本文用百分数 |
| SOH | 健康状态，当前可用能力相对初始值 | 容量/电阻/功率多口径，本文用容量 |
| SOP | 功率状态，当前可充/可放功率 | 受 SOC、温度、电压、能量、PCS 限制 |
| 安时积分 | 按电流对时间积分估算 SOC | 会受采样误差、倍率、温度影响 |
| OCV | 开路电压 | 与 SOC 有非线性关系，平台区不敏感 |
| EKF | 扩展卡尔曼滤波 | 用电池模型+量测修正 SOC |
| 均衡 | 减少电芯间 SOC/电压差异 | 被动耗能、主动转移 |
| 联锁 | 故障时强制停机/断开/闭锁 | 分电芯、模组、簇、舱、PCS、EMS |
| 状态机 | 定义正常/降额/限功率/停机/隔离 | 要可观测、可复位、可追溯 |
| 热失控 | 电池内部放热失控的链式反应 | 安全设计的核心场景 |

### 0.3 先记住四个数

100 MW/200 MWh、280 Ah 电芯的合成算例：

- **SOC 安时积分从 50% 放电 100 A、1 h 后降到 14.286%**；同一时刻 OCV 3.225 V 对应 15.0%，校正量约 **+0.714 个百分点**。
- **600 次循环、2 年后 SOH 95.1%**：循环衰减 0.9 个百分点、日历衰减 4.0 个百分点，剩余容量 266.28 Ah。
- **SOP 在 40% SOC、25 ℃ 为 100 MW；45 ℃ 降到 70 MW（35 ℃ 起每升高 1 ℃ 降额 3%）；15% SOC、25 ℃ 只有 20 MW**：温度与能量都可能成为瓶颈。
- **单簇 16 串电芯最大压差 40 mV、被动均衡 100 mA，均衡时间约 280 h**：被动均衡很慢，不能指望它解决严重不一致。

> 口径提醒：上述数字是教学模型的确定性输出，不是任何真实电芯、BMS 或储能电站的参数。真实 SOC/SOH/SOP 随电芯化学体系、温度、倍率、老化、BMS 算法和运行历史变化，必须以厂家数据和现场标定为准。

### 0.4 本文不做什么

- 不提供真实电芯型号、容量、内阻、OCV 曲线、BMS 阈值或联锁逻辑；
- 不实现完整的电化学模型、EKF/UKF、热模型、热失控传播或消防仿真；
- 不替代 BMS 算法设计、电池安全评估、消防设计、并网检测或运行规程；
- 不把某个 SOC 算法的误差当作所有 BMS 的误差；
- 不给出"某型号电池一定能/不能满足某场景"的结论。

## 1. 为什么 BMS 与 EMS 的边界是核心

### 1.1 两个系统，两个时间尺度

BMS 的时间尺度是毫秒—秒：

- 采集电芯电压、温度、电流；
- 估算 SOC/SOH/SOP；
- 判断过压/欠压/过温/温差/绝缘/接触器/通信故障；
- 驱动均衡；
- 执行保护联锁。

EMS 的时间尺度是秒—分钟—小时—天：

- 功率分配与能量管理；
- SOC 计划与备用；
- 市场申报与调度指令跟踪；
- 运行方式切换；
- 故障分级与告警。

如果边界不清，会出现：

- EMS 以为 SOC 还有 30%，BMS 实际只有 10%，调度指令无法执行；
- EMS 按额定功率申报，BMS 因高温/低 SOC 限功率，考核罚款；
- BMS 因单体过压跳闸，EMS 不知道原因，反复重启；
- BMS 的故障等级与 EMS 的状态机不一致，出现"一个说正常、一个说停机"。

### 1.2 BMS 给什么，EMS 用什么

| BMS 输出 | EMS 用途 | 常见问题 |
|---|---|---|
| SOC | 能量计划、备用、申报 | 漂移、平台区、校正策略 |
| SOH | 容量申报、检修、寿命评估 | 口径不一（容量/电阻/功率） |
| SOP | 功率上限、调频/调峰能力 | 温度/能量/电压限制未透传 |
| 单体电压/温度 | 一致性、热管理、故障定位 | 采样精度、通信延迟 |
| 绝缘电阻 | 安全联锁 | 阈值、湿度、老化 |
| 接触器/预充状态 | 启停逻辑 | 粘连、拒动 |
| 故障等级 | 状态机、告警、停机 | 等级定义不一致 |
| 均衡状态 | 运维、SOC 校正 | 均衡电流小、时间长 |

EMS 不应"绕过 BMS"直接控制接触器/电芯；BMS 也不应"绕过 EMS"做全站功率分配。两者通过明确的接口和状态机协作。

### 1.3 边界写进合同

BMS/EMS 的技术协议至少要写：

- SOC/SOH/SOP 的定义、精度、更新周期、校正条件；
- 故障等级、阈值、复位条件、联锁动作；
- 通信协议、点表、超时、重连、数据质量；
- 均衡策略、均衡电流、启停条件；
- 与 PCS/消防/空调/门禁的联锁；
- 责任边界：谁负责 SOC 精度、谁负责功率可达性、谁负责安全停机；
- 软件版本升级后的复核与验收。

**边界不清的典型后果是：出问题时 BMS 厂家说"EMS 指令不对"，EMS 厂家说"BMS 数据不准"，业主找不到责任方。**

## 2. SOC：算出来，还要校正

### 2.1 安时积分

```text
SOC(t) = SOC(0) − (1 / C_N) ∫ η I(t) dt × 100%
```

- `C_N`：额定容量（Ah）；
- `I`：电流（放电为正）；
- `η`：库仑效率；
- `SOC(0)`：初始 SOC。

算例：280 Ah 电芯，初始 50%，放电 100 A、1 h：

```text
SOC = 50 − 100 × 1 / 280 × 100 = 14.286%
```

安时积分的问题：

- 电流采样误差会累积；
- 倍率、温度、老化改变可用容量；
- 充放电效率不是常数；
- 初始 SOC 可能不准；
- 长期运行没有校正会漂移。

### 2.2 OCV 校正

OCV 与 SOC 有非线性关系。算例 OCV 表：

| SOC（%） | OCV（V） |
|---:|---:|
| 0 | 2.80 |
| 10 | 3.20 |
| 20 | 3.25 |
| 30 | 3.28 |
| 40 | 3.30 |
| 50 | 3.31 |
| 60 | 3.32 |
| 70 | 3.33 |
| 80 | 3.34 |
| 90 | 3.40 |
| 100 | 3.65 |

3.225 V 落在 10%—20% 之间：

```text
SOC_ocv = 10 + (3.225 − 3.20) / (3.25 − 3.20) × 10 = 15.0%
```

与安时积分 14.286% 相差 0.714 个百分点。OCV 校正的难点：

- 需要静置/低倍率，动态下 OCV 不可直接测；
- 磷酸铁锂在 20%—80% 平台区电压变化很小，OCV 对 SOC 不敏感；
- 温度、 hysteresis、老化会改变 OCV 曲线；
- 校正太频繁可能引入噪声，校正太少会漂移。

### 2.3 模型法

工程上常用：

- EKF/UKF：用等效电路模型（OCV、R0、RC）和量测更新 SOC；
- 滑模观测器；
- 数据驱动/机器学习（辅助，不替代安全逻辑）；
- 多方法融合：安时积分 + OCV 校正 + 模型法 + 满充/满放标定。

无论哪种方法，都要回答：

- 精度是多少，在什么工况下？
- 校正条件是什么，多久一次？
- 平台区/低温/大倍率下误差多大？
- SOC 误差如何影响 SOP、备用、申报？
- 有没有冗余/交叉校验？

### 2.4 SOC 误差的业务后果

- 申报容量偏大 → 实际可用能量不足 → 偏差考核/违约；
- 备用 SOC 留得过低 → 紧急支撑时没电；
- SOC 显示过高 → 过充风险；
- SOC 显示过低 → 过放风险/寿命下降；
- 多簇 SOC 不一致 → 环流、出力不均、寿命差异。

**SOC 不是"显示值"，是资产可用性和安全边界的输入。**

## 3. SOH：容量、电阻与寿命

### 3.1 三种口径

| 口径 | 定义 | 用途 | 局限 |
|---|---|---|---|
| 容量 SOH | 当前可用容量 ÷ 初始容量 | 能量申报、寿命评估 | 受温度/倍率/截止电压影响 |
| 电阻 SOH | 当前内阻 ÷ 初始内阻 | 功率能力、热评估 | 受温度/SOC/频率影响 |
| 功率 SOH | 当前 SOP ÷ 初始 SOP | 调频/调峰能力 | 受工况影响大 |

本文算例用容量 SOH：

```text
SOH = 100% − 循环衰减 − 日历衰减
```

### 3.2 循环与日历

算例假设：

- 循环衰减 1.5 个百分点/1000 次；
- 日历衰减 2.0 个百分点/年；
- 600 次循环、2 年。

```text
循环衰减 = 1.5 × 600 / 1000 = 0.9 个百分点
日历衰减 = 2.0 × 2 = 4.0 个百分点
SOH = 100 − 0.9 − 4.0 = 95.1%
剩余容量 = 280 × 0.951 = 266.28 Ah
```

真实衰减不是线性：

- 前几百次循环可能较快，之后趋缓；
- 高温、满充搁置、深放电、大倍率会加速；
- 日历衰减与温度/ SOC 强相关；
- 不同电芯化学体系差异很大；
- 衰减到 80% 通常被视为寿命终点，但项目可按保修/安全/经济性定义。

### 3.3 SOH 的业务用途

- 可用容量申报：SOH 95.1% 意味着容量修正后的能量约 190.2 MWh；按 10%—90% SOC 窗口，全窗口可用能量约 152.2 MWh，若从 50% SOC 起放电则当前可放约 76.1 MWh（再扣 RTE 和辅助用电）；
- 检修计划：SOH 下降快时提前排查；
- 保修索赔：循环/日历/温度/倍率记录；
- 二手/梯次利用：SOH 与安全状态；
- 投资模型：容量衰减导致收益下降、增容/更换成本。

SOH 不能只看一个数：要区分**可恢复容量损失**（均衡/标定后恢复）和**不可恢复衰减**（材料/SEI/锂库存损失）。

## 4. SOP：功率不是额定值

### 4.1 SOP 的约束

```text
SOP = min(
  功率上限（PCS/变压器/线路）,
  能量上限（可用能量 ÷ 持续时间）,
  温度降额后的功率,
  电压/电流限制,
  SOC 窗口限制
)
```

算例：100 MW/200 MWh，SOC 下限 10%，持续 0.5 h，最大 0.5C，35 ℃ 起每升高 1 ℃ 降额 3%（45 ℃ 时温度系数 0.70）。

| 场景 | 能量裕度（MWh） | 能量限功率（MW） | 温度系数 | 温度限功率（MW） | SOP（MW） |
|---|---:|---:|---:|---:|---:|
| 40% SOC，25 ℃ | 60 | 120 | 1.00 | 100 | 100 |
| 40% SOC，45 ℃ | 60 | 120 | 0.70 | 70 | 70 |
| 15% SOC，25 ℃ | 10 | 20 | 1.00 | 100 | 20 |

读法：

- 40% SOC、25 ℃：PCS/额定功率是瓶颈，SOP=100 MW；
- 40% SOC、45 ℃：温度降额到 70 MW；
- 15% SOC、25 ℃：能量只够 20 MW 持续 0.5 h，SOP=20 MW。

### 4.2 为什么 EMS 不能把 SOP 当常数

- 高温时段光伏/负荷/市场机会可能同时出现，但 SOP 已降额；
- 低 SOC 时能量比功率更紧，调频/备用能力下降；
- 低温充电可能受限（析锂风险），SOP 充电方向另算；
- 电压接近上限/下限时，功率可能被提前限制；
- 多簇并联时，SOP 不是单簇 SOP 简单相加（不一致、环流、通信）。

EMS 的调度模型要把 SOP 作为**时变约束**，并在申报/备用/AGC 中预留裕度。

### 4.3 SOP 与备用

如果 EMS 承诺 20 MW 备用，但当时 SOP 只有 15 MW，备用是"纸面备用"。工程上要：

- 备用容量 ≤ SOP − 当前出力；
- 备用持续时间 ≤ 可用能量 ÷ 备用功率；
- 温度/ SOC 变化时滚动校核；
- 多簇/多站聚合时考虑相关性；
- 备用与能量市场/辅助服务申报协调。

## 5. 均衡：慢功夫

### 5.1 被动均衡

被动均衡用电阻消耗高电压电芯的能量：

- 成本低、电路简单；
- 均衡电流小（几十—几百 mA）；
- 能量以热的形式耗散；
- 均衡时间长。

算例：取一个 16 串电池簇做教学简化（实际电站簇串数更高，但单电芯均衡时间与串数无关；每个单体配一个均衡电阻，按最高单体计算），最大压差 40 mV，280 Ah，均衡电流 100 mA，假设 0.25%/mV：

```text
ΔSOC = 40 mV × 0.25%/mV = 10%
多余能量 = 10% × 280 Ah × 3.2 V = 89.6 Wh
均衡功率 = 0.1 A × 3.2 V = 0.32 W
均衡时间 = 89.6 / 0.32 = 280 h
```

约 11.7 天。这还没有考虑：

- 均衡只在特定条件（静置/充电末段）启动；
- 均衡电流随电压/温度变化；
- 电芯自放电/不一致继续产生；
- BMS 采样误差。

**被动均衡适合"小偏差、长期维护"，不适合"严重不一致、临时抱佛脚"。**

### 5.2 主动均衡

主动均衡把能量从高 SOC 电芯转移到低 SOC 电芯：

- 效率更高、发热少；
- 电路复杂、成本高；
- 均衡电流可以更大；
- 仍需考虑安全/隔离/故障。

主动均衡不是"万能"：电芯容量/内阻差异是物理问题，均衡只能缓解 SOC 不一致，不能修复已损坏的电芯。

### 5.3 什么时候均衡

- 充电末段/静置时；
- 压差超过阈值；
- 维护/检修时；
- 发现某簇/某模组持续偏低；
- 不是"一有压差就全力均衡"。

均衡策略要与 SOC 校正、热管理、充放电计划配合。严重不一致要先查原因（连接电阻、采样、内阻、微短路），不是盲目均衡。

## 6. 安全联锁：分层、分级、可复位

### 6.1 联锁层级

| 层级 | 典型判据 | 动作 | 复位 |
|---|---|---|---|
| 电芯 | 过压/欠压/过温/低温/内短路 | 停止充/放、告警 | 人工/自动（按等级） |
| 模组 | 电压/温度/采样异常 | 限功率/隔离模组 | 人工检查 |
| 电池簇 | 簇过流/绝缘/接触器/熔断器 | 断开簇、告警 | 人工 |
| 电池舱 | 气体/烟雾/温升/消防 | 停机、排风、灭火、切断 | 消防/人工 |
| PCS | 过流/过压/欠压/过温/通信 | 封锁脉冲/跳闸 | 人工/自动 |
| 升压变/开关柜 | 过流/零序/温度/压力 | 跳闸 | 人工 |
| EMS | 全站故障/通信/消防 | 停机/隔离/告警 | 人工 |

### 6.2 联锁原则

- **故障安全**：失电/通信中断/传感器故障时，进入安全状态；
- **分层独立**：BMS 的安全联锁不能只依赖 EMS；
- **硬线优先**：紧急停机、消防、门禁等关键联锁应有硬线/独立回路；
- **闭锁与复位**：故障要锁存，复位要人工确认/检查；
- **可追溯**：记录故障时间、判据、动作、复位人；
- **防误**：检修/调试要有挂牌/隔离/防误逻辑。

### 6.3 典型联锁场景

- 电芯过压 → BMS 请求 PCS 降功率/停机；
- 簇绝缘低 → 断开簇接触器，禁止合闸；
- 舱内可燃气体/烟雾 → 停机、切断、排风、消防；
- 冷却失效/温度高 → 降额/停机；
- PCS 故障 → 断开交流/直流开关；
- 消防喷放 → 切断非消防电源，防止复燃/触电；
- 门禁/检修 → 禁止远程操作。

联锁逻辑要与保护整定、消防设计、PCS 控制、EMS 状态机一致。保护整定见[《微电网与储能电站保护整定》](微电网与储能电站保护整定-2026-11.md)。

## 7. 状态机与故障分级

### 7.1 状态

一个可运维的状态机至少包括：

```text
停机（Stop）
  → 预充/自检（Precharge）
  → 待机（Standby）
  → 充电/放电（Charge/Discharge）
  → 降额（Derated）
  → 限功率（Limited）
  → 故障停机（Trip）
  → 隔离（Isolated）
```

状态转换要有：

- 进入条件；
- 动作（接触器/PCS/告警）；
- 退出条件；
- 复位权限；
- 记录/上报。

### 7.2 故障分级

| 等级 | 含义 | 典型动作 | EMS 处理 |
|---|---|---|---|
| 1 级（告警） | 轻微异常，不影响运行 | 记录/提示 | 继续运行，关注 |
| 2 级（降额） | 需要限制功率/温度 | 降额/限功率 | 调整计划/申报 |
| 3 级（停机） | 需要停机检查 | 停机/断开 | 退出市场/备用 |
| 4 级（安全） | 热失控/消防/绝缘严重 | 紧急停机/隔离/消防 | 全站安全、告警 |

故障分级要与 BMS、PCS、EMS、消防的等级定义对齐；不能出现"BMS 4 级、EMS 只当告警"。

### 7.3 状态机的可观测性

- 每个状态要有明确的遥测/遥信；
- 状态转换要有 SOE/日志；
- EMS 要能看到 BMS 的故障码/等级；
- 远方/就地控制要有优先级；
- 通信中断要有明确的安全默认状态；
- 复位不能"一键掩盖"故障。

## 8. D 级合成算例：100 MW/200 MWh 的状态边界

> 本算例为合成数据，仅用于演示 SOC/SOH/SOP/均衡的计算链；不对应任何真实电芯、BMS 或储能电站。

### 8.1 参数

| 项目 | 数值 |
|---|---:|
| 额定功率 | 100 MW |
| 额定能量 | 200 MWh |
| 电芯容量 | 280 Ah |
| 电芯标称电压 | 3.2 V |
| SOC 下限/上限 | 10% / 90% |
| 初始 SOC | 50% |
| 放电电流 | 100 A |
| 放电时间 | 1 h |
| 循环 | 600 次 |
| 运行年数 | 2 年 |
| 循环衰减 | 1.5 个百分点/1000 次 |
| 日历衰减 | 2.0 个百分点/年 |

### 8.2 SOC

| 方法 | 结果 |
|---|---:|
| 安时积分 | 14.286% |
| OCV（3.225 V） | 15.0% |
| 校正量 | +0.714 个百分点 |

### 8.3 SOH

| 项目 | 数值 |
|---|---:|
| 循环衰减 | 0.9 个百分点 |
| 日历衰减 | 4.0 个百分点 |
| SOH | 95.1% |
| 剩余容量 | 266.28 Ah |

### 8.4 SOP

| 场景 | SOP（MW） | 瓶颈 |
|---|---:|---|
| 40% SOC，25 ℃ | 100 | 额定功率 |
| 40% SOC，45 ℃ | 70 | 温度降额 |
| 15% SOC，25 ℃ | 20 | 能量裕度 |

### 8.5 均衡

| 项目 | 数值 |
|---|---:|
| 最大压差（单簇 16 串） | 40 mV |
| 估算 SOC 差 | 10% |
| 多余能量 | 89.6 Wh |
| 均衡功率 | 0.32 W |
| 均衡时间 | 280 h |

### 8.6 这个算例说明什么

- 安时积分与 OCV 校正可以差 0.7 个百分点，长期不校正会更大；
- SOH 95.1% 不是"还能跑 95.1% 的功率"，容量/功率/电阻要分开看；
- SOP 在不同温度/SOC 下差 5 倍，EMS 不能当常数；
- 被动均衡 280 h，说明它只能解决小偏差；
- 状态边界要把 SOC/SOH/SOP/温度/故障等级一起传给 EMS。

### 8.7 这个算例不说明什么

- 不代表真实电芯的 OCV 曲线、衰减率、内阻、热特性；
- 不覆盖 EKF/UKF、热模型、热失控传播、消防；
- 不覆盖多簇并联、环流、不一致、采样误差；
- 不给出真实 BMS 阈值、联锁逻辑或设备选型结论；
- 不能替代 BMS 算法验证、安全评估和现场标定。

## 9. 数据与通信

### 9.1 数据点

BMS 至少要给 EMS：

- 簇/模组/电芯电压（最大/最小/平均）；
- 温度（最大/最小/平均/温差）；
- 电流、SOC、SOH、SOP（充/放）；
- 绝缘电阻；
- 接触器/预充/熔断器状态；
- 故障码/等级；
- 均衡状态；
- 累计充放电量/循环次数；
- 通信状态/时间戳。

### 9.2 通信

- CAN/RS485/Modbus/TCP 等协议各有实时性/可靠性差异；
- 采样周期、上传周期、超时、重连要定义；
- 数据质量位（有效/无效/旧数据）要传；
- 多簇/多舱聚合要有统一时标；
- 与 PCS/EMS/消防/云平台的接口要隔离/冗余；
- 网络安全：访问控制、加密/认证、日志、补丁。

SCADA/数据链路见[《SCADA 与电力监控数据链路》](SCADA与电力监控数据链路-2026-11.md)，EMS 接口见[《EMS 数据接口参考架构》](EMS数据接口参考架构-2026-11.md)。

### 9.3 数据质量

- SOC/SOH/SOP 是"估算值"，不是"测量值"；
- 要带置信度/质量位；
- 通信中断时 EMS 要用保守值/退出市场；
- 多源数据冲突时要有仲裁；
- 历史数据要能追溯算法版本/标定记录。

## 10. 标准与安全

- **GB/T 34131-2023《电力储能用电池管理系统》**对 BMS 的功能、性能、通信、安全提出要求；版本以现行有效文本为准。
- **GB/T 36276-2023《电力储能用锂离子电池》**覆盖电池性能与安全测试；具体测试项目以标准原文为准。
- **GB/T 36558-2023《电力系统电化学储能系统通用技术条件》**给出储能系统通用技术要求。
- **GB/T 42288-2022《电化学储能电站安全规程》**涉及电站安全运行；具体条款以正式文本为准。
- **GB 44240-2024《电能存储系统用锂蓄电池和电池组安全要求》**是电池安全的重要强制性标准，2025-08-01 实施；具体条款以正式文本为准。
- **GB/T 51048-2025《电化学储能电站设计标准》**涉及布置、消防、电气、通风设计；2026-04-01 实施，替代 GB 51048-2014。
- **GB/T 34120-2023《电化学储能系统储能变流器技术要求》**涉及 PCS 与 BMS 的接口/保护。
- **GB/T 40090-2021《储能电站运行维护规程》**涉及运维、巡检、故障处理。
- IEC 62619、IEC 62933-5-2、UL 9540A 等国际标准/测试方法可作为参考，但适用性要按项目所在市场和并网要求判断。

标准不能替代厂家的电芯/BMS 数据和安全评估；热失控、消防、气体检测等要以实际测试和设计为准。

## 11. 对投资、运营与交易的含义

### 11.1 投资

- SOC/SOH/SOP 的精度和衰减假设直接影响可用能量、收益和更换成本；
- BMS 的均衡能力、采样精度、故障分级影响运维成本；
- 消防/联锁/通信/备件是隐性投资；
- 保修条款要覆盖容量衰减、循环次数、温度/倍率条件；
- 不同厂家 BMS 的 SOC 算法/接口差异会影响 EMS 集成。

### 11.2 运营

- 每日核对 SOC 与电量、SOC 与 OCV/标定；
- 定期检查压差、温差、绝缘、接触器；
- 高温/低温季节调整 SOP 和运行策略；
- 均衡不能替代检修，严重不一致要查原因；
- 故障分级/复位要有规程；
- 软件升级后要复核 SOC/SOP 和联锁。

### 11.3 交易与市场

- 申报可用容量要用 SOH/SOP 修正后的值；
- 备用/调频要预留 SOC 和温度裕度；
- 高温/低 SOC 时不能按额定功率承诺；
- 故障停机要退出市场/备用，避免考核；
- 储能参与辅助服务时，BMS 限功率可能导致履约失败；
- 交易员要关注电站的 SOC/SOH/SOP 状态和检修计划。

### 11.4 数据与 AI 的边界

AI 可以做 SOC/SOH 估计、异常检测、寿命预测，但：

- 训练数据要覆盖真实工况/老化/故障；
- 安全联锁不能由 AI 实时替代；
- 模型要有可解释性和审计；
- 预测结果要带置信度；
- "AI 说电池健康"不能替代 BMS 保护和安全评估。

## 12. 常见错误（10 条）

1. **把 SOC 当测量值**：SOC 是估算值，不校正会漂移。
2. **用额定功率当 SOP**：温度、SOC、能量、电压都会限制功率。
3. **SOH 只看容量**：功率能力/内阻/安全状态可能先恶化。
4. **忽略 SOC 平台区**：磷酸铁锂 20%—80% 的 OCV 对 SOC 不敏感，校正困难。
5. **被动均衡当万能**：均衡电流小、时间长，严重不一致要先查原因。
6. **联锁只靠软件**：通信中断/EMS 故障时，关键联锁要有硬线/独立回路。
7. **故障等级不统一**：BMS 4 级、EMS 只当告警，导致误判。
8. **通信中断用最后值**：旧数据可能让 EMS 继续调度，必须用保守值/退出。
9. **软件升级不复核**：BMS/EMS 升级后 SOC/SOP/联锁可能变化。
10. **把 BMS 当"黑箱"**：不读故障码/单体数据，无法定位不一致/热问题。

## 15. 速查

### 15.1 六个公式

```text
SOC(t) = SOC(0) − (1 / C_N) ∫ η I dt × 100%
SOC_ocv = 插值(OCV 表)
SOH = 100% − 循环衰减 − 日历衰减
SOP = min(功率上限, 可用能量 / 持续时间, 温度降额, 电压/电流限制)
均衡时间 = 多余能量 / 均衡功率
可用能量 = 额定能量 × SOH × (SOC − SOC_min) / 100
```

### 15.2 五个必问

1. SOC 用什么算法，精度多少，多久校正一次，平台区怎么办？
2. SOH 是容量、电阻还是功率口径，衰减假设是什么？
3. SOP 是否随温度/SOC/能量实时更新，EMS 是否把它当约束？
4. 均衡电流多大，严重不一致要多久，是否先查原因？
5. 联锁分几层，通信中断/失电时是否安全，复位权限是谁？

### 15.3 工具

```bash
# 在 skills/ems-dispatch/tools 下
python bms.py                 # 打印 SOC/SOH/SOP/均衡
python bms.py --json          # JSON 输出
python selftest.py            # 断言本文数字
```

`bms.py` 只做安时积分、线性插值、线性衰减和简化 SOP/均衡的确定性演示，不是生产级 BMS 算法。
