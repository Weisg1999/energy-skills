## 0. 一页速查

### 0.1 微网控制链分层

| 层级 | 时间尺度 | 典型功能 | 本文是否覆盖 |
|---|---|---|---|
| 继电保护 | ≤10 ms | 故障切除、防孤岛、解列 | 否（只给约束边界） |
| 一次控制 | ms–s | 下垂、构网型（GFM）电压/频率支撑 | 否 |
| 二次控制 | s–min | 频率/电压恢复、AGC/AVC | 部分（设定值） |
| 微网中央控制器 | 100 ms–s | 并/离网切换、状态机、黑启动时序 | 部分（§6.6） |
| **EMS 优化调度** | **min–h** | **96 点经济调度、备用核算、滚动修正** | **本文主体** |
| 计划/市场 | day-ahead | 申报、中长期分解、需量管理 | 引用其他技能 |
| 规划 | 年 | 容量配置、选址定容 | 否 |

**EMS 不替代保护与控制。** 优化器给出的是安全边界内的功率设定值计划；故障穿越、解列、同期合闸由保护与控制器完成。

### 0.2 三句话

1. **日前是 MILP，不是 LP**：充放互斥、启停、购售互斥都是逻辑约束；去掉它们会得到"同时充放"的虚假最优。
2. **三条硬边界先于目标函数**：并网点最大受电/送出功率、380 V 微网 EMS 的指令与上送周期、非计划孤岛必须快速解列。目标再优，越界即不可执行。
3. **可交付优于最优**：超时返回可行解、不可行给诊断、数值异常回退上一版计划，比"追求 0 gap"更能保证日运行。

### 0.3 适用与不适用

| 适用 | 不适用 |
|---|---|
| 并网型微网日前/日内经济调度 | 大电网机组组合与全网络安全约束 |
| 单站或多站储能的峰谷套利、需量管理 | 电力市场报价策略与结算（见《现货报价量化专家》） |
| 园区/站点级源网荷储协同 | 毫秒级保护定值与电磁暂态 |
| 孤岛内经济调度与备用核算 | 黑启动全过程时序设计（只给约束与校验点） |

## 1. 问题定位：微网 EMS 是什么运筹问题

微网 EMS 的日前优化，本质是回答：**在 96 个 15 分钟时段里，源、荷、储、网各出多少力，才能使全天购电成本最低，同时满足设备、并网与业务约束。**

### 1.1 六维度识别

| 维度 | 识别结论 | 对建模的影响 |
|---|---|---|
| 优化目标 | 单目标（成本最小）为主，经济性、SOC 跟随、功率平滑用加权/惩罚折叠 | 需要设计惩罚系数与正则项 |
| 决策变量 | 连续（功率、SOC）+ 逻辑（充放互斥、购售互斥、启停） | 混合整数规划（MILP） |
| 约束类型 | 容量、时间窗、备用、并网限值、业务规则、功率平衡 | 多类约束模块组合 |
| 问题边界 | 多周期（96 时段耦合，SOC 跨期递推） | 时序耦合，不是单周期 LP |
| 不确定性 | 常见实现为确定性单曲线（光伏/负荷/电价各一条预测） | 需演进为随机/鲁棒/MPC |
| 求解要求 | 全局最优，日前可接受秒级到十秒级 | 需设时间限、间隙阈值与降级路径 |

### 1.2 为什么是 MILP，而不是 LP 或 NLP

**第一层（物理直觉）**：储能要么充电、要么放电，不能同时充放。这个"二选一"是逻辑约束，连续 LP 无法表达。

**第二层（建模）**：若允许同时充放，模型会在同一时段"左手充电、右手放电"，制造循环损耗并可能套取数值漏洞。充放互斥把问题从 LP 抬升为 MILP。

**第三层（求解）**：MILP 可行域非凸，不能用单纯形一步求解，必须用分支定界：先解 LP 松弛得下界，再对分数整数变量分支，逐步逼近全局最优。

> 去掉充放互斥，问题退化为纯 LP，可秒解但物理不自洽；加入二次损耗或电池老化曲线，则升为 MIQP/MINLP。多数生产系统刻意停在 MILP，是**精度与可解性的工程折中**。

### 1.3 与经典运筹问题的同构关系

| 经典问题 | 同构点 | 可借鉴的解法 |
|---|---|---|
| 多周期生产计划/库存（Lot-Sizing） | SOC ↔ 库存，充放电 ↔ 生产/消耗 | Wagner-Within 动态规划、MILP formulation |
| 机组组合（Unit Commitment） | 充放互斥 ↔ 开停机 0-1，爬坡 ↔ ramp rate | SOS1/Big-M、最小启停时间 |
| 报童/两阶段随机规划 | 光伏负荷不确定 ↔ 需求随机 | 场景法、L-shaped/Benders 分解 |
| 滚动时域控制（MPC） | 日内定时重优化 ↔ receding horizon | 预测 horizon 滚动 + 反馈校正 |
| 网络流 | KCL 功率平衡 ↔ 流守恒 | 网络单纯形（扩展潮流时） |

### 1.6 三条硬约束（模型必须显式表达）

**① 并网点最大受电/送出功率**

GB/T 33589-2026 引入最大受电功率、最大送出功率两个概念。模型必须用 `p_imp`、`p_exp` 两个非负变量分别设限：

```
0 ≤ p_imp[t] ≤ P_imp_max
0 ≤ p_exp[t] ≤ P_exp_max
SOS1(p_imp[t], p_exp[t])
```

若只用一个净功率变量 `p_cc = p_imp − p_exp`，会出现三个问题：两个不同限值无法分别表达；同时购售无法检查；需量电费与结算口径无法对账。

**② 380 V 微网 EMS 的指令与上送周期**

公开解读要求 380 V 微网 EMS 接收并执行有功功率指令，运行数据上送周期不大于 15 min。工程含义：

- 调度时段与通信周期对齐（15 min），不要用 5 min 模型却按 15 min 下发；
- 指令需有回执、超时与重发；通信中断时本地控制器按最后有效曲线或规则兜底；
- 上送数据要带时标，EMS 与 MGCC 必须时间同步，否则滚动优化会用到"未来数据"。

**③ 非计划孤岛与计划孤岛**

- 非计划孤岛由保护快速解列，**不是优化器可以选择的运行方式**；
- 计划孤岛须经调度许可，EMS 的 `z_island` 是外部输入，不是决策变量；
- 孤岛内必须有构网型（GFM）电源形成电压/频率，否则计划不可执行；
- 孤岛期要做能量裕度校验（可用电量 ≥ 预计孤岛时长内负荷电量）。

### 1.7 常见口径误区

| 误区 | 正确口径 |
|---|---|
| 把 20 MW 当成所有微网的规模上限 | 20 MW 是 GB/T 42731-2023 在 ≤35 kV 场景下的技术基线；具体项目以接入论证与地方要求为准 |
| 把 1339 号文的"可再生能源≥50%"当现行强制 | 该文件已过有效期，只能作政策沿革；现行要求看 GB/T 33589-2026、GB/T 42731-2023 与地方细则 |
| 把"并网型微网"与增量配电网、源网荷储一体化混为一谈 | 三者边界、许可与结算不同；本笔记只讨论微网 EMS |
| 把功率因数 0.98 套到所有电压等级 | 10–35 kV 与 380 V 要求不同（公开解读为 0.98/0.95） |
| 把最大受电功率等同于变压器容量 | 前者是运行限值，后者是设备容量；还受线路、保护与调度方式约束 |

## 2. 参考架构：原型—求解—编排三层

成熟的微网优化系统通常不是"一个程序算完"，而是三层分工。

| 层次 | 职责 | 典型产出 | 技术选型 |
|---|---|---|---|
| 算法原型层 | 建模验证、现场数据回归、契约定义 | 可复现的算例、模型文件、接口定义 | Python + 代数建模语言（Pyomo/OR-Tools 等） |
| 求解内核层 | 高性能、可容器化的求解服务 | gRPC 服务，输入 96 点数组，输出功率/SOC 曲线 | C++/Rust + 求解器 C-API（SCIP/CBC/Gurobi/HiGHS） |
| 业务编排层 | 多源数据装配、定时与事件触发、策略与容错、结果下发 | 日计划、滚动计划、告警与回退曲线 | Go/Java + 任务队列 + 关系库/时序库 |

### 2.1 数据流（抽象）

```
预测服务（负荷/光伏/风电） ─┐
电价服务（峰谷平尖/需量）    ─┼─> 编排层：拼装 96 点输入 ─> gRPC ─> 求解层（MILP）
设备配置 / 实时 SOC / 状态   ─┘                                      │
                                                                     v
监控/时序库 <─ 结果落库 <─ 编排层：聚合、校验、回退 <─ 功率/SOC/备用曲线
                                                                     │
                                                                     v
                                                              MGCC/下层控制器执行
```

### 2.2 MMCS 与 MEMS 的分工

IEC TS 62898-3-4 给出一种常见拆分：容量较大（如 >100 kW）的微网把**微网监控/控制（MMCS）**与**能量管理（MEMS）**分开；容量较小的微网可一体实现。工程上的对应关系：

| 角色 | 关注 | 时间尺度 | 失败模式 |
|---|---|---|---|
| MMCS/MGCC | 状态机、并离网切换、保护配合、通信 | 100 ms–s | 切换失败、通信中断 |
| MEMS/EMS | 经济调度、备用核算、滚动修正 | min–h | 超时、不可行、预测偏差 |
| 设备控制器 | 功率跟踪、下垂/GFM、保护 | ms–s | 限幅、脱网 |

**边界不清的典型症状**：EMS 直接写设备寄存器，绕过 MGCC 的切换逻辑；或 MGCC 自行改 EMS 的功率设定值而不回传。两种都会让"计划—执行"不可追溯。

### 2.3 五条架构经验

1. **契约先行**：原型与生产求解器共享同一份接口定义，算法重写时调用方零改动。契约冻结是"算法与工程分离"的关键。
2. **求解器无状态**：求解服务不持有业务状态，便于水平扩展；状态与策略留在编排层。
3. **契约字段必须全链路生效**：定义了却未实现的字段（价格、时间窗、备用、需量参数）会退化为"隐式约定"，是主要技术债。**要么实现，要么删除。**
4. **计划要能回写与对账**：下发曲线、实际执行、偏差原因三者要能按订单号关联，否则滚动优化无法判断"是预测错了还是执行没跟上"。
5. **时间统一**：EMS、MGCC、计量、市场申报用同一时区与同一时段编号（含跨日、夏令时/时区切换），否则 96 点会错位。

### 2.4 评估—优化闭环

可调能力评估（给定当前状态算上调/下调裕度）与优化调度常被做成两个模块。若评估结果只用于展示，不进入优化约束，就形成"评估—优化开环"：优化器不知道设备真实的调节裕度，评估也拿不到优化后的计划。

**闭环做法**：把评估得到的容量/速率/持续时长作为优化模型的动态变量界或备用约束，再把优化后的计划回灌给评估做可行性校验。

| `max_p` | 计费需量 | 连续 |
| `p_pv_used[t], p_pv_curt[t]` | 光伏使用/弃光 | 连续 |
| `p_shed[t]` | 失负荷 | 连续 |
| `p_dg[g,t], u_dg, y_dg, z_dg` | 柴发功率/运行/启动/停机 | 连续 + 0-1 |
| `p_ev_ch/p_ev_dis[j,t], soc_ev[j,t]` | EV 充放与 SOC | 连续 |
| `r_up/r_dn[...]` | 各类资源备用 | 连续 |
| `D[i]` | 退化吞吐/当量循环 | 连续 |

### 3.3 目标函数（最小化）

```
min  Σ_t ( C_buy[t]·p_imp[t] − C_sell[t]·p_exp[t] )·Δt          ① 购售电
   + C_dem·max_p                                                 ② 需量
   + Σ_i Σ_t c_deg[i]·(p_ch[i,t] + p_dis[i,t])·Δt                ③ 退化
   + w_soc·Σ_i Σ_t (d_plus[i,t] + d_minus[i,t])                  ④ SOC 跟踪
   + w_l1·Σ_i Σ_t (u[i,t] + v[i,t])                              ⑤ 功率平滑
   + c_curt·Σ_t p_pv_curt[t]                                     ⑥ 弃光
   + c_shed·Σ_t p_shed[t]                                        ⑦ 失负荷
   + Σ_g Σ_t (c_fuel[g]·p_dg[g,t] + c_su[g]·y_dg[g,t])·Δt        ⑧ 柴发燃料/启动
   + c_co2·Σ_t (e_grid·p_imp[t] + Σ_g e_dg·p_dg[g,t])·Δt         ⑨ 碳（可选）
   − c_term·Σ_i soc[i,T]                                         ⑩ 终端储能价值（可选）
```

- ④ 中 `d_plus − d_minus = soc − soc_ref`，目标罚 `d_plus + d_minus`。
- ⑤ 中 `u − v = p_net[t] − p_net[t−1]`，目标罚 `u + v`。
- 权重是**相对量级**：`w_soc` 取 1e2–1e4（取决于 SOC 用 % 还是 0–1），`w_l1` 取 1e-6–1e-4。必须先归一化目标量级再标定，不能照搬。
- ③ 与 ⑩ 不建议同时启用：日循环模型用 ③，跨日模型用 ⑩，否则会重复计价。

### 3.4 约束条件

```
(C1) 并网功率平衡
     p_imp[t] − p_exp[t] + Σ_g p_dg[g,t] + p_pv_used[t] + p_wind_used[t]
     + Σ_i (p_dis[i,t] − p_ch[i,t]) + Σ_j (p_ev_dis[j,t] − p_ev_ch[j,t])
     = P_load[t] + Σ_l p_fl[l,t] − p_shed[t]                         ∀t

(C2) 孤岛平衡
     p_imp[t] = p_exp[t] = 0                                        ∀t: z_island[t]=1

(C3) SOC 递推（t = 0..T−1）
     soc[i,t+1] = soc[i,t]
       + (100·Δt/E[i])·(η_ch[i]·p_ch[i,t] − p_dis[i,t]/η_dis[i])
       − σ[i]·Δt

(C4) SOC 边界与端点
     SOC_min[i] ≤ soc[i,t] ≤ SOC_max[i]
     soc[i,0] = SOC_init[i]
     soc[i,T] = SOC_init[i]（日循环）或 soc[i,T] ≥ SOC_end[i]（EV 离网）

(C5) 充放互斥
     SOS1(p_ch[i,t], p_dis[i,t])
     或 p_ch ≤ P_ch_max·b_ch；p_dis ≤ P_dis_max·b_dis；b_ch + b_dis ≤ 1

(C6) 爬坡（首尾环形）
     abs(p_net[i,t] − p_net[i,t−1]) ≤ ΔP_max[i]，t=0 时取 t−1 = T−1

(C7) 功率包络
     P_lo[i,t] ≤ p_net[i,t] ≤ P_hi[i,t]

(C8) 需量（对购电，不对净功率）
     max_p ≥ p_imp[t]        ∀t
     max_p ≥ D0

(C9) 柔性负荷守恒（只移不增）
     Σ_t p_fl[l,t] = 0
     −P_fl_down[l,t] ≤ p_fl[l,t] ≤ P_fl_up[l,t]

(C10) 并网点限值与购售互斥
      0 ≤ p_imp[t] ≤ P_imp_max·(1 − z_island[t])
      0 ≤ p_exp[t] ≤ P_exp_max·(1 − z_island[t])
      SOS1(p_imp[t], p_exp[t])

(C11) 备用容量与能量
      Σ_i r_up_ess[i,t] + Σ_g r_up_dg[g,t] + r_up_dr[t] + r_up_ev[t] ≥ R_up[t]
      （下调同理）
      0 ≤ r_up_ess[i,t] ≤ min(P_dis_max − p_dis[i,t], ΔP_max[i])
      r_up_ess[i,t]·τ ≤ η_dis[i]·(soc[i,t] − SOC_min[i])/100·E[i]
      0 ≤ r_dn_ess[i,t] ≤ min(P_ch_max − p_ch[i,t], ΔP_max[i])
      r_dn_ess[i,t]·τ ≤ (SOC_max[i] − soc[i,t])/100·E[i]/η_ch[i]

(C12) 风光与弃电
      p_pv_used[t] + p_pv_curt[t] = P_pv[t]
      0 ≤ p_pv_curt[t] ≤ P_pv[t]
      0 ≤ p_shed[t] ≤ P_load[t] − P_critical[t]

(C13) 柴发启停与爬坡
      P_dg_min·u_dg[g,t] ≤ p_dg[g,t] ≤ P_dg_max·u_dg[g,t]
      y_dg[g,t] − z_dg[g,t] = u_dg[g,t] − u_dg[g,t−1]
      y_dg + z_dg ≤ 1
      最小连续运行/停机时间（用累计 0-1 约束）
      abs(p_dg[g,t] − p_dg[g,t−1]) ≤ ΔP_dg_max[g]

(C14) 孤岛可行性
      z_island[t] ≤ gfm_available[t]
      Σ_g P_dg_max·u_dg + Σ_i (P_dis_max − p_ch[i,t]) ≥ P_load[t] + R_up[t]
      孤岛期能量裕度：可用电量 ≥ 预计孤岛时长内的负荷电量

(C15) 退化
      D[i] = Σ_t (p_ch[i,t] + p_dis[i,t])·Δt（或雨流计数当量循环）
      D[i] ≤ D_max[i]（日/月/年预算）

(C16) 无功/电压（可选）
      Q 上下限、功率因数范围；配网潮流或灵敏度近似

(C17) N-1/韧性（可选）
      任一关键设备退出后仍满足关键负荷；或场景化校验

(C18) 碳与绿电（可选）
      e_grid·p_imp 计入范围二；绿电/绿证抵扣须单独口径
```

> **SOC 索引**：`soc` 有 `T+1` 个值，`soc[0]` 是初始状态，`soc[T]` 是末端。写成 `soc[t]` 与 `soc[t−1]` 的递推也常见，但必须与初始条件、终端条件对齐，**差一位就会把全天计划整体平移 15 min**。

### 3.5 模型边界：不建模什么

| 不建模 | 原因 | 替代做法 |
|---|---|---|
| AC 潮流/节点电压 | 微网规模小，但非线性强；嵌入 MILP 会变成 MINLP | 线性化 DistFlow、灵敏度约束，或事后校验 |
| 频率动态/惯量 | 时间尺度 ms–s，与 15 min 调度不匹配 | 用 GFM 容量、备用与保护定值做约束 |
| 保护配合 | 依赖设备与整定，不是经济问题 | 并网检测、HIL/PHIL 验证 |
| 电池电化学/热过程 | 太细，日内不可解 | 退化吞吐/当量循环 + 温度修正系数 |
| 市场报价 | 属于交易策略 | 引用《现货报价量化专家》 |
| 黑启动全过程 | 是时序与操作票问题 | 给黑启动校验点与能量裕度约束 |

### 3.6 规模量级

以 `T=96`、4 台储能、20 个充电枪、2 台柴发为例：连续变量约数千个，0-1 变量约数千个，SOS1 约束约 2–3 千条。这个规模对现代 MIP 求解器不算大，**难点在数值条件、退化建模与滚动调用的稳定性**，不在变量数。

## 4. 关键建模技巧

### 4.1 SOC 递推必须含效率与自放电

```
soc[t+1] = soc[t] + (100·Δt/E)·(η_ch·p_ch[t] − p_dis[t]/η_dis) − σ·Δt
```

漏掉效率会系统性高估套利收益：充电时少算损耗、放电时多算可用电量。**效率和容量单位（kWh）必须同时进入递推，SOC 用百分比时不要忘记 `/100`。**

单元测试：充 1 kWh 再放 1 kWh，SOC 净变化应为 `−(1/η_ch − η_dis)` 量级的损耗；`η=0.95` 时往返效率约 0.9025。

### 4.2 充放互斥：Big-M、SOS1 与指示约束

| 方案 | 数学表达 | LP 松弛质量 | 分支效率 | 适用 |
|---|---|---|---|---|
| Big-M | `p_ch ≤ M·b_ch`；`p_dis ≤ M·b_dis`；`b_ch+b_dis ≤ 1` | 松（M 大时 b=0.5 仍允许半功率） | 慢 | 求解器不支持 SOS1/指示约束时的兜底 |
| SOS1 | `SOS1(p_ch, p_dis)`，至多一个非零 | 紧（凸包天然排除同时非零） | 快 | 生产首选 |
| 指示约束 | `b=0 ⟹ p_ch=0`；`b=1 ⟹ p_dis=0` | 取决于求解器实现 | 中 | 支持指示约束的求解器，表达最直观 |

Big-M 的 `M` 通常取功率上限；`M` 越大松弛越松，`M` 越小可能误割可行解。**SOS1 不需要调 M，是更稳的生产选择。**

### 4.3 需量电费：对购电功率取最大

```
max_p ≥ p_imp[t]   for all t
max_p ≥ D0
obj += C_dem · max_p
```

目标最小化会自然把 `max_p` 压到实际最大购电功率。三个易错点：

1. **不要对净功率取最大**：净功率把中午反送与晚峰受电混在一个变量里，既无法分别设限，也无法与需量结算口径对账。
2. **不要漏 `D0`**：本月已发生最大需量，遗漏会导致月初重复计费或月底低估。
3. **确认计费口径**：是按月最大 15 min 平均受电功率，还是按变压器容量/合同需量；不同口径对应不同约束。

### 4.4 绝对值：u-v 拆解

```
dP = u − v,  u ≥ 0,  v ≥ 0
abs(dP) = u + v
```

只要目标里是最小化 `u+v`，最优解不会让 u、v 同时为正。SOC 偏差同理，用 `d+ − d−` 拆解后对 `d+ + d−` 罚。

### 4.5 SOC 日循环与跨日套利

若不做日循环约束，优化器会把末端 SOC 放到最低，等于"偷"第二天的电，日成本看起来更低但跨日不可持续。三种做法：

| 做法 | 表达 | 适用 | 风险 |
|---|---|---|---|
| 显式终端等式 | `soc[T] = soc[0]` | 日循环、有固定作息 | 初始 SOC 异常时会把偏差带入全天 |
| 终端不等式 | `soc[T] ≥ SOC_end` | EV、备用要求 | 可能留下过多电量 |
| 终端价值 | 目标加 `−c_term·soc[T]` | 跨日连续优化 | `c_term` 难标定，易造成末端囤电 |

### 4.6 用变量界代替逻辑约束

不可调设备不必新增 0-1 变量，直接把功率上下界夹到当前值：

```
if not adjustable:
    P_lo = P_hi = current_power
```

这比"加一个开关变量"更轻，也避免求解器在无意义的分支上浪费时间。

### 4.7 EV/V2G 建模

- `T_start/T_end` 表示在网窗口；非在网时段把功率包络置 0，比在模型里写复杂时间窗更稳。
- `SOC_end` 是离网目标；硬跟随可用大系数惩罚，软跟随则允许偏差并计入违约成本。
- `P_dis_max > 0` 天然支持 V2G，有序充电（V1G）与 V2G 可共用一套模型；V1G 时把放电上限置 0。
- 充电惩罚用于抑制"价差不足却充了再放"的无效循环；惩罚单价应按退化成本标定，而不是拍一个数。
- 通信与协议：有序充电可参照 GB/T 47503-2026；V2G 涉及 OCPP 2.0.1、ISO 15118、GB/T 27930 等，**协议版本与互操作性要在项目层面核实**。
- 降级策略要前置：全程满功率仍达不到目标 SOC → 直接快充；初始 SOC 越界 → 先充/放回可行域；正常情况才进求解器。

### 4.8 多储能聚合

| 口径 | 做法 | 风险 |
|---|---|---|
| 逐设备建模 | 每台储能独立变量与 SOC | 规模大，但物理准确 |
| 聚合成虚拟储能 | 功率直接求和，SOC 按容量加权 | 简化，可能掩盖设备间效率、循环次数与环流差异 |

聚合 SOC 的常见写法：

```
SOC_agg = Σ_i E[i]·soc[i] / Σ_i E[i]
```

但聚合后无法保证每台设备都不越界。**对外展示可用聚合值，下发控制必须回到逐设备曲线**；调度前要用逐设备 SOC 做一次可行性回代。

### 4.9 退化建模的三档精度

| 档位 | 模型 | 成本 | 适用 |
|---|---|---|---|
| 一档 | 吞吐量线性：`c_deg·Σ(p_ch+p_dis)·Δt` | 低 | 日前经济调度 |
| 二档 | 当量循环：按 DoD 分档加权，或雨流计数 | 中 | 周/月计划、寿命评估 |
| 三档 | 电化学-热耦合 | 高 | 研发、质保争议 |

工程建议：日前用一档，月度复盘用二档；**不要用"循环次数"单一指标替代吞吐与深度**，否则会低估高 SOC 浮充与浅充浅放的差异。

### 4.10 备用的四个维度

备用不是只报一个 kW 数，至少要回答四件事：

| 维度 | 含义 | 模型落点 |
|---|---|---|
| 容量 | 能增加/减少多少功率 | `r_up/r_dn` 上限 |
| 速率 | 多快能达到 | 爬坡约束与响应时间 |
| 持续时长 | 能维持多久 | 能量约束 `r·τ ≤ 可用电量` |
| 能量 | SOC 裕度是否足够 | 充/放方向的 SOC 余量 |

储能备用是 **SOC 相关**的：上调（放电）受 `soc − SOC_min` 限制，下调（充电）受 `SOC_max − soc` 限制；同时备用会挤占套利空间，必须在目标或约束里显式权衡。

### 4.11 孤岛、GFM 与黑启动

**孤岛不是稳态优化问题，而是带时序的状态切换。** 优化器能做的是：

1. 孤岛前：核算孤岛期能量裕度与 GFM 容量；
2. 孤岛中：在孤岛平衡下做经济调度与备用分配；
3. 复电前：校验同期条件，安排负荷逐级恢复。

| 阶段 | 关键动作 | EMS 角色 |
|---|---|---|
| 非计划孤岛 | 保护检测 → 快速解列 → GFM 建压 → 切负荷保关键负荷 | 读取状态，重算孤岛计划 |
| 计划孤岛 | 调度许可 → 功率预平衡 → 解列 → 孤岛运行 | 生成孤岛计划与备用 |
| 黑启动 | 启动电源 → 建立母线电压 → 逐级带负荷 → 并网 | 给启动顺序与能量校验点 |
| 重连 | 同期检测 → 合闸 → 功率回代 | 平滑过渡，避免冲击 |

GFM 是孤岛可行性的前提：跟网型（GFL）变流器无法独立建压。GB/T 47968-2026 对构网型变流器提出通用要求，选型与测试要以正式文本为准。

### 4.12 常见建模错误

| 错误 | 后果 | 检查方法 |
|---|---|---|
| 净功率单变量 | 进/出限值无法分别表达，需量口径错 | 检查是否有 `p_imp/p_exp` 两个变量 |
| 需量按净功率 | 需量电费被低估或对账不符 | 检查 `max_p ≥ p_imp` |
| SOC 索引差一位 | 全天计划平移 15 min | 检查 `soc[0]` 与 `soc[T]` 的定义 |
| 漏效率/自放电 | 套利收益虚高 | 1 充 1 放守恒测试 |
| 充放互斥用 LP 松弛 | 同时充放，损耗虚假 | 检查是否有 SOS1/0-1 |
| EV 未进入功率平衡 | EV 成为"死变量"，计划与物理不符 | 检查 KCL 是否含 EV 项 |
| 孤岛时 PCC 不为零 | 孤岛计划物理不可行 | 检查 `z_island` 是否强制置零 |
| 备用只算容量不算能量 | 申报能力虚高，考核不合格 | 检查 SOC 余量与持续时间 |
| 日循环缺失 | 末端偷电，跨日不可持续 | 检查终端等式/价值 |
| 爬坡首尾不闭环 | 跨日功率跳变 | 检查 `t=0` 与 `t=T−1` 的衔接 |
| 柔性负荷不守恒 | 总用电量被悄悄削减 | 加总量等式约束 |
| 退化只按循环次数 | 低估高 SOC 浮充与浅充浅放 | 用吞吐/雨流复核 |
| 多储能聚合后不还原 | 单台越界、环流 | 下发前逐设备回代 |
| 单位混用 kW/kWh/15 min | 结果差 4 倍或 100 倍 | 统一 `Δt=0.25`，写清单价口径 |
| 权重未归一化 | 求解器数值病态、目标被单项支配 | 先算各项量级再定权 |

## 5. 求解与工程化

### 5.1 分支定界在做什么

```
1. LP 松弛：忽略整数性，解连续 LP，得下界
2. 分支：对分数变量分裂子问题
3. 定界：子问题下界劣于当前最优整数解则剪枝
4. 割平面：收紧松弛，加速收敛
5. 回溯：直到 gap 达标或时间耗尽
```

### 5.2 生产求解器必须设的参数

| 参数 | 作用 | 建议 |
|---|---|---|
| 时间限 `limits/time` | 防止大微网无限求解 | 按调用超时留余量，如 10 s 调用设 8–9 s |
| 间隙 `limits/gap` | 提前接受近优解 | 1%–2% 通常足够；备用/安全相关场景可收紧 |
| 线程 `lp/threads` | 控制资源占用 | 与容器 CPU 限额一致，避免超卖 |
| 热启动/模型复用 | 降低高频调用开销 | 复用模型结构，更新参数与初始解 |
| 数值容差 | 避免虚假不可行 | 统一量纲，必要时缩放约束与目标 |

**超时必须返回当前最优可行解，而不是直接失败。** 求解器异常要分类处理：不可行、超时、数值错误、内部错误，分别走不同降级路径。

### 5.3 降级阶梯

| 状态 | 判定 | 动作 |
|---|---|---|
| 正常 | gap 达标、时间充裕 | 下发计划 |
| 超时有可行解 | 有 incumbent，gap 未达标 | 下发 incumbent，标记"近优" |
| 不可行 | 约束冲突 | 输出 IIS/冲突约束，按优先级松弛（先软约束、后安全约束），并告警 |
| 数值错误 | 缩放/容差问题 | 重缩放、换求解器或重启，回退上一版计划 |
| 求解器崩溃 | 进程异常 | 回退上一版计划 + 规则曲线，记录现场 |
| 无任何可行解 | 初始 SOC/设备状态异常 | 走规则兜底（快充/保关键负荷），人工介入 |

### 5.4 分解与加速

| 场景 | 方法 | 注意 |
|---|---|---|
| 多场景随机 | Benders/L-shaped：主问题定日前计划，子问题算各场景成本 | 场景数多时收敛慢，需加割平面管理 |
| 多微网/多站点 | ADMM/对偶分解 | 需要协调层与隐私边界，收敛性依赖参数 |
| 超长 horizon | 时间分解/滚动 | 边界 SOC 与备用要传递，否则全局最优性丢失 |
| 大规模 EV | 聚合建模 + 逐车回代 | 聚合可行域要保守，避免回代越界 |

### 5.5 数值与实现陷阱

- Big-M 过大导致松弛过松；优先 SOS1。
- 功率单位 kW 与电量 kWh 混用；15 分钟时段要乘 `Δt=0.25`。
- 效率写在目标而不是 SOC 递推里，导致守恒被破坏。
- 惩罚系数过大导致数值病态；先归一化再调权。
- 每次请求新建求解器实例，冷启动开销大；高频场景应复用模型。
- 异常捕获后统一返回失败码，会吞掉"超时但有可行解"的信息。
- 约束重复或冗余（同一限值写两遍）会拖慢 presolve，需定期清理。

### 5.6 基准与回归

| 项目 | 做法 |
|---|---|
| 算例集 | 固定 10–20 个典型日（晴/阴/雨、工作日/周末、夏/冬），附电价与设备参数 |
| 指标 | 目标值、gap、求解时间、约束违反量、SOC 轨迹、备用利用率 |
| 回归 | 模型改动后逐例对比；目标恶化超过阈值必须解释 |
| 随机性 | 固定随机种子；场景法记录场景生成参数 |
| 版本 | 模型版本、求解器版本、参数集三者一起入库 |

## 6. 双时间尺度与 MPC

### 6.1 日前 + 日内双环

| 环 | 触发 | 窗口 | 初始 SOC | 性质 |
|---|---|---|---|---|
| 日前 | 每日固定时刻 | 次日 0 点起 96 点 | 常用保守假设（如 SOC 下限） | 开环计划 |
| 日内滚动 | 每 15 min–1 h | `[now, now+24h]` | 读实时 SOC | 闭环纠偏，近似 MPC |

日内用最新 SOC 与滚动预测重优化，只执行首个时段，下一时段再滚动——这是滚动时域控制的离散近似。

### 6.2 MPC 形式

```
min_{u_0..u_{H−1}}  Σ_{k=0}^{H−1} L(x_k, u_k) + J_H(x_H)
s.t.                x_{k+1} = f(x_k, u_k)
                    x_k ∈ X,  u_k ∈ U
                    x_0 = 当前实测状态
```

- `x`：SOC、设备状态、并网点功率等；
- `u`：充放电功率、购售功率、柴发设定值；
- `f`：SOC 递推与功率平衡；
- `J_H`：终端代价或终端约束。

### 6.3 与教科书 MPC 的差距

1. **horizon 硬编码**：窗口固定 24 h，未参数化；
2. **无反馈校正**：只是"用新数据重算"，没有用上一时刻预测误差修正当前预测；
3. **无终端代价/终端约束**：稳定性靠 SOC 日循环近似；
4. **无约束收紧**：预测偏差大时，计划贴着限值跑，执行时容易越界。

升级方向：参数化 `H`；加预测误差校正项（如 `x̂_{k+1} = f(x_k,u_k) + κ(y_k − ŷ_k)`）；加终端代价/约束；对 PCC 与 SOC 做鲁棒收紧。

### 6.4 分层设定值链

| 层级 | 周期 | 输出 | 失败处理 |
|---|---|---|---|
| EMS | 15 min–1 h | 96 点功率/SOC/备用计划 | 超时用 incumbent 或上一版 |
| MGCC | s | 设备设定值、启停命令 | 指令回执、超时重发 |
| 设备控制器 | ms–s | 功率跟踪、下垂/GFM | 限幅、保护脱网 |

**设定值要带斜率限制与保持策略**：新计划与旧计划之间加爬坡过渡，通信中断时保持最后有效值或按规则降功率，避免阶跃冲击。

### 6.5 事件驱动调度

充电类业务（V2G、有序充电）不适合定时批量，常见做法：

- 插枪/下单即触发首次优化；
- 延迟 15 min 用实测 SOC 纠偏；
- 此后每 30 min 重优化；
- 读不到 SOC 时先下发小功率"探针"曲线，再优化；
- 订单号 + 时效校验，防止过期曲线误下发；
- 特殊枪型走固定规则兜底，不强行进求解器。

**规则兜底不是退步，而是把"模型算不准"的场景显式隔离。**

### 6.6 状态机（IEEE 2030.7 口径）

| 状态/转换 | 含义 | EMS 职责 |
|---|---|---|
| SS1 并网 | 与主网并联运行 | 经济调度、需量管理、备用 |
| SS2 孤岛 | 独立运行 | 孤岛经济调度、能量裕度监控 |
| T1 计划孤岛 | 有许可的主动解列 | 生成孤岛计划，预平衡功率 |
| T2 非计划孤岛 | 故障/失电导致 | 读取状态，切至孤岛计划，保关键负荷 |
| T3 重连 | 同期合闸 | 功率回代、平滑过渡 |
| T4 黑启动 | 全黑后恢复 | 启动顺序、能量校验点 |

状态机由 MGCC 执行；EMS 只负责各状态下的计划与约束，不自行发起切换。

### 6.7 备用部署与跟踪

- 计划层：在 basepoint 之外预留 `r_up/r_dn`，并保证 SOC 能量足够；
- 执行层：接收 AGC/AVC 或调度指令，按爬坡与响应时间跟踪；
- 考核层：记录响应时间、跟踪误差、可用率，反馈到下一次备用申报；
- **备用与套利共享同一 SOC 裕度**，不能各算各的。

### 6.8 反模式

| 反模式 | 后果 | 纠正 |
|---|---|---|
| 每分钟重优化 | 计划抖动、设备频繁动作 | 固定周期 + 事件触发，加切换惩罚 |
| 新计划直接阶跃下发 | 冲击、保护动作 | 加爬坡过渡 |
| 计划不回写实际执行 | 无法归因 | 订单号关联计划/执行/偏差 |
| 忽略指令时延 | 跟踪误差大 | 在模型中加时延或提前量 |
| 孤岛计划不做能量校验 | 孤岛中途失电 | 加能量裕度约束 |

## 7. 不确定性优化

### 7.1 不确定性来源

| 来源 | 典型偏差 | 影响 |
|---|---|---|
| 光伏 | 云层、遮挡、污染 | 白天功率与弃光 |
| 风电 | 风速/风向 | 夜间/全天功率 |
| 负荷 | 天气、生产班次、节假日 | 峰值与需量 |
| 电价 | 市场出清、政策调整 | 套利方向 |
| EV | 到达时间、停留时长、目标 SOC | 充电负荷与 V2G 能力 |
| 设备 | 故障、检修、限功率 | 可用容量 |
| 模型 | 效率、退化、温度修正 | 系统性偏差 |

### 7.2 确定性 + 备用

最常见、成本最低的做法：用点预测优化，再按预测误差分位数留备用。

```
R_up[t] = quantile_{1−α}(预测误差分布)
```

优点是易落地；缺点是无法区分"备而不用"与"备用不足"的经济价值。

### 7.3 两阶段随机规划与 CVaR

```
min  Σ_s π_s·C_s(x, y_s) + λ·CVaR_α(成本)
s.t. 第一阶段：日前计划 x（购售、启停、备用）
     第二阶段：各场景下的调整 y_s
```

- 第一阶段决策在所有场景下可行（或允许弃负荷/弃光作为惩罚）；
- 场景数多时用 Benders/L-shaped 分解；
- CVaR 用于控制尾部风险，适合对失负荷/考核敏感的场景。

### 7.4 鲁棒优化

- Box 不确定集：`|ξ_t − ξ̂_t| ≤ δ_t`；
- Budget 不确定集（Bertsimas-Sim）：限制同时偏离的时段数，平衡保守性与经济性；
- 可调鲁棒：第一阶段定计划，第二阶段按实现值调整。

鲁棒解的保守度由不确定集大小控制；**不确定集要用历史误差标定，不能拍脑袋**。

### 7.5 分布鲁棒与机会约束

- 分布鲁棒（DRO）：在 Wasserstein/矩不确定集内求最坏分布，样本少时比随机规划稳；
- 机会约束：`P(违约) ≤ ε`，凸近似后进入 MILP；
- 适用：预测误差分布未知、但要求可行性保证的场景。

### 7.6 多目标

把固定的 SOC 惩罚、平滑惩罚改为 epsilon-约束或目标规划，让运营方显式选择"经济性 vs 电池寿命 vs 电能质量"，而不是把权衡藏在魔数里。

| 方法 | 表达 | 适用 |
|---|---|---|
| 加权和 | `Σ w_k·f_k` | 快速试算，权重难解释 |
| epsilon-约束 | 主目标 + 其余 `f_k ≤ ε_k` | 生成 Pareto 前沿 |
| 字典序 | 先保安全，再保成本，再保平滑 | 有明确优先级 |

### 7.7 成熟度分级

| 级别 | 特征 | 典型做法 |
|---|---|---|
| L1 | 确定性单曲线 | 点预测 + 固定备用 |
| L2 | 确定性 + 滚动 | 日内重优化、SOC 闭环 |
| L3 | 场景/随机 | 两阶段随机、CVaR |
| L4 | 鲁棒/DRO | 不确定集、机会约束 |
| L5 | 自适应/学习 | 预测-优化联合、在线学习 |

多数生产系统在 L2；L3 以上要有数据与运维能力支撑，不是模型越复杂越好。

### 7.8 评估方法

| 指标 | 含义 |
|---|---|
| 样本外成本 | 用未参与训练/标定的历史日回放 |
| CVaR | 最差 5%–10% 日的平均成本 |
| 违约率 | 越限、失负荷、备用不足的发生频率 |
| 备用利用率 | 预留备用被实际调用的比例 |
| 计划稳定性 | 相邻两次计划的功率变化量 |

### 7.9 建议顺序

```
近期：MPC 显式化 + 多目标 epsilon-约束
中期：场景法两阶段随机 + CVaR
远期：鲁棒/DRO + 离网/孤岛 + 潮流约束
```

## 8. 可调能力评估：可行域边界

评估模块回答"当前状态下还能上调/下调多少、能持续多久、多快"。常用六项指标：

| 指标 | 含义 |
|---|---|
| 最大上调容量 | 增加受电/减少发电的能力 |
| 最大下调容量 | 减少受电/增加发电的能力 |
| 上调持续时长 | 按可用能量与功率计算 |
| 下调持续时长 | 同上 |
| 上调速率 | kW/min |
| 下调速率 | kW/min |

### 8.1 典型计算

- **储能上调（放电）**：
  `min(P_dis_max − p_dis, ΔP_max, η_dis·(soc − SOC_min)/100·E/τ)`；
  持续时长 `≈ 可用电量 ÷ 放电功率`。
- **储能下调（充电）**：
  `min(P_ch_max − p_ch, ΔP_max, (SOC_max − soc)/100·E/η_ch/τ)`。
- **光伏**：上调容量 ≈ 当前出力（弃光空间）；下调容量 ≈ 当前出力；速率受逆变器与出力特性限制。
- **柴发**：上调 ≈ `P_dg_max − p_dg`；下调 ≈ `p_dg − P_dg_min`；速率按机组爬坡率。
- **充电枪**：上调 ≈ `min(请求功率, 最大功率) − 当前功率`；持续时长按电池剩余容量与 SOC 上限估算。
- **站点**：五类资源求和后，受并网点进线限值截断，再扣除已承诺的备用。

### 8.2 闭环

评估结果至少有三个用途：

1. 需求响应/辅助服务申报的能力边界；
2. 优化模型的动态功率包络与备用约束；
3. 计划执行前的可行性校验。

只做第 1 项、不做第 2 项，就是"评估—优化开环"。

### 8.3 与并网标准对齐

- 评估输出要能对应 GB/T 33589-2026 的最大受电/送出功率口径；
- 380 V 微网按 15 min 上送周期准备数据，评估结果带时标与有效期；
- 评估的"可持续时长"要与备用考核的持续时间口径一致，不能一个按 15 min、一个按 1 h。

### 8.4 常见错误

| 错误 | 后果 |
|---|---|
| 只看功率不看能量 | 申报能力虚高，持续不了 |
| 忽略效率 | 放电可用电量高估 |
| 忽略已承诺备用 | 重复申报，实际不可用 |
| 忽略 PCC 限值 | 站点合计超过进线能力 |
| 忽略设备状态 | 检修/限功率设备被计入 |

## 9. 算例（合成数据）

### 9.1 设定

| 项目 | 取值 |
|---|---|
| 时段 | 96 点 × 15 min |
| 光伏 | 500 kW 峰值 |
| 储能 | 1000 kWh / 500 kW，`η_ch=η_dis=0.95` |
| SOC | 20%–95%，日循环 |
| 并网点 | 最大受电 900 kW，最大送出 0 kW |
| 备用 | 50 kW（上调） |
| 需量/退化 | 本算例不计，单独敏感性说明 |
| 负荷 | 双峰（上午、晚间） |

### 9.2 结果

| 指标 | 无储能 | 有储能 | 变化 |
|---|---|---|---|
| 日购电成本 | 4,637.5 元 | 4,161.0 元 | −476.5 元（−10.3%） |
| 最大需量 | — | 834.2 kW | 需量电费另计 |

### 9.3 典型解形态

- 谷时段（00:00–07:00）：储能满功率充电，SOC 从 20% 升至 95%；
- 峰时段（10:00–15:00、18:00–21:00）：放电抵消购电；中午光伏大发时放电受 `load − pv` 限制，不倒送；
- 尖峰（21:00–23:00）：SOC 已在前段耗尽，体现"容量有限、需统筹全天"。

### 9.4 敏感性（定性）

| 变化 | 预期影响 |
|---|---|
| 光伏 +20% | 中午弃光增加；若允许送出，弃光转为收益 |
| 储能 +20% | 成本继续下降，但边际收益递减 |
| 允许送出 | 中午多余电量可售，PCC 双变量与购售互斥更关键 |
| 计入需量电费 | 储能更倾向削峰，谷充可能减少 |
| 计入退化成本 | 循环次数下降，浅充浅放增多 |
| 备用需求提高 | 可用套利容量下降，成本上升 |

### 9.5 读法

> 以上为合成算例，仅用于演示模型行为；真实项目须用现场曲线、实际电价与设备参数重算。**不同项目的绝对成本不可直接比较**，应比较"有无储能/有无优化"的增量与约束是否满足。

## 10. 工程复核清单

### 10.1 P0：影响正确性或可用性

| 检查项 | 常见表现 | 处理 |
|---|---|---|
| PCC 是否双变量 | 只有一个净功率 | 改为 `p_imp/p_exp`，分别设限并互斥 |
| 需量是否按购电 | 对净功率取最大 | 改为 `max_p ≥ p_imp`，保留 `D0` |
| SOC 索引与端点 | 差一位、末端偷电 | 核对 `soc[0..T]`、日循环/终端价值 |
| 效率与自放电 | 递推漏项 | 1 充 1 放守恒测试 |
| 充放互斥 | LP 松弛同时充放 | SOS1/指示约束/Big-M |
| EV 是否进入平衡 | EV 只优化不参与 KCL | 补 KCL 项，充放符号都进 |
| 孤岛时 PCC 置零 | 孤岛计划仍购售 | `z_island` 强制置零 |
| 备用容量+能量 | 只报 kW 不报 kWh | 加 SOC 余量与持续时间约束 |
| 退化预算 | 无退化或只算循环次数 | 吞吐/雨流，按项目口径 |
| 超时降级 | 异常统一返回失败 | 返回 incumbent + 备用曲线 |
| 滚动闭环 | 定时器在跑，结果未回写 | 校验首时段执行与下一轮输入 |
| 契约字段 | 定义了但模型不读 | 逐字段核对，未实现则删除 |

### 10.2 P1：影响性能或可维护性

| 检查项 | 常见表现 | 处理 |
|---|---|---|
| 硬编码魔数 | 爬坡、聚合功率、评估系数写死 | 提为配置并给默认值 |
| 求解器复用 | 每请求新建实例 | 模型复用 + 热启动 |
| 初始 SOC 假设 | 日前固定用 SOC 下限 | 用实时/预测 SOC，或做情景 |
| 多储能聚合 | 只给聚合 SOC | 下发前逐设备回代 |
| 死代码与生成文件 | 未调用模块、生成代码入库 | 清理，生成放 CI |
| 分层泄漏 | 业务层直接操作 HTTP 上下文 | 下沉 service |
| 时间同步 | 各服务时区/时标不一致 | 统一 UTC/本地时区与时段编号 |
| 配置冲突 | 两服务共用端口、测试连错 | 配置外置，启动自检 |

### 10.3 P2：工程化与可观测性

| 检查项 | 处理 |
|---|---|
| 语言/依赖版本 | 升级到受支持版本，补 CI/lint |
| 日志与绘图 | 服务端禁止交互式绘图，改结构化日志 |
| 健康检查与指标 | gRPC health + Prometheus |
| 并发与限流 | 串行 sleep 改并发 + 限流器 |
| 传输安全 | TLS、鉴权、密钥管理 |
| 回归测试 | 典型算例快照，模型变更对比 |
| 告警分级 | 求解失败/越限/通信中断分级上报 |

### 10.4 标准合规映射

| 要求 | 模型/工程落点 | 证据 |
|---|---|---|
| 最大受电/送出功率 | C10 双变量与限值 | 参数表、约束导出、越限告警 |
| 功率因数/无功 | C16 可选约束 | 运行曲线、并网检测 |
| 频率范围 | 保护/控制定值，不进 15 min 模型 | 并网检测、HIL |
| 模式切换 | C2/C14 + 状态机 §6.6 | T1–T4 测试记录 |
| 通信与数据上送 | 15 min 周期、时标、回执 | 通信日志、对时记录 |
| 计量 | DL/T 698.45 等（按项目） | 计量点表、抄表核对 |
| 网络安全 | IEC 62443 / GB/T 22239 | 等保测评、访问控制 |
| EMS 功能与测试 | GB/T 36274、GB/Z 120.305 | 功能清单、测试报告 |

### 10.5 测试与验收

| 测试 | 方法 | 通过标准 |
|---|---|---|
| 模型单元测试 | 构造算例，验证守恒/边界/互斥 | 无同时充放、SOC 守恒、限值不越 |
| 回放测试 | 历史日回放 | 成本不劣于基线，约束满足 |
| HIL/PHIL | 控制器与功率硬件在环 | 指令跟踪、切换时序正确 |
| T1–T4 | 计划孤岛/非计划孤岛/重连/黑启动 | 按 IEEE 2030.7/2030.8 用例通过 |
| AGC/AVC 跟踪 | 阶跃/斜坡指令 | 响应时间、稳态误差达标 |
| 电能质量 | 谐波、电压偏差、闪变 | 符合并网标准 |
| 通信中断 | 断网/丢包/时延 | 本地兜底，不误动作 |
| 长时运行 | 72 h 连续 | 无内存泄漏、无计划漂移 |
| 网络安全 | 渗透/等保 | 无高危漏洞，权限最小化 |

### 10.6 红线

1. 孤岛时并网点仍有购售功率；
2. 同时充放或同时购售未被约束；
3. 备用容量超过 SOC 可支撑的能量；
4. 计划越限（PCC/SOC/爬坡）仍下发；
5. 超时/异常直接下发空计划或全零计划；
6. 未做时间同步就使用"实时"数据；
7. 把合成算例收益当作项目承诺。

### 11.1 模块边界

- 并网/离网切换的时序与黑启动流程；

- 储能寿命模型（循环次数、DoD、温度）；
- 辅助服务申报与考核规则（按省/区域）；
- 真实或合成的 96 点源荷曲线与电价曲线；
- 当地并网标准与调度协议（含通信规约、点表）。

### 11.3 与现有技能的分工

- 市场规则、结算、电价机制 → 《电力交易专家》；
- 资源聚合、VPP 运营、需求响应 → 《虚拟电厂专家》；
