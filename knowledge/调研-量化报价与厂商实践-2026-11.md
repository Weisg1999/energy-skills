# 调研：量化报价与厂商实践（2026-11）

> 目的：为 `skills/spot-bidding-quant` 的"报价工程与产品化"部分提供公开事实底稿。按**参与侧**（卖给发电/售电的交易决策产品）与**运营/规则侧**（交易中心与电网的出清引擎、技术支持系统）两类整理。全部来自公开渠道，标注来源级别；**企业宣称的效果一律 C 级，不得作为基准**。

## 1. 上海路明星光智能科技有限公司（Lumin AI）

| 项目 | 内容 | 级别/来源 |
|---|---|---|
| 主体 | 上海路明星光智能科技有限公司，2025-02-19 成立，法定代表人 姬有，注册资本 2089.8884 万元 | B 级：企业工商信息（天眼查/爱企查公开页） |
| 业务 | 面向电力市场参与者，以机器学习做发用两侧现货交易指导；工商范围含发电、输电、供（配）电业务许可 | B 级 |
| 规模 | 截至 2025 年底年代理交易电量 >400 亿 kWh，覆盖以华东为主的 8 个省份；技术人员占比 >60% | C 级：企业对外宣传 |
| 团队 | 创始团队来自哥伦比亚大学、哈佛、斯坦福、清华、上海交大等及阿里/腾讯/Google/Meta | C 级：招聘与媒体材料 |
| 产品线 | 火电（日前报价与申报）、新能源（气象/功率/负荷/电价预测 + 策略）、储能与配储（投资建议+改造+运营+运维）、售电（行情/预测/现货/中长期/负荷管理）、用户（电费/能效/交易/碳资产）、VPP（监控-调度-交易-运营） | C 级：厂商发布稿 |
| 系统 | 2026-06 发布 LuminFlex，宣称"气象—功率—负荷—电价—交易"全链路自研预测，支持一键导出交易中心申报文件、减少改单 | C 级 |
| 效果宣称 | 价格预测准确率最高优化 30%；安徽市场价差方向正确率约 70%、2026-08 日前申报累计收益 >200 万元、平均 3.61 元/MWh；山东市场准确预测正负电价并捕捉光伏骤降导致的快速上涨 | C 级：媒体报道厂商口径 |
| 储能宣称 | 每百 MWh 年增收 >100 万元；全生命周期综合收益提升 10%~15%；配储电站收益提升 15% 以上 | C 级 |
| 合作 | 2026-02 与上海电力大学经济与管理学院开展校企合作交流 | B 级：高校官网 |

**为什么这些数字不能当基准**：未披露基线模型、样本区间、省份规则版本、方向正确率的步长与死区、是否含考核与偏差成本、储能测算的循环成本与电价样本。引用时只能写"某厂商宣称"，不能写"行业平均"。

**为什么值得记**：它的公开采购记录比任何宣传都更清楚地说明运营侧系统在做什么改造——出清算法按标包单独采购、RUC 与日前的并行/串行架构被单列为改造内容、跨经营区电价计算模块另立。这三件事直接对应参与者最关心的三件不确定：**我未中标会不会被开机、跨省价差怎么形成、规则变了多久生效**。

**必须避免的误读**：南方区域市场的"天权"求解器由南网自研，不能算作清能互联的成果；媒体所称"性能超越国际先进求解器 14%""7000+ 节点、200 万+ 出清变量"为 C 级媒体口径。

## 4. 同期其他厂商专利（对照，说明技术路线不是孤例）

- 昆明电力交易中心：多尺度卷积 + Transformer 编码的多任务价格预测（点预测、方向概率、波动强度）；
- 力田科技：年度/月度/日前三级级联价格预测；
- 派能科技、海博思创：LSTM Seq2Seq、时序整合的价格预测。

结论：价格预测的技术路线已趋同（多尺度特征 + 分任务输出 + 偏差校正），**差异化不在模型结构，而在数据工程、规则适配和复盘能力**。这也是本技能把"申报校验—改单—T+1 归因"单列一章的原因。

## 5. 对本技能设计的影响

| 采纳 | 说明 |
|---|---|
| 全链路视角 | 预测 → 报价 → 申报 → 出清 → 复盘，缺一环无法归因 |
| 残差校正独立成层 | 对应 CN121278688A 的两因子结构，代码 `forecast.fit_residual_model` |
| 方向正确率单列 | 厂商口径约 70%，但必须补步长/死区/样本区间三项说明 |
| 申报文件校验与改单留痕 | 厂商卖点"减少改单"，反过来说明改单是主要操作风险 |
| 自建 vs 采购判断 | 商业系统覆盖全链路，但最后一公里（校验、改单、归因）仍需自建 |
| 生产级引擎与教学仿真的边界 | 运营侧的 SCUC/SCED/RUC/联合出清/ATC 决定"什么叫边际、未中标如何补偿"，小仿真只做机制演示（正文 10.4） |
| 规则参数层与模型层分离 | 对应运营侧以"组件化约束"响应规则变化；规则调整只改参数层，不重写模型（正文 10.4 推论 3） |
| 区分运营侧与参与侧供应商 | 参与侧产品的规则层要跟上运营侧系统改造节奏，采购合同需约定规则变更的适配责任（正文 12.4） |

| 不采纳 | 原因 |
|---|---|
| 把厂商效果数字写进正文当基准 | C 级，无基线定义 |
| 复现 encoder-decoder 模型 | 与"零依赖标准库"约束冲突；技能给出方法路线与评价协议即可 |
| 任何"提高报价收益 X%"的结论 | 无实盘验证条件，属于不可证伪宣称 |

## 6. 待核实

- 路明星光宣称的 400 亿 kWh 代理电量与 8 省覆盖，缺少第三方核验，仅企业口径；
- "准确率最高优化 30%"的对比基线未公开，无法判断是相对何种模型；
- 安徽 3.61 元/MWh 的平均收益是否扣除偏差考核与考核罚款，未说明；
- 清能互联"20+ 省级市场""专精特新小巨人""C 轮融资"等为媒体与企业口径，未逐项核验；其在南方区域的具体交付边界（引擎核心算法 / 功能加装 / 运维）未公开；
- 南方区域 RUC 与日前"并行/串行"两种架构的实际切换条件，需查交易中心正式规则与技术规范书，本笔记只确认其被列为改造内容；
- 各省报价段数、限价、二次限价参数的 2026 年最新值，需逐省核对交易中心规则（见 `knowledge/省级市场状态表-2026-11.md`）。
