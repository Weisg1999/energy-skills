# 海外并网与合规手册：中国厂商投决前的七道门（2026-11）

> 数据截止：2026-11-10｜定位：横向专题第一篇
> 适用边界：覆盖德国、英国、法国、意大利、西班牙、荷兰、波兰、比利时/北欧、美国、澳大利亚、日本十一个市场，以及欧盟层面的并网、网络、电池与供应链规则。本文是合规框架与查证入口，不构成法律意见；具体项目以当地电网运营商、监管机构、公告机构（Notified Body）和交易文件为准。
> 用途：回答“设备能不能进、项目能不能并、并了会不会被罚、数据要不要交、股权能不能买”五类问题。遇到单一市场的交易规则，回到对应的海外市场模块；本文只做横向对照。

## 0. 一页看懂

### 0.1 七道门，不是一道门

```
海外储能项目合规
├─ 门 1  并网（Grid Code）
│  ├─ 欧盟：RfG 2016/631 + 本国实施 + EN 50549
│  ├─ 国家：VDE-AR-N / G99 / CEI 0-21 / NTS / Netcode / NC RfG
│  └─ 并网协议、单元证书、建模、测试、调试
├─ 门 2  设备安全（Product Safety）
│  ├─ IEC 62933 / IEC 62619 / IEC 63056 / IEC 62477
│  ├─ UL 9540 / UL 1741 / IEEE 1547（北美）
│  └─ CE / UKCA / UN 38.3 / 并网认证
├─ 门 3  消防（Fire）
│  ├─ NFPA 855 / UL 9540A（北美及引用地区）
│  └─ 欧盟/各国消防规范 + 电池法规热失控要求
├─ 门 4  网络安全（NIS2）
│  ├─ 实体范围、风险管理、24h/72h/1 个月报告
│  └─ 供应链安全、EMS/SCADA/远程运维合同
├─ 门 5  电池法规与电池护照
│  ├─ 碳足迹声明、性能等级、再生含量、尽职调查
│  └─ 2027-02-18 数字护照 + 二维码 + 海关核验
├─ 门 6  供应链与产业政策（NZIA / IAA）
│  ├─ 非价格标准、本地含量、 resilience
│  └─ 公共采购与招标资格
└─ 门 7  外资审查（FDI）
   ├─ 欧盟合作机制 + 成员国审查
   └─ 美国 CFIUS/FIRRMA、日本 FEFTA、澳洲 FIRB、英国 NSIA
```

- **七道门是并联，不是串联**：并网过了，消防可能卡；设备过了，电池护照可能卡；项目过了，股权交易可能被外资审查卡。
- **每道门都有“时间窗”**：并网排队 6–36 个月、认证 3–9 个月、消防审查 3–12 个月、电池护照数据准备 12–18 个月；投决模型要把合规时间当成现金流变量，不是后台事务。
- **每道门都有“责任人”**：设备商、EPC、业主、运营商、进口商（producer）责任不同；电池法规下的“生产者”可能是进口商，不是中国制造商。

## 1. 并网规则的分层：欧盟框架与本国实施

### 1.1 三层结构

| 层级 | 文件 | 作用 | 对储能的意义 |
|---|---|---|---|
| 欧盟网络码 | RfG (EU) 2016/631 | 发电模块并网要求 | 储能按 power park module 处理的情况最常见 |
| 欧盟网络码 | DCC (EU) 2016/1388 | 需求设施并网要求 | 储能作为负荷/双向设施时适用 |
| 欧盟网络码 | HVDC (EU) 2016/1447 | 高压直流并网 | 大型海风/互联项目 |
| 欧洲标准 | EN 50549-1/-2 | 低压/中压发电设施并网 | 各国标准的共同底稿 |
| 本国实施 | VDE-AR-N、G99、CEI 0-21、NTS、Netcode 等 | 具体门槛、测试、证书 | 项目真正被审的是这一层 |

- **RfG 是“框架”，不是“证书”**：它规定 Type A/B/C/D 的分级和参数范围，具体测试、建模、证书由本国 TSO/DSO 实施。
- **Type A/B/C/D 的门槛以 RfG 第 5 条和本国实施为准**：大陆欧洲同步区通常以 1 MW、50 MW、110 kV 为分界；英国、爱尔兰、北欧同步区有单独门槛。不要拿一个国家的门槛套另一个国家。
- **储能的双重身份**：充电时是负荷，放电时是发电；RfG 管发电模块，DCC 管需求设施，项目可能同时触发两套要求。并网申请时要明确“运行模式”和“控制架构”，否则会被要求补做 DCC 合规。
- **EN 50549 不是“欧盟强制认证”**：它是欧洲标准，各国通过本国电网规则引用；有 CE 标志不等于满足并网要求，并网证书是单独的。

### 1.2 并网申请的标准动作

| 步骤 | 产出 | 常见耗时 | 备注 |
|---|---|---|---|
| 1. 预可研/接入咨询 | 可接入容量、接入点、初步方案 | 1–3 个月 | 先问“有没有容量”，再谈设备 |
| 2. 正式申请 | 并网申请、单线图、参数表 | 1–2 个月 | 资料不全会被打回 |
| 3. 系统研究 | 潮流、短路、稳定、保护配合 | 3–12 个月 | 新能源富集区更久 |
| 4. 并网协议 | 连接条件、费用、工期 | 1–6 个月 | 关注“照付不议”和延期条款 |
| 5. 设备认证 | 单元证书/型式试验/建模报告 | 3–9 个月 | 与设备采购并行 |
| 6. 调试与验收 | 测试报告、涉网试验 | 1–3 个月 | 频率/电压/无功/故障穿越 |
| 7. 注册与市场准入 | MaStR/市场注册/辅助服务预审 | 1–3 个月 | 没有注册不能结算 |

- **并网排队是投决的第一约束**：设备可以买，土地可以租，但接入点不能凭空造；很多项目的“开发权”本质是排队位置。
- **系统研究结论会改变项目配置**：无功要求、构网要求、短路比、限发比例，都会改变 PCS 选型和收益率。
- **并网协议里的“限发”条款要建模**：如果电网要求 0 出力或限功率，项目的捕获率假设要下调。

## 2. 十一个市场的并网要点

### 2.1 德国：单元证书是硬门槛

| 项目 | 内容 |
|---|---|
| 低压 | VDE-AR-N 4105；户用/工商储 |
| 中压 | VDE-AR-N 4110；大储最常见 |
| 高压 | VDE-AR-N 4120 |
| 超高压 | VDE-AR-N 4130 |
| 技术指引 | FGW TR3（电气特性）、TR4（建模/仿真）、TR8（认证） |
| 证书 | 单元证书（Unit Certificate）、组件证书、并网声明 |
| 登记 | MaStR（市场主数据登记） |

- **中压及以上要“单元证书 + 建模”**：不是交一份型式试验报告就完事；FGW TR4 要求提供 PSCAD/DIgSILENT 等模型，TSO 会用模型做系统研究。
- **储能按发电/负荷双向设备处理**：充电功率、放电功率、无功能力、故障穿越都要申报；只报放电容量会被要求补件。
- **VDE-AR-N 4110 覆盖中压**：风机、光伏、储能都要满足；储能的无功、频率响应、高/低电压穿越测试比传统光伏更严。
- **认证周期**：PCS 单元证书 3–6 个月，系统集成后并网测试 1–3 个月；如果换 PCS 型号或电池簇，可能要重新做部分测试。
- **常见坑**：拿低压证书去接中压；模型版本与现场固件不一致；MaStR 登记滞后导致不能结算。

### 2.2 英国：G99 之后还有队列

| 项目 | 内容 |
|---|---|
| 户用/小系统 | G98（≤16 A/相） |
| 中大系统 | G99（>16 A/相） |
| 出口限制 | G100；ANM（主动网络管理） |
| 输电 | NESO 连接协议；TMO4+ 队列改革 |
| 并网主管 | DNO（配网）；NESO（输网） |

- **G99 是配网并网的核心**：G99 覆盖大于 16 A/相 的发电设施，储能按发电/储能混合设施申请；需要提交接线图、保护定值、仿真模型和调试计划。
- **G100 管出口限制**：如果接入点容量小于设备容量，需要用 G100 认证的出口限制方案；出口限制的可靠性和失效安全是审查重点。
- **TMO4+ 改变排队逻辑**：2025–2026 年英国推进连接改革，按“项目成熟度”重排队列；没有规划许可、土地和融资的项目会被移出快速通道。新项目拿到 2030 年前接入日期的难度显著上升。
- **输电并网**：大型储能走 NESO 的连接流程；与配网并网不同，输电并网还要考虑平衡机制（BM）注册和 BSC。
- **常见坑**：只看 G99 证书，不看 DNO 的连接条件；出口限制方案没有 G100 认证；队列改革后仍按旧时间表做投决。

### 2.3 意大利：CEI 0-21 与 CEI 0-16 分工明确

| 项目 | 内容 |
|---|---|
| 低压 | CEI 0-21；户用/工商储 |
| 中高压 | CEI 0-16；大储/电站 |
| 并网主管 | 配电网运营商（e-distribuzione 等）；TERNA（输电） |
| 认证 | 型式试验 + 并网认证 + 现场测试 |
| 特殊点 | 中低压并网设备强制符合 CEI 标准 |

- **CEI 0-21 管低压**：不仅管逆变器，也管储能系统的并网保护、无功、频率响应和反孤岛；工商储一体机通常按 CEI 0-21 认证。
- **CEI 0-16 管中高压**：对无功能力、电压支撑、故障穿越和通信的要求更高；大储项目要按 CEI 0-16 做单元认证和现场测试。
- **认证与补贴/拍卖挂钩**：MACSE、容量市场、FER X 都要求项目具备并网资格；并网证书是参与拍卖的前置条件之一。
- **常见坑**：用光伏逆变器证书替代储能证书；CEI 0-21 版本更新后未重新测试；中压项目只做 CEI 0-21。

### 2.4 西班牙：2026 年并网规则更新

| 项目 | 内容 |
|---|---|
| 基础法规 | RD 647/2020；Orden TED/749/2020 |
| 2026 更新 | Orden TED/82/2026，修改 TED/749/2020 |
| 覆盖 | 小型发电、储能、自消费 |
| 关键变化 | 自消费技术豁免（DT3ª RD 647/2020）取消，2026-05-12 起全面合规 |
| 并网主管 | REE（输电）；CNMC（监管） |

- **NTS 是西班牙的并网技术规范体系**：包括对发电设施、需求设施和储能的技术要求；项目要按 NTS 和 REE 的并网程序提交模型与测试。
- **2026 年更新收紧自消费**：过去部分自消费项目可以豁免某些技术要求，TED/82/2026 取消该豁免；表后储能和自发自用项目也要按并网规范做合规。
- **储能并网许可不等于建成**：截至 2026 年，西班牙有大量电池项目持有并网许可但未并网；许可有期限和里程碑要求，未按期建设可能失效。
- **常见坑**：拿旧版 TED/749/2020 做设计；忽略自消费豁免取消；并网许可与土地/环境许可不匹配。

### 2.5 法国：RTE/Enedis 两套接入 + 容量认证

| 项目 | 内容 |
|---|---|
| 低压 | NF C 15-100；工商储/表后 |
| 高压 | NF C 13-100；RTE DTR |
| 并网主管 | RTE（输网）；Enedis（配网）；CRE（规则/费用批准） |
| 容量机制 | CRE 认证；PL-1/PL-4；PPI 豁免 2026-11-23 截止 |
| 特殊点 | 2026 年底并网框架改革；非 firm/“gabarits”仅 B 级信息 |

- **两套接入对象**：输网项目走 RTE，配网/表后项目走 Enedis；保护、通信、故障穿越、无功和调试按 DTR 与并网协议执行，部分规则/费用需 CRE 批准。
- **接入权不是排队**：2025 年末已获接入权约 30 GW（数据中心 14、制氢 9.5、工业 6.5），另有电池排队约 14 GW / 180 项目（A，RTE）；两类数字不能相加当“总排队”。
- **典型时长官方未披露**：不能引用单一固定值；2026 年底并网框架改革完成后，接入时限与非 firm 选项可能变化，投决前向 RTE 确认。
- **容量资格是第二道门**：CRE 认证、按参数降额、可用性义务；PPI 豁免 2026-11-23 截止，错过会影响前期费用回收。
- **消防与认证**：低压 NF C 15-100、高压 NF C 13-100 是常用标准；UL 9540A 不是法国强制认证，ICPE 具体 rubrique 未找到官方文本，按项目环评/消防审查办理。
- **常见坑**：把接入权当并网；忽略容量认证与 PPI 截止；用 UL 9540A 替代法国消防审查；IEF 只看“不到 10%”。

### 2.6 荷兰：先解决“有没有容量”

| 项目 | 内容 |
|---|---|
| 并网规则 | Netcode elektriciteit |
| 主管 | TenneT（输电）；区域 DSO；ACM（监管） |
| 结构性问题 | 电网拥堵，新增容量排队 |
| 储能机会 | 容量限制合同（capacity-limiting contract）+ 电池 |
| 优先顺序 | 缓解拥堵的项目优先；医院、消防等关键服务优先 |

- **荷兰的并网瓶颈不是标准，是容量**：大量地区红色拥堵，新增或扩容申请排队；2026 年中约 1.5 万家企业/机构在等待名单上（C 级）。
- **容量限制合同是折中方案**：用户接受在电网紧张时限功率，换取更快接入；配套电池可以在限功率时保供，并参与市场交易。
- **储能被列入“缓解拥堵”的优先类别**：大型电池可以帮助电网调峰、缓解局部阻塞，因此在部分拥堵区获得优先接入；具体资格以 DSO 的优先规则为准。
- **常见坑**：先买设备再申请接入；忽略“运输/施工”对电网的影响；没有评估容量限制合同的收益损失。

### 2.7 波兰：并网条件有法定时限

| 项目 | 内容 |
|---|---|
| 并网规则 | 能源法 + NC RfG 实施 + PSE/OSD 技术条件 |
| 主管 | PSE（输电）；OSD（配网）；URE（监管） |
| 时限 | ≤1 kV：30 天内出连接条件；>1 kV：150 天内 |
| 费用 | 储能并网费按并网成本的一半计（能源法修正案，B/C） |
| 特殊点 | 并网许可多、实际并网少；2026–2028 是集中并网期 |

- **并网条件是“有法定时限”的**：这降低了不确定性，但不等于一定能接入；PSE/OSD 仍会做系统研究，容量不足时会给出限发或扩容方案。
- **储能并网费减半**：波兰通过能源法修正案降低储能并网成本，并把储能纳入 DSO/TSO 的投资计划；具体适用以最新法规为准。
- **并网许可与实际并网差距大**：大量项目持有并网条件但未建成；投决时要看“并网条件有效期 + 建设里程碑”，不要只看许可数量。
- **常见坑**：把并网条件当成并网协议；忽略限发条款；没有预留扩容/升压站工期。

### 2.8 比利时与北欧：预审和辅助服务资格

- **比利时**：C10/11 是低压/中压并网的技术标准（Synergrid），输电并网走 Elia；储能还要通过 Elia 的辅助服务预审（FCR/aFRR/mFRR）。CRM 资格与并网容量、降额因子挂钩。
- **北欧**：各国 grid code 与平衡市场规则不同；FCR-N/FCR-D、aFRR、mFRR 的预审和计量要求是储能收入的前提。mFRR EAM 的 15 分钟能量激活市场改变了报价与结算逻辑。
- **共同点**：并网容量、辅助服务预审、平衡责任主体（BRP）注册是三件不同的事；只拿到并网协议，不等于能参与辅助服务。
- **常见坑**：忽略预审的响应时间/持续时间要求；没有本地 BRP；把并网容量当成可交易容量。

### 2.9 美国：IEEE 1547 + UL 1741 + AHJ

| 项目 | 内容 |
|---|---|
| 分布式并网 | IEEE 1547-2018；UL 1741（逆变器） |
| 储能系统 | UL 9540；NEC 706（安装） |
| 消防 | NFPA 855；UL 9540A |
| 并网主管 | ISO/RTO（批发）；州 PUC；地方 AHJ |
| 队列 | FERC Order 2023 改革；PJM/CAISO 各自队列 |

- **美国没有统一并网码**：IEEE 1547 是分布式并网的技术基准，UL 1741 是设备认证；具体并网条件由 ISO/RTO tariff、州规则和地方 AHJ 决定。
- **UL 9540 是系统认证**：电池、PCS、BMS、消防、控制作为一个系统认证；换电芯/换 PCS 可能触发重新认证。
- **NFPA 855 是安装标准**：间距、防火分区、灭火、通风、应急响应；地方 AHJ 可能加严，保险公司也可能要求 UL 9540A 大规模火烧测试（LSFT）。
- **队列改革**：FERC Order 2023 要求 RTO 采用先到先得 +  readiness 门槛；PJM 2026 年首轮并联队列约 715 个项目/201.5 GW，研究周期约 40 个月（B）。
- **ERCOT 特殊点**：ERCOT 是州内系统，并网走 ERCOT 的 NOGRR/资源注册；2026-08-01 生效的 NOGRR 282 对逆变器与储能控制参数有新要求，项目要按新规复核。
- **常见坑**：只做 UL 1741 不做 UL 9540；忽略 AHJ 的消防审查；共址项目没有处理容量资格和并网费。

### 2.10 澳大利亚：NER + AEMO 注册

| 项目 | 内容 |
|---|---|
| 并网规则 | National Electricity Rules（NER）；AEMO 注册 |
| DER 并网 | AS/NZS 4777.2 |
| 储能安全 | AS 5139（B） |
| 消防 | 州/领地消防规范 + NCC |
| 市场注册 | Generator / Market Customer / IRP |

- **并网与市场注册是两条线**：NSP（网络服务提供商）给连接协议，AEMO 给市场注册；储能可以按 Generator、Market Customer 或 IRP 注册，不同类别义务不同。
- **AS/NZS 4777.2 管 DER**：户用/工商储的逆变器并网要求；大储走 NER 和 AEMO 的并网标准，不适用 4777.2。
- **FCAS 资格是单独预审**：并网不等于能提供 FCAS；要通过 AEMO 的 MASS 测试，证明响应时间、持续时间、控制精度。
- **常见坑**：只拿连接协议不做市场注册；忽略 MLF/IRLF 对收益的影响；FCAS 预留没有纳入 SOC 模型。

### 2.11 日本：电气事业法 + 系统连系规程

| 项目 | 内容 |
|---|---|
| 法律 | 电气事业法；系统连系规程（JEAC 9701） |
| 并网主管 | 一般送配电事业者；OCCTO（系统协调） |
| 市场 | JEPX 30 分钟现货；容量市场；EPRX；LTDA |
| 外资 | 外为法事前届报 |
| 消防 | 消防法 + 建筑基准法 |

- **并网审查细**：日本对频率、电压、故障穿越、无功、保护配合的要求细，提交资料多；并网前要与一般送配电事业者做系统研究。
- **30 分钟市场粒度**：JEPX 日前是 48 个 30 分钟商品；储能调度和 SOC 模型要按 30 分钟，不是 15 分钟。
- **容量市场/LTDA 资格与并网挂钩**：没有并网容量，不能参与容量市场或 LTDA；LTDA 还要求 ≥6 小时时长（第 3 回起）。
- **外资审查**：电气业中的一般送配电、送电、≥5 万 kW 发电属于外为法核心行业，事前届报；审查 30 日、最长 5 个月（A）。
- **常见坑**：用中国并网标准做日本项目；忽略 30 分钟结算；外资申报滞后。

## 3. 设备认证：一张“证书地图”

### 3.1 国际电工委员会（IEC）

| 标准 | 范围 | 用途 |
|---|---|---|
| IEC 62933 系列 | 电能存储系统（EES） | 术语、规划、安全、并网、环境 |
| IEC 62619 | 工业用锂二次电池/电池组安全 | 电芯/电池组安全 |
| IEC 63056 | 电能存储系统用二次电池/电池组 | 储能电池安全 |
| IEC 62620 | 工业用锂二次电池性能 | 容量、效率、循环 |
| IEC 62477-1 | 电力电子变换器安全 | PCS 安全 |
| IEC 61000 系列 | 电磁兼容 | EMC |
| UN 38.3 | 锂电池运输 | 海运/空运/陆运 |

- **IEC 62933 是“系统级”标准族**：不是单一证书；不同部分覆盖术语、规划、安全、并网、环境、火灾。项目招标常要求“符合 IEC 62933-5-2”或“IEC 62933-5-3”，要看清是哪一部分。
- **电池与系统分开认证**：电芯/模组按 IEC 62619/63056，系统按 IEC 62933/UL 9540；PCS 按 IEC 62477-1；缺一项都可能被业主拒绝。
- **UN 38.3 是运输门槛**：没有 UN 38.3 报告，电池不能合法运输；这是项目物流的前置条件，不是并网要求。

### 3.2 北美：UL 与 IEEE

| 标准 | 范围 | 备注 |
|---|---|---|
| UL 9540 | 储能系统与设备 | 系统级认证；电池/PCS/BMS/消防一起 |
| UL 9540A | 热失控火灾蔓延测试 | 第 6 版 2026-03 发布，强制 LSFT |
| UL 1741 | 逆变器/并网设备 | 与 IEEE 1547 配合 |
| IEEE 1547-2018 | 分布式能源并网 | 电压/频率/无功/故障穿越 |
| NEC 706 | 储能系统安装 | 电气安装 |
| NFPA 855 | 固定式储能安装 | 间距、消防、通风 |

- **UL 9540 是“系统认证”，不是“电池认证”**：电池、PCS、BMS、消防系统、控制逻辑要作为一个系统评估；换电芯、换 PCS、改消防方案都可能触发重新认证。
- **UL 9540A 第 6 版把 LSFT 推到台前**：2026-03-13 发布，强制大规模火烧测试；NFPA 855-2026 将 LSFT 纳入安装合规前置条件（B）。
- **IEEE 1547-2018 是并网基准**：美国分布式并网按 IEEE 1547，具体参数由州/ISO 的 tariff 决定；UL 1741 是设备认证，两者不能互相替代。
- **常见坑**：只做 UL 9540A 不做 UL 9540；UL 9540A 报告版本过旧；NFPA 855 的地方修订版与 2026 版不一致。

### 3.3 欧洲：CE、EN 与并网认证

| 项目 | 内容 | 备注 |
|---|---|---|
| CE-LVD | 低电压指令 2014/35/EU | 电气安全 |
| CE-EMC | 电磁兼容指令 2014/30/EU | 干扰/抗扰 |
| RoHS | 有害物质限制 | 材料合规 |
| 电池法规 | (EU) 2023/1542 | 碳足迹、护照、回收 |
| 并网 | EN 50549 / 本国 grid code | 并网证书 |
| 消防 | 各国消防规范 + 电池法规热失控 | 项目级审批 |

- **CE 是“自我声明 + 技术文件”**：大多数储能设备不需要公告机构发证，但需要有完整的技术文件、风险评估、测试报告；并网认证是单独的。
- **EN 50549-1/-2 是并网通用标准**：低压/中压发电设施；部分国家用 EN 50549-10 或本国标准覆盖储能并网测试，具体以 CENELEC 和本国电网运营商为准（B）。
- **电池法规改变“CE”的内涵**：除了 LVD/EMC/RoHS，还要满足电池法规的碳足迹、标签、护照、尽职调查；CE 标志不再是“一张证书”，而是一套持续义务。
- **常见坑**：把 CE 当并网证书；技术文件没有覆盖储能系统；电池法规的“生产者”责任没有落地到进口商。

### 3.4 认证与并网的关系

```
设备认证（型式试验）
   ├─ IEC / UL / EN 标准 → 证明设备安全与性能
   ├─ 并网认证（Unit Certificate / G99 / CEI）→ 证明设备符合电网规则
   └─ 项目认证（系统集成 + 现场测试）→ 证明整个项目符合并网协议
```

- **三层不能互相替代**：IEC 62619 过了，不代表 VDE-AR-N 4110 过；UL 9540 过了，不代表 NFPA 855 安装合规。
- **项目级认证常被忽略**：即使设备有证书，现场接线、保护定值、通信、无功设置仍要按并网协议测试；现场测试不通过，项目不能并网。
- **认证的“版本”很重要**：标准更新后，旧证书可能不被接受；投标前要确认业主/电网运营商接受的版本和有效期。

## 4. 消防：从“设备安全”到“安装合规”

### 4.1 北美：NFPA 855 + UL 9540A

| 要素 | 要求 | 对项目的影响 |
|---|---|---|
| 间距 | 储能与建筑、红线、其他危险物的最小距离 | 决定土地面积和总图 |
| 防火分区 | 防火墙、防火间距、分隔 | 影响土建成本 |
| 灭火 | 自动喷水/气体/水雾；抑制复燃 | 影响消防系统和保险 |
| 通风 | 可燃气体探测与排风 | 影响 HVAC 与控制 |
| 应急 | 消防接入、应急断电、标识 | 影响运维与培训 |
| LSFT | UL 9540A 大规模火烧测试 | 影响设备选型与保险 |

- **NFPA 855-2026 把 LSFT 纳入安装合规**：没有 UL 9540A 大规模火烧测试报告，项目可能无法通过消防审查、无法融资、无法投保（B）。
- **AHJ 是最终裁判**：NFPA 855 是模型规范，地方消防局（AHJ）可以加严；同一套设备在不同州/县可能得到不同结论。
- **保险是隐形门槛**：保险公司可能要求额外的热失控测试、消防系统、运维协议；没有保险，项目融资关闭不了。

### 4.2 欧洲：电池法规 + 国家消防规范

- **电池法规的热失控要求**：电池法规要求电池/系统提供安全信息，热失控测试方法与 UL 9540A 有相似之处，但不等于 UL 9540A 认证；欧盟没有全盘采纳 NFPA 855。
- **国家消防规范**：德国各州消防规范、英国 BS 标准与消防评估、意大利 VVF、西班牙自治州许可、波兰消防审批；项目要按当地规范做消防设计。
- **保险与业主标准**：欧洲业主/保险商常要求 UL 9540A 或等效测试；即使当地法规不强制，商业合同也可能强制。
- **常见坑**：只按设备证书做消防设计；忽略地方 AHJ 的附加要求；没有把消防审批时间纳入项目计划。

### 4.3 澳大利亚与日本

- **澳大利亚**：AS 5139 储能安全、NCC 建筑规范、州消防规范；大储项目还要看各州的规划许可和消防要求。
- **日本**：消防法、建筑基准法、电气事业法；储能系统的设置、防火、通风、标识要按消防法申报；项目审批周期长。
- **共同点**：消防不是“设备认证”，是“项目审批”；设备证书只是敲门砖，最终看总图、间距、消防系统和应急方案。

## 5. NIS2：网络安全从“IT 的事”变成“董事会的事”

### 5.1 适用范围与门槛

| 要素 | 内容 |
|---|---|
| 法律 | Directive (EU) 2022/2555 |
| 生效 | 2023-01-16 |
| 转化截止 | 2024-10-17 |
| 适用 | 2024-10-18 起 |
| 行业 | Annex I 能源（电力、区域供热、石油、天然气、氢）等 |
| 门槛 | 中型及以上企业：≥50 员工或年营业额 >€10m |
| 分类 | essential（关键）/ important（重要） |
| 罚则 | essential：€10m 或全球营业额 2%；important：€7m 或 1.4% |

- **电力子行业覆盖发电、输配、NEMO、市场参与者**：储能按“电力 undertaking/市场参与者”落入范围的可能性高，具体以成员国转化法为准（B）。
- **不是“自愿指南”**：NIS2 是指令，成员国必须转化为国内法；不遵守可能被罚、被限制经营、管理层被追责。
- **供应链安全是核心**：Art 21(2)(d) 要求评估供应链安全，包括供应商和 service provider 的漏洞与 practices；中国设备商/EMS 供应商会被要求提供安全证据。

### 5.2 合规义务

| 义务 | 内容 | 落地动作 |
|---|---|---|
| 风险管理 | 风险评估、事件处理、业务连续性、供应链安全 | 建立 ISMS；做资产清单和威胁建模 |
| 技术措施 | 多因素认证、加密、访问控制、漏洞管理 | EMS/SCADA 加固；远程运维 MFA |
| 事件报告 | 24h 早期预警、72h 事件通知、1 个月最终报告 | 建立 24/7 响应流程；与 CSIRT 对接 |
| 管理层责任 | 管理层批准风险措施、接受培训 | 董事会签字；指定 CISO |
| 供应链 | 供应商安全要求、合同条款 | 采购合同加安全附件；审计权 |

- **24h/72h/1 个月是硬时钟**：从“意识到重大事件”开始算；没有 24/7 响应能力，企业很难按时报告。
- **储能项目的“事件”包括**：EMS 被入侵、SCADA 失控、远程运维账号泄露、电池数据被篡改、并网控制指令被伪造。
- **合同要写清楚**：设备商/EMS 供应商的漏洞披露、补丁时限、事件配合、数据访问、审计权；否则出事时责任不清。

### 5.3 2026 年转化状态

| 国家/地区 | 状态 | 备注 |
|---|---|---|
| 比利时、克罗地亚 | 2024-10-17 前完成 | 少数按时完成的国家 |
| 波兰 | 2026-03-02 转化，2026-04-02 生效 | 晚于截止日 |
| 荷兰 | 2026-07-10 完成 | 晚于截止日 |
| 爱尔兰、西班牙、法国、荷兰 | 2026-07-08 被欧盟委员会诉至法院 | 未完成全面转化 |
| 多数成员国 | 2026 年中已转化或接近完成 | 具体以欧盟委员会/各国官方为准 |

- **“欧盟有指令”不等于“当地已执行”**：各国转化进度不同，执法力度不同；项目要按“当地法”做合规，不是按指令原文。
- **跨境项目**：在多个成员国运营的企业，可能要在每个国家分别注册/报告；不要假设“一国合规，全欧合规”。
- **常见坑**：把 NIS2 当成 IT 部门的事；没有做供应链安全评估；事件报告流程没有演练。

## 6. 电池法规与电池护照：2027-02-18 是硬节点

### 6.1 时间表

| 日期 | 义务 | 适用 |
|---|---|---|
| 2024-02-18 | 电池法规开始适用 | 所有电池 |
| 2025-02-18 | EV 电池碳足迹声明（已延期） | EV 电池 |
| 2026-02-18 | >2 kWh 工业电池碳足迹声明（已延期） | 工业电池（含储能） |
| 2026-08-18 | 通用信息标签；碳足迹性能等级标签 | EV/LMT/工业电池 |
| 2026-07-16 | DPP 注册系统实施条例 (EU) 2026/1778 通过 | 电池护照 |
| 2026-07-20 | DPP 注册系统上线（B/C） | 电池护照 |
| 2027-02-18 | 电池护照强制；所有电池加 QR 码 | EV/LMT/>2 kWh 工业电池 |
| 2027-08-18 | 供应链尽职调查 | 相关电池 |
| 2028-08-18 | 再生材料含量：Co 16%、Li 6%、Ni 6% | EV/LMT/工业电池 |

- **储能电池属于“工业电池 >2 kWh”**：直流侧容量超过 2 kWh 的储能系统，原则上要护照；具体按电池类别、用途和投放方式判断。
- **护照不是“贴个二维码”**：它是贯穿电池全生命周期的数据体系，约 71 项数据点（委员会 2026-08 指南，B/C），包括身份、溯源、碳足迹、再生含量、电化学性能、拆解与安全。
- **数据分层**：公开信息（制造商、材料、碳足迹）与受限信息（健康状态、循环次数、维修记录）分级访问；数据要持续更新，不是一次性填报。
- **海关核验**：进口产品的唯一标识将在欧盟海关环节核验；没有护照/二维码，产品可能无法上市。

### 6.2 责任划分

| 角色 | 责任 |
|---|---|
| 生产者（producer） | 在欧盟首次投放电池的一方，包括进口商；承担护照、标签、碳足迹、回收责任 |
| 制造商 | 提供数据、技术文件、碳足迹核算、供应链溯源 |
| 进口商 | 确认生产者责任已履行；保存合规文件 |
| 回收商 | 访问拆解/回收数据；反馈再生含量 |
| 公告机构 | 碳足迹验证、部分合规评估 |

- **“生产者”可能是进口商**：中国制造商把电池卖给欧洲进口商，进口商可能是法规下的 producer；合同要明确谁负责护照、谁承担召回/罚款。
- **数据要“可验证”**：碳足迹要按欧盟方法学核算，第三方验证；供应链要穿透到矿山，证明没有环境破坏和劳工风险。
- **再生含量**：2028-08-18 起，钴 16%、锂 6%、镍 6%；提前布局回收料供应链，否则可能无法达标。

### 6.3 对中国厂商的影响

- **碳足迹是新的“成本项”**：电力碳因子、运输、前驱体、正极材料都要核算；用中国电网平均因子还是项目绿电，会显著改变结果。
- **数据跨境**：护照数据要存放在欧盟可访问的系统；涉及供应链数据出境，要评估中国数据合规与欧盟访问要求的冲突。
- **产品设计**：电芯/模组/系统的身份编码、BMS 数据接口、拆解设计要提前做；后期改造比前期设计贵得多。
- **常见坑**：把电池护照当成 2027 年的事；没有做碳足迹核算；供应链数据无法追溯；进口商/制造商责任不清。

## 7. NZIA 与产业政策：公共采购的“非价格标准”

### 7.1 NZIA 的核心数字

| 要素 | 内容 |
|---|---|
| 法规 | Regulation (EU) 2024/1735 |
| 生效 | 2024-06-29 |
| 目标 | 2030 年欧盟净零技术制造能力满足 40% 需求 |
| 非价格标准 | 2025-12-30 起，成员国拍卖至少 30% 年容量或 6 GW 适用 |
| 权重 | 非价格标准占评标 15–30% |
| 韧性 | 单一第三国供应 >85% 时触发 |
| 实施条例 | (EU) 2025/1176（2025-05-23） |

- **NZIA 不是“禁止中国产品”**：它通过非价格标准（可持续性、韧性、网络安全、本地就业等）给欧盟制造加分；中国产品仍可参与，但要在评标中弥补差距。
- **适用对象是“净零技术”**：太阳能、风能、电池/储能、电网、热泵、电解槽、CCS、核能等；储能项目在成员国招标中可能适用。
- **“30% 或 6 GW”是触发门槛**：成员国可以选择按容量比例或绝对规模适用；具体拍卖规则决定中国设备能不能参与。
- **意大利 FER X 是先行案例**：FER X 对 >1 MW 光伏的组件、电池片、逆变器来源设限，首次执行 NZIA 供应链标准；储能项目的 MACSE/容量市场是否适用，要看拍卖条款。

### 7.2 工业加速器法案（IAA，草案）

| 要素 | 内容 | 状态 |
|---|---|---|
| 提案 | 2026-03-04 欧盟委员会提出 | 草案，未生效 |
| 公共采购 | 分阶段“欧盟制造”：先 BMS/组件，后电芯 | 谈判中 |
| 外资条件 | 投资 >€100m 且来源国占全球产能 >40% | 谈判中 |
| 审批标准 | 六项中满足四项（本地用工、研发、采购、合资、持股 ≤49%、知识产权） | 谈判中 |
| 不追溯 | 已建/在建项目不受影响 | 谈判中 |

- **IAA 是“草案”，不是现行法**：不要按草案做已生效的合规结论；但可以作为项目选址/股权结构的提前量。
- **“€100m + 40%”针对制造业投资**：不是所有储能项目投资；具体适用范围以最终文本为准。
- **不追溯是窗口期**：已开工/已签约项目可能不受影响，这也是 2026 年中国厂商密集签约的原因之一（C）。
- **常见坑**：把 IAA 当成已生效；忽略 NZIA 在招标中的评分；没有准备本地含量/碳足迹证明。

## 8. 外资审查：股权交易也可能被卡

### 8.1 欧盟层面

| 要素 | 内容 |
|---|---|
| 现行法规 | Regulation (EU) 2019/452，2020-10-11 适用 |
| 新法规 | 2026-06-17 通过，取代 2019/452；生效后 18 个月适用（B/C） |
| 机制 | 成员国审查 + 欧盟合作机制 |
| 覆盖 | 能源、关键基础设施、关键技术、关键原材料等 |
| 新增 | 欧盟境内企业但最终由第三国控制的交易 |

- **欧盟不是“统一审查”**：审查权在成员国；欧盟委员会可以发表意见，但最终决定在成员国。
- **新法规扩大范围**：覆盖欧盟境内企业但最终由第三国投资者控制的交易；敏感领域可能强制审查（B/C，以最终文本为准）。
- **能源资产是敏感领域**：电网、发电、储能、LNG、关键矿产都可能触发审查；少数股权、董事会席位、否决权、数据访问都可能被认定为“控制”。

### 8.2 主要国家

| 国家 | 法规/机构 | 触发点 | 备注 |
|---|---|---|---|
| 美国 | CFIUS/FIRRMA；财政部 | 控制权、关键基础设施、房地产、数据 | 少数股权+否决权也可能触发 |
| 日本 | 外为法；财务省/经产省 | 核心行业（电气、发电 ≥5 万 kW） | 事前届报；审查 30 日、最长 5 个月 |
| 澳大利亚 | FIRB；财政部 | 能源、关键基础设施、土地 | 门槛按投资者国籍/资产类型 |
| 英国 | NSIA 2021；BEIS/DSIT | 17 个敏感行业（含能源） | 强制申报；未申报可能无效 |
| 德国 | AWV；BMWK | 关键基础设施、能源、国防 | 跨行业审查；可附条件 |
| 法国 | IEF；经济部 | 能源、国防、交通、数字；非欧经区 25% 表决权（上市 10%） | 事前审批 |
| 意大利 | Golden Power；总理府 | 能源、网络、国防 | 可附条件/否决 |
| 西班牙 | FDI 审查；贸易部 | 能源、关键基础设施 | 2020 年起扩展 |
| 波兰 | 2020 年审查法；UOKiK | 能源、关键基础设施 | 事前申报 |
| 比利时/荷兰/北欧 | 比利时联邦审查机制 + 区域权限；荷兰 Vifo（BTI）；瑞典 ISP、丹麦/芬兰/挪威各国筛查法 | 能源、关键基础设施、敏感技术 | 门槛与申报时点按各国法；不能套用欧盟统一规则（C，逐国核实） |

- **比/荷/北欧不是一套规则**：比利时联邦与区域权限并存，荷兰走 Vifo/BTI，北欧各国筛查法和门槛不同；同一笔交易在不同国家可能得出不同结论，必须逐国做 Jurisdiction Analysis。

- **“不到 10% 就免报”是过时理解**：CFIUS/FIRRMA、日本外为法、英国 NSIA 都可能覆盖少数股权 + 权利安排；要看“控制”而不是“持股比例”。
- **交易结构设计要前置**：合资、少数股权、董事会观察员、技术许可、数据访问，都可能触发审查；先做 Jurisdiction Analysis，再谈估值。
- **时间成本**：美国 CFIUS 30 天初审 + 45 天调查（可延长）；日本 30 日 + 最长 5 个月；欧盟成员国 1–6 个月；要把审查时间写进 SPA 的 long-stop date。

### 8.3 中国厂商的常见路径

| 路径 | 优点 | 风险 |
|---|---|---|
| 设备出口 | 轻资产、快 | 关税/供应链审查；并网/认证门槛 |
| OEM/ODM | 本地品牌、合规 | 技术授权、质量责任 |
| 本地建厂 | 绕开关税/本地含量 | 重资产、FDI 审查、补贴条件 |
| 合资 | 本地资源、合规 | 控制权/知识产权/退出 |
| 收购存量项目 | 快速获得并网/容量 | 外资审查、负债/许可瑕疵 |

- **设备出口不是“没有合规”**：电池法规、NIS2 供应链、UL 9540A、并网认证都适用；只是没有 FDI 审查。
- **本地建厂要过 FDI + 补贴 + 本地含量**：德国/法国/意大利/西班牙/波兰都可能审查；美国还有 FEOC/ITC 限制。
- **合资要设计“控制权”**：50/50 合资可能被认定为共同控制；董事会席位、否决权、知识产权许可都可能触发审查。

## 9. 合规项目时间轴：把“审批”当成关键路径

### 9.1 典型 100 MW/200 MWh 项目的合规时间轴（D 级，方法演示）

| 阶段 | 时间 | 关键交付 | 依赖 |
|---|---|---|---|
| 选址/土地 | 0–6 月 | 土地权属、规划许可 | 地方规划 |
| 并网申请 | 0–3 月 | 申请受理、接入点 | 电网容量 |
| 系统研究 | 3–15 月 | 并网方案、限发条件 | 电网研究 |
| 设备认证 | 3–12 月 | IEC/UL/并网证书 | 设备选型 |
| 消防审批 | 6–18 月 | 消防设计、AHJ 许可 | 总图/设备 |
| NIS2 合规 | 6–18 月 | ISMS、事件流程、合同条款 | IT/OT |
| 电池护照 | 6–24 月 | 数据、碳足迹、DPP 注册 | 供应链 |
| FDI 审查 | 交易前 1–6 月 | 申报/批准 | 交易结构 |
| 建设/调试 | 12–24 月 | 并网测试、市场注册 | 设备/施工 |

- **关键路径不是设备交付，是并网+消防+数据**：设备可以提前买，但并网研究、消防审批、电池护照数据往往更慢。
- **并行是唯一解**：设备认证、消防设计、NIS2、电池护照要同步启动；串行做会把 18 个月拖成 36 个月。
- **时间轴要写进投决模型**：每延迟 1 个月，融资成本、电价暴露、设备降价/涨价都会变。

### 9.2 合规成本清单

| 项目 | 量级（D 级） | 备注 |
|---|---|---|
| 并网研究/测试 | €0.2–1.0m | 取决于电网和项目规模 |
| 设备认证 | €0.1–0.5m | IEC/UL/并网 |
| 消防设计与审批 | €0.1–0.3m | 不含消防系统硬件 |
| NIS2 合规 | €0.05–0.3m/年 | ISMS、审计、人员 |
| 电池护照/碳足迹 | €0.1–0.5m | 数据、验证、系统 |
| 法律/外资审查 | €0.1–0.5m | 交易结构、申报 |
| 合计 | €0.65–3.1m | 不含硬件和土建 |

> 以上为合成量级，不是报价；实际成本随项目规模、国家、设备类型、认证范围变化。

## 10. 十个坑

1. **把 CE 当并网证书**：CE 是产品安全，并网要看 VDE/G99/CEI 等本国规则；两者不能互相替代。
2. **只做设备认证，不做项目认证**：现场保护定值、通信、无功、故障穿越测试不通过，项目不能并网。
3. **忽略消防审批时间**：NFPA 855/AHJ 或欧洲地方消防审批可能比设备交付更慢；总图要提前做。
4. **电池护照等到 2027 年**：数据、碳足迹、供应链溯源需要 12–18 个月；2026 年就要启动。
5. **把 NIS2 当成 IT 项目**：EMS/SCADA/远程运维是 OT 安全，事件报告有 24h/72h 硬时钟；董事会要签字。
6. **供应链数据不可追溯**：电池法规要求穿透到矿山；没有供应链数据，护照和碳足迹都做不出来。
7. **NZIA 只影响光伏**：储能招标也可能适用非价格标准；投标前要看招标条款。
8. **外资审查只看持股比例**：少数股权+否决权/董事会席位也可能触发；交易结构要前置设计。
9. **并网许可当并网协议**：许可有期限和里程碑；没有并网协议，项目不能投运。
10. **合规成本没有进投决**：认证、消防、NIS2、护照、法律费用是真实成本；漏算会高估 IRR。

## 12. 算例（D 级：方法演示，不是投资建议）

### 12.1 合规延迟对 IRR 的影响

假设：

- 项目：100 MW/200 MWh，capex €30m，年 EBITDA €6m；
- 融资：70% 债务，利率 5%，建设期利息按 capex 计；
- 延迟：并网+消防+护照合计延迟 6 个月。

计算：

```
建设期利息增加 ≈ €30m × 70% × 5% × 0.5 = €0.525m
EBITDA 损失 ≈ €6m × 0.5 = €3.0m
总影响 ≈ €3.525m（未折现）
```

- **延迟 6 个月可能吃掉 0.5–1.0 个百分点的 IRR**；具体取决于电价曲线和融资结构。
- **如果延迟导致错过容量市场/拍卖交付年**，损失更大；要把“交付年”当成硬约束。

### 12.2 合规成本对 LCOS 的影响

```
LCOS = (capex + 合规成本 + 运维现值 - 残值) / 全生命周期放电量
```

假设合规成本 €1.5m，全生命周期放电量 400 GWh：

```
合规成本分摊 ≈ €1.5m / 400 GWh = €3.75/MWh
```

- **合规成本不是小数**：€3.75/MWh 相当于 LCOS 的 5–10%；在低价差市场可能决定项目生死。
- **认证/消防/护照的成本要按项目分摊**，不能只算设备单价。

### 12.3 电池护照数据准备的“关键路径”

| 任务 | 前置 | 时间 |
|---|---|---|
| 碳足迹核算 | 电力因子、供应链数据 | 3–6 月 |
| 第三方验证 | 核算报告 | 2–4 月 |
| DPP 数据映射 | 71 项数据点 | 3–6 月 |
| 系统对接 | DPP 注册库 | 2–4 月 |
| 试运行 | 海关/客户 | 1–2 月 |

- **总时间 11–22 个月**；如果 2027-02-18 是硬节点，最晚 2025 年底/2026 年初就要启动。
- **数据缺口**：供应链矿山数据、回收料比例、碳足迹因子；这些不是 IT 系统能补的。

## 13. 2026–2027 观察点

- **欧盟**：RfG/DCC 修订；NIS2 各国执法；电池护照 DPP 注册库运行；NZIA 拍卖执行；IAA 立法进度。
- **德国**：VDE-AR-N 版本更新；单元证书互认；StromVKG 招标的并网/本地含量条件。
- **英国**：TMO4+ 队列改革落地；G99/G100 版本；NSIA 审查案例。
- **意大利**：CEI 0-21/0-16 更新；MACSE 第二轮并网资格；NZIA 在 FER X 的执行。
- **西班牙**：TED/82/2026 执行；自消费合规；并网许可里程碑。
- **法国**：2026 年底并网框架改革；容量认证与 PPI 豁免 2026-11-23；IEF 门槛执行。

### 口径提醒

- **标准版本**：IEC/UL/NFPA/VDE 都有版本号；引用时写“现行版”，不要把旧版当现行。
- **“认证”与“合规”**：认证是证书，合规是持续义务；电池法规/NIS2 都是持续义务，不是一次性证书。
- **“欧盟”与“成员国”**：指令要转化为国内法；项目要看当地法，不是只看布鲁塞尔。
- **“并网”与“市场注册”**：并网协议不等于市场注册；辅助服务/容量市场还有单独预审。
- **“设备”与“项目”**：设备证书不等于项目合规；现场测试、消防审批、数据护照都是项目级。
