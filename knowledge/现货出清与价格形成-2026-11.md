## 0. 一页看懂

### 0.1 三句话

- **出清不是"把报价从低到高排个序"**：SCUC 先决定哪些机组开机、何时启停，SCED 再决定开机机组各发多少；报价只是输入，约束和目标函数是另一半。
- **价格是约束的影子价格，不是成本的加总**：能量平衡的影子价格给出系统价，网络约束把它拉成节点价，备用/爬坡/最小出力等约束会改写价格或制造补偿；"边际机组"只是最后一个被需要的增量段，不一定是报价最高的机组。
- **出清结果要读四件事**：中标量、节点价、约束是否 binding、补偿/uplift。只看价格，会把"中标但亏钱"误读成好结果。

### 0.2 关键数字与口径

| 概念 | 含义 | 来源与级别 |
|---|---|---|
| SCUC | 安全约束机组组合：决定启停与出力计划，含最小开停机、启停成本、爬坡、网络与备用 | 市场出清通用定义，A |
| SCED | 安全约束经济调度：给定开机状态，决定各机组出力与价格 | 市场出清通用定义，A |
| 边际机组 | 最后一个被需要的增量报价段所属机组；其报价（或该段报价）决定统一价 | 边际定价定义，A |
| 节点价 LMP | 节点多供 1 MW 负荷的系统边际成本，可分解为能量 + 阻塞 + 网损 | 现货市场通用定义，A；推导见 [从潮流到节点电价](潮流阻塞与节点电价-2026-11.md) |
| 阻塞租金 | 受端价与送端价之差 × 过断面潮流；是市场盈余，不是某台机组的收入 | 机制恒等式，A |
| uplift / 补偿 | 按报价结算的收入低于按规则核定的成本时，补足差额的机制 | 规则与机制设计，A/B；口径逐省不同 |
| 价格上限/下限 | 申报或出清的限价，随省份与年份调整 | 省级规则，B；引用前查最新文件 |
| 本文算例 | 三机组、四时段、单节点、纯能量 | **D 级合成**，不对应任何真实市场 |

> **口径提醒**：报价段数、单调性、限价、二次限价、必开机组、补偿规则、RUC 与日前市场的先后顺序、节点价还是分区价结算，均由省份规则决定。本文只讲"引擎如何把报价变成价格"，不替代省级细则。

## 1. 出清引擎的输入、约束与输出

### 1.1 一台机组进入出清模型时，带的不是一条线，而是一组参数

报价曲线只是最显眼的一项。出清模型还要知道：

| 输入 | 作用 | 缺了会怎样 |
|---|---|---|
| 报价曲线 | 决定经济上的供给顺序 | 无法排序，只能用默认报价或成本代理 |
| 最小/最大出力 | 决定可行域与必发量 | 会算出"低于最小出力"的假计划 |
| 启停成本、空载成本 | 决定开机是否值得 | 便宜机组被频繁启停，成本被低估 |
| 最小开机/停机时间 | 决定跨时段可行性 | 计划看起来便宜，实际无法执行 |
| 爬坡/滑坡 | 决定相邻时段能否衔接 | 价格尖峰被平滑掉，或计划不可执行 |
| 初始状态 | 决定第一天是否受历史约束 | 冷启动/热启动成本算错 |
| 检修/可用容量 | 决定实际可申报能力 | 供给虚高，价格被低估 |
| 网络与断面 | 决定电能能否送到负荷 | 全网一个价，阻塞价差消失 |
| 备用需求 | 决定留多少空余容量 | 能量价偏低，稀缺时无可用备用 |
| 政策约束 | 必开、优先发电、限价、环保 | 结果不符合规则，无法结算 |

这张表的含义是：**报价是"愿意卖"的曲线，参数是"能不能卖、怎么卖"的边界**。交易员常把注意力全放在报价上，但价格异常往往来自边界参数——最小出力、必开、检修、断面限额、备用要求。

### 1.2 两层决策：先组合，再调度

```text
[输入] 负荷预测 + 报价曲线 + 机组参数 + 网络/备用/政策
   ↓
[SCUC] 机组组合：开/停、启停时刻、跨时段约束
   ↓
[SCED] 经济调度：开机机组各发多少、潮流、价格
   ↓
[输出] 中标量 + 节点价 + 潮流 + 阻塞租金 + 补偿/uplift
```

- **SCUC** 是混合整数问题：开/停是 0/1 变量，目标含启动成本、空载成本、能量成本，约束含最小开停机、爬坡、备用、网络安全。
- **SCED** 在给定开机状态下是连续优化：目标通常是按报价的购电成本最小（或社会福利最大），约束含功率平衡、出力上下限、爬坡、备用、网络。
- **日前与实时**：日前通常做 SCUC + SCED，实时做更短周期的 SCED（或滚动 SCUC）；实时价格由实时平衡与约束决定，不等于日前价。两结算的细节见 [101 问 B](电力现货市场101问-B-出清结算与省域实践.md) 与 [电力交易专家](../skills/electricity-trading-expert/SKILL.md)。

### 1.3 输出不止一个价格

一次出清至少产出五类结果：

1. **机组中标量/出力曲线**：每台机组每个时段发多少；
2. **价格**：系统价、分区价或节点价，以及能量/阻塞/网损分量；
3. **潮流与断面**：哪些线路/断面达到限额，哪些约束 binding；
4. **盈余**：阻塞租金、备用盈余、不平衡资金；
5. **补偿**：必开补偿、启动补偿、空载补偿、make-whole uplift 等。

交易员如果只看第 2 项，就会漏掉"为什么中标了却亏钱"（第 5 项）和"为什么价格高但自己没受益"（第 1、3 项）。

### 1.4 为什么不能把 SCUC 当成大号 SCED

SCED 是凸问题（在报价单调、约束线性的前提下），功率平衡约束的对偶变量可以直接解释为系统边际价。SCUC 含整数变量，整数规划没有与连续对偶一一对应的"价格"；同样一条功率平衡约束，在机组组合变化时可能对应不同的边际机组和补偿需求。

因此，实际市场通常要在三种做法中选：

- **按 SCED 边际价结算 + 对非凸成本做补偿**：价格信号清晰，但需要 uplift；
- **凸包定价/扩展 LMP**：用凸包构造一个可支持的价格，减少 uplift，但计算和解释复杂；
- **按报价结算 + 规则补偿**：便于执行，但价格可能不反映真实稀缺。

各省选择不同，不能把一种做法当成"现货市场的标准答案"。这也是为什么"价格"和"补偿"要一起读。

## 2. 报价曲线怎么变成供给曲线

### 2.1 分段报价：把"愿意卖"拆成台阶

最常见的报价形式是若干段"价格—电量"对，价格随电量单调不减：

| 段 | 价格（元/MWh） | 电量（MW） | 累计（MW） | 含义 |
|---|---:|---:|---:|---|
| 最小出力块 | 180 | 100 | 100 | 开机后必须发的部分 |
| 增量段 1 | 240 | 100 | 200 | 第一段可调出力 |
| 增量段 2 | 320 | 100 | 300 | 第二段可调出力 |

出清时，最小出力块不是"可买可不买"的普通段：机组一旦开机，这一块通常必须被吸收（或被必开/最小出力约束强制）。增量段才按价格排序，进入边际排序。

### 2.2 块报价：全有或全无

块报价（block bid）把一段电量作为一个整体：要么全接受，要么全不接受，不能拆成部分。它适合表达"这台机组要么开机带满一段，要么不干"的意愿，但会带来两个后果：

- **非凸性**：排序后可能出现"便宜的块没被接受、更贵的块被接受"的组合，因为块不能拆分，需要和其他块/机组凑出可行的供需；
- **补偿**：被接受的块，其报价可能高于统一出清价；若按统一价结算，收入不足以覆盖报价，需要 make-whole。

这就是"paradoxically rejected block"（ paradoxical rejection，悖论性拒绝）的来源：不是排序错了，而是全有或全无的组合约束让"按单价排序"失效。是否允许块报价、允许哪些类型，逐省规则不同；交易员看到"便宜块没中"时，先查块报价规则，不要直接认定系统错误。

### 2.3 启停成本、空载成本、最小出力：它们不在报价曲线里，但会改变排序结果

- **启动成本**：锅炉点火、汽轮机暖机、辅机启动等的一次性成本；它让"今天开机"比"今天买电"更贵。
- **空载成本**：机组维持同步、不带负荷时的成本；只要开机就发生。
- **最小出力**：机组稳定燃烧/环保/供热要求决定的下限；它让系统在低负荷时段"不得不发"。

这三项不进入"元/MWh"的增量排序，而进入 SCUC 的目标函数和约束。所以会出现：

- 报价便宜的机组没开机：因为启动成本 + 最小开机时间 + 低负荷，算总账不划算；
- 报价贵的机组在开机：因为它已经在线，增量成本低，或者它是必开/供热机组；
- 低负荷时段价格为负：因为最小出力 + must-run 让系统供大于求。

### 2.4 报价不等于成本，但监管会看成本

报价是"愿意卖的价格"，成本是"实际发生的费用"。两者可以不同：

- 价格接受者（非枢机机组）在竞争性市场中，按边际成本报价是最优策略；
- 枢机机组有经济加价空间，但持续、无成本依据的加价属于经济持留，是监管红线；
- 市场监测会用成本参考价、Lerner 指数、申报充足率等识别异常，细节见 [101 问 B](电力现货市场101问-B-出清结算与省域实践.md) 与 [量化报价与交易风控](量化报价与交易风控-工程化-2026-11.md)。

因此，本模块讲"报价如何进入出清"，不讲"如何用报价操纵市场"。策略与合规边界归报价技能，规则与监管归交易技能。

### 2.5 报价曲线的可用性：别把"额定容量"当"可申报容量"

申报前要确认：

- 检修、降容、辅机故障后的可用容量；
- 最小出力是否受供热、环保、水位、气压限制；
- 爬坡能力是否受辅机、燃料、控制方式限制；
- 是否被标记为必开、必停、调试、固定出力；
- 新能源的预测出力与置信水平，储能 SOC 与可用充放电功率。

这些参数决定"报价曲线能不能兑现"。报价再漂亮，若可用容量不足，出清后执行不了，偏差会进实时结算。

## 3. SCED：单时段经济调度

### 3.1 目标与约束

在给定开机状态下，SCED 的典型目标是最小化按报价的购电成本：

```text
min  sum_i sum_s  p_is * q_is
s.t. sum_i q_i = D + losses
     pmin_i <= q_i <= pmax_i
     q_i - q_i_prev <= ramp_up_i
     q_i_prev - q_i <= ramp_down_i
     network constraints
     reserve requirement
```

其中 `p_is` 是机组 i 第 s 段的报价，`q_is` 是该段被接受的电量。若报价单调、约束线性，这是一个线性规划；功率平衡约束的对偶变量就是系统边际价（无阻塞、无网损时）。

### 3.2 无阻塞时：最后一个增量段定价

把各机组的增量段按价格从低到高排列，依次满足负荷，最后一个被部分或全部接受的段的价格，就是系统边际价。注意三个细节：

- **边际机组可能是"部分中标"**：负荷落在某段中间，该段的价格定价，但只接受一部分；
- **边际机组不一定是"报价最高"**：如果高报价机组没开机或没被需要，它不影响价格；
- **最小出力块可能高于边际价**：它被强制吸收，但不参与定价；这时需要补偿。

### 3.3 有最小出力时：价格可能低于机组的"第一段报价"

假设系统负荷很低，所有开机机组的最小出力之和已经超过负荷。此时：

- 系统无法再下调，只能让机组在最小出力上运行，甚至过发；
- 价格可能跌到下限（负价），因为系统需要信号让机组停机或让用户多用电；
- 按统一价结算，最小出力块报价高于价格的机组收入不足，需要 uplift。

这不是"价格算错了"，而是**非凸约束下统一价不能同时满足效率与成本回收**的必然结果。读结果时要同时看价格和补偿。

### 3.4 有网络时：SCED 的价格变成节点价

把网络约束加入 SCED，功率平衡的对偶不再是一个全网统一价，而是各节点的 LMP：

```text
LMP_n = energy + congestion_n + loss_n
```

- 无阻塞、忽略网损：各节点价相同；
- 有阻塞：送端价低、受端价高，价差 = 阻塞约束的影子价格 × 灵敏度；
- 有网损：受端价通常略高，因为多供 1 MW 需要多发一点来覆盖损耗。

推导、三节点手算和阻塞租金见 [从潮流到节点电价](潮流阻塞与节点电价-2026-11.md)；本模块只强调：**节点价是 SCED 的对偶输出，不是报价的简单排序结果**。

### 3.5 备用与爬坡：它们会改变"有效供给"

如果能量与备用联合出清，SCED 的目标和约束会同时考虑：

- 能量中标量；
- 备用中标量；
- 机组的能量 + 备用容量不超过最大出力；
- 备用需求满足。

这会产生两个价格：能量价和备用价。备用价本质上是被备用占用的容量在能量市场上的机会成本；当系统稀缺时，备用约束 binding，能量价和备用价都可能升高。备用机会成本的算例见 [电力交易专家](../skills/electricity-trading-expert/SKILL.md) §5，代码在 `market.py` 的 `reserve_opportunity_cost`。

爬坡约束则会把"瞬时供给"变成"跨时段可交付的供给"：即使总容量充足，若爬坡不够，系统也可能在负荷快速上升时出现稀缺价。单时段 SCED 看不到这一点，必须用多时段模型。

### 3.6 SCED 价格的三句话

- **价格由边际约束决定，不由平均成本决定**；
- **报价曲线越陡，价格越容易被少量负荷变化推高**；
- **非凸约束下，价格之外还要看 uplift**。

## 4. SCUC：跨时段与启停

### 4.1 机组组合在决定什么

SCUC 决定：

- 每个时段哪些机组开机；
- 何时启动、何时停机；
- 启动后是否满足最小开机时间，停机后是否满足最小停机时间；
- 相邻时段的出力是否满足爬坡；
- 是否满足备用、网络、供热、必开等约束。

目标是最小化"能量成本 + 启动成本 + 空载成本 + 其他可计入成本"。这是一个混合整数规划，规模大时会用分解、启发式或滚动优化。

### 4.2 为什么"便宜机组没开机"是正常的

假设一台煤电机组报价很低，但启动一次要 6,000 元，最小开机 2 小时。负荷只高 1 小时，开机省下的能量成本可能不到 6,000 元，还要承担最小开机时间的约束。此时最优解可能是：

- 让已经在线的高报价机组多发电；
- 让便宜机组保持停机；
- 等待负荷持续升高后再启动。

所以，"报价低"只是"如果开机，增量排序靠前"，不等于"一定开机"。交易员看到自己的低价机组没中标，先查启动成本、最小开机时间、负荷持续时长和备用要求，不要只怪报价。

### 4.3 跨时段约束会改变价格

SCUC 的跨时段约束会通过两种方式影响价格：

- **容量可用性**：机组因最小停机时间不能立即启动，或因最小开机时间不能立即停机，改变了各时段的可用供给；
- **成本分摊**：启动/空载成本进入目标函数，可能改变边际机组，进而改变价格；若价格机制不覆盖这些成本，就需要补偿。

因此，跨时段价格尖峰不一定是"有人抬价"，也可能是"系统为了满足跨时段约束，必须用更贵的机组"。

### 4.4 RUC、日前与实时：顺序不同，价格含义不同

实际市场常见的层次：

- **可靠性机组组合（RUC）**：以可靠性为目标，确定需要开机的机组，可能先于或并行于日前市场；
- **日前市场**：在RUC结果或自身SCUC基础上，做经济调度与定价；
- **实时市场**：根据最新预测与系统状态，做短周期SCED/滚动SCUC，处理偏差。

RUC 与日前市场是"并行"还是"串行"、未中标机组是否仍被开机、按什么价格结算，直接影响"日前价格"和"实时价格"的含义。这些实现细节写在规则与技术规范书里，各省不同；拿不到系统说明时，用历史出清结果反推并标注"待核实"。

### 4.5 非凸性下的价格：为什么需要"补偿"这个词

SCUC 的整数变量让"功率平衡的对偶"不再是一个可直接结算的价格。常见处理：

- 按 SCED 边际价结算，再对启动、空载、最小出力等未回收成本做补偿；
- 用凸包定价/扩展 LMP，构造一个能覆盖成本的价格；
- 按报价结算，再按规则处理盈余/缺口。

不同做法对交易员的影响不同：同样中标，按边际价 + 补偿可能比按报价结算更稳定；同样高价，凸包价格可能比边际价更平滑。读价格时一定要问：**这个价格是边际价、报价，还是包含补偿的综合价？**

## 5. 从系统价到节点价

### 5.1 三个分量，一句话

```text
节点价 = 能量分量 + 阻塞分量 + 网损分量
```

- **能量分量**：参考节点的边际能量价，反映系统整体供需；
- **阻塞分量**：线路/断面约束的影子价格 × 该节点对约束的灵敏度；
- **网损分量**：多供 1 MW 引起的边际网损变化。

无阻塞、忽略网损时，节点价退化为系统价。推导和手算见 [从潮流到节点电价](潮流阻塞与节点电价-2026-11.md)。

### 5.2 边际机组与节点价不是一一对应

在一个有阻塞的网络里：

- 不同节点可能有不同的边际机组；
- 同一台机组可能在某个节点是边际的，在另一个节点是 inframarginal 的；
- 受端节点价可能由"本地贵机组"定，送端节点价可能由"外送便宜机组"定。

所以，"我们省的边际机组是谁"这个问题，只有在指定节点、时段和网络状态下才有意义。全省一个边际机组，只在无阻塞或统一结算的简化模型里成立。

### 5.3 阻塞租金：不是电网的"利润"

阻塞租金 =（受端节点价 − 送端节点价）× 过断面潮流。它来自节点价结算的会计恒等式，通常用于：

- 金融输电权（FTR）的支付来源；
- 按规则返还给负荷或发电侧；
- 冲抵不平衡资金。

它不是某台机组的收入，也不是电网公司的自由现金流。把阻塞租金当成"自己的收益"是常见误读。机制与 FTR 见 [电力交易专家](../skills/electricity-trading-expert/SKILL.md) 与 [从潮流到节点电价](潮流阻塞与节点电价-2026-11.md) §3–§4。

### 5.4 网损：边际网损不是平均网损

平均网损率是"总损耗/总发电"，用于统计和分摊；边际网损是"多供 1 MW 负荷时，系统需要多发的量"，用于定价。两者可能差很多，尤其在重载、长距离输电时。

因此，节点价的网损分量不能用"平均线损率 × 电价"估算；它由潮流模型的边际损耗因子决定。交易员若用平均网损做报价，可能在阻塞/重载时段系统性偏差。

### 5.5 统一出清、分区结算、节点结算：先确认口径

国内现货的常见组合：

- **出清侧**：SCED 可能按节点价出清，也可能按分区/统一价出清；
- **结算侧**：有的省按节点价结算，有的按统一加权价、分区价或差价合约结算；
- **用户侧**：可能按统一价 + 分摊，不直接看到节点价。

报价前必须确认：你看到的"出清价"是不是"结算价"？如果出清按节点、结算按统一，节点价差会通过盈余/分摊处理，不能直接用它算自己的收入。省级口径见 [省级市场状态表](省级市场状态表-2026-11.md) 与 [101 问 B](电力现货市场101问-B-出清结算与省域实践.md)。

### 5.6 负价与局部阻塞可以同时出现

负价不一定是"全系统供大于求"，也可能是局部阻塞：

- 送端富余、外送断面受限，送端节点价被压到负；
- 受端缺电，受端节点价很高；
- 同一时刻，两个节点价格符号相反。

这时，"负价"是局部信号，不是全省平均价。用全省均价解释自己的节点收益，会错得离谱。

## 6. 特殊约束如何改写价格

### 6.1 最小出力与必开：价格可以低于机组的报价

最小出力/必开机组的特点是"不能停、不能低于某个出力"。它们的最小出力块进入系统，但不参与边际定价。结果是：

- 低负荷时段，系统供大于求，价格可能为负；
- 必开机组的最小出力报价高于价格，收入不足，需要补偿；
- 若补偿规则不覆盖，机组会亏损，影响后续可用性。

读法：看到负价，先查是不是最小出力/必开/供热/新能源大发导致的过发；看到某台机组中标但亏损，先查它是不是必开、是否拿到补偿。

### 6.2 启停与最小开停机：价格尖峰可能来自"不能马上开机"

当负荷快速上升，而便宜机组因最小停机时间不能立即启动，系统只能用更贵的在线机组。此时价格尖峰反映的是"跨时段可行性"，不是"当前时段燃料成本"。

同理，负荷下降时，机组因最小开机时间不能立即停机，可能导致负价。价格的时间形状，往往由启停约束塑造。

### 6.3 备用：机会成本会进入价格

备用要求机组留出容量，不能全部用于能量。备用的机会成本 = 被备用占用的容量在能量市场上本可以赚到的钱。系统越稀缺，机会成本越高，备用价和能量价都可能上升。

如果备用与能量联合出清，备用约束 binding 时，能量价可能高于"纯能量边际机组"的报价；如果分开出清，备用价可能单独结算。两种机制的价格含义不同，不能直接比较。

### 6.4 爬坡：有容量不等于有可交付的容量

爬坡约束把"容量"变成"可交付的容量"。当负荷快速变化或新能源出力骤降时，即使总装机充足，系统也可能因为爬坡不够而出现稀缺价。

单时段模型看不到爬坡约束；用单时段价格解释日内尖峰，常常会归因错误。多时段/滚动优化才能看到"爬坡稀缺"。

### 6.5 储能：充电和放电都可能是边际的

储能在现货中的报价/申报通常受 SOC、充放电功率、效率、循环成本、并网上限约束。出清时：

- 放电时，储能是供给方，可能成为边际机组；
- 充电时，储能是需求方（或负供给），可能压低价格，甚至在负价时段"被付费充电"；
- 循环成本决定套利门槛：峰谷价差不够，充放电不划算；
- SOC 跨时段约束让储能的价格响应具有路径依赖。

储能收益与循环成本见 [储能投资与运营专家](../skills/storage-investment-operations/SKILL.md)；EMS 侧调度见 [储能 EMS 优化调度](储能EMS优化调度-算法与工程-2026-11.md)。

### 6.6 新能源：近零边际成本与负价

新能源的边际成本接近零，报价通常很低（或报量不报价）。高渗透率时段：

- 新能源大发，压低价格，甚至形成负价；
- 火电因最小出力/供热/启停约束不能快速下调，加剧过发；
- 网络阻塞让富余新能源送不出去，局部负价更严重；
- 预测误差让实时价格与日前价格偏离，偏差进实时结算。

"负价"不是新能源的错，也不是市场失灵；它是系统在灵活性不足时发出的信号。消纳、储能、需求响应和网络扩容是回应这个信号的工具。

### 6.7 约束与价格症状对照

| 约束 | 典型价格症状 | 谁承担成本 | 常见误读 |
|---|---|---|---|
| 最小出力/必开 | 低负荷负价、机组中标但亏损 | 系统补偿/机组自身 | "负价是数据错误" |
| 启停/最小开停机 | 尖峰/低谷时间被拉长 | 系统/用户 | "价格高就是有人抬价" |
| 备用 | 稀缺时段能量价与备用价同时上升 | 用户/分摊 | "备用价是额外收费" |
| 爬坡 | 负荷快速变化时尖峰 | 用户 | "装机够就不会缺" |
| 阻塞 | 送端低、受端高，价差扩大 | 负荷/盈余分摊 | "价差是发电侧赚了" |
| 网损 | 受端价略高，重载时更明显 | 用户 | "平均线损×电价" |
| 储能 SOC | 充放电时段价格响应不对称 | 储能/套利者 | "储能报价没有成本" |

## 7. 负价、稀缺价与限价

### 7.1 负价：系统在说"现在少发一点"

负价出现在"供大于求 + 下调困难"的时段：

- 新能源大发，边际成本近零；
- 火电最小出力/供热/启停约束让它不能快速停机；
- 网络阻塞让富余电力送不出去；
- 需求侧灵活性不足，无法吸收过剩。

负价的功能是让机组愿意停机/少发，让用户愿意多用电，让储能愿意充电。它可能持续几分钟到几小时，取决于系统灵活性和规则。

读法：负价不是"发电厂倒贴钱做慈善"，而是"系统愿意付钱让你消耗/少发"。如果你有储能、可调负荷或灵活机组，负价是机会；如果你有必开发电机组，负价是成本。

### 7.2 稀缺价：系统在说"现在多供一点"

稀缺价出现在"供给不足 + 备用不足"的时段：

- 负荷高峰、机组非停、新能源出力低于预测；
- 备用约束 binding，系统愿意为少量增量容量付高价；
- 价格可能接近上限，甚至触发行政稀缺定价。

稀缺价的功能是激励机组可用、储能放电、用户削峰。它不等于"市场力"：真正的市场力需要看剩余需求、申报行为、成本依据和竞争结构，识别方法见 [101 问 B](电力现货市场101问-B-出清结算与省域实践.md) 与 [电力市场风险、信用与结算](电力市场风险、信用与结算-2026-11.md)。

### 7.3 价格帽与地板价：规则参数，不是模型常数

价格上限/下限是市场规则参数，随省份、年份、甚至季节调整。常见量级：

- 上限：部分省份在 1,000–1,500 元/MWh 量级，具体以最新规则为准；
- 下限：常见 0 或负值，负值深度逐省不同；
- 二次限价：部分省份在触发条件后收紧限价，规则更复杂。

交易员不能把"上次看到的限价"写进模型当常数；每次报价前核对最新规则。限价会改变报价行为（接近上限时，机组有动机持留或报满），也会改变价格分布（截尾、尖峰），回测时必须用与样本期一致的限价。

### 7.4 负价与稀缺价不是对称的

负价和稀缺价都反映供需失衡，但机制不对称：

- 负价受"下调能力"和"最小出力"约束，往往持续、局部、与新能源出力相关；
- 稀缺价受"上调能力"和"备用"约束，往往短暂、尖锐、与故障/高温/寒潮相关；
- 负价的底部是价格下限，稀缺价的顶部是价格上限/VOLL；
- 负价时段储能充电可以赚钱，但受 SOC/效率/并网上限限制；稀缺时段储能放电可以赚钱，但受能量/功率限制。

因此，不能用同一个"价格预测模型"同时解释负价和尖峰；特征、分布和约束都不同。

### 7.5 限价与补偿要一起看

当价格触及上限，按边际价结算可能不足以覆盖机组的真实成本/机会成本；规则可能用补偿、容量机制或稀缺定价来补足。反过来，当价格触及下限，必开机组的亏损可能通过补偿/分摊处理。

读"价格到顶/到底"时，问三个问题：有没有补偿？补偿由谁出？补偿是否进入我的结算？只看价格，会漏掉一半。

## 8. 出清结果怎么读

### 8.1 五张表

拿到一次出清结果，至少看五张表：

| 表 | 看什么 | 用来回答 |
|---|---|---|
| 机组中标表 | 每台机组每时段的中标量、开机状态 | 我发了多少？是否被必开/压出力？ |
| 价格表 | 系统价/节点价、能量/阻塞/网损分量 | 价格从哪来？我在哪个节点？ |
| 潮流/断面表 | 哪些线路/断面 binding、潮流方向 | 阻塞是否影响我的节点价？ |
| 盈余表 | 阻塞租金、备用盈余、不平衡资金 | 价差的钱去哪了？ |
| 补偿表 | 启动/空载/必开/make-whole | 中标为什么还亏？补偿是否到账？ |

### 8.2 单机读法：中标 ≠ 赚钱

对一台机组，按顺序算：

```text
电能收入 = 中标电量 × 节点价
按报价成本 = 各中标段电量 × 该段报价
启动/空载成本 = 按规则计入
净收入 = 电能收入 - 按报价成本 - 启动/空载成本
uplift = max(0, 按报价成本 + 启动/空载 - 电能收入)
```

若净收入为负但拿到 uplift，实际亏损可能被补足；若没有 uplift，亏损就是真实亏损。交易员要把"能量价差收益"和"补偿收益"分开看，不能用一个平均价掩盖。

### 8.3 组合读法：捕获价与节点价不是一回事

对新能源/储能/售电组合：

- **捕获价** = 组合实际结算收入 / 组合上网电量，受出力曲线、节点位置、合约、偏差影响；
- **节点价** = 某个节点/时段的边际价格，不是你所有电量的成交价；
- **全省均价** = 所有节点/时段的加权平均，可能与你无关。

用全省均价评价自己的组合，会高估或低估收益。捕获价、节点价、合约价的关系见 [储能投资与运营](储能投资与运营-2026-11.md)、[新能源项目开发与并网](新能源项目开发与并网-2026-11.md) 与 [电力市场风险、信用与结算](电力市场风险、信用与结算-2026-11.md)。

### 8.4 结算读法：日前 + 实时，偏差另算

国内现货常见"日前 + 实时"两结算：

- 日前中标电量按日前价结算；
- 实时实际与日前的偏差按实时价结算；
- 中长期合约按差价/差价合约处理；
- 阻塞盈余、分摊、补偿另列。

所以，"出清价"只是结算的一个输入。结算差异桥、科目拆解与对账方法见 [101 问 B](电力现货市场101问-B-出清结算与省域实践.md)、[101 问 C](电力现货市场101问-C-结算TTS与政策演进.md) 与 [量化报价与交易风控](量化报价与交易风控-工程化-2026-11.md) §8。

### 8.5 复盘五问

1. **价格从哪来？** 能量、阻塞、网损、备用、启停，哪个分量/约束主导？
2. **我是边际的吗？** 我的报价段是否决定了价格？还是被别人的报价定价？
3. **我为什么中标/没中标？** 经济排序、必开、最小出力、启动成本、网络、备用，哪个原因？
4. **我赚钱了吗？** 按节点价算收入，减去按报价成本、启动/空载，是否为正？有没有 uplift？
5. **如果报价移动 1 元/MWh，结果会变吗？** 用报价扫描/回测验证，而不是凭感觉。

## 9. 合成算例：三机组、四时段

> 以下全部为 **D 级合成数据**，每个时段按 1 h 计；若实际为 15 分钟，电量与成本需乘 0.25。算例由 [clearing.py](../skills/spot-bidding-quant/tools/clearing.py) 计算，运行 `python skills/spot-bidding-quant/tools/clearing.py --demo` 可复现。

### 9.1 机组参数

| 机组 | 节点 | 最小出力 | 最大出力 | 最小出力报价 | 增量段 1 | 增量段 2 | 启动成本 | 最小开/停 | 初始状态 | 爬坡 |
|---|---|---:|---:|---:|---|---|---:|---|---|---|
| coal-a | 送端 | 100 | 300 | 180 | 100 MW @ 240 | 100 MW @ 320 | 0 | 2 / 2 h | 开机 2 h | 150 MW/h |
| coal-b | 送端 | 80 | 260 | 260 | 110 MW @ 340 | 70 MW @ 480 | 6,000 | 2 / 2 h | 停机 2 h | 160 MW/h |
| gas-c | 受端 | 20 | 120 | 520 | 100 MW @ 650 | — | 1,000 | 1 / 1 h | 停机 1 h | 120 MW/h |

单位：出力 MW，报价 元/MWh，启动成本 元/次，时间 h。coal-a 初始已开机 2 h，coal-b/gas-c 初始已停机。算例为单节点能量出清；节点列只用于说明"同一套机组可以挂在不同节点"，不计算网络价差。

### 9.2 单时段 SCED：负荷 430 MW

三台机组都在线。最小出力合计 200 MW，剩余 230 MW 按增量段排序：

| 顺序 | 机组/段 | 报价（元/MWh） | 可接受（MW） | 本次接受（MW） | 累计（MW） |
|---:|---|---:|---:|---:|---:|
| 1 | coal-a 段 1 | 240 | 100 | 100 | 300 |
| 2 | coal-a 段 2 | 320 | 100 | 100 | 400 |
| 3 | coal-b 段 1 | 340 | 110 | 30 | 430 |

边际段是 coal-b 段 1，出清价 **340 元/MWh**。中标：

| 机组 | 中标（MW） | 按报价成本（元/h） | 按 340 元收入（元/h） | uplift（元/h） |
|---|---:|---:|---:|---:|
| coal-a | 300 | 74,000 | 102,000 | 0 |
| coal-b | 110 | 31,000 | 37,400 | 0 |
| gas-c | 20 | 10,400 | 6,800 | **3,600** |
| 合计 | 430 | 115,400 | 146,200 | **3,600** |

关键点：gas-c 的最小出力报价 520 元/MWh 高于出清价 340 元/MWh，但它必须开机（本算例把它当作在线/必开），所以产生 3,600 元 make-whole。**出清价没有错，补偿也不是亏损补贴，而是非凸约束下统一价无法覆盖成本的结果。**

### 9.3 单时段 SCED：负荷 250 MW，价格低于两台机组的首段报价

最小出力 200 MW，剩余 50 MW 由 coal-a 段 1（240 元/MWh）承接。出清价 **240 元/MWh**。此时：

- coal-b 的最小出力报价 260 > 240，产生 1,600 元 uplift；
- gas-c 的最小出力报价 520 > 240，产生 5,600 元 uplift；
- 合计 uplift **7,200 元**。

这说明：**边际价由最后一个增量段决定，而不是由所有在线机组的首段报价决定**。低负荷时段，价格可以低于多台机组的"第一段报价"，因为它们的最小出力是被强制的，不是边际的。

### 9.4 四时段 SCUC：负荷 260 / 600 / 520 / 300 MW

用同一组参数做四时段机组组合，考虑启动成本、最小开停机和爬坡。最优结果：

| 时段 | 负荷（MW） | 开机组合 | 中标（MW） | 出清价（元/MWh） | 能量成本（元） | 启动成本（元） |
|---:|---:|---|---|---:|---:|---:|
| 1 | 260 | coal-a | a=260 | 320 | 61,200 | 0 |
| 2 | 600 | coal-a + coal-b + gas-c | a=300, b=260, c=40 | 650 | 189,200 | 7,000 |
| 3 | 520 | coal-a + coal-b | a=300, b=220 | 480 | 146,600 | 0 |
| 4 | 300 | coal-a + coal-b | a=220, b=80 | 320 | 69,200 | 0 |
| 合计 | — | — | — | — | **466,200** | **7,000** |

总成本 = 466,200 + 7,000 = **473,200 元**；按出清价计算的总收入 = 818,800 元；uplift = 0（本算例中，所有在线机组的按报价成本都被价格覆盖）。

读法：

- **coal-b 为什么第 1 时段不开？** 第 1 时段 coal-a 单独可以覆盖 260 MW，coal-b 开机要付 6,000 元启动成本，还要满足最小开机 2 h；算总账不划算。
- **coal-b 为什么第 2 时段开、第 3/4 时段继续开？** 第 2 时段 600 MW 需要它；第 3 时段继续开可以避免停机再启动；第 4 时段继续开，虽然 coal-a 单独也能供 300 MW，但 coal-b 的最小出力 80 MW 比 coal-a 的边际段便宜，且避免违反最小停机时间/再启动成本，所以留在线上。
- **gas-c 为什么只第 2 时段开？** 第 2 时段 600 MW 需要它的 40 MW；第 3 时段 520 MW 由 coal-a + coal-b 更便宜，gas-c 停机。
- **第 4 时段价格为什么是 320，而不是 coal-b 的 260？** coal-b 的最小出力 80 MW 是强制的，边际增量来自 coal-a 段 2（320 元/MWh）；coal-b 的 260 元/MWh 首段不是边际段。这再次说明"边际机组≠报价最高的机组"，也说明"最低报价≠定价"。

### 9.5 算例不包含什么

- 网络阻塞、网损、节点价差；
- 备用联合出清、AGC/调频；
- 块报价、二次限价、必开补偿的完整规则；
- 储能 SOC、新能源预测误差、实时市场；
- 省级结算口径、中长期合约、分摊。

这些分别由 [从潮流到节点电价](潮流阻塞与节点电价-2026-11.md)、[101 问 B](电力现货市场101问-B-出清结算与省域实践.md)、[量化报价与交易风控](量化报价与交易风控-工程化-2026-11.md)、[预测误差→申报→EMS 闭环](预测误差申报与EMS闭环-2026-11.md) 和 [电力交易专家](../skills/electricity-trading-expert/SKILL.md) 覆盖。算例的作用是校准"报价→出清→价格→补偿"的口径，不是预测任何真实市场价格。

## 10. 常见错误（10 条）

1. **把边际机组当成报价最高的机组**：边际机组是最后一个被需要的增量段，可能报价很低；高价机组没开机就不影响价格。
2. **用平均成本/燃料成本代替报价曲线**：出清用的是报价，不是会计成本；成本只用于监管参考和自营测算。
3. **只看统一价，不看节点价/结算口径**：出清按节点、结算按统一，或反过来，都会让你的收益算错。
4. **把最小出力当普通报价段**：最小出力是强制的，可能高于出清价；不读 uplift 就会把"中标亏损"当成异常。
5. **忽略启停成本和最小开停机**：便宜机组没开机，往往是启动成本 + 最小开机时间 + 低负荷持续时长造成的，不是报价错了。
6. **把 SCUC 的对偶直接当价格**：整数变量下没有简单的连续对偶；价格可能按 SCED 边际价 + 补偿，或凸包定价，必须先确认机制。
7. **把阻塞租金当自己的收入**：阻塞租金是节点价结算的会计盈余，通常用于 FTR/返还/分摊，不是某台机组的收益。
8. **把负价当数据错误**：负价是供大于求 + 下调困难的有效信号；删掉负价会系统性高估收益。
9. **把价格帽当预测上限**：限价是规则参数，会改变报价行为和价格分布；回测必须用与样本期一致的限价。
10. **用单时段模型解释跨时段价格**：爬坡、SOC、启停、最小开停机让价格具有路径依赖；单时段模型看不到这些约束。

## 速查

### 核心公式

| 内容 | 公式/口径 |
|---|---|
| 系统边际价（无阻塞） | 最后一个被接受的增量段报价 |
| 节点价 | LMP = 能量 + 阻塞 + 网损 |
| 阻塞租金 | (受端价 − 送端价) × 过断面潮流 |
| 按报价成本 | Σ 中标段电量 × 该段报价 |
| 电能收入 | 中标电量 × 节点价 |
| uplift | max(0, 按报价成本 + 启动/空载 − 电能收入) |
| 备用机会成本 | 被备用占用的容量在能量市场的机会收益 |
| 储能套利门槛 | 循环成本 / 往返效率（见 `bid.storage_arbitrage_threshold`） |
| SCUC 目标 | 能量成本 + 启动成本 + 空载成本（+ 其他规则成本） |
| SCED 目标 | 按报价购电成本最小（或社会福利最大） |

### 10 秒判断

1. **价格是统一价、分区价还是节点价？** 先确认口径。
2. **哪个约束 binding？** 能量、网络、备用、爬坡、最小出力，还是启停？
3. **我是边际的还是被强制的？** 边际段定价；最小出力/必开不定价但可能拿补偿。
4. **我的收入覆盖成本了吗？** 按节点价算收入，再看 uplift。
5. **这是日前还是实时？** 两结算下，日前价不等于最终收益。

### 算例数字

- SCED 430 MW：价格 **340** 元/MWh；coal-a 300、coal-b 110、gas-c 20 MW；总成本 **115,400** 元；uplift **3,600** 元。
- SCED 250 MW：价格 **240** 元/MWh；coal-a 150、coal-b 80、gas-c 20 MW；uplift **7,200** 元。
- SCUC 260/600/520/300 MW：价格 **320/650/480/320** 元/MWh；能量成本 **466,200** 元；启动 **7,000** 元；总成本 **473,200** 元；收入 **818,800** 元；uplift **0**。
- 复现：`python skills/spot-bidding-quant/tools/clearing.py --demo`；断言：`python skills/spot-bidding-quant/tools/selftest.py`。

### 三句话带走

- **报价是输入，约束是价格的一半**：不看约束，只排序，会把出清讲成"报价表"。
- **边际机组是最后一个增量段，不是成本最高的机组**：低价段也可以定价。
- **中标不等于赚钱**：价格、补偿、结算口径要一起读。
