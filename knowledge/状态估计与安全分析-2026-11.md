## 0. 一页看懂

### 0.1 三句话

- **状态估计是 EMS 的"共同运行方式"**：它把不同时标、不同测点、可能带坏数据的 SCADA 量测，压成一组自洽的母线电压/相角，让 AGC、AVC、ED、安全校核用同一张网、同一个断面。
- **估计值必须带"可信度"**：收敛不等于正确；要看可观测性、残差、拓扑状态、量测质量。坏数据不处理，会把误差抹到所有状态上。
- **安全分析是"在估计状态上做假设"**：N-1、ATC、安全约束调度都建立在状态估计和网络模型上；状态错了，限额和价格都会错。

### 0.2 关键概念

| 概念 | 含义 | 本文口径 |
|---|---|---|
| 拓扑处理 | 把开关/刀闸状态变成母线模型和电气岛 | 状态错误比量测错误更致命 |
| 状态估计 | 由冗余量测估计网络状态（电压幅值/相角） | 本文用直流 WLS 演示，交流 SE 只讲结构 |
| 量测冗余 | 量测数多于状态数，留出检验空间 | 冗余不足时坏数据不可辨识 |
| 可观测性 | 能否唯一确定状态 | 拓扑可观测 + 数值可观测，缺一不可 |
| 坏数据 | 偏离真实值且不被模型解释的量测 | 用残差/标准化残差检验，不能凭感觉删 |
| 伪量测 | 预测负荷、计划出力、零注入等补充信息 | 权重不能压过真实量测；必须标注来源 |
| N-1 | 单一元件故障后的安全校核 | 只看可信故障集，不是所有组合 |
| ATC | 可用输电能力 | 随运行方式、故障、限额变化，不是固定容量 |
| 安全约束调度 | 在 N-1/限额约束下做 ED/SCED/SCUC | 与状态估计、故障集、限额共同决定 |
| 状态估计 vs 潮流 | 潮流假设注入已知；状态估计从量测反推状态 | 两者输入输出不同，不能混用 |

### 0.3 先记住四个数

3 节点直流合成算例（基准 100 MVA）：

- **7 个量测、2 个状态**：冗余 5；真实相角 `θ2 = -0.020 rad`、`θ3 = -0.030 rad`。
- **一个坏数据**：线路 1-3 有功量测 `0.180 pu`，真实值 `0.150 pu`；WLS 估计变为 `θ2 = -0.020539`、`θ3 = -0.031470`，坏数据标准化残差 **5.21**（示例阈值 3.0）。
- **剔除后回到真值**：去掉该量测重新估计，得到 `θ2 = -0.020000`、`θ3 = -0.030000`，基准潮流 `0.200 / 0.150 / 0.050 pu`。
- **N-1 越限**：线路 1-2 停运后，线路 1-3 潮流 **0.350 pu**，限额 **0.300 pu**，越限 **0.050 pu = 5 MW**；在 bus3 增加 0.05 pu 本地出力/削减负荷后可回到 0.300 pu。

### 0.4 本文不做什么

- 不提供真实电网的拓扑、阻抗、限额、故障集或量测配置；
- 不实现完整的交流状态估计、PMU 线性估计、动态状态估计或配电系统 SE；
- 不替代调度机构的 N-1 扫描、ATC 计算、安全校核或市场出清；
- 不把直流线性算例的结论直接搬到交流电网、电压稳定或暂态稳定问题；
- 不把状态估计结果当作保护定值、安稳策略或设备控制指令。

## 1. 为什么 EMS 需要状态估计

### 1.1 SCADA 给的是量测，不是运行方式

SCADA 能提供：

- 线路/变压器有功、无功、电流；
- 母线电压；
- 开关/刀闸位置；
- 机组/场站出力、负荷；
- 频率、保护/告警信号。

但这些量测通常：

- 来自不同设备、不同采样周期，时标不完全一致；
- 有坏点、冻结值、通信中断、质量位异常；
- 不是每个母线、每条线路都装表；
- 有量测误差，甚至存在系统性偏差；
- 开关状态可能和实际不符（拓扑错误）。

EMS 的高级应用不能直接拿一堆不同步、不完整、可能错误的量测去算潮流或安全限额；它需要一个**自洽、带质量标记、可复现**的运行方式。状态估计就是干这个的。

### 1.2 状态估计与潮流计算的区别

| 项目 | 潮流计算 | 状态估计 |
|---|---|---|
| 已知 | 发电机出力、负荷注入、电压/相角参考 | 冗余量测（潮流、电压、注入、开关状态） |
| 求 | 母线电压幅值/相角、支路潮流 | 母线电压幅值/相角（状态） |
| 冗余 | 通常无冗余 | 有冗余，可做坏数据检验 |
| 误差 | 输入假设即"真值" | 量测有误差，估计带不确定度 |
| 用途 | 规划、方式计算、调度预想 | 实时/准实时运行方式、安全分析输入 |

潮流计算回答"给定注入，电网会怎样"；状态估计回答"根据这些量测，电网现在最可能是什么状态"。

### 1.3 EMS 应用链

```text
SCADA/RTU/PMU
   ↓ 量测、状态量、时标、质量位
拓扑处理（开关/刀闸 → 母线/电气岛）
   ↓ 网络模型
状态估计（WLS/其他）
   ↓ 母线电压/相角、残差、可观测性
安全分析（N-1、电压/热稳定、ATC）
   ↓ 限额、越限、校正措施
ED/AGC/AVC/市场出清
   ↓ 指令、价格、考核
```

这条链上任何一环失真，后面都会放大：

- 拓扑错 → 状态估计用错网络；
- 状态错 → N-1 越限判断错；
- 限额错 → AGC/AVC 指令越限或过度保守；
- 故障集错 → 市场出清的安全约束错。

### 1.4 状态估计的输出不只是"电压"

一个可用的状态估计结果至少应带：

- 收敛状态、迭代次数、目标函数值；
- 各母线电压幅值/相角（交流）或相角（直流）；
- 支路潮流/注入估计；
- 量测残差、标准化残差、可疑量测列表；
- 可观测性/不可观测区域；
- 拓扑岛、参考母线、孤岛处理；
- 数据时标、所用模型版本、质量标记。

只给一张电压云图，不足以支撑安全分析。

## 2. 网络模型与拓扑处理

### 2.1 母线/支路模型

状态估计的网络模型至少包括：

- 母线（节点）编号与类型（平衡/PV/PQ）；
- 支路（线路/变压器）首末母线、阻抗/电纳、变比、限额；
- 并联补偿（电容/电抗）、负荷、发电机/场站；
- 开关/刀闸状态与拓扑关系；
- 参考母线/相角基准；
- 电气岛划分。

模型版本要和 SCADA 状态、检修票、方式单对应；拿旧模型估新方式，残差可能看起来正常，但结果是错的。

### 2.2 拓扑处理

拓扑处理把"开关/刀闸状态"变成"母线模型"：

1. 读取开关/刀闸位置、质量位、检修状态；
2. 合并同一电气节点上的闭合开关；
3. 按支路连接关系划分电气岛；
4. 识别孤岛、悬空节点、零注入节点；
5. 给每个电气岛指定参考母线；
6. 把拓扑变化写入状态估计和后续应用。

常见拓扑错误：

- 开关状态错（该合未合、该分未分）；
- 检修状态未同步；
- 刀闸/接地刀位置混淆；
- 支路一端断开但模型仍闭合；
- 孤岛没有参考母线；
- 母线合并/拆分后量测映射错。

拓扑错误可能表现为"坏数据"：残差大、估计偏差，但删量测解决不了。要用开关状态一致性、多断面、计划/检修票、现场核对来定位。

### 2.3 直流潮流近似

本文用直流潮流演示状态估计，因为它是线性的、可手算：

```text
P_ij = (θ_i - θ_j) / x_ij
```

假设：

- 支路电阻远小于电抗；
- 相角差小，`sin θ ≈ θ`；
- 电压幅值接近 1.0 pu；
- 忽略网损和无功。

它适合讲清楚"量测—状态—残差"的结构，但不能用于电压稳定、无功/电压、网损精确计算或交流安全校核。

### 2.4 交流状态估计的额外复杂性

交流 SE 的状态是电压幅值和相角，量测方程是非线性的：

- 有功/无功潮流、电压幅值、电流幅值、注入；
- 需要迭代（Gauss-Newton 等）；
- 需要好的初值、数值稳定性和收敛判据；
- 无功/电压量测对电压稳定分析很重要；
- 变压器分接头、并联补偿、发电机无功限值会影响可观测性；
- 坏数据与拓扑错误更难区分。

本文不展开交流 SE 的迭代细节，只保留结构上的对应关系。

### 2.5 参数错误

即使拓扑正确，参数错误也会让状态估计有偏：

- 线路阻抗/电纳录错；
- 变压器变比/分接头位置错；
- 线路长度/温度修正未更新；
- 并联补偿容量/状态错；
- 互感/零序参数不适用于正序计算。

参数错误通常表现为"残差有系统性方向"，不是随机坏点；换量测权重或删量测不能根治。

### 2.6 可观测性

可观测性分两层：

- **拓扑可观测**：网络结构和量测配置能否覆盖所有状态；
- **数值可观测**：量测方程是否线性无关、数值条件是否良好。

常见问题：

- 某些母线没有注入/电压量测，也没有伪量测；
- 支路量测很多但集中在同一区域，另一区域不可观测；
- 孤岛没有参考母线；
- 量测权重极端，导致数值病态；
- 零注入约束没有用上（浪费了已知信息）。

不可观测时，状态估计器可能：

- 只估计可观测区域，其他区域保持上次值/计划值；
- 用伪量测补足，但结果依赖伪量测权重；
- 直接失败，拒绝输出。

工程上必须知道"这次估计覆盖了哪些区域、哪些是伪量测撑起来的"，不能把不可观测区域的估计当实测。

### 2.7 伪量测

伪量测包括：

- 预测负荷；
- 发电计划/场站出力计划；
- 零注入约束（无负荷/无发电的母线）；
- 历史状态/上次估计；
- 调度员输入的运行方式。

使用原则：

- 标注来源和权重，不能与真实量测混淆；
- 权重不能压过真实量测，否则真实量测被"淹没"；
- 伪量测不能用来掩盖拓扑/参数错误；
- 关键区域应尽量有真实量测冗余。

## 3. WLS 状态估计

### 3.1 量测模型

```text
z = h(x) + e
```

- `z`：量测向量（m 维）；
- `x`：状态向量（n 维，直流为相角，交流为幅值/相角）；
- `h(x)`：量测函数；
- `e`：量测误差，假设零均值、协方差 `R`。

权重矩阵：

```text
W = R^(-1) = diag(1/σ_i^2)
```

`σ_i` 是第 i 个量测的标准差；权重越大，越相信该量测。

### 3.2 目标函数

```text
J(x) = (z - h(x))^T W (z - h(x))
```

WLS 估计就是找使加权残差平方和最小的 `x`。

直流线性情况下 `h(x) = H x`：

```text
x_hat = (H^T W H)^(-1) H^T W z
```

交流情况下用 Gauss-Newton 迭代：

```text
x_(k+1) = x_k + (H_k^T W H_k)^(-1) H_k^T W (z - h(x_k))
```

其中 `H_k` 是量测函数在 `x_k` 处的雅可比矩阵。

### 3.3 3 节点算例的系统

| 项目 | 数值 |
|---|---|
| 基准容量 | 100 MVA |
| 母线 | 1（平衡）、2、3 |
| 支路 1-2 | x = 0.10 pu |
| 支路 1-3 | x = 0.20 pu |
| 支路 2-3 | x = 0.20 pu |
| 真实相角 | θ1 = 0，θ2 = -0.020 rad，θ3 = -0.030 rad |
| 真实注入 | bus1 +0.35，bus2 -0.15，bus3 -0.20 pu |
| 支路限额 | 1-2：0.40；1-3：0.30；2-3：0.20 pu |

真实潮流：

```text
P12 = (0 - (-0.020)) / 0.10 = 0.200 pu
P13 = (0 - (-0.030)) / 0.20 = 0.150 pu
P23 = (-0.020 - (-0.030)) / 0.20 = 0.050 pu
```

### 3.4 量测配置

| 编号 | 量测 | 真实值 | 标准差 σ | 说明 |
|---:|---|---:|---:|---|
| 1 | P12 | 0.200 pu | 0.005 | 线路有功 |
| 2 | P13 | 0.150 pu | 0.005 | 本算例注入坏数据 0.180 |
| 3 | P23 | 0.050 pu | 0.005 | 线路有功 |
| 4 | θ2 | -0.020 rad | 0.002 | 相角量测（示意 PMU） |
| 5 | θ3 | -0.030 rad | 0.002 | 相角量测（示意 PMU） |
| 6 | P2 注入 | -0.150 pu | 0.006 | 母线 2 注入 |
| 7 | P3 注入 | -0.200 pu | 0.006 | 母线 3 注入 |

7 个量测、2 个状态，冗余 5。冗余不是"越多越好"，而是要有独立信息；重复量测同一支路不一定提高可观测性。

### 3.5 量测矩阵 H

状态 `x = [θ2, θ3]^T`，各量测函数：

| 量测 | 表达式 | H 行 |
|---|---|---|
| P12 | -10 θ2 | [-10, 0] |
| P13 | -5 θ3 | [0, -5] |
| P23 | 5 θ2 - 5 θ3 | [5, -5] |
| θ2 | θ2 | [1, 0] |
| θ3 | θ3 | [0, 1] |
| P2 注入 | 15 θ2 - 5 θ3 | [15, -5] |
| P3 注入 | -5 θ2 + 10 θ3 | [-5, 10] |

注入行的推导：bus2 注入 = 流向 bus1 + 流向 bus3 = `-P12 + P23`；bus3 注入 = `-P13 - P23`。符号约定要在代码和文档中写死，否则残差会整体反号。

### 3.6 WLS 结果

把坏数据 `z2 = 0.180` 代入，WLS 估计：

```text
θ2 = -0.020539 rad
θ3 = -0.031470 rad
J  = 27.18
```

估计潮流：

```text
P12 = 0.205391 pu
P13 = 0.157349 pu
P23 = 0.054654 pu
```

残差与标准化残差：

| 量测 | 残差 | 标准化残差 | 读法 |
|---|---:|---:|---|
| P12 | -0.005391 | -1.47 | 正常范围 |
| P13 | 0.022651 | **5.21** | 超过示例阈值 3.0，可疑 |
| P23 | -0.004654 | -1.03 | 正常范围 |
| θ2 | 0.000539 | 0.27 | 正常范围 |
| θ3 | 0.001470 | 0.76 | 正常范围 |
| P2 注入 | 0.000737 | 0.18 | 正常范围 |
| P3 注入 | 0.012003 | 2.86 | 偏高但未超阈值，需结合其它检验 |

坏数据不是"残差最大就一定是坏数据"：P3 注入的标准化残差 2.86 也偏高，可能是坏数据扩散/量测相关；需要看多个断面、拓扑、参数和量测独立性。

### 3.7 剔除坏数据后重估

去掉 P13 量测后，用剩余 6 个量测重估：

```text
θ2 = -0.020000 rad
θ3 = -0.030000 rad
J ≈ 0
```

恢复真实潮流 `0.200 / 0.150 / 0.050 pu`。这说明：

- 本例的冗余足够识别单个坏数据；
- 剔除后必须重估，不能只把残差改小；
- 如果剔除后仍不收敛/残差大，可能是拓扑或参数错误，不是量测问题。

### 3.8 自由度与检验

- 自由度 `df = m - n`；本例 7 - 2 = 5。
- 可以用卡方检验判断"整体残差是否过大"，但它不能直接告诉你哪个量测坏。
- 标准化残差用于逐点定位；阈值 3.0 是示例，实际按误报/漏报权衡。
- 多个坏数据、杠杆点、拓扑错误会让单点检验失效，需要组合检验/稳健估计。

### 3.9 数值问题

- 参考母线选择影响 H 的秩；没有参考母线，相角不可唯一。
- 量测权重差异过大，`H^T W H` 条件数变差；要用稳定的线性求解。
- 状态尺度不同（相角 rad、电压 pu），要统一单位。
- 稀疏网络要用稀疏求解；本文 3 节点用稠密矩阵只为演示。

## 4. 坏数据与拓扑错误

### 4.1 残差从哪来

残差：

```text
r = z - h(x_hat)
```

残差不是误差本身：WLS 会把一部分误差吸收到状态里，残差是"模型解释不了的部分"。残差协方差：

```text
Ω = R - H (H^T W H)^(-1) H^T
```

标准化残差：

```text
r_i^N = r_i / sqrt(Ω_ii)
```

`Ω_ii` 越小，同样的残差越显著；杠杆点（对状态影响大的量测）残差可能很小，但一旦出错影响很大。

### 4.2 坏数据的四种来源

| 来源 | 例子 | 特征 | 处理 |
|---|---|---|---|
| 量测坏点 | 变送器故障、通信误码 | 单点残差大、随机 | 剔除/重估/换表 |
| 拓扑错误 | 开关状态错、检修未同步 | 多量测残差同向、区域性问题 | 核对开关/方式单，修模型 |
| 参数错误 | 阻抗/变比错 | 系统性偏差、换断面仍存在 | 校参数，不能靠删量测 |
| 伪量测错误 | 预测负荷偏差大、计划出力过期 | 与真实量测冲突 | 降权/替换/标注 |

### 4.3 坏数据的掩盖与淹没

- **掩盖**：两个坏数据互相抵消，残差都不大；
- **淹没**：一个坏数据把残差扩散到多个正常量测，导致误删；
- **杠杆点**：某些量测对状态影响大，残差小但估计偏差大；
- **相关量测**：同一物理量的多个测点同时错，冗余失效。

单点标准化残差检验不是万能的；要有多个断面、独立量测、拓扑核对和参数校验。

### 4.4 拓扑错误为什么更危险

拓扑错误会改变量测函数 `H`，不是改变 `z`：

- 你以为线路在运行，实际已断开；
- 你以为母线分裂，实际合并；
- 你以为开关合上，实际检修隔离。

此时残差可能很大，也可能因为伪量测/低冗余而"看起来正常"。安全分析会基于错误拓扑算 N-1，限额和价格都不可信。

### 4.5 坏数据处理流程

1. 检查数据质量位、时标、通信状态；
2. 跑状态估计，检查收敛、目标函数、可观测性；
3. 计算标准化残差，列可疑量测；
4. 核对拓扑/开关/检修/方式单；
5. 核对参数/变比/补偿状态；
6. 剔除或降权可疑量测，重估；
7. 若仍异常，标记该区域不可信，通知调度/现场；
8. 记录处理过程，供复盘。

不能"看到残差大就删"，也不能"删到收敛为止"。

### 4.6 稳健估计

稳健估计（LAV、Huber、M 估计等）可以降低坏数据影响，但：

- 不能替代拓扑/参数校验；
- 阈值/权重仍要调；
- 多个坏数据/杠杆点仍可能失效；
- 结果可解释性和审计要求更高。

对大多数 EMS 场景，"好数据+冗余+检验+重估"比"复杂稳健算法掩盖问题"更可靠。

## 5. N-1、ATC 与安全分析

### 5.1 安全 vs 充裕

- **安全性**：故障后系统能否保持运行（热稳定、电压、功角等）；
- **充裕性**：是否有足够发电/容量满足负荷（资源充足性）；
- **N-1**：单一元件（线路、变压器、发电机等）故障后的安全校核；
- **N-1-1/ N-2**：更严重/组合故障，按规则和风险选择，不是默认全做。

状态估计提供当前运行方式，安全分析在其上做"如果某元件停运会怎样"的假设。

### 5.2 N-1 扫描的基本步骤

1. 取状态估计后的网络状态（拓扑、注入、电压/相角）；
2. 选择可信故障集（线路、变压器、发电机、母线等）；
3. 对每个故障修改网络模型（开断支路/调整注入）；
4. 重新计算潮流（直流/交流）；
5. 检查支路限额、母线电压、功角/稳定限制；
6. 记录越限元件、越限量、是否孤岛/失负荷；
7. 形成安全约束/校正措施，送入 ED/AGC/AVC/市场。

N-1 不是"把所有线路都断一遍"就完事：故障集要基于电压等级、拓扑、保护/安稳、历史故障率、规则要求筛选。

### 5.3 算例：N-1 越限

基准潮流（状态估计剔除坏数据后）：

| 支路 | 基准潮流（pu） | 限额（pu） | 基准是否越限 |
|---|---:|---:|---|
| 1-2 | 0.200 | 0.400 | 否 |
| 1-3 | 0.150 | 0.300 | 否 |
| 2-3 | 0.050 | 0.200 | 否 |

N-1 扫描：

| 停运支路 | 剩余支路潮流（pu） | 越限 | 说明 |
|---|---|---|---|
| 1-2 | 1-3：**0.350**；2-3：0.150 | 1-3 超 0.300，越限 0.050 | 本算例重点 |
| 1-3 | 1-2：0.350；2-3：0.200 | 无（2-3 正好到限） | 临界 |
| 2-3 | 1-2：0.350；1-3：0.200 | 无 | 安全 |

以 100 MVA 基准，0.050 pu = **5 MW**。这就是"基准没问题、N-1 后才越限"的典型场景；调度不能只看基准潮流。

### 5.4 校正措施

对停运 1-2 的越限，可选的校正：

- 在 bus3 增加 0.05 pu 本地出力（或削减 0.05 pu 负荷），把 bus3 注入从 -0.20 调到 -0.15；
- 调整 bus2/bus3 的发电/负荷分配，改变潮流分布；
- 切换拓扑（如果有备用通道）；
- 调用储能/需求响应，提供局部支撑；
- 降额/限发，牺牲部分经济性换取安全。

校正后（bus3 注入 -0.15）：

```text
1-3 潮流 = 0.300 pu（回到限额）
2-3 支路潮流 = -0.150 pu（即 3→2 为 0.150 pu）
```

这是**示例性**校正，不保证实际电网有同样的灵敏度；真实校正要考虑交流潮流、电压、保护、稳定和成本。

### 5.5 ATC 是什么，不是什么

ATC（Available Transfer Capability）是"在现有基础上还能增加多少输电"：

```text
ATC ≈ TTC - 现有交易 - 输电可靠性裕度 - 容量效益裕度
```

- `TTC`：总输电能力；
- `TRM`：输电可靠性裕度；
- `CBM`：容量效益裕度；
- 现有交易/潮流：当前使用量。

ATC 不是固定容量：

- 随运行方式、故障集、限额、电压水平变化；
- N-1 后 ATC 可能降为 0 或负值（需要校正）；
- 市场出清用的 ATC 要注明计算断面、故障集、裕度口径；
- 跨省/跨区交易见[《省间与跨区交易》](./省间与跨区交易-2026-11.md)。

本算例中，基准 1-3 的"剩余容量"= 0.300 - 0.150 = 0.150 pu（15 MW）；但停运 1-2 后，1-3 已越限，N-1 ATC 为 0，必须先校正。这个数字只用于演示，不是实际 ATC。

### 5.6 安全约束调度

安全约束调度（SCED/SCUC）把 N-1/限额作为约束：

- 目标：最小成本/最大社会福利；
- 约束：功率平衡、机组/场站出力、爬坡、备用、网络限额、N-1 约束；
- 结果：出力计划、节点价、阻塞分量、安全校正成本。

状态估计/安全分析提供"约束是否成立"；市场出清提供"经济最优"。两者不能互相替代：

- 没有状态估计，安全约束可能基于错误运行方式；
- 没有安全校核，出清结果可能不可执行；
- 没有市场机制，安全校正可能没有成本信号。

节点价推导见[《从潮流到节点电价》](./潮流阻塞与节点电价-2026-11.md)，出清见[《现货出清与价格形成》](./现货出清与价格形成-2026-11.md)。

### 5.7 电压安全与频率安全

- **电压安全**：N-1 后母线电压是否越限、无功是否足够、是否电压崩溃；需要交流潮流/无功电压分析，直流 SE 不够。
- **频率安全**：N-1 后有功缺额、惯量、一次/二次调频是否够；状态估计不直接算频率，但提供初始潮流/出力。
- **暂态/动态安全**：故障后的功角/电压/频率轨迹；状态估计只提供初始状态，不能替代动态仿真。

安全分析不是"一个 N-1 扫描解决所有问题"；要按时间尺度分解。

## 6. 从状态估计到 AGC/AVC/ED

### 6.1 时间尺度不匹配

| 应用 | 典型周期 | 对状态估计的要求 |
|---|---|---|
| AGC | 4—16 s | 不一定每次跑 SE；用最新有效状态 + 实时 ACE/限额 |
| AVC | 秒—分钟 | 需要电压/无功状态，SE 周期可能跟不上，需本地控制 |
| ED | 5—15 min | 用最新 SE 状态做经济分配 |
| 安全分析 | 分钟—小时 | 用 SE 状态 + 故障集做 N-1/ATC |
| 市场出清 | 日前/日内 | 用预测/计划 + 安全约束，不直接用实时 SE |

状态估计周期通常慢于 AGC/AVC；不能假设"AGC 每次指令都有新 SE"。工程上要：

- 给状态打时标/质量位；
- 设定有效期；
- SE 失败时降级/保持/告警；
- 关键安全限额用保守值或上次有效值，并明确风险。

### 6.2 各应用消费什么

| 应用 | 从 SE/安全分析拿什么 | 不能拿什么 |
|---|---|---|
| AGC | 网络限额、可调能力、当前出力/频率 | 直接把 SE 相角当 ACE |
| AVC | 母线电压、无功分布、电压限额 | 用 SE 代替本地电压闭环 |
| ED | 当前注入、网损、限额、阻塞 | 用 SE 代替经济优化 |
| 安全分析 | 状态、拓扑、故障集、限额 | 用 SE 代替暂态稳定 |
| 市场 | 安全约束、ATC、阻塞 | 用实时 SE 代替日前预测 |

### 6.3 失败模式与降级

状态估计可能：

- 不收敛（初值差、坏数据多、模型错）；
- 可观测性不足（量测缺失/拓扑变化）；
- 拓扑错误（开关状态错）；
- 参数错误（阻抗/变比错）；
- 数值病态（权重极端/参考母线问题）。

应有行为：

- 报警并标记状态无效；
- 保留上次有效状态，但设有效期；
- 缩小到可观测区域，明确未覆盖区域；
- 通知调度/现场核对；
- 安全分析/市场出清使用保守限额或暂停相关约束；
- 不能"静默使用坏状态"。

### 6.4 质量标记

一个可操作的 SE 输出至少带：

- `converged`：是否收敛；
- `observable`：可观测区域/不可观测区域；
- `island_count`：电气岛数量；
- `objective`：目标函数值；
- `max_normalized_residual`：最大标准化残差；
- `bad_data`：可疑量测列表；
- `topology_version` / `model_version`；
- `timestamp` / `valid_until`。

下游应用要根据这些标记决定"用/不用/降级"。

### 6.5 与 AGC/AVC 的边界

状态估计/安全分析给 AGC/AVC 提供：

- 网络限额（线路/变压器/电压）；
- 当前运行方式；
- 可调能力/阻塞信息；
- 安全校正建议。

它不直接下发 AGC/AVC 指令，也不替代场站闭环。AGC/AVC 的控制链、考核与通信见[《AGC/AVC 与频率电压闭环》](./AGC-AVC与频率电压闭环-2026-11.md)。

## 7. D 级合成算例：从量测到 N-1

> 本节全部为合成数据，仅用于演示方法；不代表任何真实电网、量测配置或安全校核结果。

### 7.1 系统与量测

| 项目 | 数值 |
|---|---|
| 基准容量 | 100 MVA |
| 母线 | 1（平衡）、2、3 |
| 支路 | 1-2（x=0.10）、1-3（x=0.20）、2-3（x=0.20） |
| 限额 | 1-2：0.40；1-3：0.30；2-3：0.20 pu |
| 真实状态 | θ2=-0.020 rad，θ3=-0.030 rad |
| 量测数/状态数 | 7 / 2 |
| 坏数据 | P13 量测 0.180 pu（真实 0.150 pu） |

### 7.2 量测与残差

| 量测 | 量测值 | 估计值 | 残差 | 标准化残差 |
|---|---:|---:|---:|---:|
| P12 | 0.200 | 0.205391 | -0.005391 | -1.47 |
| P13 | **0.180** | 0.157349 | 0.022651 | **5.21** |
| P23 | 0.050 | 0.054654 | -0.004654 | -1.03 |
| θ2 | -0.020 | -0.020539 | 0.000539 | 0.27 |
| θ3 | -0.030 | -0.031470 | 0.001470 | 0.76 |
| P2 注入 | -0.150 | -0.150737 | 0.000737 | 0.18 |
| P3 注入 | -0.200 | -0.212003 | 0.012003 | 2.86 |

### 7.3 坏数据处理

```text
最大标准化残差 = 5.21（P13）> 3.0（示例阈值）
→ 标记 P13 可疑
→ 核对拓扑/参数/时标/质量位
→ 剔除 P13，重估
→ θ2 = -0.020000，θ3 = -0.030000，J ≈ 0
```

### 7.4 N-1 扫描

| 停运 | 1-2 潮流 | 1-3 潮流 | 2-3 潮流 | 越限 |
|---|---:|---:|---:|---|
| 无 | 0.200 | 0.150 | 0.050 | 无 |
| 1-2 | — | **0.350** | 0.150 | 1-3 超 0.050 pu |
| 1-3 | 0.350 | — | 0.200 | 无（到限） |
| 2-3 | 0.350 | 0.200 | — | 无 |

### 7.5 校正

```text
bus3 注入从 -0.20 调到 -0.15（增加 0.05 pu 本地出力/削减负荷）
停运 1-2 后：1-3 = 0.300 pu，2-3 支路 = -0.150 pu（即 3→2 为 0.150 pu）
```

### 7.6 这个算例说明什么

- 状态估计能把冗余量测变成自洽状态；
- 标准化残差能定位单个坏数据，但要结合拓扑/参数/多断面；
- 剔除坏数据后必须重估；
- 基准安全不等于 N-1 安全；
- N-1 越限可以用本地校正/再调度缓解，但要付出成本；
- ATC 会随故障和校正变化，不是固定值。

### 7.7 这个算例不说明什么

- 不代表真实电网的阻抗、限额、量测配置；
- 不覆盖交流潮流、无功/电压、网损、电压稳定；
- 不覆盖多个坏数据、杠杆点、拓扑错误；
- 不覆盖保护/安稳/暂态稳定；
- 不给出实际 ATC、出清价格或调度指令。

## 8. 常见错误（10 条）

1. **把状态估计当潮流计算**：潮流假设注入已知，状态估计从冗余量测反推状态；输入输出不同，不能混用。
2. **忽略拓扑/开关状态错误**：拓扑错会改变量测函数，残差可能大也可能"看起来正常"；先核对开关/检修/方式单。
3. **只看估计值，不看残差/可观测性**：收敛不等于正确；不可观测区域的估计可能是伪量测/上次值撑起来的。
4. **用伪量测淹没真实量测**：伪量测权重大于实测，会把真实量测拉偏；必须标注来源和权重。
5. **坏数据直接删除不重估**：删了量测但不重算状态，后续应用仍用旧状态；必须重估并检查。
6. **用单点残差判断全部**：多个坏数据会互相掩盖/淹没，杠杆点残差小但影响大；要结合多断面/拓扑/参数。
7. **把 N-1 当 N-2 或所有故障**：故障集要基于规则/风险/可信故障，不是把所有组合都扫一遍。
8. **把 ATC 当固定容量**：ATC 随运行方式、故障、限额、裕度变化；N-1 后可能为 0，必须重算。
9. **状态估计结果直接进 AGC/AVC 而不检查时标/质量**：SE 周期慢于 AGC/AVC，过期状态会误导限额和控制。
10. **用状态估计替代保护/稳定分析**：SE 是静态运行方式，不替代继电保护、暂态稳定、电压稳定/宽频振荡分析。

## 11. 速查

### 11.1 五个公式

```text
P_ij = (θ_i - θ_j) / x_ij

x_hat = (H^T W H)^(-1) H^T W z

r = z - H x_hat

Ω = R - H (H^T W H)^(-1) H^T
r_i^N = r_i / sqrt(Ω_ii)

ATC ≈ TTC - 现有交易 - TRM - CBM
```

### 11.2 五个必问

1. 这次状态估计覆盖哪些区域，哪些是伪量测撑起来的？
2. 拓扑/开关/检修状态核对过吗，模型版本是哪一版？
3. 最大标准化残差是多少，可疑量测剔除后重估了吗？
4. N-1 故障集和限额是最新的吗，基准安全是否等于 N-1 安全？
5. 下游 AGC/AVC/ED/市场用的是哪一时刻、哪个质量位的状态？
