# 需求响应、车网互动与灵活性资源：从基线到结算（2026-11）

> 数据截止：2026-11-08｜定位：知识库模块（不单独拆技能）
> 相关技能：[虚拟电厂专家](../skills/virtual-power-plant/SKILL.md)（聚合架构与商业模式）、[电力交易专家](../skills/electricity-trading-expert/SKILL.md)（现货、辅助服务与结算）、[储能投资与运营](../skills/storage-investment-operations/SKILL.md)（用户侧储能经济性）、[新能源项目开发与并网](../skills/renewable-project-development/SKILL.md)（并网与机制电价）
> 用途：回答"哪些资源能调、能调多少、按什么产品调、基线怎么认、考核怎么算、V2G 怎么参与市场"六类问题。本文只做资源侧的需求响应与车网互动知识整理；VPP 平台架构与商业模式归 VPP 技能，市场规则与价格出清归电力交易技能，项目财务归储能/新能源技能。

## 0. 一页看懂

### 0.1 一条主线

```
  资源盘点        能力认定        产品选择        邀约/调用        基线计量        考核结算        复盘
     │              │              │              │              │              │              │
 行业/设备       容量/时长       削峰/填谷       日前/实时       基线/表计       补偿/罚款       偏差/改进
 可调比例        爬坡/通知       电量/容量       可靠性          修正/审计       资金/分摊       规则版本
     └──────────────┴──────────────┴──────────────┴──────────────┴──────────────┴──────────────┘
                                       需求响应 = 用价格买"少用电/多用电"的能力
```

- **资源侧回答"谁可调"**：工业可中断、楼宇空调、用户侧储能、充电桩、数据中心备电、分布式电源，各有不同的可调深度、时长与机会成本。
- **机制侧回答"怎么买"**：削峰/填谷、日前/实时、电量/容量、邀约/紧急，是不同的产品，不是同一个"补贴"。
- **结算侧回答"给多少"**：基线决定响应量，响应率决定系数，考核决定罚款，资金池决定能不能兑现。
- **V2G 是资源侧的新变量**：车是移动储能，但单车容量小、可用性受出行约束，必须靠聚合与规模。

### 0.3 八个判断

1. **需求响应是"保险 + 期权"，不是年年都能赚大钱的生意**：2026 年迎峰度夏全国未启动 DR，但能力建设、容量补偿、VPP 调节仍在发生；只用"一年调用几次"算账，会低估它的保供与配网价值。
2. **能力 ≠ 可调用 ≠ 实际响应**：9,000 万kW 是资源潜力/能力口径，530 个 VPP 的 1,800 万kW 是平台聚合口径，真正调用时还要打同时率、可用率、响应率三道折扣。
3. **基线是 DR 的"会计核心"**：基线认定决定了大部分争议；同一块负荷，基线高 5%，补偿可能高 5%–10%，也可能被判定为操纵。
4. **价格上限 ≠ 结算价**：2,700 元/MWh 是"允许报到哪里"，不是"每度都按 2.7 元结算"；出清价、响应率系数、速度系数、考核罚款才是到手价。
5. **V2G 的第一性不是"卖电"，是把车变成可调容量**：私家车单打独斗很难覆盖双向桩成本；车队、公交、园区、换电站先跑通，私家车靠规模化与车网协同后进入。
6. **V2G 经济性由"价差 × 利用率 − 衰减 − 设备"决定**：价差低于约 0.4 元/kWh 的私家车项目要谨慎；利用率（每年参与天数）比单价更敏感。
7. **2026 夏天没启动 DR，不代表 DR 没用**：它是保供的"最后一张牌"，也是配网阻塞、局部重载、新能源消纳的"日常工具"；价格型 DR（峰谷电价）一直在隐性工作。
8. **2026 是规则年**：广东市场化 2.0、江苏快速响应、VPP 国标 GB/T 47241-2026、V2G 试点扩围同时落地；做项目先做"规则版本库"，再谈资源。

## 1. 边界：DR、VPP、有序用电、V2G 各是什么

### 1.1 六个概念

| 概念 | 一句话定义 | 谁组织 | 自愿/强制 | 收益来源 | 典型时长 |
|---|---|---|---|---|---|
| 需求响应（DR） | 用经济激励引导用户自愿改变用电行为，削峰或填谷 | 政府主管部门、电网、交易中心 | 自愿 | 补偿、市场出清 | 分钟–小时 |
| 有序用电 | 供应不足时依法依规控制部分负荷，保供用电秩序 | 政府、电网 | 强制 | 一般无补偿，按政策 | 小时–日 |
| 虚拟电厂（VPP） | 聚合分布式电源、可调负荷、储能，作为新型主体参与系统与市场 | 运营商 | 合同自愿 | 现货、辅助服务、DR、容量 | 秒–小时 |
| 车网互动（V2G） | 电动汽车与电网双向充放电，车作为移动储能 | 聚合商、充电运营商 | 合同自愿 | 电价差、DR、辅助服务 | 分钟–小时 |
| 可中断负荷 | 合同约定在需要时中断/削减的负荷 | 电网、聚合商 | 合同 | 容量 + 电量 | 分钟–小时 |
| 共享储能 | 储能容量按需租用、共享调用 | 储能运营商 | 合同 | 租金、服务费 | 小时 |

- **DR 是"产品"，VPP 是"主体"**：VPP 可以卖 DR，也可以卖现货、辅助服务；DR 可以由用户直接卖，也可以由负荷聚合商、VPP 代理。
- **DR 是"经济手段"，有序用电是"行政手段"**：1261 号明确"先错峰、后避峰、再限电"，DR 在前、有序用电在后。
- **V2G 是"双向"，有序充电（V1G）是"单向"**：V1G 已在规模化，V2G 是增量；把 V1G 说成 V2G，会高估可放电容量。

### 1.2 DR 与 VPP 的关系

```
                 ┌──────────────── 虚拟电厂（主体） ────────────────┐
                 │  资源池：分布式电源 + 可调负荷 + 储能 + 充电桩     │
                 │  能力：预测 / 聚合 / 控制 / 计量 / 结算           │
                 └───────┬───────────────┬───────────────┬──────────┘
                         │               │               │
                    需求响应          现货/中长期        辅助服务
                   （削峰/填谷）      （报量报价）      （调频/备用/爬坡）
```

- **VPP 不是 DR 的同义词**：VPP 是组织形态，DR 是它可参与的一个市场品种。
- **DR 也不是 VPP 的子集**：大工业用户可以直接参与 DR，不必经过 VPP；VPP 只是把分散资源"打包"的一种方式。
- **判断边界看"有没有反向供电"**：能反向供电、作为"正电厂"的，更接近 VPP；只削负荷的，是 DR 的典型形态。这条判据来自早期 VPP 研究，今天仍好用。

### 1.3 DR 与有序用电的关系

| 维度 | 需求响应 | 有序用电 |
|---|---|---|
| 触发条件 | 短时供需紧张、新能源消纳困难、局部阻塞 | 可预知供应不足，且其他措施用尽 |
| 手段 | 价格、补偿、合同 | 行政指标、负荷控制 |
| 用户选择 | 自愿参与，可报价 | 按方案刚性执行 |
| 补偿 | 有，按规则 | 一般无，或按地方政策 |
| 顺序 | 先 | 后 |

- **不能把 DR 当成"拉闸限电"**：DR 是用户自愿少用/多用，有序用电是政府依法控制。
- **不能把有序用电当成"免费 DR"**：有序用电执行成本低，但对生产、民生、营商环境的影响大；能不用就不用。
- **2023 年两份办法仍在有效期内**（2023-10-01 施行，有效期 5 年），2026 年没有新的国家层面替代文件；地方细则是在这两份办法下迭代。

### 1.4 四个常见混淆

1. **可调负荷 ≠ 可中断负荷**：可调是"能升能降"，可中断是"合同允许直接切除"；后者对生产连续性要求更高。
2. **容量 ≠ 电量**：MW 是能力，MWh 是能量；容量补偿按可用容量，电量补偿按实际响应电量。
3. **响应 ≠ 调用**：资源入库、签约是"能力"；真正发邀约、执行、计量才是"调用"；很多资源一年调用不了几次。
4. **补贴 ≠ 市场收益**：补贴是财政/电价资金池，市场收益是出清价；2026 年趋势是"补贴退、市场进"，但过渡期两者并存。

## 2. 灵活性资源盘点与能力测算

### 2.1 资源地图

```
┌──────────────────────────── 灵活性资源 ────────────────────────────┐
│ 电源侧            电网侧              负荷侧                储侧        │
│ 煤电灵活性        独立储能            工业可中断/可转移      用户侧储能  │
│ 气电顶峰          SVG/调相机          楼宇空调/居民           V2G        │
│ 抽水蓄能          互联互济            数据中心/算力          备电/共享   │
│ 新能源+储能       配网重构            电解铝/钢铁/水泥       移动储能    │
│ 可中断新能源      需求侧资源库        充电桩/换电站          热储能      │
└────────────────────────────────────────────────────────────────────┘
```

- **电源侧**：煤电灵活性改造、气电、抽蓄、新能源配储；调峰深度、爬坡率、启停时间是关键。
- **电网侧**：独立/共享储能、SVG、调相机、跨区互济；解决阻塞、电压、惯量问题。
- **负荷侧**：工业可中断/可转移、楼宇空调、居民、数据中心、电解铝/钢铁/水泥、充电桩；DR 的主战场。
- **储侧**：用户侧储能、V2G、备电、共享储能；既能削峰填谷，也能做备用与调频。

### 2.2 五维能力参数

| 参数 | 含义 | 为什么重要 | 常见陷阱 |
|---|---|---|---|
| 可调容量（MW） | 在基线上可增加/削减的最大功率 | 决定能卖多少容量 | 用铭牌功率代替可调容量 |
| 持续时间（h） | 满功率能维持多久 | 决定能卖能量型还是功率型 | 只看 1 h，忽略 2–4 h |
| 爬坡率（MW/min） | 从基线到目标功率的速度 | 决定能否做调频/快速响应 | 用理论值代替实测值 |
| 通知提前量 | 从收到指令到开始执行的时间 | 决定产品类型与价格系数 | 把"日前"资源报成"实时" |
| 可用率/响应率 | 可调用概率、实际响应/中标响应 | 决定考核与结算 | 用签约容量代替可用容量 |

补充三个"软参数"：

- **调用频次上限**：一年能被打几次？生产恢复、设备寿命、用户耐受都有上限。
- **机会成本**：少生产一吨钢、少服务一单生意、少充一次电，损失多少？
- **恢复时间**：响应结束后多久能回到正常生产？这决定连续两天的调用能力。

### 2.3 测算公式

**削峰能力：**

```
P_shave = min(P_base − P_min, P_rated, P_contract)
E_shave = Σ P_shave,t × Δt
```

**填谷能力：**

```
P_fill = min(P_max − P_base, P_rated, P_contract)
E_fill = Σ P_fill,t × Δt
```

**聚合容量（同时率与可用率）：**

```
P_agg = Σ_i P_i × k_i × a_i
```

- `P_i`：单个资源可调容量；`k_i`：同时率（同一时刻有多少资源可用）；`a_i`：可用率/响应率。
- **同时率不是 1**：100 台充电桩不会同时满功率，100 户空调不会同时响应；`k` 通常远小于 1。
- **可用率不是 100%**：设备检修、车主出行、生产安排都会让资源"在库但不可用"。

**有效响应量：**

```
ΔP_t = max(0, P_base,t − P_actual,t)
R = ΔP_t / P_bid
E_eff = Σ ΔP_t × Δt
```

**V2G 单枪可用容量：**

```
P_v2g = min(P_pile, E_available / T, S_transformer − P_load)
```

- `E_available`：车辆允许放出的电量（不是电池总容量）；`T`：放电时长；`S_transformer`：台区/配变容量裕度。
- **V2G 的瓶颈常在配变，不在车**：台区晚高峰本身重载，反向放电可能加剧电压/保护问题，必须做配网校核。

### 2.4 分行业可调比例（经验值）

| 资源 | 可调比例/潜力 | 主要约束 | 级别 |
|---|---|---|---|
| 钢铁 | 约 20% | 连续生产、炉温、订单 | C |
| 水泥 | 约 24% | 窑炉启停、熟料库存 | C |
| 电解铝 | 约 22% | 电解槽安全、阳极效应 | C |
| 楼宇空调 | 约 30% 楼宇负荷；空调约占楼宇负荷 25% | 舒适度、蓄冷、天气 | C |
| 居民负荷 | 家庭负荷 25%–50% | 用户意愿、家电类型 | C |
| 数据中心 | 5%–15%（备电/制冷/算力调度） | 业务连续性、SLA | D |
| 公共充电桩 | 30%–60% 可调（有序充电） | 车辆到达率、用户接受度 | D |
| V2G 私家车 | 单车可用 20–40 kWh；聚合同时率低 | 出行、SOC、桩兼容、质保 | D |

- **2026 年测算**：工商业可调负荷、电动汽车、分布式储能的调节潜力合计超过 3 亿kW（行业测算，C）；但"潜力"不等于"可调用"，要打同时率与可用率。
- **上海 2020 年摸底**：可调负荷 693 万kW（工业 123 万 + 商业 216 万 + 居民 351 万 + 电动汽车 2.45 万）；空调负荷占比超 40%。这是早期最完整的城市级样本，C。
- **安徽 2026-09**：全省接入 VPP 28 家，签约需求响应规模超 180 万kW；2026 年以来参与 DR 14 次，其中填谷 12 次，最大填谷负荷超 100 万kW（公开报道，C）。

### 2.5 算例 A：10 MW 工业负荷与 1,000 台充电桩

**工业负荷：**

- 基线 10 MW，最低生产负荷 4 MW，合同可调 6 MW，响应 2 h。
- 理论削峰能力 = min(10−4, 6) = 6 MW；可响应电量 = 12 MWh。
- 若实际只降到 4.6 MW，有效响应 = 5.4 MW，响应率 = 5.4/6 = 90%。
- 若报价 3 元/kWh，补偿 = 5,400 kW × 2 h × 3 = 32,400 元；机会成本 1.2 元/kWh 时，净收益 = 10,800 × (3−1.2) = 19,440 元。

**充电桩：**

- 1,000 台 7 kW 交流桩，装机 7 MW；同时充电率 30% → 2.1 MW；其中 V2G 车型占 50% → 1.05 MW；可用率 80% → 0.84 MW。
- 结论：**约 1,000–1,500 台私家车才能稳定提供 1 MW V2G 能力**（D 级经验值）；同样 1 MW，一个大工业用户可能就够了。
- 若换成 100 台 60 kW 直流桩，理论 6 MW，但同时率、V2G 比例、可用率同样打折，不能按铭牌算。

### 2.6 资源盘点的五个坑

1. **铭牌 ≠ 可调**：设备额定功率不等于在基线上的可增减功率。
2. **最低负荷 ≠ 0**：连续生产有保安负荷、工艺最低负荷，不能按"全停"算。
3. **同时率 ≠ 1**：分散资源越多，同时率越低；聚合容量不是简单相加。
4. **可用率 ≠ 100%**：签约资源在调用时可能检修、出行、生产满负荷。
5. **机会成本 ≠ 0**：少生产、少服务、少充电都有损失；只算补贴，会做出亏本买卖。

## 3. 需求响应产品体系

### 3.1 按方向：削峰与填谷

| 方向 | 目的 | 典型时段 | 资源 | 价格特征 |
|---|---|---|---|---|
| 削峰 | 缓解晚高峰/尖峰供电压力 | 10:00–15:00、18:00–22:00 | 工业可中断、空调、储能、V2G | 价格高、次数少 |
| 填谷 | 消纳新能源、压低谷差 | 午间光伏大发、深夜低谷 | 储能充电、空调蓄冷、电动汽车有序充电 | 价格低、次数多 |
| 灵活避峰 | 短时避开局部尖峰 | 提前 0.5–2 h | 可快速削减的负荷 | 系数高（最高 1.6 倍） |
| 可中断 | 紧急削峰/保安全 | 随时 | 工业可中断、备电 | 容量 + 电量 |

- **填谷不是"次要产品"**：2026 年新能源大发省份的填谷需求增加，安徽 2026 年 14 次 DR 中 12 次是填谷。
- **削峰价格通常高于填谷**：削峰是保供，填谷是消纳；但填谷频次高、竞争少，适合储能与充电桩。

### 3.2 按时序：日前、小时级、分钟级、秒级

| 类型 | 提前量 | 典型产品 | 计量 | 适用资源 |
|---|---|---|---|---|
| 日前邀约 | D-1 | 日前削峰/填谷 | 15 分钟 | 工业、楼宇、储能 |
| 小时级 | 2–6 h | 小时级响应 | 15 分钟/1 分钟 | 空调、储能、可转移负荷 |
| 分钟级 | 30 min 左右 | 快速响应/灵活避峰 | 1 分钟 | 储能、直控负荷、V2G |
| 秒级/实时 | 秒–分钟 | 调频、紧急控制 | 秒级 | 储能、V2G、可中断负荷 |

- **越靠近实时，价格系数越高，考核越严**：江苏直控型 15 元/kWh、自控型 10 元/kWh，背后是"0.5 小时内完成调整"的硬约束。
- **日前不是"提前一天通知"这么简单**：日前要报量报价、发布基线、安排生产；用户需要在前一天完成内部调度。

### 3.3 按约束：六类产品

| 产品 | 约束 | 补偿结构 | 典型场景 |
|---|---|---|---|
| 邀约型削峰 | 提前邀约，用户确认 | 电量补偿/竞价 | 可预见晚高峰 |
| 紧急型削峰 | 短提前量，必须执行 | 电量 + 考核 | 机组跳闸、线路过载 |
| 可中断负荷 | 合同约定，随时中断 | 容量 + 电量 | 工业保安负荷以外 |
| 灵活避峰 | 提前 0.5–2 h，短时削减 | 电量 × 高系数 | 局部尖峰 |
| 填谷响应 | 增加用电 | 电量补偿 | 新能源消纳 |
| 需求响应容量/备用 | 只备用，不一定调用 | 容量补偿（元/kW·月） | 系统备用、容量充裕度 |

- **容量型产品卖"随时可用"，电量型产品卖"实际响应"**：前者适合储能、备电、可中断负荷；后者适合生产弹性大的工业。
- **不要把"容量补偿"和"电量补偿"混在一起报价**：一个是期权费，一个是执行费；结算单要分开列。

### 3.4 产品矩阵

| 产品 | 提前量 | 持续时间 | 调用频次 | 价格结构 | 最适合 |
|---|---|---|---|---|---|
| 日前削峰 | D-1 | 1–4 h | 中 | 电量 | 工业、楼宇、储能 |
| 实时削峰 | 分钟级 | 0.5–2 h | 低 | 电量 × 速度系数 | 储能、直控负荷 |
| 可中断 | 分钟级 | 1–4 h | 低–中 | 容量 + 电量 | 工业可中断 |
| 灵活避峰 | 0.5–2 h | 0.5–2 h | 中 | 电量 × 1.4–1.6 | 空调、储能 |
| 填谷 | D-1/实时 | 2–6 h | 高 | 电量（低价） | 储能、充电桩 |
| 容量/备用 | 月/年 | 随时 | 低 | 元/kW·月 | 储能、备电、可中断 |

### 3.5 价格结构与系数

**电量补偿：**

```
C_energy = E_eff × p × α_speed × α_rate
```

**容量补偿：**

```
C_capacity = P_available × p_cap × T
```

**两部制：**

```
C = C_capacity + C_energy
```

- `p`：出清价/补偿单价；`α_speed`：速度系数；`α_rate`：响应率系数；`P_available`：可用容量。
- **价格上限只是"申报天花板"**：广东 2,700 元/MWh、江苏 15/10 元/kWh、广州 3.5 元/kWh，都是上限；实际按出清价/系数结算。
- **系数是"隐形价格"**：响应率 80% 以上系数 1.0、50%–80% 系数 0.6、低于 50% 为 0（福建口径，C）；速度系数 1–3 倍（厦门口径，C）。
- **考核是"负价格"**：未达到中标量的 80%，按差额扣罚；扣罚公式各省不同，但逻辑一致。

### 3.6 报价策略（简版）

1. **算机会成本**：少生产、少服务、少充电的损失，是报价的地板。
2. **算设备损耗**：储能循环、空调启停、电池衰减，都是成本。
3. **算考核风险**：报价越高，考核越严；宁可少报，不要报满。
4. **算竞争**：价格优先、容量优先（江苏），边际出清；不是报得高就赚得多。
5. **算时间**：同一时段不能重复参与多个产品；报了这个，就不能报那个。

### 3.7 产品选择树

```
有生产弹性/可转移工序?
├─ 是 → 工业可中断/可转移 → 日前削峰 / 可中断
└─ 否
   ├─ 有储能/空调/充电桩?
   │  ├─ 是 → 短时削峰/填谷 → 实时/灵活避峰/填谷
   │  └─ 否
   │     ├─ 有备电/自备电源?
   │     │  ├─ 是 → 容量/备用
   │     │  └─ 否 → 先做计量与资源入库，不急着报价
```

## 4. 基线认定与效果评估

### 4.1 基线是什么

**基线（baseline）**：假定用户没有参与需求响应时，在响应时段"本来会用多少电"的负荷曲线。它是反事实，不是实际负荷。

```
响应量 = 基线负荷 − 实际负荷
```

- 基线高，响应量就大；基线低，响应量就小。**基线认定是 DR 结算的第一道会计**。
- 基线不是"历史最大负荷"，也不是"昨天同一时刻的负荷"；它是按规则计算的、可复现的曲线。

### 4.2 常用方法

| 方法 | 怎么做 | 适用 | 风险 |
|---|---|---|---|
| 典型日平均法（5+3） | 取响应日前 5 个工作日/3 个非工作日，同时刻 15 分钟样本平均 | 大多数工业、商业、居民 | 天气、生产变化大时失真 |
| 异常剔除 | 剔除低于均值 25% 或高于 200% 的样本，向前递推 | 所有方法的前处理 | 剔除规则不一致会引发争议 |
| 回归法 | 用温度、湿度、产量、日期等解释负荷 | 空调、可变生产 | 模型过拟合、数据质量差 |
| 控制组法 | 找一组未响应、特征相似的客户作对照 | 聚合商、居民 | 对照组难匹配 |
| 实时修正 | 用响应前 3 h 的负荷差修正基线 | 实时/紧急响应 | 修正窗口被操纵 |
| 最大/平均基线 | 最大基线用于容量，平均基线用于电量 | 容量型/电量型产品 | 两个口径混用 |

**典型省份口径：**

- **四川 2026**：按户号、按时段，工作日取前 5 个未响应工作日，非工作日取前 3 个；15 分钟样本；剔除低于均值 25% 或高于 200% 的样本；D-1 12:00 前发布基线及样本。
- **安徽**：工作日 5 个参考日，剔除响应时段平均负荷低于 5 日均值 75% 的日期；剔除最低日后平均；非工作日 3 个参考日；实时响应用响应前 3 h 作为修正窗口。
- **湖南**：工作日 5 个、非工作日 3 个，15 分钟采样，剔除低于 25%/高于 200% 的样本；取平均基线、最大基线。
- **共同点**：都强调"未响应、未执行有序用电"的正常日；都允许异常剔除与动态修正；都由电网/交易中心计算并发布。

### 4.3 标准与规范

| 标准 | 用途 | 级别 |
|---|---|---|
| DL/T 2162-2020《用户参与需求响应基线负荷评价方法》 | 基线评价原则、方法、偏差 | 行业标准，A |
| GB/T 32127《需求响应效果监测与综合效益评价导则》 | 效果监测与综合效益 | 国标，A/B |
| GB/T 37016《电力用户需求响应节约电力测量与验证技术要求》 | 节约电力 M&V | 国标，A/B |

- **DL/T 2162-2020** 提出公平合理、准确简明、数据典型三项原则，并定义基线偏差；做基线审计时可以拿它当框架。
- **M&V 不是"看电表"**：要区分整体表（Option C）与分项表（Option B），要说明基线、修正、不确定性。

### 4.4 基线操纵与防作弊

**常见操纵：**

1. **响应前抬高负荷**：提前开空调、充电、启动设备，把基线"垫高"。
2. **生产前移/后移**：把响应时段的产量挪到前后，实际总产量没变。
3. **选择有利样本日**：挑高负荷日做基线，剔除低负荷日。
4. **利用修正窗口**：在响应前 3 h 故意抬高负荷，让实时修正把基线抬高。
5. **聚合商跨用户腾挪**：把响应量从 A 用户挪到 B 用户，重复计算。

**防御：**

- **基线封顶**：基线不超过历史同日最大负荷的 105%–110%（各省不同）。
- **随机/盲邀约**：不提前透露具体时段，减少"垫基线"。
- **控制组/对照组**：用未响应用户校验基线合理性。
- **前后各加一天**：把响应日前后的负荷纳入考核，防止"前移后移"。
- **数据审计**：15 分钟计量、表计校验、平台日志、现场核查。
- **惩罚条款**：基线操纵一经查实，取消补偿、罚款、退出资源库。

### 4.5 有效响应与考核

| 指标 | 公式 | 用途 |
|---|---|---|
| 实际响应负荷 | `ΔP = max(0, P_base − P_actual)` | 计算响应量 |
| 响应率 | `R = ΔP / P_bid` | 判断是否有效、定系数 |
| 有效响应电量 | `E_eff = Σ ΔP × Δt` | 计算补偿 |
| 考核差额 | `max(0, θ × Q_bid − Q_actual)` | 计算罚款 |
| 超额封顶 | `min(ΔP, cap × P_bid)` | 防止过度响应套利 |

- **有效门槛**：有的省 50%，有的省 80%；低于门槛可能不计补偿，甚至考核。
- **超额封顶**：江苏直控型超过申报值 150% 按 150% 计，自控型超过 120% 按 120% 计；防止"报少放多"套利。
- **考核系数**：各省不同，但通常是"差额 × 价格 × 系数"，且罚款有上限。

### 4.6 算例 B：基线 10 MW、报价 2 MW、响应 2 h

| 场景 | 实际负荷 | 响应量 | 响应率 | 补偿/罚款（3 元/kWh） |
|---|---|---|---|---|
| 正常 | 8.2 MW | 1.8 MW | 90% | 补偿 1.8 MW × 2 h × 3 = 10,800 元 |
| 响应不足 | 8.8 MW | 1.2 MW | 60% | 若系数 0.6：1.2 × 2 × 3 × 0.6 = 4,320 元 |
| 严重不足 | 9.5 MW | 0.5 MW | 25% | 补偿 0；罚款 (1.6−0.5) × 2 × 3 = 6,600 元 |
| 基线被抬高 0.5 MW | 8.2 MW | 2.3 MW | 115% | 按 100% 或 120% 封顶；多计 0.5 × 2 × 3 = 3,000 元 |

- **基线抬高 0.5 MW（5%）**，在 10 MW 用户身上就是 3,000 元/次的差异；一年 10 次就是 3 万元。
- **响应率 60% 时，补偿可能只剩 40%**；响应率 25% 时，补偿归零还要罚款。报价 2 MW 前，先确认自己能稳定做到 1.6 MW 以上。

### 4.7 基线争议检查清单

1. 样本日是否都是"未响应、未有序用电"的正常日？
2. 是否剔除了检修、停产、节假日、极端天气？
3. 异常剔除规则是否与细则一致（25%/200%、75%、最低日）？
4. 是否用了实时修正？修正窗口是否被操纵？
5. 基线是否超过历史同日最大负荷的封顶？
6. 聚合商的基线是否是各用户基线之和？有没有重复计算？
7. 计量点是否独立、表计是否校验、数据是否 15 分钟完整？

## 5. 调用、结算与考核

### 5.1 全流程

```
注册/签约 → 能力测试 → 资源入库 → 邀约/出清 → 用户确认 → 执行 → 监测
   → 效果评估 → 结果公示 → 结算 → 复盘/退出
```

| 环节 | 谁做 | 交付物 | 常见失败 |
|---|---|---|---|
| 注册/签约 | 用户、聚合商、交易中心 | 合同、户号、计量点 | 户号与计量点不一致 |
| 能力测试 | 电网/负荷管理中心 | 测试报告、可调容量 | 测试时段不代表真实高峰 |
| 资源入库 | 电网/交易中心 | 资源清单、基线 | 资源重复入库 |
| 邀约/出清 | 交易中心/电网 | 邀约、出清结果 | 价格优先/容量优先规则不清 |
| 用户确认 | 用户/聚合商 | 确认回执 | 未及时确认视为放弃 |
| 执行 | 用户/聚合商 | 执行记录、曲线 | 只关设备，未达目标 |
| 监测 | 电网/平台 | 15 分钟/1 分钟数据 | 表计故障、通信中断 |
| 评估 | 电网/交易中心 | 基线、响应量、响应率 | 基线争议 |
| 公示 | 交易中心/电网 | 公示清单 | 用户未及时申诉 |
| 结算 | 电网/交易中心 | 结算单、发票/退补 | 科目不清、重复扣罚 |
| 复盘/退出 | 各方 | 复盘报告、退出申请 | 长期不响应仍占资源 |

### 5.2 结算公式

**电量型：**

```
C = E_eff × p × α_speed × α_rate
```

**容量型：**

```
C = P_available × p_cap × T
```

**两部制：**

```
C = P_available × p_cap × T + E_eff × p_energy
```

**考核：**

```
Penalty = max(0, (θ × Q_bid − Q_actual) × p × β)
```

**净收益：**

```
Net = C − C_opportunity − C_equipment − C_labor − C_penalty − C_platform
```

- **结算周期**：常见"日清月结"（四川）、按月/季度结算；居民/小用户可能按季度或年度。
- **结算依据**：电网企业电能计量装置；平台数据是过程证据，表计是结算证据。
- **发票/退补**：企业用户通常走电费退补或服务费发票；居民用户走平台/电网代发。
- **税务**：补偿款、服务费、容量费的税目不同，合同要写清。

### 5.3 资金从哪来

| 来源 | 机制 | 优点 | 风险 |
|---|---|---|---|
| 尖峰电价增收 | 季节性尖峰电价多收的钱，注入 DR 资金池 | 用户侧自筹，财政压力小 | 资金来源不稳定，随电价政策变化 |
| 系统运行费 | 纳入输配电价/系统运行费 | 稳定、可持续 | 需要价格主管部门核定 |
| 财政补贴 | 省/市财政预算 | 启动快、力度大 | 不可持续、年度额度有限 |
| 受益者付费 | 电网、发电、用户按受益分摊 | 公平 | 分摊机制复杂、争议大 |
| 市场出清 | 现货/辅助服务/容量市场 | 价格信号真实 | 需要市场成熟、监管到位 |

- **"以支定收"**：先确定可用资金，再倒推可采购的响应容量与价格；河北等地采用这一逻辑（C）。
- **2026 年趋势**：从"尖峰电价资金池"转向"系统运行费 + 市场"，从"政府补贴"转向"谁受益、谁承担"；但过渡期仍以资金池为主。
- **不要假设补贴一定兑现**：先看预算、再看规则、再看结算周期；财政资金到位慢是常见风险。

### 5.4 重复参与与双计禁止

- **同一资源、同一时段，不能重复参与 DR、辅助服务、现货**；江苏明确"参与并中标的负荷快速响应资源在同一时段内不得重复参与需求响应"。
- **一个用户一个月只能绑定一家 VPP**（广东，B）：防止多家聚合商重复申报同一负荷。
- **聚合商内部要去重**：同一户号、同一计量点、同一设备，不能在不同资源池重复计算。
- **绿证/碳/DR 不能重复计算**：同一度电的绿色属性、碳减排、削峰价值，分属不同市场，合同要写清归属。

### 5.5 证据链与争议处理

**保留五类证据：**

1. 邀约通知（时间、时段、容量、价格）。
2. 基线及样本（D-1 发布版本）。
3. 执行记录（设备动作、功率曲线、平台日志）。
4. 计量数据（15 分钟/1 分钟，表计编号）。
5. 结算单与公示（补偿、考核、扣罚明细）。

**争议处理五步：**

```
收到结算单 → 3–5 个工作日内核对 → 提出书面异议 → 电网/交易中心复核 → 公示/仲裁
```

- **超期视为认可**：很多细则规定异议期，过期不再受理。
- **先核对基线，再核对计量，最后核对系数**：80% 的争议在基线，15% 在计量，5% 在系数。

## 7. 车网互动（V2G）

### 7.1 三层：V1G、V2G、V2H/V2B

| 层级 | 能量方向 | 能力 | 现状 | 关键约束 |
|---|---|---|---|---|
| V1G 有序充电 | 电网→车 | 错峰充电、削峰填谷 | 已规模化 | 用户习惯、桩/车兼容 |
| V2G 车网互动 | 双向 | 削峰、填谷、调频、备用 | 试点→规模化 | 双向桩、电池质保、计量 |
| V2H/V2B | 车→家/建筑 | 备电、离网、需量管理 | 小规模 | 切换装置、安规、成本 |

- **V1G 是当前的主力**：不改车、不改电池、成本低，靠峰谷电价就能跑；V2G 是增量，不是替代。
- **V2G 的价值在"容量"**：单车 60 kWh 只能放 20–40 kWh，但聚合 1 万辆车就是 200–400 MWh，相当于一座中型储能电站。

  - 深圳：光明虹桥公园单站 61 辆车、4.21 MW，接入深圳 VPP 管理中心（B）。

### 7.4 技术架构

```
┌──────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ 车辆 BMS │←→│ 双向充电桩/直流桩 │←→│ 台区/配变/保护 │←→│ 聚合平台/VPP │
│ SOC/温度 │    │ 功率/计量/通信  │    │ 容量/电压/谐波 │    │ 预测/策略/结算│
└──────────┘    └──────────────┘    └──────────────┘    └──────┬───────┘
                                                               │
                                              ┌────────────────┴────────────────┐
                                              │ 电网调度 / 交易中心 / 负荷管理中心 │
                                              │ 邀约 / 出清 / 考核 / 结算          │
                                              └─────────────────────────────────┘
```

- **车端**：BMS 提供 SOC、温度、可用充放电功率、健康状态；V2G 需要车端允许反向放电。
- **桩端**：双向桩/直流桩，支持计量、通信、保护、孤岛检测；交流 V2G 成本低但功率小，直流 V2G 功率大但成本高。
- **台区**：配变容量、电压、谐波、保护定值是硬约束；V2G 集中放电可能造成过电压、保护误动。
- **平台**：聚合、预测、报价、控制、计量、结算；要能对接负荷管理系统、调度自动化、交易平台。
- **标准**：充电系统、连接器、通信协议、互操作性标准体系仍在完善；跨品牌车-桩-网兼容是落地难点。具体标准号与版本以现行目录为准。

### 7.5 参与市场的四条路径

| 路径 | 卖什么 | 门槛 | 收益 | 难点 |
|---|---|---|---|---|
| 需求响应 | 削峰/填谷/可中断 | 低–中 | 补偿 | 基线、调用频次 |
| 电力现货 | 电能量 | 中–高 | 价差 | 预测、申报、偏差 |
| 辅助服务 | 调频/备用/爬坡 | 高 | 容量+里程 | 响应速度、持续时间、AGC 接口 |
| 容量/容量租赁 | 可用容量 | 中 | 容量补偿/租金 | 认定规则、可用率 |

- **DR 是最现实的入口**：门槛低、规则成熟；先把 DR 跑通，再谈现货/辅助服务。
- **辅助服务对 V2G 不友好**：单车响应快但持续时间短、可用性受出行影响；聚合后可以试，但要算"考核风险"。
- **容量市场还在试点**：V2G 能否被认定为等效储能、给多少容量补偿，各地不同；不要假设"有电池就有容量"。
- **绿证/碳**：V2G 放电本身不产生绿证；只有当充电电量来自绿电且链证完整时，才有绿色属性；不要重复计算。

### 7.6 计量与结算

- **独立计量**：V2G 桩应具备独立的充/放电计量，能区分正向充电、反向放电；居民用户可能需要单独表计。
- **放电价格**：目前多以"放电上网电价/补偿价"结算，部分地区明确反向放电价格（江苏 2025-08 电价政策，B）。
- **输配电费**：车主充电时缴输配电费，放电时是否抵扣/退还，全国尚未统一；这是 V2G 经济性的关键变量（公开讨论，B/C）。
- **平台分成**：聚合商/充电运营商通常收 10%–30% 服务费；合同要写清结算顺序、税费、发票。
- **结算周期**：DR 按月/季度；现货/辅助服务按月；居民 V2G 可能按日/月。

### 7.7 电池寿命与质保

| 事实 | 数据 | 含义 | 级别 |
|---|---|---|---|
| 主流动力电池循环寿命 | 2,000–3,000 次（LFP 可达 3,000–5,000 次） | 私家车全生命周期通常只用 400–600 次 | C |
| 私家车年充电频次 | 50–100 次 | 有大量"闲置循环"可用于 V2G | C |
| V2G 可用 SOC 窗口 | 20%–80%/95% | 浅充浅放，避免深度循环 | B |
| 80 次满充满放测试 | 容量衰减 0.13% | 受控条件下衰减小；不代表所有工况 | C |
| 质保缺口 | 多数车企未明确 V2G 放电是否纳入质保 | 车主最大顾虑；部分试点折算等效里程 | B/C |

- **"V2G 一定伤电池"不准确**：浅充浅放、窄 SOC 窗口、温控良好的情况下，额外衰减有限；但"完全不衰减"也不准确。
- **"V2G 不伤电池"也不准确**：深度循环、高温、高频充放电会加速衰减；关键在控制策略与质保。
- **质保是商业化的前提**：没有车企背书，车主不愿长期参与；广州等地试点把放电量折算等效行驶里程纳入质保（B/C），但全国未统一。

### 7.8 经济性算例（合成，D 级）

**私家车：**

- 电池 60 kWh，V2G 可用 30 kWh/天；每年参与 300 天 → 9,000 kWh/年。
- 价差（放电价−充电价）0.7 元/kWh → 毛收入 6,300 元/年。
- 电池衰减成本 0.15 元/kWh → 1,350 元/年。
- 双向桩 8,000 元，8 年折旧 → 1,000 元/年；安装 2,000 元/8 年 → 250 元/年；运维 200 元/年；平台分成 10% → 630 元/年。
- 净收益 ≈ 6,300 − 1,350 − 1,000 − 250 − 200 − 630 = **2,870 元/年**。
- 盈亏平衡价差 ≈ (1,350+1,000+250+200+630)/9,000 = **0.381 元/kWh**；若每年只参与 150 天，盈亏平衡价差约 **0.76 元/kWh**。

**公交/车队：**

- 50 辆公交，每辆 V2G 可用 200 kWh，300 天 → 3 GWh/年。
- 价差 0.45 元/kWh → 135 万元/年；衰减 0.12 元/kWh → 36 万元；双向桩 50 台×5 万元/8 年 → 31.25 万元；运维 8 万元。
- 净收益 ≈ 135 − 36 − 31.25 − 8 = **59.75 万元/年**。
- 结论：**车队/公交先跑通**，因为利用率高、停车集中、调度可控；私家车靠规模与车网协同后进入。

**关键敏感度：**

| 变量 | 变化 | 对净收益的影响 |
|---|---|---|
| 价差 | 0.7 → 0.4 元/kWh | 私家车净收益从 2,870 降至约 170 元/年 |
| 年参与天数 | 300 → 150 天 | 盈亏平衡价差翻倍 |
| 桩成本 | 8,000 → 3,000 元（补贴/共享） | 盈亏平衡价差降至约 0.27 元/kWh |
| 衰减成本 | 0.15 → 0.30 元/kWh | 净收益减少 1,350 元/年 |

- **算例不含**：输配电费抵扣、需量电费、容量补偿、辅助服务、补贴、电池残值；实际项目要逐项加入。
- **不要用"峰值电价−谷时电价"直接当价差**：还要扣充电服务费、输配电费、平台分成、税费。

### 7.9 并网与配网约束

1. **配变容量**：V2G 集中放电可能让台区反向重载；先做台区承载力评估。
2. **电压**：反向功率可能导致过电压，尤其是光伏高渗透台区；需要无功/电压协同。
3. **保护**：双向潮流改变保护定值；孤岛检测、反孤岛保护必须可靠。
4. **谐波/电能质量**：大量桩同时工作，谐波、闪变、三相不平衡要校核。
5. **通信/网络安全**：车-桩-网-云链路要加密、鉴权、防篡改；聚合平台要满足电力监控系统安全防护要求。
6. **计量**：充/放电分开计量，表计精度、通信中断补采、数据留存。
7. **消防/场地**：地下车库、密集停车区的消防、通风、疏散要求。

### 7.10 V2G 项目落地十问

1. 车端是否支持 V2G？哪些车型、哪些年款、哪些协议？
2. 桩端是否双向？交流还是直流？功率、效率、待机损耗？
3. 台区是否允许反向功率？配变容量、电压、保护是否校核？
4. 计量是否独立？充/放电能否分开结算？
5. 放电价格/补偿是否明确？输配电费是否抵扣？
6. 电池质保是否覆盖 V2G？衰减责任谁承担？
7. 用户是否愿意？SOC 下限、用车时间、补偿是否足够？
8. 聚合平台能否对接调度/交易/负荷管理系统？
9. 参与哪个市场？DR、现货、辅助服务、容量？考核能否承受？
10. 退出机制是否清楚？设备残值、合同期限、数据归属？

## 8. 2026 年运行图景：能力上来了，调用为什么不多

### 8.1 2026 年迎峰度夏数据

| 指标 | 数据 | 含义 | 级别 |
|---|---|---|---|
| 全国最大负荷 | 15.57 亿kW，四次创历史新高，较 2025 年极值增约 4,900 万kW | 保供压力持续上升 | A/B |
| 区域/省级纪录 | 6 个区域电网、20 个省级电网多次创新高 | 局部高峰更突出 | B |
| DR/有序用电 | 31 个省份均未采取 DR、有序用电措施 | 供应侧+市场调节扛住了 | B |
| 装机 | 超 40 亿kW；46 条特高压；新型储能 1.53 亿kW | 保供底盘厚 | B |
| VPP | 超 530 个，最大调节能力 1,800 万kW 以上 | 需求侧调节规模化 | B |
| 需求侧调节能力 | 超 9,000 万kW，占最大负荷 6.0% 以上 | 已超 2025 年 3%–5% 目标 | B |
| 上海 VPP | 164.77 万kW 实测响应 | 城市级 VPP 进入"百万千瓦"时代 | B |
| 深圳 VPP | 140 万kW，61 家运营商、1.4 万+ 用户 | 市场化聚合规模 | B |

- **"没启动 DR"不等于"DR 没参与"**：上海 VPP 在迎峰度夏期间做了 164.77 万kW 响应，属于市场化的系统调节，不是政府行政 DR。
- **"能力 9,000 万kW"不等于"随时能调 9,000 万kW"**：这是资源潜力/能力口径；实际调用要打同时率、可用率、响应率。

### 8.2 三层口径

```
理论潜力（资源盘点）
   └─ 可调用能力（入库、签约、测试、平台接入）
        └─ 实际响应（邀约、执行、计量、考核）
```

| 口径 | 2026 示例 | 折扣因素 |
|---|---|---|
| 理论潜力 | 工商业+EV+分布式储能 >3 亿kW（C） | 资源是否愿意参与 |
| 能力/入库 | 需求侧 9,000 万kW、VPP 1,800 万kW | 同时率、可用率、测试 |
| 实际响应 | 上海 164.77 万kW、深圳 140 万kW | 调用次数、响应率、考核 |

- **做规划用"能力"，做结算用"实际响应"**：两个口径不能混。
- **做投资用"可调用能力 × 年调用次数 × 单价"**：只算能力，会高估收益；只算 2026 年实际调用，会低估期权价值。

### 8.3 为什么 2026 年没启动 DR

1. **供应侧充足**：40 亿kW 装机、1.53 亿kW 新型储能、46 条特高压、省间互济，峰值缺口被覆盖。
2. **价格型 DR 在隐性工作**：峰谷电价、尖峰电价让用户主动错峰，不需要行政邀约。
3. **VPP 市场化调节替代了部分 DR**：上海、深圳 VPP 参与系统调节，不是政府补贴型 DR。
4. **局部问题用配网/储能/需求侧管理解决**：不是全省缺口，不需要全省 DR。
5. **DR 是"最后一张牌"**：能不用就不用；不用，说明系统更安全，不是 DR 失败。

### 8.4 DR 的三种价值

| 价值 | 说明 | 怎么变现 |
|---|---|---|
| 保供/可靠性 | 尖峰缺额时的"最后一道防线" | 容量补偿、保供补贴、避免限电损失 |
| 配网/阻塞 | 局部重载、断面过载、电压问题 | 局部 DR、灵活避峰、VPP |
| 市场/消纳 | 削峰填谷、新能源消纳、市场价格平抑 | 现货、辅助服务、填谷补偿 |

- **DR 不是"每年都能卖很多电"的生意**：它是期权，价值在"需要时可用"；只按能量收入估值，会低估。
- **DR 也不是"只靠补贴"的生意**：2026 年趋势是市场化，VPP 通过现货/辅助服务/容量获得收益，DR 只是其中一个品种。

### 8.5 从"补贴型 DR"到"市场型 DR"

| 阶段 | 特征 | 2026 位置 |
|---|---|---|
| 补贴型 | 政府/电网出钱，邀约响应，按次补偿 | 仍是主流，但资金趋紧 |
| 市场型 | 年度交易、竞价出清、容量+电量、VPP 入市 | 广东、江苏、浙江、山东先行 |
| 自主调度型 | 资源自主选择市场、跨空间交易 | 尚未成熟 |

- **2026 年的关键词是"市场化 2.0"**：广东年度交易、江苏快速响应、浙江容量+电量、山东 VPP 方案，都是把 DR 从"补贴"推向"市场"。
- **过渡期的三个并存**：补贴与市场并存、日前与实时并存、省级与区域并存；做项目要按"当地规则版本"设计，不要拿一个省的模式套全国。

## 10. 常见误解（15 条）

1. **"需求响应就是拉闸限电"**：DR 是自愿、经济激励；有序用电才是行政控制。
2. **"DR 就是 VPP"**：DR 是产品，VPP 是聚合主体；VPP 还能卖现货、辅助服务。
3. **"可调容量就是实际响应"**：还要打同时率、可用率、响应率三道折扣。
4. **"签约就能拿钱"**：容量型只给容量费，电量型要实际调用并考核。
5. **"基线就是实际负荷"**：基线是反事实，是"如果没有响应会用多少电"。
6. **"基线越低越容易拿钱"**：基线低，响应量小；基线高，可能被判操纵。
7. **"响应率 100% 才有效"**：各省门槛不同，常见 50%/80%；低于门槛才无效。
8. **"价格上限就是结算价"**：上限只是申报天花板；出清价、系数、考核才是到手价。
9. **"DR 可以无限次调用"**：用户有生产、设备、耐受上限；调用频次是合同约束。
10. **"V2G 就是有序充电"**：V1G 单向，V2G 双向；V1G 已规模化，V2G 是增量。
11. **"V2G 放电收入就是净收益"**：还要扣充电成本、输配电费、衰减、设备、平台分成。
12. **"V2G 一定伤电池"**：浅充浅放、窄 SOC 窗口下衰减小；但质保缺口是现实问题。
13. **"所有电动车都能 V2G"**：车端、桩端、协议、授权都要支持；不是有电池就行。
14. **"V2G 可以替代储能"**：车会走、容量小、可用性低；V2G 是补充，不是替代。
15. **"2026 夏天没启动 DR，说明 DR 没用"**：DR 是期权/保险；没调用说明系统安全，不代表没有价值。

### 核心公式

| 用途 | 公式 |
|---|---|
| 削峰能力 | `P_shave = min(P_base − P_min, P_rated, P_contract)` |
| 填谷能力 | `P_fill = min(P_max − P_base, P_rated, P_contract)` |
| 聚合容量 | `P_agg = Σ P_i × k_i × a_i` |
| 有效响应 | `ΔP = max(0, P_base − P_actual)`；`E_eff = Σ ΔP × Δt` |
| 响应率 | `R = ΔP / P_bid` |
| 电量补偿 | `C = E_eff × p × α_speed × α_rate` |
| 容量补偿 | `C = P_available × p_cap × T` |
| 考核 | `Penalty = max(0, (θ × Q_bid − Q_actual) × p × β)` |
| 净收益 | `Net = C − C_opportunity − C_equipment − C_labor − C_penalty` |
| V2G 单枪 | `P_v2g = min(P_pile, E_available / T, S_transformer − P_load)` |
| V2G 净收益 | `NP = R_dis + R_cap + R_aux + Sub − C_chg − C_tariff − C_deg − C_capex − C_om` |
| 衰减成本 | `C_deg = C_batt / (N_cycle × E_usable)` |

### 数据口径提醒

- **kW 与 kWh 不能混**：能力按 kW，电量按 kWh；容量补偿与电量补偿是两本账。
- **"能力/潜力/可调用/实际响应"四层口径**：9,000 万kW 是能力，530 个 VPP 的 1,800 万kW 是平台聚合，实际调用还要打折。
- **"价格上限"不是"结算价"**：2,700 元/MWh、15 元/kWh、3.5 元/kWh 都是上限；实际按出清价、系数、考核。
- **"聚合可调充电 5,000 万kW"不等于"反向放电 5,000 万kW"**：前者含有序充电，后者才是 V2G 放电。
- **"2026 夏天没启动 DR"**：指 31 个省份未采取 DR/有序用电措施；上海、深圳 VPP 的市场化调节不算行政 DR。
- **"V2G 试点 30 个/32 个"**：241 号写 30 个，部分报道写 32 个；以官方附件为准。
- **"V2G 不伤电池"要加条件**：浅充浅放、窄 SOC、温控良好；质保缺口仍是商业化前提。
- **"DR 补偿"要扣机会成本**：少生产、少服务、少充电的损失，可能吞掉全部补贴。
- **"省级规则"迭代快**：2026 年广东、江苏、浙江、山东均有新版；引用必须写文号、日期、上限/口径。
- **"基线"是反事实**：不是实际负荷，也不是历史最大负荷；争议先查样本日、剔除规则、修正窗口、封顶。
