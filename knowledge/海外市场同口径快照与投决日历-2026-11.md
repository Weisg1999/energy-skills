# 海外市场同口径快照与投决日历（2026-11）

> 适用边界：把十一个海外市场模块里的关键数字拉平到同一张表，并标出“能用、慎用、待核实”三种状态；不替代单市场规则，不构成法律、税务或投资意见。口径定义、级别与时点逐项标注；空缺不猜数，直接写“待核实”。
> 用途：回答“十一市场能不能横着比”“并网排队到底多长”“下一季度有什么硬节点”“中国主体进每个市场要过哪几道门”“哪些 C 级数字必须先复核”五类问题。

---

## 0. 一页看懂

### 0.1 这张表解决什么

| 问题 | 这张表能给 | 这张表不能给 |
|---|---|---|
| 市场规模 | 有出处的装机/储能/排队数字，带级别与时点 | 统一的“最新值”；很多格子本身就是空缺 |
| 收益环境 | 负价小时、均价、捕获率、降额因子的可用口径 | 项目级 IRR；缺本地电价曲线、电网费和合同结构 |
| 进入难度 | 并网排队、非 firm 选项、中国主体六道门槛 | 法律意见；外资审查要按交易结构逐案判断 |
| 时间窗口 | 2026Q4–2027 的拍卖、咨询、法规节点 | 确定的中标结果；日历只标“预计/待公布” |
| 数据质量 | 每个数字的级别、时点、复核入口 | 把 C 级数字直接写进投决模型 |

### 0.2 三条使用规则

1. **先看级别，再看数字**：A 级可直接引用；B 级写明“据报道/交易所口径”；C 级只能做量级判断；D 级只用于演示。
2. **先对齐口径，再做比较**：储能“存量/管线/招标规模”不是一回事；均价“日前/实时/系统价”不是一回事；容量“铭牌/并网/降额”不是一回事。
3. **空缺是结论，不是缺陷**：本表剩余“待核实”本身说明十一市场的数据透明度差异；下一轮补数按 §1.4 的优先级做，不靠记忆填格。

> 口径说明：本轮按确认后的**十一市场**执行（澳、德、英、意、西、法、荷、波、比·北欧、美、日）；美、日、法三篇虽为后加，也纳入同一张表，避免“八篇一套口径、十一篇另一套口径”。

## 1. 同口径快照总表

### 1.1 七列口径定义

| 列 | 本文口径 | 常见混用 |
|---|---|---|
| 装机 | 全国/全市场总装机（GW），含所有电源 | 只算新能源、只算 NEM/ERCOT、用发电量替代装机 |
| 储能存量/管线 | 存量=已投运；管线=已许可/在建/申请；招标=拍卖规模 | 把“许可 24.3 GW”写成“装机 24.3 GW” |
| 2025–2026 均价 | 年度日前市场均价（本币/MWh），注明市场与年份 | 用实时价、系统价、PUN、JEPX 系统价直接替代 |
| 负价小时 | 年度日前市场负价小时数（h/年），注明市场 | 只给单次负价事件；把实时负价当日前 |
| 捕获率 | 技术捕获价 ÷ 基荷均价（%），注明技术与年份 | 用“光伏均价”替代捕获率；不写参考价口径 |
| 并网排队 | 排队规模（GW 或项目/申请数）+ 典型时长 | 把申请量当在建量；不写“申请/许可/在建”状态 |
| 降额因子 | 容量市场/可靠性机制实际折算比例（%） | 用铭牌容量算容量收入；把 ELCC 当固定系数 |

### 1.3 五个读数

1. **装机列已补到“有口径的国家级数字”，但口径仍不统一**：澳大利亚 73.07 GW 仅 NEM、不含屋顶；德国 294.7 GW 是净装机含屋顶；英国 103.8 GW 含配电网与屋顶；意大利 145.9 GW 是毛有效装机含分布式光伏；波兰 77.331 GW 是 brutto；比利时/北欧是 ENTSO-E 净发电容量；ERCOT 184.9 GW 含 PUN/DGR/SODG；PJM 184.2 GW 含净进口；CAISO 103.5 GW 含 WEIM；日本 327.27 GW 是供电计划年末计划值。十一个数字不能直接排序当“市场规模”。
2. **均价列只能做量级对照**：德国 €89.32、西班牙 €65.29、法国 €61.1、荷兰 €86.81、比利时 €82.39 是日前均价；意大利 €115.9 是 PUN；英国 £80.66 是 IMRP 简单平均；PJM $50.70 是负荷加权 LMP；CAISO $39 是简单平均；日本 ¥11.06/kWh 是系统价；澳大利亚 A$89.9 是 NEM 现货。**没有两个市场的数字天然可比**，先换算币种、再对齐加权方式与市场范围。
3. **负价小时只有德国、法国、英国是 A 级年度值**：德国 573 h、法国 513 h、英国 168 h；西班牙 553 h（<0）为 B 级、另有 247 h 恰为零价；荷兰 584 h、波兰 310 h 为 C 级；意大利 0 h 只是 8,040 h 样本；美国与澳大利亚只有占比或缺失；日本制度上无负价。跨国比较前先确认“日前/实时”“全年/样本”和“<0 是否含 =0”。
4. **储能数字最容易被混用**：意大利 7.961 GW 是含分布式的累计；西班牙 24.3 GW 是“已许可”不是“已投运”；波兰 685 MW 是容量市场中标；英国 7,645 MW 是 LDES 倾向性决定；法国 14 GW/180 是并网队列；ERCOT 15,008 MW 是在运电池。六类数字不能相加，也不能当“存量”。
5. **捕获率仍是最大空缺**：只有西班牙给出光伏捕获价约 €33.95/MWh、同比下降约 19.7%（C，2025），这是价格不是比率。其余市场没有“技术捕获价 ÷ 基荷均价”的同口径数据；用光伏均价或 PPA 价替代捕获率，会系统性高估。

### 2.2 四种排队治理

```
英国 TMO4+：
  从“先到先得”转向“ready + needed”
  → 项目要证明土地、设备、资金、并网条件都就绪
  → 占位不建会被清理；队列从约 750 GW 压到 200–250 GW（C）

西班牙 RDL 7/2026：
  灵活接入（flexible access）+ 自消费预留 10%
  → 允许在限定时段限出力换取更快接入
  → 具体条款以 BOE-A-2026-6544 为准（B）

荷兰 ATR85：
  非 firm 合同，以限出力/限充电换取更快接入
  → 2025 年约 9 GW 非 firm 容量被提供（B）
  → 2026-07-01 起接入优先排序框架生效（B/C）

美国 ERCOT Batch Zero：
  2026-09-03 分类：204 个项目/66.4 GW 为“基荷”，158 个/127.9 GW 为“研究负荷”
  → 最终分配预计 2027 年春（C）
  → 大负荷与储能争抢并网和输电资源
```

### 2.3 投决读法

- **排队规模不是可开发规模**：申请量里包含大量“占位不建”和“一址多报”；英国 TMO4+ 的清理比例就是证据。
- **典型时长比排队规模更影响 IRR**：PJM 研究约 40 个月、ERCOT 大负荷排到 2027 年，意味着并网时间要按“P90 延迟”做敏感性，而不是按开发商口头承诺。
- **非 firm 是“用收益换时间”**：荷兰 ATR85、西班牙灵活接入都会限制可用容量或时段；模型里要把“限出力小时”和“容量收入减少”同时扣掉。
- **先确认状态再引用**：申请、许可、在建、并网、投运是五个状态；本表在“排队规模”列尽量写状态，未写状态的数字不能当在建。
- **法国的 30 GW 与 14 GW 不是一回事**：30 GW 是 2025 年末已授接入权（数据中心/制氢/工业），14 GW/180 是电池并网队列；两者相加会把“已授”与“排队”混成一个数。RTE 未披露典型并网时长，模型里只能用 P50/P90 区间假设并标注为 D 级。

### 4.2 六个共性门槛

1. **本地主体**：十一市场都要求本地公司/分支机构或项目公司；纯财务投资可以只持股，但参与市场交易通常要本地注册。
2. **许可/备案**：英国按业务许可、意大利按 BRP/BSP、波兰按 koncesja、法国按 CRE 容量认证、日本按电气事业法备案；“一张表走天下”不成立。
3. **并网**：并网协议通常早于市场注册；英国 TMO4+、西班牙灵活接入、荷兰 ATR85、法国 2026 年底并网改革都会改变“先到先得”的假设。
4. **平衡责任**：德国 BKV、英国 BSC Party、意大利 BRP、西班牙/荷兰/法国 BRP、波兰 POB、日本平衡责任；没有平衡责任主体，偏差结算无法落地。
5. **信用/担保**：交易所保证金、BSC 信用覆盖、容量市场履约担保、并网保证金、母公司担保；跨境主体要提前和银行确认授信。
6. **REMIT/市场滥用**：欧盟 REMIT、英国 REMIT、美国市场操纵规则、日本交易监视；报送与记录保存是持续义务，不是上线前一次性工作。

### 4.3 国别备注

- **澳大利亚**：AEMO 既是调度又是结算，注册入口集中；但 FIRB、保函、零售授权是另一套。中资项目常见路径是收购已开发项目或与本地开发商合资。
- **德国**：平衡组（Bilanzkreis）是硬门槛；EEG、电网费、§14a/§118(6) 会改变储能经济性，不能只看 EPEX 价差。
- **英国**：BSC 接入是硬门槛，多数海外主体通过收购项目或本地伙伴进入；TMO4+ 下“占位不建”会被清理。
- **意大利**：MACSE 是储能专用长周期拍卖，按 €/MWh·年支付；容量市场、MSD/MB 和 MACSE 是三条收入线，资格与担保分开。
- **西班牙**：容量市场 2026 年才落地，首拍未举行；RDL 7/2026 的灵活接入和 10% 自消费预留会改变并网策略。
- **法国**：容量机制 2026 年集中到 RTE 单一买方，4 h 电池走 PL-1、长时/新建看 PL-4；IEF 外资审查（非欧盟 25%、欧盟 10%）与 CRE 容量认证是两道独立门槛；ARENH 已终止，VNU 不是保底电价。
- **荷兰**：没有容量市场；拥堵和非 firm 接入是核心约束；Energiewet 2026-01-01 生效，但细则仍在落地。
- **波兰**：容量市场 + NFOŚiGW 补贴双轮；补贴只减 CAPEX，且与容量收入叠加会扣减；电池降额约 13%（C）必须复核。
- **比利时/北欧**：比利时看 CRM 多年合同；北欧看 12 个报价区的分区价差和水电/核电边际；四国许可、平衡责任、税率不同，不能用一套模板。
- **美国**：ERCOT 能量-only、PJM 容量市场、CAISO RA 三种范式；CFIUS、FEOC、301 关税、电网设备行政令是叠加风险，设备与股权结构要一起设计。
- **日本**：外为法事前届报 + 电气事业法备案 + 平衡责任三件事；接续检讨排队与件数上限是并网硬约束；LTDA 合同可提升可融资性。

### 5.3 复核方法

```
第一步：找一手来源
  法规 → 官方公报/监管机构
  拍卖 → 交易所/TSO 公告
  装机 → TSO/统计机构年度报告

第二步：对齐单位与口径
  €/MW·年 vs €/MWh·年 vs 美元/kW·月
  铭牌 vs 并网 vs 降额 vs ELCC
  日前 vs 实时 vs 系统价

第三步：双源交叉
  至少一个 A 级 + 一个独立来源
  两个 C 级不能互相证明

第四步：回填
  升级 → 改级别与时点
  无法确认 → 保留“待核实”并写区间
  过期 → 标“历史值”，不删除
```
