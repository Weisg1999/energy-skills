# EMS 数据接口参考架构：设备、调度、市场与计量结算的契约（2026-11）

> 数据截止：2026-11-19｜定位：知识库模块（储能与 EMS·接口工程）
> 相关技能：[EMS 优化调度专家](../skills/ems-dispatch/SKILL.md)（数据契约）、[储能投资与运营专家](../skills/storage-investment-operations/SKILL.md)（结算对账）、[虚拟电厂专家](../skills/virtual-power-plant/SKILL.md)（聚合接口）
> 用途：回答"EMS 要接哪些接口、每个接口的契约字段是什么、为什么模型赚钱结算亏钱、计量点怎么映射、接口怎么随市场演进"五类问题。本文把 [储能 EMS](储能EMS优化调度-算法与工程-2026-11.md) §1.10 的接口观察与 §2.6 的数据契约升级为正式参考架构；具体字段、协议与考核口径以项目设计、现行标准与省级规则为准。

## 0. 一页看懂

### 0.1 三句话

- **接口是 EMS 的契约边界**：EMS 不是孤立算法，它通过四类接口（设备、调度、市场、计量结算）与外部交换数据。接口契约不清，算法再好也算错账。
- **同源同时标是铁律**：优化用的输入与结算用的数据必须同源、同时标、同计量点。否则"模型里赚钱、结算时亏钱"——这是 EMS 项目最常见的隐性亏损。
- **契约要最小可用**：定义了却未实现的字段必须删除，不能留作隐式约定。接口随市场演进（现货连续、联合出清、分布式入市），用观察指标触发复核，不是凭空预留。

### 0.2 关键数字与口径

| 概念 | 含义 | 来源与级别 |
|---|---|---|
| 四类接口 | 设备 / 调度 / 市场 / 计量结算 | 架构归纳，A |
| 同源同时标 | 优化输入与结算数据同源、同时标、同计量点 | 工程铁律，A |
| 计量点映射 | 站用表（PCS 侧）↔ 关口表（并网点）的精度/时标/拓扑映射 | 结算口径，A |
| 结算 MTU | 最小结算时间单元，多为 15 min | 各省结算细则，B |
| 能力包络 | 上报调度的可用功率/能量/SOC 范围 | 调度接口，A |
| 断网自治 | 与市场/云断开时按本地保底策略运行 | 工程原则，A |

> 本文所有算例为 **D 级合成数据**，电量、价格、损耗均为教学假设，不对应任何真实场站。

## 1. 接口全景

### 1.1 四类接口

```text
[设备层 BMS/PCS/热管理/消防]
        ↓ 设备接口（状态上行 / 设定值下行）
[站控层 EMS + SCADA + 协调控制器]
        ↓ 调度接口（AGC/AVC 令 / 执行回读 / 能力上报）
        ↓ 市场接口（价格穿透 / 申报 / 中标 / 考核）
[云/聚合层 多站管理 / VPP / 交易]
        ↓ 计量结算接口（关口表 / 对账 / 结算）
[市场层 调度机构 / 交易中心 / 辅助服务市场]
```

### 1.2 数据流闭环

市场出清/调度计划 → EMS 优化 → 功率与 SOC 计划 → 站控校验 → PCS 设定值 → 执行 → 计量遥测 → 结算考核 → 反馈修正模型。详见 [储能 EMS](储能EMS优化调度-算法与工程-2026-11.md) §2.2。

### 1.3 接口与分层的关系

设备接口在设备—站控边界，调度/市场接口在站控—云—市场边界，计量结算接口贯穿全链路。场站群集控的接口是单站接口的多站扩展，见 [场站群与集控 EMS 架构](场站群与集控EMS架构-2026-11.md)。

## 2. 设备接口契约

### 2.1 职责边界

| 系统 | 向 EMS 提供 | EMS 不得越权 |
|---|---|---|
| BMS | SOC、SOH、允许充放功率、单体电压/温度、告警等级 | 绕过 BMS 限值下发指令 |
| PCS | 实际 P/Q、可用功率、故障码、效率、故障穿越状态 | 下发超 PCS 能力的指令 |
| 热管理/消防 | 温度、烟感、可燃气体、阀状态 | 告警时继续充放 |
| 协调控制器 | 执行结果、跟踪偏差、联锁状态 | 跳过联锁直接控接触器 |

### 2.2 关键字段

- **状态上行**：实时 SOC/SOH、温度/压差、可用功率（BMS/PCS 限功率）、告警等级、并网点 P/Q/电压/频率；
- **设定值下行**：有功/无功设定点、充放功率限值、SOC 目标；
- **静态参数**：额定功率/能量、SOC 窗口、充放效率、自放电率、爬坡率、响应时间、温度降额表、PCS 效率曲线。

字段单位、来源、频率与缺失后果的完整契约见 [储能 EMS](储能EMS优化调度-算法与工程-2026-11.md) §2.6。点表与协议见 [SCADA](SCADA与电力监控数据链路-2026-11.md) §2、§3。

### 2.3 限值双保险

模型内约束 + 下发前独立校验，两处都过才允许执行。EMS 出计划，PCS/协调控制器做快速跟踪——不要把秒级控制塞进优化模型。

## 3. 调度接口契约

### 3.1 指令与回读

- **接收**：AGC/AVC 指令、计划曲线、调度令（来源/权限/范围校验）；
- **执行回读**：实际跟踪结果、偏差、响应时间；
- **能力上报**：可用功率/能量包络、SOC 范围、爬坡率、可用率。

### 3.2 涉网性能

AGC 调节速率/精度/响应时间、一次调频动作合格率、AVC 调节性能须按两个细则考核口径上报。考核公式与免考见 [并网运行考核与两个细则](并网运行考核与两个细则-2026-11.md)，涉网试验见 [并网测试与涉网验收实务清单](并网测试与涉网验收实务清单-2026-11.md)。

### 3.3 时延与时钟

调度接口闭环时延须满足控制周期要求，时钟统一（SOE/计量/调度时标同源）。时延与时间同步见 [SCADA](SCADA与电力监控数据链路-2026-11.md) §4。

---

## 4. 市场/交易接口契约

### 4.1 价格穿透

EMS 优化需要完整价格信号：分时/现货购售价、需量电价、调频容量/里程价/K 值、备用/爬坡价、容量补偿价与时长分母。价格口径与查证见 [电价](../skills/tariff-bill-optimization/SKILL.md) 与各省模块。

### 4.2 申报与中标

- **申报曲线**：日前/实时申报功率曲线，时域须覆盖结算 MTU；
- **中标曲线**：已中标容量与曲线，避免重复申报；
- **能力上报**：向市场申报可用能力包络。

申报与偏差结算的闭环见 [预测误差申报与 EMS 闭环](预测误差申报与EMS闭环-2026-11.md)。

### 4.3 结算时域覆盖

控制时域短于结算时域会"局部最优、全天结算变差"。预测、滚动优化与申报点数的时域必须覆盖结算 MTU（多为 15 min，部分市场更细）。

### 4.4 联合出清与 SOC 机会成本

能量与辅助服务联合出清时，SOC 机会成本从"事后核算"变成"实时定价"，调频/备用/能量在同一目标里排序。接口要能接收联合出清结果并实时反映 SOC 影子价格。

## 5. 计量结算接口契约

### 5.1 计量点是最易忽略的字段

EMS 优化用**站内量测**（PCS 侧站用表），结算用**关口表**（并网点）。两者精度、时标、拓扑不同，必须在契约里写清映射关系。

### 5.2 映射三要素

- **精度**：站用表与关口表精度等级差异；
- **时标**：采集/冻结时标对齐，15 min 冻结口径一致；
- **拓扑**：站用变损、线损、多计量点分摊的归属。

### 5.3 对账

结算电量与 EMS 计划电量逐时段对账，差异归因到计量映射/损耗/时标/考核。对账与收益归因见 [量化报价与交易风控](量化报价与交易风控-工程化-2026-11.md) §8。

## 6. 接口设计六原则

1. **同源同时标**：优化输入与结算数据同源、同时标、同计量点。
2. **优化与控制分离**：EMS 出计划，PCS/协调控制器快速跟踪。
3. **限值双保险**：模型约束 + 下发前独立校验。
4. **断网自治**：与市场/云断开时按本地保底策略运行（安全优先、避免越限），恢复后对账。
5. **指令可追溯**：每条计划/设定值/执行结果/越限告警可回放，支持事后归因。
6. **契约最小可用**：定义了却未实现的字段必须删除，不留隐式约定。

详见 [储能 EMS](储能EMS优化调度-算法与工程-2026-11.md) §2.4 五条架构经验（本文补"契约最小可用"为第六条）。

## 7. 接口演进观察清单

以下六件事会改变接口设计，均为 B/C 级判断，用观察指标触发复核（规则发布后 1 个月内更新），不是承诺。升级自 [储能 EMS](储能EMS优化调度-算法与工程-2026-11.md) §1.10。

| 变化 | 对接口契约的影响 | 观察指标 |
|---|---|---|
| 现货连续运行与更细结算粒度 | 预测/优化/申报时域覆盖结算 MTU | 本省现货连续运行公告、结算 MTU |
| 能量与辅助服务联合出清 | SOC 机会成本实时定价，多品种同目标排序 | 出清规则是否联合优化、实时市场上线 |
| 分布式/户用入市、VPP 扩大 | 站端退化为执行末梢，能力包络/基线/分解指令成主接口 | 分布式入市规则、聚合商注册结算规则 |
| 绿电直连/源网荷储/微网内部结算 | 内部结算价与外部市场价并行，按成员/合同拆分计量分摊 | 650/688 号后续细则、直连合同范式 |
| 负电价常态化与弃电成本 | 充电从套利变避免考核/消纳，合约分解与充电来源限制重算 | 本省负价小时数、现货限价与负价规则 |
| 容量补偿与辅助服务考核细化 | 可用率/K 值/恢复电量/考核周期进目标，容量资格动态约束 | 114 号文省级细则、辅助服务考核修订 |

## 8. 合成算例（D 级）：计量点映射错误的隐性亏损

### 8.1 场景

储能电站某日放电，PCS 侧站用表计放电 100 MWh，并网点关口表计 97 MWh（站用变损 + 线损约 3%，D 级假设）。结算按关口表，放电结算价 900 元/MWh。

### 8.2 两种算法的收益差

| 口径 | 计量电量（MWh） | 放电收益（元） |
|---|---|---|
| EMS 按站用表（错） | 100 | 90,000 |
| 结算按关口表（对） | 97 | 87,300 |
| 差额 | 3 | **2,700** |

### 8.3 读图

- EMS 若按站用表算收益，每日高估 2,700 元——"模型里赚钱、结算时亏钱"。
- 根源是计量点映射缺失：站用表 ≠ 关口表，差 3% 损耗。
- 修正：契约里写清计量点映射，EMS 优化与收益核算统一用关口表口径（或显式扣损耗）。
- 若再叠加时标错位（如站用表与关口表冻结时标差 15 min），偏差还会进入考核，亏损放大。

## 9. 常见错误（10 条）

1. 优化用站用表、结算用关口表，不写计量点映射。
2. 优化输入与结算数据不同时标，对账差归因不清。
3. 控制时域短于结算 MTU，局部最优全天亏。
4. 定义未实现的接口字段，留隐式约定。
5. EMS 绕过 BMS/PCS 限值下发指令。
6. 把秒级控制塞进优化模型，优化与控制不分。
7. 断网无自治策略，与市场断开即失控。
8. 指令不可追溯，事后无法归因。
9. 联合出清下仍事后核算 SOC 机会成本，多品种排序错。
10. 接口凭空预留，不用观察指标触发复核。
