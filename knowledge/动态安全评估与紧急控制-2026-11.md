## 0. 一页看懂

### 0.1 三句话

- **静态 N-1 只回答"断一条后潮流行不行"，动态安全还要回答"断开的过程中系统会不会失步、电压会不会崩、频率会不会掉穿"**。前者是代数问题，后者是微分—代数问题。
- **稳定不是"有没有解"，而是"故障切除后能不能回到可接受的运行点"**：功角要看摇摆曲线，电压要看无功支撑，频率要看功率缺额与惯量；三者时间尺度不同，判据也不同。
- **紧急控制是"用确定的代价换不确定的崩溃"**：切机、切负荷、直流调制、解列都必须提前设计、定期演练，不能等失稳了再临时决定。

### 0.2 关键概念

| 概念 | 含义 | 本文口径 |
|---|---|---|
| 静态安全 | N-1 后潮流、电压、限额是否越限 | 状态估计/安全分析模块负责 |
| 动态安全 | 故障及切除后的暂态过程是否稳定 | 本文重点，需时域或能量方法 |
| 功角稳定 | 同步机之间能否保持同步 | 分暂态（大扰动）与小干扰 |
| 电压稳定 | 负荷节点电压能否维持 | 分短期与长期，需无功/负荷动态 |
| 频率稳定 | 有功缺额后频率能否恢复 | 看 RoCoF、最低点、恢复时间 |
| 临界切除时间 | 故障后不失稳的最长切除时间 | CCT，本文用等面积与仿真互校 |
| 稳定裕度 | 当前方式离失稳还有多远 | 时间、能量、阻尼、功率多口径 |
| 预防控制 | 故障前就把方式调到安全区 | 发电计划、限额、N-1 校核 |
| 紧急控制 | 故障后按策略切机/切负荷/解列 | 安稳装置、UFLS/UVLS、RAS |
| 在线 DSA | 用实时方式做动态安全评估 | 依赖状态估计、模型与故障集 |

### 0.3 先记住四个数

SMIB 合成算例（100 MVA 基准，H=5 s，f0=50 Hz）：

- **初始功角 11.54°，切除角 84.55°，不稳定平衡角 156.42°**；等面积 CCT **0.3677 s**，时域仿真 CCT 同为 **0.3677 s**。
- **0.30 s 切除稳定**，最大功角 94.77°；**0.45 s 切除失稳**，约 0.529 s 越过不稳定平衡点。
- **理想化切机**把机械功率从 0.6 pu 降到 0.4 pu，CCT 延长到 **0.5084 s**，0.45 s 切除变为稳定。
- **RoCoF**：1000 MW 缺额、100 GW 系统、H=4 s，初始频率变化率 **−0.0625 Hz/s**；H 降到 2 s 时变为 **−0.125 Hz/s**。

> 口径提醒：CCT 和 RoCoF 都是合成算例的确定性结果，不是任何真实电网的稳定极限。真实 CCT 取决于故障类型、保护动作、模型参数、运行方式和稳定判据。

### 0.4 本文不做什么

- 不提供真实机组的 d/q 轴参数、励磁/调速模型、负荷模型或变流器控制参数；
- 不实现完整的多机暂态稳定、小干扰特征值、电压稳定连续潮流或电磁暂态仿真；
- 不替代调度机构的动态安全分析、安稳策略设计、定值整定或黑启动方案；
- 不把 SMIB 的等面积结论直接套到多机、直流送出、弱电网或构网型变流器场景；
- 不把"某次仿真通过"当作并网合规或投资安全的充分条件。

## 1. 从静态 N-1 到动态安全

### 1.1 静态 N-1 的边界

状态估计与安全分析回答的是：给定一个运行方式，断开一条线路/一台变压器后，剩余网络还有没有解、支路是否越限、电压是否在范围内、ATC 还剩多少。它是**代数校核**，把故障当成"断线后的新稳态"。

但真实故障有一个过程：

1. 故障发生，电压跌落，故障电流注入；
2. 保护动作，断路器熄弧，故障支路断开；
3. 发电机转子因功率不平衡开始加速/减速；
4. 励磁、调速、变流器控制、负荷、HVDC/FACTS 共同响应；
5. 系统要么回到同步运行，要么失步、电压崩溃、频率崩溃。

静态 N-1 只看第 3 步之后的一个平衡点，不看第 1—4 步的轨迹，也不保证这个平衡点能被到达。**"有解"不等于"可达"，"不越限"不等于"不失稳"。**

### 1.2 时间尺度

| 现象 | 典型时间尺度 | 主要状态 | 常用工具 |
|---|---|---|---|
| 电磁暂态/操作过电压 | 微秒—毫秒 | 电流、磁链、行波 | EMT 仿真 |
| 继电保护与断路器 | 毫秒—几十毫秒 | 开关状态、保护逻辑 | 保护仿真、录波 |
| 暂态功角稳定 | 0.1—10 s | 转子角、转速 | 机电暂态仿真、能量函数 |
| 小干扰振荡 | 0.1—10 Hz | 功角/控制模态 | 特征值、阻抗/频率扫描 |
| 短期电压稳定 | 0.1—10 s | 感应电动机、HVDC、IBR | 机电—电压混合仿真 |
| 长期电压稳定 | 数十秒—数分钟 | 变压器分接头、AGC、负荷恢复 | 中长期仿真、连续潮流 |
| 频率稳定 | 数秒—数分钟 | 频率、惯量、调频 | 频率仿真、RoCoF 估算 |
| 热稳定 | 数分钟—数小时 | 设备温度、载流 | 热平衡计算 |

同一场故障可能同时触发多个问题：短路期间电压跌落导致新能源脱网，新能源脱网造成频率缺额，频率下降又触发低频减载。**动态安全分析必须能跨时间尺度串联事件，而不是每个问题单独看。**

### 1.3 动态安全评估的输出

一次可用的 DSA 至少应回答：

- 在哪些故障、哪些运行方式下不稳定？
- 不稳定形态是什么：功角失步、电压崩溃、频率崩溃、控制器振荡？
- 稳定裕度多大：CCT、能量裕度、阻尼比、最低电压、频率最低点？
- 哪些元件/场站是关键：临界机组、关键断面、薄弱母线？
- 需要什么预防/紧急控制：限额、切机、切负荷、解列、直流调制？
- 结论对模型、参数、故障清除时间有多敏感？

只给一句"通过/不通过"，不足以支撑运行或投资决策。

### 1.4 规划态、运行态与在线 DSA

| 场景 | 数据基础 | 时间预算 | 输出用途 |
|---|---|---|---|
| 规划态 | 规划网架、典型方式、设计参数 | 天—周 | 网架加强、设备选型、稳定极限 |
| 日前/方式安排 | 预测负荷、检修计划、开机方式 | 小时 | 稳定限额、预防控制、开机约束 |
| 在线 DSA | 状态估计断面、实时拓扑、模型库 | 分钟级 | 预警、辅助决策、紧急控制预置 |
| 事后复盘 | 录波、PMU、SOE、保护动作 | 小时—天 | 模型校正、策略改进、责任分析 |

在线 DSA 的最大瓶颈通常不是算法，而是**模型和数据的可信度**：状态估计错了、模型参数过期、故障集漏了，算得再快也没用。状态估计模块见[《状态估计与安全分析》](状态估计与安全分析-2026-11.md)。

## 2. 稳定分类与判据

### 2.1 四类稳定

GB 38755《电力系统安全稳定导则》把稳定问题分为功角稳定、电压稳定、频率稳定三类；工程上还会单独校核设备热稳定。工程上常把功角稳定再分为暂态（大扰动）和小干扰（动态）稳定。

| 类型 | 扰动性质 | 核心问题 | 典型判据 |
|---|---|---|---|
| 暂态功角稳定 | 大扰动（短路、断线、切机） | 第一摇摆能否保持同步 | 摇摆曲线、CCT、能量裕度 |
| 小干扰功角稳定 | 小扰动 | 振荡模态是否衰减 | 阻尼比、特征值、阻抗判据 |
| 电压稳定 | 大/小扰动、负荷增长 | 电压能否维持 | P-V/Q-V 裕度、最低电压与持续时间 |
| 频率稳定 | 大功率缺额/过剩 | 频率能否恢复到允许范围 | RoCoF、最低/最高频率、恢复时间 |
| 热稳定 | 过载 | 设备是否超温 | 载流/温度限值、持续时间 |

### 2.2 稳定判据不是一条线

"稳定/不稳定"在工程上是带时间和幅值容差的概念：

- **功角**：通常要求故障后转子角不超过某个阈值、振荡在若干秒内衰减、机组间最大角差可控；具体阈值按导则和调度规程。
- **电压**：不只看最低电压，还看低于某电压的持续时间、恢复速度、是否引发电动机堵转或新能源脱网。
- **频率**：不只看最低频率，还看 RoCoF、低于 47 Hz 的持续时间、恢复时间、是否触发连锁脱网。
- **小干扰**：阻尼比要留裕度，不能"刚好大于零"；弱电网下阻尼随运行点变化。

### 2.3 稳定裕度的四种口径

| 口径 | 定义 | 优点 | 局限 |
|---|---|---|---|
| 时间裕度 | CCT − 实际切除时间 | 直观，便于保护配合 | 只适用于暂态首摆 |
| 能量裕度 | 临界能量 − 故障清除时能量 | 可量化，适合灵敏度 | 依赖模型与能量函数构造 |
| 阻尼裕度 | 模态阻尼比 − 门槛 | 适合小干扰 | 非线性大扰动下不充分 |
| 功率/限额裕度 | 稳定极限 − 当前传输功率 | 便于运行和交易 | 需要大量离线计算 |

**不同口径不能混用**：CCT 裕度大不代表阻尼好，阻尼好不代表电压稳，电压稳不代表频率稳。

### 2.4 与三道防线的关系

[《电力系统通识 E》](故障保护与安全防御-2026-11.md)讲过三道防线：

- 第一道：快速切除故障，保持稳定；
- 第二道：稳定破坏时切机、切负荷、直流调制、解列；
- 第三道：失步解列、低频/低压减载、黑启动。

DSA 的作用是**判断第一道够不够、第二道什么时候动、第三道是否兜得住**。它不是第四道防线，而是三道防线的"体检和预演"。

## 3. 暂态功角稳定：等面积与 CCT

### 3.1 单机无穷大模型

把一台同步机经电抗接到无穷大母线，忽略电阻、阻尼和调压器动态：

```text
M d²δ/dt² = Pm − Pe
Pe = (E' U / X) sinδ
M = 2H / ωs，ωs = 2π f0
```

- `δ`：转子功角；
- `M`：惯性时间常数（s²/rad）；
- `H`：惯性常数（s）；
- `Pm`：机械功率；
- `Pe`：电磁功率；
- `E'`：机内电势；
- `U`：无穷大母线电压；
- `X`：机端到无穷大的等值电抗。

这个模型不能描述多机、励磁、调速、阻尼和变流器，但它能把"加速面积 = 减速面积"讲清楚。

### 3.2 等面积定则

故障期间，电磁功率下降（严重时接近零），机械功率大于电磁功率，转子加速，形成**加速面积**：

```text
A_acc = ∫(Pm − Pe_fault) dδ
```

故障切除后，电磁功率恢复，若转子角超过新的平衡点，电磁功率大于机械功率，形成**减速面积**：

```text
A_dec = ∫(Pe_post − Pm) dδ
```

稳定的临界条件是加速面积等于减速面积；此时对应的切除角 `δc` 给出临界切除时间：

```text
t_cct = sqrt( 2 M (δc − δ0) / (Pm − Pe_fault) )
```

### 3.3 算例：0.3677 s 从哪来

合成参数：

| 参数 | 数值 |
|---|---|
| H | 5 s |
| f0 | 50 Hz |
| Pm（故障前/故障中/故障后） | 0.6 / 0.6 / 0.6 pu |
| E' | 1.2 pu |
| U | 1.0 pu |
| X（故障前/故障后） | 0.4 / 0.8 pu |
| 故障期间电磁功率 | 0 pu |
| 阻尼 | 0 |

计算链：

```text
ωs = 2π × 50 = 314.159 rad/s
M = 2 × 5 / 314.159 = 0.031831 s²
Pmax_pre = 1.2 × 1.0 / 0.4 = 3.0 pu
δ0 = asin(0.6 / 3.0) = 11.537°
Pmax_post = 1.2 × 1.0 / 0.8 = 1.5 pu
δsep = asin(0.6 / 1.5) = 23.578°
δmax = 180° − 23.578° = 156.422°
解等面积方程：δc = 84.550°
t_cct = sqrt(2 × 0.031831 × (1.4757 − 0.2014) / 0.6) = 0.3677 s
```

时域仿真用 RK4（步长 1 ms）得到同一个 CCT；0.30 s 切除时最大功角 94.77°，0.45 s 切除时在约 0.529 s 越过不稳定平衡点。**等面积给解析上界，时域仿真验证轨迹和后续摇摆**，两者应互相校核，而不是只信一个。

### 3.4 多机系统为什么不能直接套

多机系统里：

- 每台机的等值电抗和机内电势随网络拓扑、出力、励磁变化；
- 故障期间多台机同时加速，但加速程度不同；
- 关键机组/临界割集决定系统失稳模式，不是"每台机各自算 CCT"；
- 励磁、调速、PSS、负荷、HVDC/FACTS 都会改变轨迹；
- 失稳可能是多摆、模式切换或控制器引发，不是单摆。

工程上用**时域仿真 + 能量函数/EEAC + 特征值/阻抗分析**组合，不用单机公式硬套。

### 3.5 故障切除时间不是常数

实际切除时间由保护动作、断路器熄弧、失灵保护、通信和开关性能决定：

- 近端故障电流大，保护可能更快，但 CT 饱和、暂态分量会影响；
- 断路器开断需要几个周波，故障电流过零熄弧；
- 断路器失灵时由失灵保护切除相邻开关，时间更长；
- 单相重合闸有去游离时间，重合于永久故障会二次冲击；
- 新能源场站的 FRT 要求可能与重合闸冲突。

**CCT 必须和"实际可能的最长切除时间"比，而不是和铭牌上的保护动作时间比。** 保护与重合闸的基本原理见[《电力系统通识 E》](故障保护与安全防御-2026-11.md)。

### 3.6 新能源让暂态稳定变在哪

同步机的短路电流由励磁电动势和电枢反应决定，故障初期有很大的次暂态电流，天然提供同步力矩。变流器并网的新能源：

- 故障电流被控制器限流，通常只有额定电流的 1.1—1.5 倍；
- 没有物理转子，不提供传统惯量；
- 锁相环（PLL）与电网耦合，弱网下可能失锁或振荡；
- 控制模式在故障期间切换（限流、无功优先、负序抑制），动态特性随策略变化；
- 构网型（GFM）变流器可以模拟电压源和惯量，但受能量、限流和过流能力约束。

因此，"新能源渗透率高的系统暂态稳定更好/更差"不能一概而论：**同步机被替换会减少惯量和短路容量，但构网型控制、快速无功支撑和可控切机也可能改善特定场景的稳定性**。必须做场景化仿真。

| 特性 | 同步机 | 跟网型变流器 | 构网型变流器 |
|---|---|---|---|
| 故障电流 | 大，次暂态可达数倍额定 | 限流，约 1.1—1.5 倍额定 | 限流，但可提供电压源行为 |
| 惯量 | 物理惯量 | 无，依赖控制 | 可模拟惯量 |
| 同步机制 | 转子摇摆 | PLL/控制同步 | 功率同步/虚拟同步 |
| 失稳形态 | 功角失步 | PLL 失锁、控制振荡、脱网 | 限流饱和、能量耗尽、模式切换 |
| 等面积适用性 | 单机近似可用 | 不直接适用 | 不直接适用 |

## 4. 时域仿真与在线 DSA

### 4.1 时域仿真做什么

时域仿真把"故障发生—保护动作—网络变化—控制响应"按时间积分，输出：

- 发电机功角、转速、电磁功率、机端电压；
- 母线电压、支路潮流；
- 励磁、调速、PSS、HVDC/FACTS、IBR 控制状态；
- 保护/安稳动作、开关变位；
- 频率、RoCoF、最低电压。

它是动态安全的"金标准"，但前提是模型、参数、事件序列正确。

### 4.2 模型清单

| 元件 | 至少需要的模型 | 常见问题 |
|---|---|---|
| 同步机 | d/q 轴暂态/次暂态、励磁、调速、PSS | 参数过期、饱和/限幅缺失 |
| 新能源场站 | 变流器控制、FRT、限流、保护、场站控制器 | 厂家模型黑箱、版本不一致 |
| 负荷 | 静态 ZIP + 感应电动机比例 | 负荷构成不清，动态比例拍脑袋 |
| HVDC/FACTS | 换流器控制、闭锁、调制 | 控制模式和保护逻辑漏项 |
| 变压器 | 分接头、饱和、接线 | 分接头位置与运行方式不符 |
| 线路 | 序参数、互感、串联补偿 | 零序参数、弧光电阻忽略 |
| 保护/安稳 | 动作逻辑、延时、失灵 | 只做"理想切除"，不做拒动/误动 |

### 4.3 故障集与场景

可信故障集通常包括：

- 三相短路、单相接地、相间故障；
- 线路单相/三相跳闸，单相重合闸；
- 变压器故障、母线故障；
- 发电机/场站全停、直流单极/双极闭锁；
- 关键断面 N-1、N-1-1；
- 新能源大规模脱网、SVG 退出；
- 保护拒动、断路器失灵、安稳拒动。

故障集不是越多越好，要按电压等级、拓扑、历史故障率、保护配置和规则要求筛选，并记录**为什么选/为什么不选**。

### 4.4 在线 DSA 的工程链

```text
状态估计断面
   ↓ 拓扑、注入、电压
模型库/参数库
   ↓ 发电机、负荷、IBR、直流
故障集/预想方式
   ↓ N-1、N-1-1、极端场景
时域仿真/能量函数/特征值
   ↓ 稳定裕度、越限、关键元件
预警/辅助决策
   ↓ 限额、预防控制、紧急控制预置
调度员/安稳装置
```

时间预算通常只有几分钟，所以在线 DSA 会做：

- 故障筛选（用指标先排除明显安全/明显失稳的场景）；
- 并行计算；
- 降阶/同调等值；
- 机器学习代理模型（只做筛选，不做最终判据）；
- 只对关键场景做全时域仿真。

### 4.5 模型校验

模型错了，DSA 只是"精确地算错"。校验数据来源：

- PMU/故障录波：功角、频率、电压、电流；
- SCADA：出力、电压、开关状态；
- 保护/安稳动作报告；
- 并网检测报告：FRT、AGC/AVC、一次调频、阻抗扫描；
- 厂家型式试验：变流器限流、过流能力、控制响应。

校验不是"调参数让曲线好看"，而是核对**模型结构、参数来源、初始化、事件序列和限幅/保护逻辑**。并网测试清单见[《并网测试与涉网验收实务清单》](并网测试与涉网验收实务清单-2026-11.md)。

### 4.6 数值问题

- 积分步长：机电暂态常用毫秒级，开关事件附近要减小步长；
- 初始化：潮流解与动态模型初始状态必须一致；
- 事件处理：保护/开关动作要精确插值，不能"跨步"；
- 刚性：励磁、直流、变流器控制时间常数差异大，需隐式/变步长算法；
- 限幅与饱和：励磁、调速、变流器电流限幅必须建模；
- 数值振荡：网络切换可能产生非物理尖峰，需 snubber 或插值；
- 收敛失败：不是"稳定"，要标记为无效计算。

## 5. 电压稳定与频率稳定

### 5.1 电压稳定不是"电压低一点"

电压稳定问题分：

- **短期电压稳定**：感应电动机堵转、HVDC 换相失败、新能源低电压脱网，时间 0.1—10 s；
- **长期电压稳定**：负荷恢复、变压器分接头动作、AGC 响应、无功限值，时间数十秒到数分钟；
- **静态电压稳定**：P-V/Q-V 曲线鼻点、无功裕度，给运行限额提供参考。

常见误区：

- 只看当前电压值，不看负荷增长方向和裕度；
- 忽略电动机负荷的动态，把负荷当恒阻抗；
- 忽略变压器分接头的负调压效应；
- 忽略新能源在低电压下的电流限幅和无功能力；
- 把无功补偿当成"越多越好"，不看动态响应和过电压。

### 5.2 P-V/Q-V 与连续潮流

P-V 曲线描述传输功率与电压的关系，鼻点对应静态电压稳定极限；Q-V 曲线描述无功注入与电压的关系。连续潮流可以跟踪鼻点和裕度，但它假设准稳态，不替代动态仿真。

工程上要给出：

- 当前方式的无功裕度；
- 关键母线/断面的电压稳定极限；
- N-1 后的裕度变化；
- 低压减载/无功紧急投入的门槛和顺序。

### 5.3 频率稳定的三个指标

| 指标 | 含义 | 主要影响因素 |
|---|---|---|
| RoCoF | 初始频率变化率 | 功率缺额、惯量、系统规模 |
| 频率最低点 | 扰动后频率跌到多低 | 一次调频、负荷频率特性、UFLS |
| 恢复时间 | 频率回到允许范围多快 | 二次调频、备用、机组爬坡 |

RoCoF 的简化估算：

```text
RoCoF ≈ − f0 × ΔP / (2 H S_base)
```

它只描述**初始斜率**，不代表最低点。惯量低、缺额大时 RoCoF 大，但如果有快速一次调频和足够备用，最低点仍可能可控；反之，RoCoF 不大但调频慢，也可能跌穿。

### 5.4 低频减载与高频切机

低频减载（UFLS）按频率分轮切负荷，目标是把频率拉回允许范围，同时避免过切导致高频。高频切机在功率过剩时切除机组。两者都要与：

- 机组低频/高频保护；
- 新能源 FRT 与频率保护；
- HVDC 频率限制控制；
- 解列装置；
- 储能/需求响应的快速响应；

协调。GB/T 40596《电力系统自动低频减负荷技术规定》和 GB/T 40588《电力系统自动低压减负荷技术规定》给出了配置与整定的基本原则；具体轮次、门槛、延时和切负荷量以调度方案为准。低频减载的基本逻辑见[《电力系统通识 E》](故障保护与安全防御-2026-11.md)，惯量与灵活性市场见[《频率、惯量与灵活性供需》](频率惯量与灵活性供需-2026-11.md)。

### 5.5 电压/频率/功角的耦合

三者不是独立的：

- 电压跌落会导致新能源脱网，造成功率和频率缺额；
- 频率下降会导致火电辅机失速、出力下降，进一步恶化电压；
- 无功不足会导致电压崩溃，线路损耗增加，加剧有功缺额；
- 切机可能提升频率，但减少无功支撑，恶化电压；
- 切负荷可能保频率，但突然甩负荷会引发过电压。

**紧急控制必须做联合仿真**，不能"频率问题只切负荷、电压问题只投电容"。

## 6. 紧急控制与三道防线

### 6.1 紧急控制的工具箱

| 措施 | 作用 | 代价 | 典型场景 |
|---|---|---|---|
| 切机 | 减少过剩有功，抑制加速 | 损失发电、可能影响电压 | 送端过剩、高频、暂态加速 |
| 快关汽门 | 快速降低机械功率 | 锅炉/汽机应力、恢复慢 | 火电近端故障 |
| 制动电阻 | 消耗过剩有功，抑制加速 | 设备投资、热容量 | 水电/大机组暂态稳定 |
| 直流功率调制 | 快速调节直流功率 | 依赖直流通道、通信 | 交直流混联、区域振荡 |
| 切负荷 | 减少缺额，保频率/电压 | 用户停电、经济代价 | 受端缺额、低频/低压 |
| 解列 | 把失步系统分成同步岛 | 供电中断、频率/电压再平衡 | 失步、连锁故障 |
| 无功紧急投入 | 支撑电压 | 设备容量、过电压 | 电压跌落、HVDC 换相失败 |
| 新能源快速降功率 | 减少过剩/支撑频率 | 弃风弃光、考核 | 高频、过载、稳定极限 |

### 6.2 事件驱动与响应驱动

- **事件驱动**：检测到故障/开关变位/直流闭锁，按预置策略动作；速度快，但依赖故障识别和通信。
- **响应驱动**：检测到频率、电压、功角、功率越限，按反馈量动作；适应性好，但响应慢、定值难调。
- **混合**：事件前馈 + 响应反馈，工程上最常见。

安稳装置（稳控系统）通常由主站、子站、执行站组成，按"故障场景—控制措施"表动作。GB/T 40587《电力系统安全稳定控制系统技术规范》规定了系统（装置）的一般要求、功能配置、技术要求和二次回路/网络安全要求；GB/T 26399《电力系统安全稳定控制技术导则》给出策略设计原则。

### 6.3 策略表不是"if 故障 then 切机"

一张可执行的策略表至少包含：

- 故障类型、故障元件、故障位置、故障切除时间；
- 运行方式/断面潮流范围；
- 动作判据（电气量、开关量、时间窗）；
- 控制对象、控制量、动作顺序、延时；
- 拒动/误动/通信中断的兜底；
- 与保护、重合闸、FRT、AGC/AVC、UFLS/UVLS 的配合；
- 定值版本、审批、执行日期、复核记录。

### 6.4 紧急控制的代价与风险

- 切机/切负荷过多会造成频率/电压过调，甚至引发新的稳定问题；
- 解列后各岛功率不平衡，可能频率崩溃；
- 直流调制受限于换流站能力和通信延时；
- 新能源快速降功率会造成弃电和考核；
- 安稳装置本身可能拒动/误动，需要独立校核和定期试验；
- 策略表基于离线计算，运行方式变化后可能失效。

**紧急控制不是"多切一点更安全"**：过切同样会失稳，只是换了一种形态。

### 6.5 与保护、重合闸、FRT 的配合

- 保护要先于紧急控制动作，但紧急控制不能等保护"确认很久"；
- 重合闸于永久故障会二次冲击，安稳策略要识别；
- 新能源 FRT 要求不脱网，但紧急控制可能要求其降功率/脱网，两者要分场景；
- 低频减载与新能源频率保护可能同时动作，需避免重复切除；
- 解列点要与保护定值、安稳策略、黑启动路径一致。

### 6.6 演练与维护

- 定期做稳控装置整组传动试验；
- 核对定值与运行方式；
- 检查通信通道、电源、GPS/北斗对时；
- 演练"装置拒动、通信中断、策略表过期"；
- 故障后复盘保护/安稳动作，更新模型和策略；
- 保留录波、SOE、动作报告，支撑责任分析和模型校正。

## 7. D 级合成算例：SMIB 的 CCT、切机与 RoCoF

> 本算例为合成数据，仅用于演示计算链与判据，不对应任何真实机组、电网或故障。

### 7.1 场景

| 项目 | 数值 |
|---|---|
| 基准容量 | 100 MVA |
| 惯性常数 H | 5 s |
| 额定频率 | 50 Hz |
| 故障前机械功率 | 0.6 pu |
| 故障中机械功率 | 0.6 pu |
| 故障后机械功率 | 0.6 pu |
| 机内电势 E' | 1.2 pu |
| 无穷大母线电压 U | 1.0 pu |
| 故障前电抗 | 0.4 pu |
| 故障后电抗 | 0.8 pu |
| 故障期间电磁功率 | 0 pu |
| 阻尼 | 0 |

### 7.2 等面积结果

| 量 | 数值 |
|---|---:|
| 初始功角 δ0 | 11.537° |
| 切除角 δc | 84.550° |
| 不稳定平衡角 δmax | 156.422° |
| 加速面积 | 0.7646 pu·rad |
| 减速面积 | 0.7646 pu·rad |
| 等面积 CCT | 0.3677 s |
| 仿真 CCT | 0.3677 s |

### 7.3 两种切除时间

| 切除时间 | 结果 | 最大功角 | 说明 |
|---:|---|---:|---|
| 0.30 s | 稳定 | 94.77° | 有裕度，振荡逐步衰减（无阻尼时等幅） |
| 0.45 s | 失稳 | 越过 156.42° | 约 0.529 s 失去同步 |

### 7.4 理想化切机

把故障中和故障后的机械功率都降到 0.4 pu（假设切机瞬时完成、无延时、无功率冲击）：

```text
δsep = asin(0.4 / 1.5) = 15.466°
δmax = 180° − 15.466° = 164.534°
δc = 104.579°
t_cct = 0.5084 s
```

0.45 s 切除此时变为稳定，最大功角 111.66°。这说明切机可以扩大稳定边界，但**这是理想化上界**：真实切机有延时、通信、机组选择、功率冲击和频率/电压副作用，不能直接把这个 0.5084 s 当运行定值。

### 7.5 RoCoF

```text
ΔP = 1000 MW
S_base = 100000 MVA
H = 4 s
f0 = 50 Hz
RoCoF = −50 × 1000 / (2 × 4 × 100000) = −0.0625 Hz/s
```

| H（s） | RoCoF（Hz/s） |
|---:|---:|
| 2 | −0.1250 |
| 4 | −0.0625 |
| 6 | −0.0417 |

这个数只说明初始斜率：同样 1000 MW 缺额，H 减半，RoCoF 翻倍。真实频率最低点还要看一次调频、负荷频率特性、UFLS 和机组/新能源的响应。

### 7.6 这个算例说明什么

- 等面积和时域仿真可以互相校核；
- CCT 对切除时间非常敏感，0.30 s 与 0.45 s 是两个世界；
- 切机可以扩展 CCT，但代价和副作用必须建模；
- RoCoF 与惯量成反比，但不等同于频率最低点；
- 稳定裕度要用"实际切除时间/实际缺额"去比，不是拿铭牌值。

### 7.7 这个算例不说明什么

- 不代表多机系统、励磁/调速、负荷动态或 HVDC/FACTS 的影响；
- 不覆盖新能源变流器的限流、PLL、FRT 和构网型控制；
- 不给出真实 CCT、切机量、低频减载定值或稳控策略；
- 不覆盖电压稳定、频率最低点、小干扰振荡或电磁暂态；
- 不能用于并网合规、设备选型或投资决策。

## 8. 对交易、投资与运营的含义

### 8.1 交易：动态限额会变成价格和偏差

- 稳定限额降低时，断面阻塞加剧，节点价差扩大；
- 新能源大发、惯量低时，动态安全约束可能比静态 N-1 更紧；
- 故障/脱网会造成价格尖峰、负价和偏差考核；
- 交易员要关注调度发布的稳定限额、检修、开机方式和天气，不只看历史价格；
- 故障后的结算差异要能追溯到调度指令、计量、保护/安稳动作记录。

### 8.2 投资：稳定支撑有价值，但不是免费

- 构网型储能、同步调相机、SVG、快速切机可以提升稳定极限，但增加投资和运行成本；
- 储能提供惯量/一次调频/电压支撑的收益取决于市场规则和并网要求；
- 新能源配储是否能替代同步机，要做场景化稳定计算，不能只看容量比例；
- 并网测试、模型校验、稳控改造、通信通道都是投决成本；
- 稳定约束可能导致弃风弃光、可用率下降和考核罚款，要进现金流和风险模型。

### 8.3 运营：模型、定值和演练是"沉默资产"

- 模型参数要跟设备改造、控制软件升级同步；
- 稳控定值要有版本、审批、执行、复核；
- 定期做整组传动和通信测试；
- 录波、PMU、SOE 要保存并用于复盘；
- 每次故障后评价保护/安稳动作，不只看"有没有跳闸"；
- 运行方式变化后，策略表和限额要重新校核。

### 8.4 数据与 AI 的边界

AI 可以做故障筛选、稳定裕度预测、模型参数辨识、异常检测，但：

- 训练数据必须覆盖真实故障形态，不能只用仿真数据；
- 代理模型只能做筛选，最终判据要由仿真/规程确认；
- 保护和安全稳定控制是确定性安全系统，不能由 AI 实时替代；
- 模型可解释性和审计要求高，不能"黑箱说稳定"。

## 9. 常见错误（10 条）

1. **把静态 N-1 当动态安全**：N-1 只检查故障后的平衡点，不检查能否到达、过程是否失稳。
2. **用铭牌切除时间算 CCT**：实际切除时间包含保护、断路器、失灵、通信延时，必须用可能的最长切除时间校核。
3. **只看首摆，不看多摆**：有些系统首摆稳定，后续振荡或控制器交互才失稳。
4. **把单机等面积套多机**：多机需要关键机组/割集、时域仿真或能量函数，不能每台机各算各的。
5. **忽略负荷动态**：感应电动机、温控负荷、LTC 会显著改变电压和功角轨迹。
6. **新能源只用恒功率源模型**：限流、PLL、FRT、负序控制、模式切换都会影响稳定，必须用厂家/检测模型。
7. **只看 RoCoF，不看频率最低点**：RoCoF 是初始斜率，最低点取决于调频、备用、负荷特性和 UFLS。
8. **紧急控制"多切一点更安全"**：过切会导致高频、过电压、解列后功率不平衡，同样会失稳。
9. **策略表不随运行方式更新**：检修、开机方式、新能源出力变化后，离线策略可能失效。
10. **只演成功路径**：不演练装置拒动、通信中断、保护误动、重合于永久故障，方案就不可靠。

## 12. 速查

### 12.1 六个公式

```text
M = 2H / ωs
M d²δ/dt² = Pm − Pe
Pe = (E' U / X) sinδ
等面积：A_acc = A_dec
t_cct = sqrt( 2 M (δc − δ0) / (Pm − Pe_fault) )
RoCoF ≈ − f0 ΔP / (2 H S_base)
```

### 12.2 五个必问

1. 这次 DSA 用的是哪个断面、哪版模型、哪些故障，故障集为什么这么选？
2. 实际可能的最长切除时间是多少，CCT 裕度还剩多少？
3. 失稳形态是功角、电压、频率还是控制器振荡，判据和门槛是什么？
4. 紧急控制切什么、切多少、什么时候切，过切/拒动/通信中断怎么办？
5. 结论对模型参数、新能源出力、开机方式和负荷构成有多敏感？

### 12.3 工具

```bash
# 在 skills/ems-dispatch/tools 下
python dynamics.py                 # 打印 SMIB 等面积、仿真、切机与 RoCoF
python dynamics.py --json          # JSON 输出
python selftest.py                 # 断言本文数字
```

`dynamics.py` 只做 SMIB 等面积、RK4 时域仿真、理想化切机和 RoCoF 的确定性演示，不是生产级动态安全分析程序。
