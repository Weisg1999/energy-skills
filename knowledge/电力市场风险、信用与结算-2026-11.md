## 0. 一页看懂

### 0.1 一条主线

```
   风险识别          信用评价          履约保障          偏差考核          结算             违约/退出         用户承接
      │                 │                 │                 │                 │                 │                 │
  内部/外部          A/B/C/D          保函/保险/现金     合同 vs 实际      日清月结          预警→暂停→注销     保底售电
  重大/一般          季度+动态         逐日盯市          免考/考核         5/8/10 工作日      保函执行          电网承接
  紧急/非紧急        激励/约束         补缴/限额          责任分摊          异议/追退补        合同终止/转让      价格与选择
      └─────────────────┴─────────────────┴─────────────────┴─────────────────┴─────────────────┴─────────────────┘
                         制度链路的终点不是"罚钱"，而是"让交易可预期、让用户不断电"
```

- **风险侧回答"会出什么事"**：市场内部的不正当竞争、合同违约、价格异常、机制漏洞；外部的供需失衡、系统故障、舆情。
- **信用侧回答"谁靠谱"**：把公共信用、财务信息、交易行为合成 A/B/C/D，按季度评价、动态调整，结果全国通用。
- **担保侧回答"拿什么兜底"**：履约保函、保险、现金保证金，按预计年售电量计收，逐日盯市、不足补缴。
- **偏差侧回答"说好的电没发/没用怎么办"**：合同电量与实际上网/用电量的差值，按省规则考核或按现货结算。
- **结算侧回答"钱怎么算、什么时候到"**：日清月结、统一时限、异议与追退补、争议调解与仲裁。
- **退出侧回答"公司倒了用户怎么办"**：暂停交易、执行保函、合同终止或转让、业务地减少/注销、保底售电承接。

### 0.3 十个判断

1. **风险防控正在从"出事再管"转向"预案 + 阈值 + 分级"**：2026-09-30 的风险防控草案把风险分成内部/外部两大类，再按影响和紧急程度分级，要求市场运营机构编预案、定期演练、监测预警、分类处置。
2. **信用评价不是"评先进"，而是"定成本"**：A 级可以适当降低履约保障、优先保底售电；C/D 级要提高保障额度、增量不得用保险、提高核验频次。信用直接变成资金占用和交易机会。
3. **履约保障的核心变化是"按生意大小收、按天盯"**：从"按历史电量静态预缴"转向"按预计年售电量 × 系数、逐日盯市、不足补缴"，售电公司的规模扩张必须用真金白银兜底。
4. **保函、保险、现金不是一回事**：保函见索即付，保险优先赔付但有除外责任和额度限制；低信用主体可能被禁止用保险提交增量保障。
5. **偏差考核没有全国统一阈值**：1656 号只给结算原则，具体免考区间、考核价格、责任分摊在省级细则；拿"±5%"套全国会出错。
6. **结算时效已经全国统一到"5/8/10"**：核对版第 5 个工作日、正式版第 8 个、账单第 10 个；异议 15 个工作日内提出，5 个工作日内确认，属实的下一周期追退补。
7. **"不平衡资金池"被明确禁止**：结算项目要独立记录、分类疏导，不能用一个池子把盈亏混在一起。
8. **售电公司退出不等于用户断电**：用户会被转为保底售电/代理购电，但价格、合同、发票、偏差责任都会变；退出前的合同终止与损失承担是高频争议。
9. **2026 年零售侧的真实风险是批零倒挂**：现货价格上行、固定分时套餐退场、系统运行费上升，靠价差套利的模式在收缩；低价抢量、阴阳合同、线下返利会被重点整治。
10. **草案不是现行法**：2026 年三份文件（售电办法、风险防控办法、信用评价指引）都还在征求意见，正式稿可能调整阈值、系数、处置梯度；做交易决策必须标注"草案口径"。

## 1. 边界：四种风险、三条链路

### 1.1 四种"风险"不要混

| 说法 | 真正含义 | 典型问题 | 主要归属 |
|---|---|---|---|
| 市场风险 | 价格、电量、供需波动带来的损益不确定性 | 现货价格飙升、负电价、偏差电量 | 交易/量化 |
| 信用风险 | 对手方不履约、不付款、不交货的可能性 | 售电公司欠费、发电企业少发、用户拖欠 | 本文 |
| 结算风险 | 计量、规则、时限、对账、资金链导致的收付不确定性 | 结算依据争议、发票、追退补、保证金不足 | 本文 |
| 合规风险 | 违反市场规则、监管规定、合同约定的责任 | 串通报价、虚假注册、阴阳合同、线下返利 | 本文 + 交易技能 |

- **市场风险可以用限额、对冲、组合管理来控**；信用风险靠准入、担保、信用评价、合同条款来控；结算风险靠流程、时限、对账、异议机制来控。
- **四类风险会互相转化**：价格持续单边上涨 → 售电公司亏损 → 保证金不足 → 违约 → 用户转保底 → 结算争议。只盯一个环节会漏掉链条。
- **"风险防控"在监管文件里是狭义的**：2026 风险防控草案管的是市场运行风险（内外部），不等同于企业内部的全面风险管理（ERM）。

### 1.2 三条链路

```
链路 A：交易前
  注册准入 → 信用评价 → 履约保障 → 交易限额 → 合同签订

链路 B：交易中
  申报 → 出清 → 偏差 → 监测预警 → 风险处置（调整/暂停/中止）

链路 C：交易后
  计量 → 结算依据 → 电费账单 → 收付 → 异议/追退补 → 争议解决
```

- **交易前**的重点是"有没有资格、有没有钱、能做多大"；**交易中**的重点是"有没有异常、要不要干预"；**交易后**的重点是"算得对不对、钱到不到位"。
- **三条链路共用一套主体标识与信用记录**：注册信息、信用等级、履约保障余额、结算记录要能串起来，否则风险监测就是盲人摸象。

### 1.3 本文与量化报价笔记的分工

| 维度 | 本文 | 量化报价与交易风控笔记 |
|---|---|---|
| 风险分类 | 监管口径的内外部风险、分级、处置 | 价格风险、电量风险、模型风险、操作风险 |
| 信用 | 信用评价指标、等级、后果、修复 | 对手方授信、限额、敞口 |
| 担保 | 保函/保险/现金、公式、盯市、执行 | 保证金占用、资金成本、压力测试 |
| 偏差 | 制度定义、省别规则、责任分摊 | 预测误差、偏差成本、报价修正 |
| 结算 | 流程、时限、异议、争议 | 对账、差异定位、PnL 归因 |
| 退出 | 违约、终止、转让、保底售电 | 对手方违约情景、损失估算 |

- **一句话**：本文回答"规则要求什么"，量化笔记回答"系统怎么实现、模型怎么算"。
- **不要重复**：本文不展开 VaR/CVaR 公式、报价曲线优化、回测框架；这些在 [量化报价与交易风控-工程化-2026-11.md](量化报价与交易风控-工程化-2026-11.md)。

### 2.2 规则之间的关系

```
                  《电力市场运行基本规则》（20 号令）
                                │
        ┌───────────────────────┼───────────────────────┐

  《电力中长期市场基本规则》  《电力现货市场基本规则》  《电力市场计量结算基本规则》
```

- **结算规则是"底座"**：中长期、现货、辅助服务都要落到计量结算基本规则的时限、异议、追退补框架。
- **风险防控是"横切"**：不替代各市场规则，而是要求各市场运营机构把风险识别、预案、处置嵌入日常运营。
- **信用评价是"连接器"**：把公共信用、财务、交易行为连到履约保障额度和交易权限。

### 2.3 2026 年三份草案的共同信号

| 信号 | 售电办法草案 | 风险防控草案 | 信用评价草案 |
|---|---|---|---|
| 从静态准入转向持续合规 | 注册资本、持续满足条件、自动减少业务地 | 市场成员内控、申报差错自担 | 季度评价、动态调整 |
| 从材料审核转向资金约束 | 履约保障按年售电量计收、逐日盯市 | 风险处置可暂停/中止市场 | C/D 级提高保障额度 |
| 从分散规则转向全国统一 | 一地注册、全国共享 | 全国风险分类、跨经营区职责 | 统一指标、结果全国通用 |
| 从单一监管转向协同 | 交易机构监测、政府处置 | 交易/调度/电网/政府/市场委员会分工 | 信用中国/信用能源数据共享 |

- **共同底线**：不能让"没有兑付能力的主体"做大交易规模，也不能让"用户因为售电公司倒下而断电"。
- **共同难点**：省级细则的阈值、系数、处置梯度差异很大；全国规则给框架，落地仍要看省。

## 3. 风险分类与治理

### 3.1 风险分类

| 大类 | 子类 | 监管定义要点 | 典型触发 |
|---|---|---|---|
| 市场内部风险 | 不正当竞争风险 | 违规行使市场力、操纵价格、持留容量、垄断协议、串通报价、哄抬或压低价格 | 报价异常一致、检修集中、份额过高 |
| 市场内部风险 | 合同违约风险 | 中长期、现货差价、辅助服务合同履约瑕疵 | 少发/超用、拒绝执行、拖欠 |
| 市场内部风险 | 市场价格异常风险 | 部分时段或局部价格持续偏高/偏低，波动或持续时间明显超常 | 尖峰价格、价格倒挂、负电价 |
| 市场内部风险 | 市场机制风险 | 规则不完善、不衔接、有缺陷/漏洞，或受不当干预 | 规则冲突、参数设置不当、地方保护 |
| 市场内部风险 | 其他市场运行风险 | 申报差错、滥用高频量化、虚假注册资料等 | 申报错误、异常高频报撤单 |
| 市场外部风险 | 电力供需失衡风险 | 供需大幅波动，出现明显缺口或富余 | 极端天气、燃料供应、大机组故障 |
| 市场外部风险 | 技术支持系统运行异常风险 | 交易/调度/结算/通信系统故障，或异常交易影响系统，或网络攻击 | 系统宕机、数据损坏、黑客攻击 |
| 市场外部风险 | 市场舆情风险 | 社会负面评价或舆情事件发酵，影响市场稳定 | 电费争议、限电传言、价格谣言 |

- **内外部不是按"谁造成"划分，而是按"风险来源"划分**：市场价格异常可能由内部操纵引起，也可能由外部供需引起；定性要看证据。
- **"其他市场运行风险"是兜底项**：申报差错、高频量化滥用、虚假注册都在这里；不要以为只有价格操纵才算风险。
- **2026 现货规则草案另列六类风险**：供需、价格异常、系统安全、技术支持系统、网络安全、市场交易异常；与风险防控办法的分类互相映射，不是两套互斥体系。

### 3.2 风险分级

```
                     影响结果
                重大风险        一般风险
          ┌──────────────┬──────────────┐
   紧急   │ 重大+紧急     │ 一般+紧急     │  → 可先处置、后报告
          ├──────────────┼──────────────┤
 非紧急   │ 重大+非紧急   │ 一般+非紧急   │  → 按预案/审定后处置
          └──────────────┴──────────────┘
```

| 维度 | 等级 | 判定要点 | 处置差异 |
|---|---|---|---|
| 影响结果 | 重大风险 | 可能引发市场暂停/中止、终端用户电价大幅波动、经营主体大面积或大额亏损 | 可提级管理；政府审定；更强处置 |
| 影响结果 | 一般风险 | 影响范围有限、可控 | 省级指导市场运营机构防控 |
| 紧急程度 | 紧急风险 | 日前/日内供需失衡、技术支持系统异常等 | 经授权可先处置、后报告 |
| 紧急程度 | 非紧急风险 | 有窗口研判、会商、审批 | 按预案或临时措施审定后执行 |

- **重大不等于紧急**：重大风险可能是慢变量（规则漏洞、持续亏损），需要会商和制度修补；紧急风险可能是局部故障，需要立即处置。
- **各地要细化阈值和"典型事件—风险类型—等级"对应清单**：全国办法只给框架，省里给阈值。
- **提级管理**：重大风险可由国家发改委、国家能源局视情况提级；跨省跨区、跨经营区交易的临时措施要报国家层面审定。

### 3.3 职责分工

| 主体 | 职责 | 容易误解的点 |
|---|---|---|
| 国家发改委、国家能源局 | 建立健全全国风险防控机制；指导跨省跨区、跨经营区风险防控 | 不是所有风险都由国家直接处置 |
| 省级政府主管部门、派出机构 | 指导辖区内一般/重大风险防控；审定临时措施；同意市场恢复 | 省级是日常防控的主责层级 |
| 电力交易机构 | 牵头全品种、各环节运营监测与风险防控；具体负责中长期等市场 | "牵头"不等于"包办"现货 |
| 电力调度机构 | 负责现货、辅助服务市场运营监测与风险防控；暂停/中止时按安全第一组织生产 | 安全优先，不是市场优先 |
| 北京电力交易中心 + 国家电力调度控制中心 | 跨经营区（北京侧）风险防控 | 与广州侧分工，不是一家统管 |
| 广州电力交易中心 + 南方电网调度控制中心 | 跨经营区（广州侧）风险防控 | 同上 |
| 电网企业 | 配合风险防控，保障电网安全与电力供应 | 不是只负责抄表收费 |
| 市场管理委员会 | 自律管理、争议调解 | 不是监管机构，没有行政处罚权 |
| 经营主体 | 建立内部风险防控机制；申报差错自担后果；配合处置 | "报错了"不能当免责理由 |

- **"谁运营、谁防范"**：交易机构对交易组织负责，调度机构对现货与辅助服务运行负责，电网企业对电网安全负责。
- **"谁申报、谁负责"**：申报差错、虚假资料、滥用高频量化，责任在经营主体；不能把锅甩给系统。
- **跨经营区是"分侧负责"**：北京侧、广州侧各自与国家/南方调度协同，跨两侧的协调由国家层面统筹。

### 3.4 闭环：监测—预警—处置—报告

```
  事前预控                事中处置                 事后修复
  ┌─────────┐          ┌─────────────┐          ┌─────────────┐
  │ 预案     │          │ 立即处置     │          │ 完善预案     │
  │ 阈值     │  ─────>  │ 调整/暂停/中止│  ─────>  │ 纳入规则     │
  │ 演练     │          │ 价格/分摊     │          │ 恢复市场     │
  │ 清单     │          │ 发电调用/负荷 │          │ 复盘问责     │
  └─────────┘          └─────────────┘          └─────────────┘
        │                      │                      │
        └──────────── 监测—预警—处置—报告 ────────────┘
```

- **事前**：编风险防范与处置预案，明确风险类型、等级、预警、程序、措施、职责；定期演练；设置阈值和典型事件清单。
- **事中**：按预案处置；未明确措施的，非紧急风险由交易机构提出临时措施，报省级主管部门/派出机构审定；跨省跨区报国家层面；紧急风险可先处置后报告。
- **事后**：风险消除后完善临时措施并纳入预案；评估是否具备重启条件；提出书面申请，按权限同意后恢复并公告。
- **暂停/中止期间**：调度机构按"安全第一"组织电力生产、优化运行方式，保障系统安全和可靠供应；不是"市场停了，电也停了"。

### 3.5 事前预控与事中处置的工具箱

| 阶段 | 工具 | 作用 | 注意 |
|---|---|---|---|
| 事前 | 交易限额 | 限制单主体/单品种敞口 | 要与履约保障余额联动 |
| 事前 | 报价上下限/申报限价 | 防止价格离群 | 限价不是出清价 |
| 事前 | 履约保障 | 资金兜底 | 逐日盯市、不足补缴 |
| 事前 | 信用约束 | 提高违规成本 | C/D 级提高保障、限制便利 |
| 事中 | 调整已有交易 | 减少失衡 | 要明确调整范围、价格、结算 |
| 事中 | 暂停/中止市场 | 阻断风险扩散 | 明确适用情形、启动条件、程序 |
| 事中 | 价格干预 | 防止价格失控 | 要说明期间价格、费用分摊 |
| 事中 | 发电调用/负荷控制 | 保系统安全 | 调度主导，按安全优先 |
| 事后 | 追退补/清算 | 纠正结算偏差 | 按 976 号的异议与追退补流程 |
| 事后 | 复盘与规则修补 | 防止同类风险 | 纳入预案和规则修订 |

- **"暂停市场"是最后手段**：能调整交易、能限价、能调用机组解决的，不轻易停市；停市会带来合同、结算、用户预期一连串问题。
- **"价格干预"要有边界**：要明确干预期间的价格形成、费用分摊、恢复条件，不能临时拍脑袋。
- **"负荷控制"是保供手段，不是市场手段**：按有序用电等规定执行，不能拿市场规则替代行政程序。

## 4. 信用评价：从道德约束到成本约束

### 4.1 谁参评、评什么

| 维度 | 内容 | 说明 |
|---|---|---|
| 参评范围 | 全国统一电力市场注册的经营主体：发电企业、售电公司、电力用户、新型经营主体 | 新型经营主体含新型储能、虚拟电厂、负荷聚合商、智能微电网、绿电直连项目等 |
| 指标结构 | 一级、二级、三级指标 | 基于公共信用状况 + 市场交易行为 |
| 信息构成 | 公共信用信息、财务信息、电力市场交易相关信息 | 公共信用从"信用中国""信用能源"归集；财务来自年度审计报告 |
| 评价原则 | 依法规范、公开透明、动态调整、协同联动 | 统一评价规则、结果全国通用 |
| 评价周期 | 原则上每季度一次，另设动态调整 | 不是一年一评 |
| 评价主体 | "谁结算、谁评价"；省级交易中心评，北京/广州汇总 | 具体分工以正式稿为准 |

- **储能、VPP 不是旁观者**：只要注册入市，就在评价范围内；容量与参数真实上报、并网运行考核、交易履约都会进入交易行为类指标。
- **财务信息缺失按 0 分处理**：不是"不扣分"，而是直接拉低综合得分；年度审计报告要按时、按要求填报。
- **公共信用是"硬约束"**：公共信用综合评价为 D 的，电力市场信用评价不能为 A；被列入严重失信主体名单的，直接 D。

### 4.2 等级与阈值

| 等级 | 综合得分区间 | 基本含义 | 典型后果 |
|---|---|---|---|
| A | (85,100] | 信用优秀 | 适当降低履约保障、扩展保障形式、便利服务、优先保底售电、评先评优 |
| B | (70,85] | 信用良好 | 按常规办理，不实施激励 |
| C | (40,70] | 信用一般/偏弱 | 限制便利服务、适当提高履约保障、提高核验频次、风险提示、重点监管 |
| D | [0,40]，或严重失信 | 信用差 | 同上并从重；严重失信原则上不得选为市场管理委员会成员，可能被限制或强制退出 |

- **分数不是"信用评级"**：它是电力市场维度的综合评价，不等同于银行内部评级、债券评级；但会直接影响保证金、交易权限、保底售电资格。
- **A 级不是终身制**：季度评价 + 动态调整；出现严重失信、重大违规、履约保障不足，可能快速下调。
- **D 级有两条路径**：分数落到 [0,40]，或被列入严重失信主体名单；后者不看分数。
- **公共信用 D 的"天花板"**：电力市场信用评价不能为 A，但未必直接 D；具体映射看正式稿。

### 4.3 评价程序

```
  信息归集          评价计算          结果公示          异议申诉          结果发布
      │                 │                 │                 │                 │
  公共信用          指标打分          5 个工作日        受理/核查        推送信用中国
  财务信息          综合得分          无异议→发布      更正/维持        信用能源
  交易行为          等级判定                                            结果可查询
```

- **信息归集**：公共信用信息在每个评价周期最后一个自然日获取；北京、广州交易中心通过接口从"信用中国""信用能源"归集，再回传省级交易中心。
- **评价计算**：按指标权重打分；财务信息缺失按 0 分；交易行为按合同履约、结算、申报、信息披露等记录。
- **公示与异议**：结果公示 5 个工作日；经营主体可提出异议，交易中心核查；无异议后发布。
- **发布与共享**：结果推送全国信用信息共享平台和能源行业信用信息平台；结果可查询一定年限（公开解读提到 3 年，具体以正式稿为准）。
- **动态调整**：新增严重失信信息，可能在 5 个工作日内调整为 D；具体触发和时限以正式稿为准。

### 4.4 激励与约束

| 对象 | 激励/约束 | 具体措施 | 交易含义 |
|---|---|---|---|
| A 级 | 激励 | 适当降低履约保障额度、扩展保障形式、容缺受理、降低核验频次、优先保底售电、评先评优 | 资金占用更低、业务办理更快、机会更多 |
| B 级 | 常规 | 按常规办理，不实施激励 | 不额外加码，也不享受便利 |
| C 级 | 约束 | 限制信用承诺/绿色通道/容缺受理；适当提高保障额度；增量不得用履约保险；提高核验频次；风险提示 | 资金更贵、审核更严、交易对手更谨慎 |
| D 级 | 约束 | 同上并从重；重点监管、提高抽查比例；严重失信不得任市场管理委员会成员 | 可能被限制交易、强制退出 |
| 严重失信 | 联合约束 | 信用中国/信用能源公示；跨部门联合惩戒 | 影响融资、招投标、政府补贴 |

- **"适当提高"不是"翻倍"**：具体幅度由省级规则或交易机构确定；不要用固定倍数套。
- **"增量不得用保险"是关键**：C/D 级新增的保障额度不能用履约保险提交，只能用保函或现金；这会显著增加资金成本。
- **A 级"优先保底售电"是双刃剑**：优先意味着责任；保底售电不是高利润业务，承接能力、价格、成本分摊要算清楚。

### 4.5 信用修复

- **修复渠道**：通过"信用中国"等渠道申请信用修复；严重失信名单有移出条件；电力市场信用评价随公共信用和交易行为变化动态调整。
- **修复不是"自动洗白"**：要完成整改、履行义务、消除影响；具体条件、期限、材料以正式稿和信用中国规则为准。
- **修复后仍留痕**：历史记录可能保留查询；银行、交易对手、监管机构仍可能参考。
- **不要等到 D 级才修复**：C 级时就要处理履约、结算、披露问题；D 级后交易权限、保证金、保底资格都会受影响。

### 4.6 数据质量与常见争议

| 争议 | 原因 | 处理建议 |
|---|---|---|
| 财务信息被按 0 分 | 未报、迟报、审计报告不合格 | 建立年报日历；提前校验口径；保留审计底稿 |
| 交易行为记录错误 | 结算争议、系统重复记录、合同归属不清 | 按月对账；异议留痕；要求交易中心更正 |
| 公共信用信息滞后 | 信用中国/信用能源更新时差 | 提前查询；发现错误及时申诉；保留证明 |
| 关联主体被合并评价 | 同一实际控制人、集团口径 | 厘清注册主体与业务边界；避免混同 |
| 跨省结果不一致 | 省级初评、汇总口径差异 | 以全国统一规则为准；向汇总机构申诉 |

- **信用评价的底座是数据**：计量、结算、合同、披露任何一环出错，都会反映到分数上。
- **"谁结算、谁评价"意味着交易中心掌握大量行为数据**：经营主体要主动核对，不要等结果公布才发现问题。

## 5. 履约保障：保函、保险与现金

### 5.1 三种凭证

| 凭证 | 本质 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| 履约保函 | 银行/担保机构出具的付款承诺 | 见索即付、信用强、交易对手接受度高 | 占用授信、有开立费、可能需要反担保 | 大多数售电公司；C/D 级增量 |
| 履约保险 | 保险公司承保履约责任 | 保费可能低于保函费、不占用银行授信 | 有除外责任、赔付流程、额度限制；低信用可能被禁 | A/B 级、增量以外部分 |
| 现金保证金 | 自有资金质押/存入指定账户 | 直接、无信用审核 | 占用现金流、机会成本高 | 小额、临时补缴、无法开保函/保险时 |

- **"见索即付"**：保函受益人索赔时，银行按表面单据付款，不介入基础合同争议；这是保函比保险更"硬"的原因。
- **"优先赔付"**：保险在符合条件时优先赔付，但不能设置不合理的免责条款、等待期、免赔额来规避责任；具体条款要逐条看。
- **额度关系**：2026 售电办法草案要求履约保函、现金保证金额度应超过履约保险额度；部分省份还限制保险占比（如贵州 2027 方案保险额度占比不超过 40%，属地方规则）。
- **低信用限制**：信用评价较低的售电公司，草案拟不得采用履约保险形式；C/D 级增量保障也不得用保险。

### 5.2 现行办法的额度口径

现行《售电公司管理办法》（发改体改规〔2021〕1595 号）下，履约保障额度通常按以下两者取大：

```
额度 = max( 过去 12 个月批发购电量 × 0.8 分/kWh,
            2 个月最大购电量 × 5 分/kWh )
```

- **口径一**：过去 12 个月批发购电量 × 0.8 分/kWh，反映年度规模。
- **口径二**：2 个月最大购电量 × 5 分/kWh，反映短期峰值风险。
- **取大**：防止"年度量小但某两个月集中采购"的风险被低估。
- **各省可能在国家框架下加严**：具体计算基数、时间窗口、是否含跨省跨区，以当地交易中心规则为准。

### 5.3 2026 草案的额度公式

```
履约保障额度 = 预计年售电量 × 1 分/kWh × 调整系数
              调整系数 ∈ [1, 10]
              最低不少于 200 万元
```

| 参数 | 含义 | 谁来确定 | 注意事项 |
|---|---|---|---|
| 预计年售电量 | 业务地预计年度售电量 | 售电公司申报，交易机构核定/动态调整 | 不是历史电量；新公司按预计 |
| 1 分/kWh | 单位保障基准 | 国家规则 | 与现行 0.8 分/kWh 不同 |
| 调整系数 | 1–10，反映信用、风险、管理能力 | 省级能源/发改部门确定并动态调整 | 系数越高，资金占用越大 |
| 200 万元 | 最低额度 | 国家规则 | 不是注册资本，不是保证金上限 |

- **与现行口径的差异**：现行按"历史购电量"和"2 个月峰值"取大；草案按"预计年售电量 × 系数"，更直接地与业务规模挂钩。
- **"预计年售电量"可以动态调整**：业务扩张、用户流失、合同变更都会影响额度；不是签约时算一次就固定。
- **系数不是企业自选**：由省级主管部门确定和动态调整；信用差、风险高的公司系数更高。
- **最低 200 万元是"地板"**：小公司也要交 200 万元；不是"不到 200 万就不用交"。

### 5.4 算例：30 亿 kWh 售电公司

> 合成算例（D 级）：30 亿 kWh 与系数均为演示参数，不构成履约保障额度测算；系数以正式稿为准。

假设：预计年售电量 30 亿 kWh，系数分别取 1、5、10；旧规按 30 亿 kWh 平稳用电估算。

| 口径 | 计算 | 额度 |
|---|---|---|
| 旧规口径一 | 30 亿 × 0.8 分/kWh = 30 亿 × 0.008 元/kWh | 2,400 万元 |
| 旧规口径二 | 2 个月电量 5 亿 kWh × 5 分/kWh = 5 亿 × 0.05 元/kWh | 2,500 万元 |
| 旧规取大 | max(2,400, 2,500) | 2,500 万元 |
| 新规系数 1 | 30 亿 × 1 分/kWh × 1 = 30 亿 × 0.01 元/kWh | 3,000 万元 |
| 新规系数 5 | 30 亿 × 1 分/kWh × 5 | 1.5 亿元 |
| 新规系数 10 | 30 亿 × 1 分/kWh × 10 | 3 亿元 |

- **结论**：同样的电量，新规下保障额度可能是旧规的 1.2 倍到 12 倍；系数是最大的敏感变量。
- **资金成本**：若保函费率为 0.5%–1.5%/年，1.5 亿元保函的年费约 75 万–225 万元；3 亿元约 150 万–450 万元（D，按假设测算，实际费率看银行）。
- **保险对比**：保险保费可能低于保函费，但保障范围、除外责任、赔付顺序不同；不能只看费率。
- **经营含义**：低价抢量会同时推高"预计年售电量"和"风险系数"，形成"越冲量、越占资金"的约束。

### 5.5 逐日盯市与补缴

```
  每日监测            额度不足            通知补缴            暂停交易            补足恢复
     │                   │                   │                   │                   │
  剩余额度            风险敞口            1 个工作日          逾期未补            1 个工作日
  动态盈亏            红色/黄色阈值        3 个工作日          暂停本省交易        恢复交易
  交易限额            下一日限额调整       完成补缴            进一步处置          解除预警
```

| 环节 | 时限 | 动作 | 后果 |
|---|---|---|---|
| 监测 | 每日 | 交易机构监测履约保障剩余额度、风险敞口、动态盈亏 | 形成预警 |
| 通知 | 1 个工作日 | 通知售电公司补缴 | 未补缴进入暂停 |
| 补缴 | 3 个工作日 | 售电公司完成补缴 | 逾期未补，暂停相关省份交易资格，处置升级 |
| 恢复 | 1 个工作日 | 足额缴纳后恢复交易 | 解除暂停 |
| 限额 | 下一交易日 | 根据剩余额度动态调整交易限额 | 防止继续扩大敞口 |
| 拦截 | 交易前 | 某笔交易将导致保函达到红色预警阈值的，不予成交 | 地方规则，如贵州 2027 方案 |

- **"逐日盯市"不是"逐日结算"**：每天估算盈亏和敞口，按剩余额度调整下一日交易限额；不是每天收付资金。
- **"暂停"是按省**：售电公司可能在 A 省被暂停，但在 B 省仍可交易；跨省经营要分别管理额度。
- **"补缴"不是"罚款"**：补缴是恢复保障额度；违规、违约另有处罚。
- **"红色预警"可能直接拦截交易**：地方规则可以把保函阈值嵌入交易前置校验，达到阈值就不让成交。

### 5.6 保函执行与保险赔付

| 场景 | 保函 | 保险 | 现金 |
|---|---|---|---|
| 售电公司欠费 | 受益人凭索赔单据要求银行付款 | 按保单约定申请赔付 | 直接扣划 |
| 争议 | 见索即付，基础合同争议另案解决 | 保险公司可能先核查责任 | 无争议 |
| 除外责任 | 较少（欺诈等除外） | 较多（故意、重大过失、未披露等） | 不适用 |
| 赔付时限 | 通常较快 | 可能较慢 | 即时 |
| 低信用主体 | 可用 | 可能被禁 | 可用 |

- **保函执行不等于"公司破产"**：执行后公司仍可经营，但额度被占用、信用受损；要继续交易必须补足。
- **保险赔付不等于"全额兜底"**：要看保额、免赔、赔付比例、除外责任；"优先赔付"不等于"无条件全赔"。
- **现金保证金最直接，但最贵**：占用现金流，机会成本高；适合临时补缴或无法开保函/保险的场景。
- **执行顺序**：多份凭证时，通常按"保函优先、先到期优先、金额与偿付适宜优先"等规则使用；地方规则可能不同。

### 5.7 履约保障的会计与现金流

| 项目 | 处理 | 影响 |
|---|---|---|
| 保函 | 表外或有负债；银行可能占用授信 | 不影响资产负债率，但影响授信额度 |
| 保险 | 保费计入费用；赔付为保险责任 | 费用化，降低当期利润 |
| 现金保证金 | 计入其他应收/受限资金 | 占用现金流，降低资金周转 |
| 反担保 | 股东担保、抵押、质押 | 增加股东责任和资产受限 |
| 保函费 | 按年/按季收取 | 直接成本，随额度上升 |
| 赔付/索赔 | 形成对售电公司的追偿权 | 可能引发诉讼、信用下调 |

- **"保函不占资金"是误解**：它占授信、要反担保、要付费；额度越大，银行越谨慎。
- **"保险比保函便宜"要看总成本**：保费 + 除外责任 + 赔付延迟 + 信用限制，可能比保函更贵。
- **"现金保证金"最透明**：但会降低周转率，适合短期、小额、过渡。

## 6. 偏差考核：合同与实际的差

### 6.1 偏差是什么

```
   合同电量（曲线）  ────────────────┐
                                     │  差值 = 偏差电量
   实际电量（曲线）  ────────────────┘
                                     │
   偏差率 k = (实际电量 − 合同电量) / 合同电量
```

| 概念 | 定义 | 注意 |
|---|---|---|
| 合同电量 | 中长期合同、现货申报、零售合同约定的电量/曲线 | 分时段、分品种 |
| 实际电量 | 实际上网/用电量，按计量点数据 | 受计量、抄表、线损影响 |
| 偏差电量 | 实际与合同的差值 | 正偏差/负偏差 |
| 偏差率 | 偏差电量 / 合同电量 | 分母口径要一致 |
| 免考区间 | 规则允许的偏差范围 | 各省不同，没有全国统一 ±5% |
| 考核价格 | 对超范围偏差的结算/惩罚价格 | 可能是现货价、中长期价、基准价的倍数 |
| 责任分摊 | 偏差由谁承担 | 按原因、合同约定、规则 |

- **偏差不是"错误"，是常态**：负荷预测、新能源出力、机组故障、检修、天气都会造成偏差；规则的目标是"可预期地分摊"，不是"消灭偏差"。
- **偏差考核不是"罚款"**：多数是结算价格差异（超额部分按更高/更低价格结算），不是行政处罚；但可能显著影响收益。
- **"偏差率"分母很关键**：按合同电量、实际电量、月度总量还是分时段，结果不同；签约时要写清楚。

### 6.2 国家规则给了什么

| 文件 | 条款 | 内容 | 含义 |
|---|---|---|---|
| 1656 号 | 第七十四条 | 中长期结算可按差价结算或差量结算；已注册入市但尚未签订中长期合同的，实际用电量或发电量按偏差电量结算 | 国家层面给"差价/差量"两种模式；无合同即偏差 |
| 1656 号 | 第七十五条 | 居民农业、代理购电的偏差电量分别结算；电网企业分别提供电量信息 | 民生与代理购电单独处理 |
| 1656 号 | 第七十六条 | 资源聚合类新型主体及分散资源按聚合服务合同价格单独结算 | VPP/聚合商有独立结算口径 |
| 1656 号 | 第七十七条 | 绿电电能量与环境价值分开结算 | 绿电偏差不能把环境价值混进去 |
| 1656 号 | 第七十八条 | 绿电环境价值按合同电量、上网电量（扣除机制电量）、用电侧电量三者取小 | 绿电结算的"三者取小" |
| 1656 号 | 第八十条 | 其他结算要求按 976 号执行 | 结算底座统一 |
| 976 号 | 第五十一条 | 结算依据/账单异议 15 个工作日；5 个工作日确认；属实的下一周期追退补 | 偏差争议的程序出口 |
| 976 号 | 第五十二条 | 计量结算争议可经市场管理委员会调解，或价格/监管调解，不成仲裁/诉讼 | 争议解决路径 |

- **1656 号没有规定全国统一的偏差免考区间和考核价格**：它给结算方式，具体参数在省级细则。
- **"差价结算"与"差量结算"是两套逻辑**：差价是合同与现货的价格差，差量是合同电量与实际电量的量差；各省选择不同，不能混用。
- **"无合同即偏差"是硬约束**：已注册入市但没签中长期合同，实际电量直接按偏差结算；不能"先交易、后补合同"。

### 6.3 省级差异：为什么不能套全国

| 省份/区域 | 规则要点 | 级别 | 备注 |
|---|---|---|---|
| 黑龙江 | 补充规定提到偏差电量允许范围 ±5%，超范围按燃煤基准价一定比例缴纳考核费用 | C | 2025 年补充规定，具体以原文为准 |
| 山东 | 2026-06-08 征求意见，收紧新能源偏差考核 | B/C | 新能源出力预测偏差是重点 |
| 陕西 | 2026-07 V1.0，绿电直连、储能单独结算 | B/C | 新型主体结算口径分化 |
| 湖北 | 2026 年"照付不议、偏差结算"，24 小时结算 | B/C | 分时结算颗粒度细 |
| 广西 | 新能源年度合同不超过实际上网电量减机制电量后的 70% | B/C | 合同上限约束 |
| 吉林 | 2026-01 提示浮动服务费超过 3% 的风险 | C | 零售侧风险提示 |
| 广东 | 市场宣传材料称 ±3% 触发、±5% 按 2 倍考核 | C | 未见正式文件，需以交易中心规则为准 |

- **省级差异体现在四个参数**：免考区间、考核价格、责任分摊、豁免情形。
- **豁免情形**：保供电、电网安全约束、不可抗力、需求响应、检修、新能源预测偏差等，各地清单不同。
- **"照付不议"**：合同电量按约定价格结算，实际不足/超出部分按偏差价格另算；不是"用多少付多少"。
- **"月结月清"与"月清月结"**：表述相近，但结算周期、清算方式可能不同；看省级规则定义。

### 6.4 偏差责任的划分

| 原因 | 谁承担 | 依据 | 注意 |
|---|---|---|---|
| 用户负荷预测偏差 | 用户/售电公司 | 零售合同、代理合同 | 合同要约定预测责任、误差带 |
| 新能源出力预测偏差 | 发电企业 | 并网规则、市场规则 | 预测精度、天气预报、限电 |
| 机组故障/检修 | 发电企业 | 合同、规则 | 是否免考看是否及时申报 |
| 电网安全约束/调度指令 | 按规则豁免或分摊 | 调度记录、规则 | 要保留指令证据 |
| 不可抗力 | 按合同/规则 | 不可抗力条款 | 通知、证明、减损 |
| 计量错误 | 责任方/按规则 | 计量规则 | 追退补、误差更正 |
| 售电公司未按零售合同采购 | 售电公司 | 零售合同 | 批零不匹配 |
| 用户私自增容/超用 | 用户 | 供用电合同 | 违约用电处理 |

- **"谁造成、谁承担"是原则，但合同可以约定分摊**：售电公司与用户可以在零售合同里约定偏差分享比例、预警、调整、证据、异议窗口。
- **"售电公司全担"不公平也不现实**：用户侧偏差、电网约束、新能源出力都不是售电公司能完全控制的；合同要写清楚边界。
- **"考核费用可以传导"**：部分省份允许售电公司将偏差考核费用按合同传导给用户；但不是所有省份都允许，要看规则。

### 6.5 算例：一个月的偏差账

假设：某售电公司代理用户，月度合同电量 100 GWh，实际用电 106 GWh；合同价 420 元/MWh；现货均价 400 元/MWh；省级规则：偏差率 ±5% 以内按现货结算，超出部分按现货价的 1.2 倍考核。

| 项目 | 电量 | 价格 | 金额 | 说明 |
|---|---|---|---|---|
| 合同电量 | 100 GWh | 420 元/MWh | 4,200 万元 | 按合同结算 |
| 实际用电 | 106 GWh | — | — | 超用 6 GWh |
| 免考区间 | 5 GWh | 400 元/MWh | 200 万元 | 5% 以内，按现货 |
| 超范围偏差 | 1 GWh | 400 × 1.2 = 480 元/MWh | 48 万元 | 超出 5% 的部分 |
| 合计购电成本 | 106 GWh | — | 4,448 万元 | 4,200 + 200 + 48 |
| 平均购电成本 | 106 GWh | — | 419.62 元/MWh | 4,448 / 106 |

- **读法**：不是"6 GWh 全部按 480 元"，而是"5 GWh 按现货、1 GWh 按 1.2 倍"；具体分段看省级规则。
- **如果规则是"全部偏差按 1.2 倍"**：6 GWh × 480 = 288 万元，比上表多 40 万元；差异很大。
- **如果规则是"偏差超过 ±5% 的部分按 2 倍"**：1 GWh × 800 = 80 万元，比上表多 32 万元。
- **如果合同价高于现货**：超用可能"占便宜"，但考核会抵消；不要只看单边。
- **如果实际是 94 GWh（少用）**：少用 6 GWh，合同照付不议，多余电量按现货/考核价处理；售电公司可能亏损。

### 6.6 合同条款清单

| 条款 | 要写什么 | 为什么 |
|---|---|---|
| 合同电量/曲线 | 分时段电量、价格、结算参考点 | 偏差计算的基准 |
| 预测与申报 | 谁预测、提前多久、误差带 | 责任划分 |
| 偏差责任 | 用户侧/售电侧/电网侧/不可抗力 | 避免"全担" |
| 偏差分摊 | 分享比例、上下限、结算方式 | 把考核费用传导清楚 |
| 预警机制 | 偏差阈值、通知时限、调整窗口 | 及早纠偏 |
| 调整机制 | 月内调整、合同转让、回购 | 减少考核 |
| 证据与记录 | 计量数据、调度指令、气象证明 | 争议时举证 |
| 异议窗口 | 多少工作日、向谁提、如何答复 | 程序权利 |
| 终止与转让 | 违约、退出、用户承接 | 退出时的保护 |
| 不可抗力 | 定义、通知、证明、减损 | 免责边界 |

- **"偏差条款"不是越严越好**：太严用户不接受，太松售电公司承担不起；要匹配用户负荷特性。
- **"预测误差带"要可执行**：按历史数据、行业特性、天气敏感性设定；不要拍脑袋。
- **"调整窗口"要写进合同**：月内调整、合同转让、回购的时限和条件；否则错过窗口只能认考核。

## 7. 结算：日清月结、5/8/10 与追退补

### 7.1 结算体系

| 层级 | 内容 | 规则依据 | 备注 |
|---|---|---|---|
| 计量 | 计量点设置、数据采集、核对、异常处理 | 976 号 | 数据是结算的基础 |
| 结算准备 | 合同、曲线、出清结果、计量数据 | 976 号、1656 号 | 多方数据要对齐 |
| 结算依据 | 交易机构出具结算依据（核对版/正式版） | 976 号 | 第 5/8 个工作日 |
| 电费账单 | 电网企业出具账单 | 976 号 | 第 10 个工作日 |
| 收付 | 发电企业、用户、售电公司与电网企业收付 | 976 号、2020 年电费结算办法 | 发票、承兑、结算协议 |
| 追退补 | 异议属实后的下一周期追退补/清算 | 976 号第五十一条 | 不是"当月改" |
| 争议 | 调解、仲裁、诉讼 | 976 号第五十二条、1656 号 | 程序出口 |

- **"日清月结"**：现货连续运行地区按日清分、按月结算；不是每天打款。
- **"月结月清"**：中长期合同按月结算、按月清算；与"日清月结"不冲突，层级不同。
- **"结算依据"不是"账单"**：交易机构给结算依据，电网企业给账单；两者主体、内容、时限不同。

### 7.2 统一时限

```
  每月第 5 个工作日        1 个工作日          第 8 个工作日        第 10 个工作日
        │                     │                     │                     │
  结算依据（核对版）      核对/异议/确认      正式结算依据          电费账单
        │                     │                     │                     │
        └──── 有异议：1 个工作日内组织核实，修正后再确认 ────┘
```

| 节点 | 时限 | 责任方 | 动作 |
|---|---|---|---|
| 核对版结算依据 | 每月第 5 个工作日前 | 电力交易机构 | 向经营主体、相关电网企业出具 |
| 核对/异议/确认 | 1 个工作日内 | 经营主体、电网企业 | 核对、反馈异议、确认 |
| 异议核实 | 1 个工作日内 | 电力交易机构 | 组织经营主体、电网企业、调度核实 |
| 修正后确认 | 1 个工作日内 | 经营主体 | 对修正后的核对版确认 |
| 正式结算依据 | 每月第 8 个工作日前 | 电力交易机构 | 发布 |
| 电费账单 | 每月第 10 个工作日前 | 电网企业 | 向发电企业、用户、售电公司发行 |

- **"工作日"不是"自然日"**：遇节假日顺延；跨月、跨年要提前排日历。
- **"具备条件的地区可进一步优化"**：有的省可能更快；以当地细则为准。
- **"1 个工作日"很短**：经营主体要提前准备对账模板、异常清单、联系人；否则容易错过确认窗口。

### 7.3 结算项目与"不得设不平衡资金池"

| 结算项目 | 内容 | 常见争议 |
|---|---|---|
| 电能量 | 中长期、现货、偏差 | 曲线、价格、结算参考点 |
| 辅助服务 | 调频、备用、爬坡等 | 调用认定、考核、分摊 |
| 容量 | 容量电价、容量补偿 | 可用容量、考核、分摊 |
| 绿电/绿证 | 电能量与环境价值分开 | 三者取小、绿证划转 |
| 零售 | 零售套餐、偏差、服务费 | 套餐条款、批零匹配 |
| 输配电价 | 输配电费、线损、交叉补贴 | 电压等级、计量方式 |
| 政府性基金及附加 | 基金、附加 | 减免、代征 |
| 代理购电/保底售电 | 代理购电、保底售电 | 价格、分摊、用户选择 |
| 违约/考核 | 偏差考核、并网考核、违约电费 | 责任、豁免、追退补 |

- **"不得设置不平衡资金池"**：每项结算项目独立记录、分类疏导；不能把不同项目的盈亏混在一个池子里。
- **"分类疏导"**：阻塞盈余、分摊费用、考核费用要按规则分配到相应主体；不能"一锅粥"。
- **"独立记录"**：交易机构、电网企业要能按项目、按主体、按时间追溯；对账时才能定位差异。
- **"不平衡资金"不是"不能有差额"**：而是不能设一个不透明的池子长期挂账；差额要按规则处理。

### 7.4 异议与追退补

| 步骤 | 时限 | 动作 | 结果 |
|---|---|---|---|
| 提出异议 | 结算依据/账单发布后 15 个工作日内 | 向交易机构/电网企业提出结算问询 | 进入核查 |
| 确认评估 | 收到问询后 5 个工作日内 | 确认和评估问询是否属实 | 属实/不属实 |
| 追退补 | 满足结算条件的下一结算周期 | 追退补或清算 | 账务更正 |
| 争议调解 | 按程序 | 市场管理委员会、价格/监管调解 | 调解协议 |
| 仲裁/诉讼 | 调解不成 | 依法仲裁或诉讼 | 法律裁决 |

- **"15 个工作日"是权利窗口**：过了窗口再提，可能不被受理；要建立台账。
- **"5 个工作日"是答复窗口**：交易机构/电网企业要确认是否属实；不是"拖到下一月"。
- **"下一周期追退补"不是"当月重开"**：当月账单已出，更正放到下一周期；现金流会滞后。
- **"争议不影响已确认部分"**：有争议的项目先挂起，无争议部分正常收付；不要因为一笔争议停掉全部结算。

### 7.5 结算风险清单

| 风险 | 表现 | 后果 | 控制 |
|---|---|---|---|
| 计量异常 | 表计故障、通信中断、数据跳变 | 电量错、结算争议 | 双表、校验、补采、异常告警 |
| 规则版本错 | 用了旧规则/旧参数 | 结算依据错误 | 规则版本库、生效日校验 |
| 合同曲线不符 | 合同曲线与实际申报/出清不一致 | 偏差、考核 | 合同—申报—出清三单核对 |
| 价格异常 | 现货价格飙升/负电价 | 购电成本失控 | 限价、对冲、压力测试 |
| 对手方违约 | 售电公司欠费、发电企业少发 | 坏账、用户转保底 | 信用评价、担保、限额 |
| 担保不足 | 保函余额低于敞口 | 暂停交易、违约 | 逐日盯市、补缴、预警 |
| 发票/税务 | 发票延迟、税率错误 | 付款延迟、争议 | 开票日历、税务复核 |
| 资金链 | 回款慢、垫资 | 流动性风险 | 现金流预测、授信 |
| 追退补 | 跨期调整 | 账务复杂、考核 | 台账、准备金的计提 |
| 数据安全 | 泄露、篡改 | 合规、信用 | 权限、审计、备份 |

- **结算风险不是财务部门一家的事**：交易、调度、计量、财务、法务要协同；任何一环出错都会反映到账单。
- **"对账"不是"核对总额"**：要按项目、按主体、按时段、按规则版本拆开；否则找不到差异。
- **"追退补"要计提**：跨期调整会影响当期利润和现金流；财务要预留。

### 7.6 对账清单

| 序号 | 核对项 | 数据源 | 差异处理 |
|---|---|---|---|
| 1 | 计量点档案 | 营销/调度/交易 | 档案不一致先更正 |
| 2 | 抄表数据 | 计量自动化系统 | 补采、校验、异常标记 |
| 3 | 合同曲线 | 交易平台 | 与申报/出清比对 |
| 4 | 出清结果 | 交易/调度 | 分时段、分节点 |
| 5 | 结算依据 | 交易机构 | 核对版/正式版 |
| 6 | 电费账单 | 电网企业 | 项目、单价、电量 |
| 7 | 规则版本 | 交易中心公告 | 生效日、过渡条款 |
| 8 | 考核/分摊 | 交易/调度 | 责任、豁免、比例 |
| 9 | 追退补 | 交易/电网 | 上期挂账、本期调整 |
| 10 | 担保余额 | 交易中心 | 与敞口匹配 |

- **"三单核对"**：合同、申报、出清；三单不一致，结算一定有问题。
- **"两版核对"**：核对版与正式版；差异要留痕，避免"正式版悄悄改"。
- **"一月一结、一月一档"**：每月归档计量、合同、出清、结算、账单、异议、追退补；审计和争议时能还原。

## 8. 对手方风险、违约与退出

### 8.1 对手方风险画像

| 对手方 | 主要风险 | 预警信号 | 缓释 |
|---|---|---|---|
| 售电公司 | 亏损、保证金不足、退出 | 批零倒挂、连续亏损、保函余额低、用户集中、欠费 | 信用评价、担保、限额、合同终止权 |
| 发电企业 | 少发、超发、机组故障 | 出力偏差大、检修频繁、燃料紧张 | 合同条款、替代采购、偏差考核 |
| 电力用户 | 拖欠电费、超用、违约用电 | 逾期、负荷异常、信用下调 | 预付费、保证金、停电程序 |
| 储能/VPP | 容量不实、调用不达标 | 参数虚报、可用率低、考核多 | 并网考核、信用、合同违约金 |
| 电网企业 | 结算延迟、计量争议 | 账单延迟、数据不一致 | 监管投诉、争议调解 |
| 交易机构 | 规则变更、系统故障 | 公告频繁、系统异常 | 规则版本库、应急预案 |

- **对手方风险不是"看财报"**：电力市场的对手方风险还看信用等级、履约保障、结算记录、交易行为。
- **"大公司"不等于"低风险"**：发电集团所属售电公司也可能亏损；要看独立法人、担保、合同。
- **"用户拖欠"是最容易被忽视的风险**：售电公司对电网企业要按时付款，但用户可能拖欠；现金流错配会拖垮售电公司。

### 8.2 违约的触发与处置

```
  预警              违约              处置              退出              承接
   │                 │                 │                 │                 │
  保函不足          欠费/少发         暂停交易          减少业务地        保底售电
  信用下调          拒绝履约          执行保函          注销              代理购电
  连续亏损          严重违规          合同终止/转让      清算              用户选择
```

| 阶段 | 触发 | 处置 | 依据 |
|---|---|---|---|
| 预警 | 保函余额低于阈值、信用下调、连续亏损 | 提示、限制新增交易、要求补充材料 | 交易机构监测、信用评价 |
| 违约 | 欠费、少发、拒绝履约、严重违规 | 暂停交易、执行保函/保险、追偿 | 合同、市场规则、担保文件 |
| 退出 | 持续不满足注册条件、长期不结算、执照注销 | 减少业务地、注销、清算 | 2026 售电办法草案、现行 1595 号 |
| 承接 | 售电公司无法履约 | 保底售电、代理购电、用户选择新售电公司 | 售电办法、地方保底售电规则 |

- **"暂停交易"不是"注销"**：暂停是限制新增交易，原有合同仍要履行；注销是退出市场。
- **"执行保函"不是"免除债务"**：保函赔付后，售电公司仍欠款，担保机构可追偿。
- **"合同终止"要有依据**：不能因为"公司经营困难"单方终止；要看合同条款、规则、监管决定。

### 8.3 2026 售电办法草案的退出机制

| 机制 | 触发 | 后果 | 备注 |
|---|---|---|---|
| 自动减少业务地 | 连续 2 个自然年未在当地实际结算 | 减少该业务地 | 单一省份经营可能等同注销 |
| 暂停业务地交易 | 连续 12 个月未在某业务地实际交易结算 | 暂停该业务地交易 | 不是注销 |
| 自动注销 | 连续 12 个月未在各业务地实际结算；营业执照注销/吊销 | 注销市场注册 | 退出市场 |
| 强制退出 | 未持续满足注册条件、未按时足额缴纳履约保障、严重违规 | 强制退出 | 具体程序看正式稿 |
| 合同处理 | 退出时未履行合同 | 自动终止；损失由售电公司承担 | 草案口径，正式稿可能调整 |
| 用户承接 | 售电公司无法履约 | 保底售电/代理购电；用户可选择新售电公司 | 次月选择，具体看地方 |

- **"自动减少业务地"是渐进式退出**：先减少省份，再暂停，再注销；不是一上来就注销。
- **"连续 12 个月未结算"是硬指标**：注册了但不实际经营，会被清理；"囤牌照"空间收窄。
- **"合同自动终止 + 损失由售电公司承担"是草案的关键变化**：正式稿是否保留、如何界定损失，要重点跟踪。
- **"用户次月选择新售电公司"**：给用户退出通道；但保底期间的价格、合同、发票要衔接。

### 8.4 保底售电与用户保护

| 维度 | 现行/地方做法 | 2026 草案信号 | 注意 |
|---|---|---|---|
| 承接主体 | 电网企业、指定售电公司 | 完善保底售电承接机制 | 各地指定方式不同 |
| 触发 | 售电公司无法履约、退出、欠费 | 无法履约 | 要有认定程序 |
| 价格 | 部分地区 1.5 倍/2 倍代理购电价格 | 无法履约当月按现货实时价格结算 | 草案删除惩罚性倍数 |
| 用户选择 | 可转其他售电公司 | 次月可选择新售电公司 | 选择窗口、合同衔接 |
| 成本分摊 | 按规则分摊 | 明确过渡与价格执行 | 不能让电网企业无限兜底 |
| 服务 | 保底供电，不断电 | 守住用电安全底线 | 计量、发票、客服要衔接 |

- **"保底售电"不是"免费兜底"**：价格通常高于正常零售套餐；用户要承担市场分摊费用。
- **"1.5 倍/2 倍"是现行/地方做法，不是全国统一**：2026 草案拟改为按现货实时价格结算；正式稿未定。
- **"用户不断电"是底线**：售电公司退出，电网企业要承接；但合同、价格、结算会变，用户要提前知情。
- **"保底售电公司"不是谁都能当**：通常由电网企业指定或市场机制确定；A 级信用可能是优先条件。

### 8.5 合同终止与转让

| 方式 | 适用 | 要点 | 风险 |
|---|---|---|---|
| 合同终止 | 售电公司退出、违约、不可抗力 | 终止条件、通知、结算截止、损失承担 | 用户可能被迫接受保底价格 |
| 合同转让 | 售电公司合并、业务出售、用户转签 | 用户同意、受让方资格、担保、结算切割 | 受让方信用、合同条款变化 |
| 用户转签 | 用户选择新售电公司 | 提前通知、计量抄表、费用结清 | 原售电公司不配合 |
| 自动承接 | 售电公司无法履约 | 保底售电/代理购电 | 价格、服务、发票衔接 |

- **"转让"要三方同意**：原售电公司、用户、新售电公司；不能单方"卖合同"。
- **"结算切割"要明确**：转让日前的电费、偏差、考核由谁承担；转让日后的计量、账单由谁负责。
- **"用户同意"不能省略**：格式条款、默认续签、自动转签可能引发争议；要留证据。
- **"损失承担"要可计算**：价差、违约金、保底价差、追偿成本；合同要约定计算方式。

### 8.6 退出情景算例

假设：某售电公司年售电量 20 亿 kWh，履约保障 2,000 万元；某月欠费 1,800 万元，保函被执行；用户 3 万户，月度用电 1.5 亿 kWh；保底售电价格比原零售套餐高 0.05 元/kWh。

| 项目 | 金额/数量 | 说明 |
|---|---|---|
| 欠费 | 1,800 万元 | 执行保函 |
| 保函剩余 | 200 万元 | 继续交易需补缴 |
| 用户月度用电 | 1.5 亿 kWh | 3 万户 |
| 保底价差 | 0.05 元/kWh | 假设 |
| 用户月度多付 | 750 万元 | 1.5 亿 × 0.05 |
| 年化多付 | 9,000 万元 | 假设全年保底 |
| 售电公司损失 | 欠费 + 违约 + 追偿 | 具体看合同 |

- **读法**：保函只能覆盖部分欠费；用户多付的保底价差可能远大于保函；这就是"事前选售电公司"的重要性。
- **"保函够不够"要看敞口**：不是看注册资本，也不是看保函绝对额；要看最大月度购电成本、用户集中度、价格波动。
- **"用户多付"不是"售电公司赚"**：保底售电的价差归承接主体/按规则分摊；售电公司已经退出。

## 9. 零售侧风险：批零倒挂与低价竞争

### 9.1 2026 年的零售市场压力

| 现象 | 数据/表现 | 级别 | 含义 |
|---|---|---|---|
| 售电公司退出 | 2026 年前 7 个月 400+ 家退出 | C | 行业出清加速 |
| 广东亏损面 | 500 家售电公司中 298 家亏损 | B/C | 批零倒挂 |
| 广东度电收益 | 2026 上半年平均 0.0039 元/kWh，2025 年约 0.0196 元/kWh | B/C | 收益大幅收缩 |
| 广西负价差 | 最大负价差 0.373 元/kWh | C | 极端月份亏损 |
| 贵州亏损 | 2026 年 1–2 月亏损超 4,000 万元 | C | 区域性问题 |
| 安徽亏损 | 2026 年 1 月亏损超 1.19 亿元 | C | 价格波动冲击 |
| 山西价差 | 约 2 分/kWh | C | 薄利 |
| 系统运行费 | 0.068 元/kWh，同比 +93% | C | 费用上升 |
| 固定分时套餐 | 约 11 个省份取消固定分时 | C | 价格风险向用户传导 |
| 广东零售均价 | 2026 上半年 0.4074 元/kWh | B/C | 零售侧价格水平 |
| 广东零售电量 | 2026 上半年 239.8 TWh | B/C | 市场规模 |

- **"批零倒挂"是核心风险**：批发市场价格上涨，零售合同价格固定或调整滞后，售电公司每卖一度电都亏。
- **"系统运行费"是隐性成本**：辅助服务、不平衡资金、分摊费用上升，会侵蚀价差。
- **"固定分时套餐退场"**：价格风险更多传导给用户，售电公司需要更复杂的套餐设计。
- **"低价抢量"不可持续**：低于成本报价、阴阳合同、线下返利会被整治；一旦价格上行，资金链断裂。

### 9.2 2026-06-08 零售市场管理通知的要点

| 要点 | 内容 | 目的 | 级别 |
|---|---|---|---|
| 价格与批发成本挂钩 | 零售价格要反映批发市场价格变化 | 减少批零倒挂 | B/C |
| 分时套餐 | 推动分时零售套餐，传导现货价格信号 | 引导用户错峰 | B/C |
| 套餐公开 | 公布全部零售套餐，便于比较 | 防止"阴阳合同" | B/C |
| 合理利润 | 不行政限制合理利润，但反对暴利 | 平衡用户与售电公司 | B/C |
| 禁止低于成本 | 禁止低于成本价不正当竞争 | 防止恶性竞争 | B/C |
| 禁止阴阳合同 | 禁止合同外返利、线下协议 | 保护用户知情权 | B/C |
| 信息披露 | 批发/零售电量、价格、套餐签约、价差最高/最低 | 提高透明度 | B/C |

- **"价格与批发成本挂钩"不是"自动传导"**：套餐可以设计联动机制，但用户是否接受、监管是否认可，要看具体规则。
- **"套餐公开"是硬要求**：所有套餐要可查询、可比较；"口头承诺""私下返利"风险高。
- **"合理利润"没有统一标准**：监管不行政限价，但会关注暴利、低价倾销、价格欺诈。
- **"阴阳合同"是高压线**：合同外返利、线下协议、虚假套餐，可能导致处罚、信用下调、退出。

### 9.3 零售套餐的风险设计

| 套餐类型 | 价格机制 | 售电公司风险 | 用户风险 | 适用 |
|---|---|---|---|---|
| 固定价 | 全年/全时段固定 | 批发价上涨时亏损 | 价格不随市场下降 | 风险偏好低、用电稳定 |
| 分时价 | 峰平谷/24 时段 | 曲线预测偏差、批零不匹配 | 峰段价格高 | 可错峰用户 |
| 均价套餐 | 按批发均价联动 | 传导较顺、但仍有滞后 | 价格随市场波动 | 接受波动的用户 |
| 保底+浮动 | 保底价 + 浮动 | 保底部分亏损 | 浮动部分不确定 | 混合偏好 |
| 服务费模式 | 电费 + 服务费 | 服务费覆盖成本 | 服务费透明 | 综合能源服务 |

- **"固定价"不是不能做**：要做压力测试、对冲、限额；不能把全年电量都锁死在低价。
- **"分时价"要匹配用户曲线**：用户峰段用电占比高，分时套餐可能更贵；要提前测算。
- **"均价套餐"是 2026 年的探索方向**：把批发均价传导给用户，减少批零倒挂；但用户接受度、规则认可度要看地方。
- **"服务费模式"是转型方向**：从价差套利转向服务增值；但服务费要透明、可计量、可比较。

### 9.4 零售侧风险控制

| 控制 | 做法 | 频率 | 责任 |
|---|---|---|---|
| 用户信用 | 查信用、收保证金、预付费 | 签约前/持续 | 销售/风控 |
| 负荷预测 | 按行业、历史、天气建模 | 日/月 | 交易/量化 |
| 批零匹配 | 中长期+现货+零售曲线匹配 | 月/周 | 交易 |
| 压力测试 | 现货价格 ±50%、偏差 ±10% | 季/月 | 风控 |
| 合同条款 | 价格调整、偏差分摊、终止权 | 签约前 | 法务/销售 |
| 担保 | 保函/保险/现金 | 持续 | 财务 |
| 信息披露 | 套餐、价格、费用 | 按月 | 合规 |
| 退出预案 | 用户承接、合同转让、保底 | 年/触发 | 管理层 |

- **"用户信用"不是只看营业执照**：要看行业景气、用电历史、拖欠记录、实际控制人信用。
- **"压力测试"要覆盖极端情景**：现货价格翻倍、负电价、偏差翻倍、用户流失、保函被执行。
- **"退出预案"要提前做**：不要等被暂停才想用户怎么办；合同里要写终止、转让、保底衔接。

### 9.5 零售合同的"高压线"

| 行为 | 为什么危险 | 可能后果 |
|---|---|---|
| 低于成本报价 | 不正当竞争、不可持续 | 处罚、信用下调、资金链断裂 |
| 阴阳合同 | 逃避监管、欺骗用户 | 合同无效、处罚、信用下调 |
| 线下返利 | 绕过平台、隐瞒价格 | 处罚、用户投诉、信用下调 |
| 虚假套餐 | 误导用户、价格欺诈 | 处罚、退款、信用下调 |
| 强制搭售 | 侵犯用户选择权 | 投诉、处罚 |
| 不披露偏差责任 | 争议、投诉 | 合同纠纷、监管关注 |
| 擅自终止合同 | 违约、用户断电风险 | 赔偿、处罚、退出 |
| 挪用保证金 | 违法、资金链风险 | 刑事/行政责任 |

- **"低价"不是竞争力**：没有对冲、没有服务、没有资金的低价，最终会变成违约。
- **"合同外承诺"风险最高**：销售口头承诺、微信返利、线下协议，一旦发生争议，公司要承担。
- **"用户知情权"是监管重点**：价格、费用、偏差责任、退出方式，都要写清楚。

## 11. 十五个常见误区

1. **"有履约保函就万事大吉"**：保函只覆盖部分敞口；逐日盯市、补缴、执行、追偿都可能发生；保函不足会被暂停交易。
2. **"履约保险等于保函"**：保险有除外责任、免赔、赔付流程；低信用主体可能被禁止用保险；"优先赔付"不等于"无条件全赔"。
3. **"注册资本 2,000 万元就是履约保障"**：2,000 万元是注册资本门槛，200 万元是履约保障最低额度，两者不是一回事。
4. **"信用评价一年一次"**：原则上每季度一次，另有动态调整；严重失信可能几个工作日内下调。
5. **"A 级是终身制"**：季度评价、动态调整；公共信用 D 不能为 A；违规、欠费、保函不足都会降级。
6. **"偏差考核全国统一 ±5%"**：1656 号没有统一阈值；各省免考区间、考核价格、责任分摊不同；套全国会出错。
7. **"偏差罚款按全部偏差电量"**：多数规则只对超出免考区间的部分按考核价结算；具体分段看省级规则。
8. **"现货价格就是零售价格"**：零售套餐有固定价、分时价、均价、服务费；还有输配电价、基金附加、系统运行费。
9. **"售电公司退出就断电"**：用户会转保底售电/代理购电；不断电，但价格、合同、发票会变。
10. **"保底售电永远 1.5 倍/2 倍"**：这是现行/地方做法；2026 草案拟改为按现货实时价格结算；正式稿未定。
11. **"结算单就是最终结果"**：还有异议、追退补、争议调解、仲裁；15 个工作日内可以提异议。
12. **"不平衡资金可以设池子"**：976 号明确不得设置不平衡资金池；结算项目独立记录、分类疏导。
13. **"信用修复自动完成"**：要申请、整改、履行义务；修复后仍可能留痕。
14. **"关联交易没有限制"**：2026 售电办法草案对发电集团与所属售电公司、同一实际控制人多售电公司有比例约束。
15. **"风险防控只是交易中心的事"**：经营主体要建内控、申报差错自担；电网企业要配合；政府要审定、提级、恢复。
16. **"零售合同可以阴阳/线下返利"**：这是高压线；可能导致处罚、信用下调、退出。
17. **"偏差责任全由售电公司承担"**：合同可以约定分摊；用户侧、电网侧、不可抗力、新能源出力都有责任边界。

## 12. 待核实与未定事项

### 数据口径提醒

- **草案 vs 现行**：2026 售电办法、风险防控办法、信用评价指引都是征求意见稿；本文标注"草案"的数字不能当现行法。
- **国家 vs 省级**：偏差免考区间、考核价格、保底售电价格、履约保障系数，很多在省级细则；不要用国家文件套地方。
- **保障额度口径**：现行 1595 号是"12 个月批发购电量 × 0.8 分/kWh"与"2 个月最大购电量 × 5 分/kWh"取大；2026 草案是"预计年售电量 × 1 分/kWh × 系数"；两者不能混算。
- **信用分数 vs 信用评级**：电力市场信用评价是行业维度，不等同于银行评级、债券评级；A 级也不等于"没有风险"。
- **保函 vs 保险 vs 现金**：三种凭证的额度、费用、赔付、限制不同；比较时要看总成本，不只看费率。
- **结算时限**：5/8/10 是"工作日"，遇节假日顺延；地方可能更严；异议 15/5 也是工作日。
- **偏差考核**：全国没有统一 ±5%；本文引用的省级数字标注级别，C 级只作线索，决策前查原文。
- **零售数据**：400+ 家退出、广东亏损面、度电收益等来自公开报道/交易中心，口径可能是"参与统计的主体"而非全行业；引用时注明来源和级别。
- **算例**：本文的保函、偏差、退出算例都是假设，用于说明计算逻辑，不是对具体项目的预测。
- **规则版本**：2026 年是规则密集修订年；做交易决策前，先查交易中心最新公告和生效日，再套本文框架。
