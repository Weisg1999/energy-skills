# 四川水电 · 丰平枯分期对冲实例

> 本目录是 `skills/electricity-trading-expert/instances/` 的四川纵向切片：**一省（四川）+ 一主体（300 MW 径流式水电、常规直购机组）+ 一个规则版本（规则体系 V4.0 行业口径 + 420/421 号征求意见稿架构，均未核到省级正式印发全文）**。配置改 `instance.json`，数据换 `data/profile_demo.csv`，运行 `run.py`，不改代码。核心问题不是"水电能不能赚钱"，而是：**中长期合同按丰平枯分期签下去，差价结算到底托住了什么、让渡了什么，丰水期余量走弃水电量消纳值不值**。
>
> 市场状态：四川现货 **2025-11 起连续结算试运行，未转正式运行**（B，截至 2026-11-12 未核到转正文件）；中长期纯金融对冲、物理电量按现货价结算（C）；日前预出清不结算、日内滚动、实时出清并结算（C/草案）。除已标注级别的规则事实外，装机、来水形态、电量、价格与合同比例均为 **D 级合成数据**，不对应任何真实水电站或交易；本实例包是 D 级合成样板，不构成报价、投资或法律建议。

## 1. 一条命令

```bash
# 配置校验 + 来源表 + 待核实清单
python skills/electricity-trading-expert/instances/sichuan-hydro-2026-11/run.py --check-config

# 合成数据全流程：丰平枯合同分解 → 金融差价结算 → 弃水情景 → 三种策略 → 敏感性
python skills/electricity-trading-expert/instances/sichuan-hydro-2026-11/run.py --demo

# 真实数据（路径指向仓库外）
python skills/electricity-trading-expert/instances/sichuan-hydro-2026-11/run.py \
  --profile /path/to/profile.csv --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/electricity-trading-expert/instances/sichuan-hydro-2026-11/make_demo.py
```

Windows 控制台默认 GBK，所有 python 命令前加 `PYTHONIOENCODING=utf-8`。

## 3. 运行逻辑（从输入到复核表）

1. **配置校验**：六个块齐全；三个规则块都有 `grade` + `source` + `status`；常规直购丰/平/枯分期比例（B）三季和为 1 且水期月份划分必须等于模块口径（丰 6–10 月、平 5/11 月、枯 1–4 及 12 月，C）；合同价必须低于分期限价（C 行业口径）；中长期角色只实现 `financial_hedge`（纯金融对冲，C）；现货申报/出清限价必须为空并写明待核实状态；弃水丰平比之和为 1。
2. **资源数据**：12 个月、同一年、月份升序；`season` 列必须与模块水期划分一致；现货价只在 2025 年 109 天试运行实测区间 −0.05 ~ 0.8 元/kWh（B）内校验——这是**数据合理性边界，不是限价**；合同权重合计为 1，且每季权重合计对齐常规直购分期比例（B）；丰水期发电占比低于 40% 时告警。
3. **合同分解**：合同电量 = 计划电量 × 合同比例 × 月度权重；权重由季内出力形态 × 全省常规直购分期比例（45.23/16.73/38.04，B）生成。
4. **金融差价结算**：物理电量全部按现货价结算（C）；合同结算 `合同电量 × (合同价 − 当月现货价)`——丰水期现货低于合同价为正（托底），枯水期现货冲高越过合同价为负（让渡上行）。
5. **弃水情景**：丰水期余量（发电量 − 合同电量）可走弃水电量消纳（2025 均价 0.1477 元/kWh、丰平比 86.42%/13.58%，B），按 `余量 × (弃水价 − 现货价)` 计增益；平水期余量留现货。
6. **策略比较**：`all_spot`（不对冲）、`contract_cfd`（中长期对冲）、`contract_cfd_surplus`（对冲 + 弃水消纳）三种策略分别计算净收入与净价，取净收入最大者为最优。
7. **敏感性**：现货整体 +30%/−20%、丰水期 −40%、枯水期 +30%、合同价 −0.02、枯季合同价 −0.03、合同比例 65%/90%、弃水价 −0.03、弃水品种缺失、来水枯年 −12%，共 12 个情景。

## 4. 合成演示的基准输出（2027 首个完整交易年）

| 项目 | 值 |
|---|---:|
| 装机容量 | 300 MW（径流式，无调节库容） |
| 计划 / 实际发电量 | 1,440,000 / 1,440,000 MWh |
| 丰/平/枯发电占比 | 61.50% / 14.00% / 24.50% |
| 合同电量（80%，按 45.23/16.73/38.04 分解） | 1,152,000 MWh |
| 丰/平/枯合同覆盖率 | 58.84% / 95.60% / 124.21% |
| 合同价（丰/平/枯） | 0.185 / 0.260 / 0.360 元/kWh（低于分期限价 211.43/333.84/415.63 元/MWh，C） |
| 加权现货捕获价 | 0.1913 元/kWh（2025 现货均价 0.2193，B；捕获率约 0.87） |
| 差价结算合计 | +4,990.19 万元（其中 1 月、12 月让渡上行 −375.62 万元） |
| 丰水期弃水余量 / 弃水增益 | 364,550 MWh / +633.40 万元 |

| 策略 | 净收入（万元） | 净价（元/kWh） | 较全现货（万元） |
|---|---:|---:|---:|
| 全电量现货（不对冲） | 27,554.40 | 0.1913 | +0.00 |
| 中长期对冲（余量留现货） | 32,544.59 | 0.2260 | +4,990.19 |
| 中长期对冲 + 弃水消纳 | 33,177.98 | 0.2304 | +5,623.58 |

**最优策略是"中长期对冲 + 弃水消纳"**，但三条结论比排名更重要：

- **对冲保护的是丰水期下行**：丰水期合同价 0.185 元/kWh 托住约 129 元/MWh（C 口径）的现货低价；枯水期现货冲高（2026-11 行业报道部分尖峰触及 730 元/MWh，C）时锁价反而让渡上行。
- **别人的分期比例不是你的分期比例**：按全省常规直购分期比例（B）签出的合同，对丰水期占比 61.5% 的径流式机组意味着枯水期 124% 超对冲、丰水期 59% 欠对冲——签约前必须用本站丰平枯出力形态重排合同曲线。
- **弃水通道只是薄溢价出口**：弃水价 0.1477 元/kWh（B）与丰水期现货价之差很薄，10 月现货越过弃水价时该月余量走弃水反而倒挂；敏感性显示弃水价跌 0.03 或品种缺失时，最优策略退回"中长期对冲"。

现货整体 +30% 时全现货策略反超（最优净收入较基准 +2,642.74 万元）；来水枯年 −12% 时最优净收入下降 3,491.17 万元——合同电量固定、来水缩水会加深超对冲。

## 6. 风格档与指纹

当前风格 `sichuan-hydro-ffkk-hedge-v1`：80% 计划电量按全省常规直购分期比例（B）分解签常规直购合同，合同按金融差价结算（C 口径的 D 级简化）；丰水期余量走弃水电量消纳（B 价），平水期余量留现货；策略比较以净收入最大为最优。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `3094fdc471a6`）。比较两个水电项目的差异时，先看指纹是否相同：指纹不同，差异首先归因于合同比例与弃水处理；指纹相同，才归因于来水形态或价格。

换风格的做法：复制 `instance.json` 为 `instance.selfshaped.json`，改 `profile_id` 并把合同权重改成按本站出力形态分解（消除枯水期超对冲），用 `--instance` 指向新文件，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库 + 本技能 `tools/contracts.py` 的捕获价函数；不加载 EMS 内核，不调用其他技能。
- **纳入**：丰平枯分期合同分解、金融差价结算、枯水期超对冲诊断、丰水期弃水消纳情景、三种策略比较、12 个敏感性情景、现货价实测区间合理性校验。
- **未纳入**：24 时段带曲线签约（V4.0 行业口径，C）、省间外送与丰枯打捆（A 级事实归省间市场）、辅助服务（现货连续结算试运行后省内调峰市场不再运行，C/草案）、煤电容量电价（231 元/kW·年，C，与本主体无关）、偏差考核与 291 号文收益回收、零售套餐、水头/径流曲线/库容等资产参数。
- **不是**：不是交易执行工具，不是来水预测，不是对四川现货价格的预测，不是投资建议；日前预出清价在本包中不作为结算依据（C/草案）。
- 真实数据放在仓库外，用 `--profile/--out` 指向本地路径；仓库内只保留 D 级合成样例。

## 8. 如何换真实数据

1. 按 `data/profile_demo.csv` 的列导出你的月度数据：`month`（YYYY-MM）、`season`（丰/平/枯，必须与模块水期划分一致）、`generation_mwh`、`contract_weight`（合计为 1，每季合计对齐你的签约分期比例）、`spot_price_cny_per_kwh`（月度或结算周期均价；在 −0.05 ~ 0.8 元/kWh 实测区间内）。
2. 在 `instance.json` 的 `policy.contract_price_cny_per_kwh` 填你各季的实际成交价（不得高于分期限价 C 口径），`contract_ratio` 填实际对冲比例。
3. `rules.surplus_water.avg_price_cny_per_kwh` 更新为当年弃水电量消纳实际成交均价（2025 口径 0.1477 元/kWh 为 B）。
4. 运行 `run.py --profile /path/to/profile.csv --out /path/to/out`；真实台账不上传、不入库。
