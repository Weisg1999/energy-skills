# 甘肃风电送山东 · 省间组合实例

> 本目录是 `skills/electricity-trading-expert/instances/` 的省间纵向切片：**一省送出（甘肃）+ 一省落地（山东）+ 一主体（200 MW 风电项目公司）+ 一个规则版本（发改办体改〔2026〕275号、发改能源规〔2025〕1656号、2027 年跨省跨区输电价格表）**。配置改 `instance.json`，数据换 `data/profile_demo.csv`，运行 `run.py`，不改代码。核心问题不是"能不能送出去"，而是**合同电量与余量分别走哪条通道、扣掉输电价和网损后还剩多少净价**。
>
> 所有电量、合同比例、山东落地价、甘肃本地价、现货价、绿电溢价与通道参数均为 **D 级合成数据**，不对应任何真实项目、通道或交易；规则文号仅用于演示计算链，不构成交易、投标或投资建议。

## 1. 一条命令

```bash
# 配置校验 + 来源表
python skills/electricity-trading-expert/instances/gansu-wind-to-shandong-2026-11/run.py --check-config

# 合成数据全流程：月度电量 → 合同分解 → 通道扣减 → 三种组合 → 敏感性
python skills/electricity-trading-expert/instances/gansu-wind-to-shandong-2026-11/run.py --demo

# 真实数据（路径指向仓库外）
python skills/electricity-trading-expert/instances/gansu-wind-to-shandong-2026-11/run.py \
  --profile /path/to/profile.csv --out /path/to/out
```

```bash

```

## 3. 运行逻辑（从输入到复核表）

1. **配置校验**：六个块齐全；三个规则块都有 `grade` + `source`；合同比例在 0–1；输电价与线损非负；只实现 `receiving_landing` 结算参考；数据契约必须包含 month / generation_mwh / contract_weight / spot_price_cny_per_kwh / green_ratio。
2. **资源数据**：12 个月、同一年、月份升序；合同曲线权重归一化后用于月度分解；月度电量合计作为实际发电量。
3. **合同分解**：合同电量 = 计划电量 × 合同比例 × 月度权重；自有合同电量 = min(发电量, 合同电量)；余量 = 发电量 − 合同电量（正）；偏差 = 合同电量 − 发电量（正）。
4. **通道扣减**：输电价按**落地电量**计（送出省 + 区域电网 + 专项工程）；网损按**发电量**计；合同综合扣减 = 线损 × 合同价 + (1 − 线损) × 输电价合计，不重复乘线损。
5. **组合结算**：合同电量按落地价减输电价结算，绿电溢价只落在自有合同电量；余量在省间现货（落地价减输电价、扣网损）与甘肃本地价之间二选一；偏差按当月现货价或本地价回购。
6. **组合比较**：`local_only`、`contract_spot`、`contract_local` 三种组合分别计算净收入与净价，取净收入最大者为最优。
7. **敏感性**：输电价 +20%、线损 7%、现货价 ±、合同价 −0.02、本地价 0.20/0.24、合同比例 50%/80%、发电量 −10%、绿电溢价 0，共 12 个情景。

## 4. 合成演示的基准输出（2027 首年）

| 项目 | 值 |
|---|---:|
| 装机容量 | 200 MW |
| 计划 / 实际发电量 | 480,000 / 480,000 MWh |
| 合同电量（70%） | 336,000 MWh |
| 合同内自有电量 | 333,600 MWh |
| 余量 / 偏差 | 146,400 / 2,400 MWh |
| 绿电电量（合同内 30%） | 100,080 MWh |
| 合同落地价 / 甘肃本地价 | 0.3300 / 0.2200 元/kWh |
| 加权现货落地价 | 0.2580 元/kWh |
| 输电价合计 / 线损率 | 0.0821 元/kWh / 5.00% |
| 合同综合扣减 / 现货综合扣减 | 0.0945 / 0.0909 元/kWh |
| 合同净价（含绿电）/ 现货余量净价 | 0.2412 / 0.1671 元/kWh |

| 组合 | 净收入（万元） | 净价（元/kWh） | 较全部本地（万元） |
|---|---:|---:|---:|
| 全部本地 | 10,560.00 | 0.2200 | +0.00 |
| 合同 + 省间现货余量 | 10,505.48 | 0.2189 | −54.52 |
| 合同 + 本地余量 | 11,271.32 | 0.2348 | +711.32 |

**最优组合是"合同电量外送、余量本地消纳"**：合同净价只比本地高 2.12 分/kWh，靠 70% 的合同比例把整体净价拉到 0.2348；余量走省间现货的净价 0.1671 低于本地 0.2200，因此"合同 + 现货"反而比全部本地低 54.52 万元。外送规模不是越大越好，边际电量要看净价。

## 6. 风格档与指纹

当前风格 `gansu-wind-export-portfolio-v1`：70% 电量签省间合同，余量在省间现货与本地市场之间取净收入较大者；偏差按当月对应价格回购；组合比较以净收入最大为最优。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `3eff3574b5b8`）。比较两个外送项目的差异时，先看指纹是否相同：指纹不同，差异首先归因于组合风格与合同比例；指纹相同，才归因于资源、价格或通道参数。

换风格的做法：复制 `instance.json` 为 `instance.conservative.json`，改 `profile_id`、合同比例与偏差处理，用 `--instance` 指向新文件，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库 + 本技能 `tools/contracts.py` 的捕获价函数；不调用其他技能。
- **纳入**：月度资源曲线、合同电量分解、自有合同电量、余量与偏差、送出省/区域/专项工程输电价、网损、绿电溢价、三种组合比较、12 个敏感性情景。
- **未纳入**：省内现货分时曲线、通道 ATC 分配、输电权、不平衡资金分摊、落地省输配电价、系统运行费、政府性基金、合同违约金、绿证核销与绿电交易溢价细节。
- **不是**：不是交易执行工具，不是通道可用容量评估，不是对甘肃—山东价差或外送收益的预测，不是投资建议。
- 真实数据放在仓库外，用 `--profile/--out` 指向本地路径；仓库内只保留 D 级合成样例。
