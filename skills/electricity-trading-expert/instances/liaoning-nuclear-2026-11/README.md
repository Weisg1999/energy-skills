# 辽宁核电机制电价＋中长期＋现货差价结算实例包

> 一个 6,000 MW 级核电厂切片（1-4 号 / 5-6 号两个机组组）、一个 2026-11 财务合约簿、一个交易日（2026-11-18）的**可运行切片**。回答的不是"明天报什么价"，而是**机制电量怎么认定（21h 窗口 × 80%）、机制差价线与电能量差价线怎么分账、负电价时段谁在兜底谁在裸奔、T+1 收入差归因给谁**。

这是 `electricity-trading-expert` 实例层的一个"一省 + 一主体 + 一规则版本"切片：**辽宁现货试行 V4.0（1+7，2026-01-01 新版限价）＋辽发改价格〔2026〕142号核电机制电价**。规则事实全部引自 [`../../../../knowledge/辽宁电力市场-2026-11.md`](../../../../knowledge/辽宁电力市场-2026-11.md) 并逐条保留级别（A/B/C）。

> **两条结算线分账、不能混算（A）**：机制电量按 142 号文单独差价结算；电能量市场全电量按实时现货价定价、中长期合约转为财务合约（A/B）——机制线与电能量差价线是两本账，本包的每一步都分开算、最后对账。**本实例包是 D 级合成样板，不构成报价、投资或法律建议；不对应红沿河核电站真实生产数据**：装机、负荷因子、合约组合与价格情景全部为 D 级占位，只有 142 号三个机制电价（0.3798/0.3823/0.3749 元/kWh，A）、21 小时窗口（02:00–05:00 不纳入，A）、80% 电量比例（A）与现货限价（申报 −0.1–1.1、出清 −0.1–1.5 元/kWh，A）是规则事实。

## 3. 运行逻辑（8 步）

1. **读配置**：`instance.json` 六个块 `meta` / `rules` / `asset` / `book` / `policy` / `data_contract`；五个规则块（spot / mid_long_term / mechanism / settlement / deviation）必须有 `grade` + `source`，`rules.mechanism.pending` 必须列明待核实项。
2. **机制电量认定**：02:00–05:00 三小时排除（A）→ 剩余 21 小时窗口 × 80%（本包按窗口电量口径实现，分母口径待核实）→ 按机组组容量比例拆分，1-4 号按 0.3823、5-6 号按 0.3749 元/kWh 记固定收入。
3. **分解合约曲线**：财务 CfD 按 `period_days` → 日电量 → 形状（`base` / `window` / `complement` / `anchors`）→ 24 时段电量；**合约只能落在市场电量上**，落在机制电量上就是重复结算。
4. **机制差价结算线**：`Σ 机制电量 ×（机制电价 − 实时价）`，按 142 号文单独结算（A）。
5. **电能量差价结算线**：`Σ 合约电量 ×（合约价 − 实时价）`；全电量先按实时价定价（A/B），日前预出清价只作信号、不进任何收入公式。
6. **两线分账对账**：`总收入 = 机制电量×机制电价 + 合约电量×合约价 + （上网 − 机制 − 合约）× 实时价`，恒等式残差必须为 0；两条线各拆 carry / shape。
7. **负电价时段敏感性**：逐负价时段拆"机制兜底 / 市场残差 / 幻觉差"；02:00–05:00 机制电量为 0，全部裸奔。
8. **T+1 五桶差异桥**：计划（预测出力 + 规则认定机制电量 + 合约簿 + 参考价）与实际（实测出力 + 认定机制电量 + 结算合约量 + 实时价）拆成机制电量 / 合约总量 / 合约曲线 / 上网电量 / 实时价五桶，残差 ≈ 0。

## 4. 关键公式

```
机制电量 qm_t = 1(时段 t ∉ [02:00,05:00)) × 80% × 上网电量_t（按机组组拆分）
机制差价   = Σ qm_t × (c_机制 − s_t)          ← 142 号单独结算线（A）
合约差价   = Σ qc_t × (c_合约 − s_t)          ← 电能量财务合约线（A/B）
总收入     = Σ 上网电量_t × s_t + 机制差价 + 合约差价
           = qm×c_机制 + qc×c_合约 + (上网 − qm − qc)×s_t   （分账对账恒等式）
负价幻觉差 = Σ_负价时段 上网×0.3798 − (qm×c_机制 + 残差×s)   ← 把全电量当机制电价的错误口径
```

其中 `s_t` 是**实时现货价**（辽宁日前仅预出清、暂停日前结算，A/B；本包工作粒度 24 时段为 D 级简化）。对冲比例的分母是**市场电量**（上网 − 机制），不是全上网电量。

> 这组数字的教学点：**两条 CfD 线盖住了约 96% 的电量，总收入对价格情景几乎不敏感**（48.3M→49.6M），残余波动全部来自 4,840 MWh/日净敞口——其中 02:00–05:00 的 3 小时贡献了绝大部分风险（无机制兜底，情景 1 下 −100 CNY/MWh 全额裸奔）。机制线 shape 为负（−3.36M）：机制电量集中在白天与晚峰高价时段，按固定 0.3798 元/kWh 结算等于把高价时段卖便宜了——这是机制电价"兜底换让利"的结构，与合约线的正 shape（夜谷重仓）方向相反。

## 7. 边界

- **只用实时价结算**：日前预出清价只作信号对照；实时偏差考核、两个细则、辅助服务、容量三层口径（煤电 100/165 元/kW·年；370 元可靠容量补偿为征求意见稿拟 2027-01-01，A 草案）均未纳入，本表收入不是最终结算收入，也不是利润。
- **只做财务 CfD**：物理执行合约、绿电合约、省间合约不在 v1；节点价结算的推进节奏未建模（统一定价为 D 级简化）。
- **机制电量按规则推算**：本包用 21h × 80% 口径认定，实际以结算单认定为准；80% 分母口径、0.3798 平均的加权口径、2027 年续期安排均挂待核实（C），见 `rules.mechanism.pending` 与 `review.md` §1。
- **不构成建议**：全部为 D 级合成数据，不对应红沿河核电站真实生产数据，不构成报价、投资、法律或税务建议。
