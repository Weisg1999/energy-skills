# 山东水泥碳履约 · 2025 配额年度样板实例

> 本目录是 `skills/carbon-asset-expert/instances/` 的第一个纵向切片：**一省（山东）+ 一主体（水泥熟料重点排放单位）+ 一个规则版本（水泥行业 2025-11-18 分配方案 + 国务院令第 775 号）**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 全部产量、排放、价格与持仓均为 **D 级合成数据**，不对应任何真实企业。

## 1. 一条命令

```bash
# 配置校验 + 规则来源表
python skills/carbon-asset-expert/instances/shandong-cement-carbon-2025/run.py --check-config

# 合成数据全流程：分配 → 缺口 → CCER 抵销 → 策略比较 → 采购时点 → 履约日历
python skills/carbon-asset-expert/instances/shandong-cement-carbon-2025/run.py --demo

# 真实数据（路径指向仓库外）
python skills/carbon-asset-expert/instances/shandong-cement-carbon-2025/run.py \
  --instance /path/to/instance.json --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/carbon-asset-expert/instances/shandong-cement-carbon-2025/make_demo.py
```

## 3. 运行逻辑（从输入到复核表）

1. **配置校验**：六个块齐全；每个规则块有 `grade` + `source`；`grade` 必须在已知分级内；购买模式只能是 `ccer_first` / `cea_only` / `break_even`。
2. **读数据**：产量必须是 12 个月、月份连续；核查表必须有且仅有 2025 年度一行；价格表至少 6 个月，且包含 `rules.prices.price_month`。
3. **算强度**：核实排放量 ÷ 熟料产量，必须落在 0.5–1.5 tCO2/t，否则视为数据错位。
4. **免费分配**：`原始分配 = 产量 × 基准线 × 强度修正系数`；再按 `核实排放量 × (1 + 盈余上限比例)` 封顶，得到有效分配。
5. **履约头寸**：缺口 = 核实排放量 − 有效分配；CCER 可抵销上限 = 核实排放量 × 5%，再与持有量、缺口取小；剩余缺口用 CEA 持仓和采购补足。
6. **策略比较**：全买 CEA、CCER 优先、盈亏平衡三种合规路径，与未清缴 5 倍 / 10 倍罚则对比；成本只计增量采购与交易成本，已持有配额和 CCER 按沉没成本处理。
7. **采购时点**：把当前月 CEA 价格与价格表中最低月比较，按推荐策略的 CEA 采购量估算差额；标注为**事后视角，不是预测**。
8. **履约日历**：按报告（3-31）、核查（6-30）、清缴（12-31）生成 7 个节点，输出 ICS 与复核表。

## 4. 合成演示的基准输出（2025 配额年度）

| 项目 | 值 |
|---|---:|
| 熟料产量 | 1,550,000 t |
| 原始分配（0.86 × 产量） | 1,333,000 t |
| 盈余上限（核实排放 × 1.03） | 1,472,900 t |
| 有效分配 | 1,333,000 t（上限未触发） |
| 核实排放量 | 1,430,000 tCO2e |
| 排放强度 | 0.9226 tCO2/t 熟料 |
| 缺口 | 97,000 t |
| CCER 抵销上限（5%） | 71,500 t |
| CCER 可用 / 已用 | 40,000 / 40,000 t |
| CEA 需求 | 57,000 t |
| CEA 持仓 / 采购 | 20,000 / 37,000 t |

| 策略 | CCER 用量 | CEA 采购 | 增量成本 | 相对最优 |
|---|---:|---:|---:|---:|
| 全买 CEA | 0 t | 77,000 t | 7,184,100 元 | +288,000 元 |
| CCER 优先 | 40,000 t | 37,000 t | **6,896,100 元** | 0 |
| 盈亏平衡 | 40,000 t | 37,000 t | 6,896,100 元 | 0 |
| 未清缴 5 倍 | 0 | 0 | 17,075,500 元 | +10,179,400 元 |
| 未清缴 10 倍 | 0 | 0 | 34,151,000 元 | +27,254,900 元 |

- **CCER 盈亏平衡价 91.30 元/t**（= CEA 92.30 + CEA 交易成本 1.00 − CCER 交易成本 2.00）；当前 CCER 84.10 元/t，低于盈亏平衡价，所以 CCER 优先优于全买 CEA。
- **采购时点**：当前月（2026-11）CEA 92.30 元/t；示例价格序列最低月为 2026-08 的 80.60 元/t，37,000 t 的事后差额 432,900 元。这是事后最低价，不能当作采购建议。
- **未清缴罚则**按缺口 37,000 t 计（缺口扣减可用 CCER 与 CEA 持仓后仍未清缴的部分）× 市场均价 × 5 或 10。

## 6. 风格档与指纹

当前风格 `carbon-compliance-ccer-first-v1`：CCER 优先、CEA 交易成本 1.0 元/t、CCER 交易成本 2.0 元/t、按 CEA 最低月采购。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `26f9f050aba2`）。比较两次履约的差异时，先看指纹：指纹不同，差异首先归因于策略参数；指纹相同，才归因于产量、排放或价格。

换风格的做法：复制 `instance.json` 为 `instance.cea-only.json`，改 `profile_id` 与 `purchase_mode`，用 `--instance` 指向新文件，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；复用 `tools/compliance.py` 与 `tools/calendar_tool.py`，分配、抵销、罚则与日历口径与技能层一致。
- **纳入**：基准线分配、盈余上限、CCER 5% 抵销、CEA 补缺、策略比较、盈亏平衡价、采购时点复盘、履约日历。
- **未纳入**：CBAM、集团合并履约、含碳量检测、地方试点配额、配额预分配与结转的会计处理、交易对手信用与履约担保。
- **不是**：不是合规意见，不是价格预测，不是交易建议。正式履约以主管部门清缴通知、注册登记系统与核查报告为准。
- 真实数据放在仓库外，用 `--instance/--out` 指向本地路径；仓库内只保留 D 级合成样例。
