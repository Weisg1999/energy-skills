# guangdong-retail-inversion-2026-11 —— 广东售电批零倒挂：失败重放与止损边界

> **失败复盘包：量化倒挂损失与止损边界。**
> 本包回答两个问题：一套"固定价套餐 + 无联动 + 无止损"的售电结构，在现货价格上行时一年亏多少、亏在哪（客户群 × 月份）；以及这套结构的不亏参数域在哪——批发成本涨多少、套餐联动比例留多少、止损线设在几块，年度净才能守住 0。
> 它是策略失败/边界类实例（`package_kind = strategy_failure_boundary`），不是定价器，也不是报价建议。

本包与 `knowledge/合成案例复盘库-2026-11.md` **案例 7（批零倒挂·套餐无联动无止损）** 一一对应：案例 7 给出的是叙事复盘——一口价年度套餐、压力测试只测价跌、没有止损三件套（毛利警戒线 + 动作清单 + 触发权限）；本包把同一套错误装进可运行模型，用 D 级合成数据量化"如果当年就是这么干，财报上会是什么样"，并扫出止损边界。案例 7 的"正确做法"（套餐分层固定+联动、双向压力测试、合同预埋解约/转售/调价条款、用户组合按负荷形态分层）在本包中体现为 Track B/C 对照盘与联动参数表。

## 一条命令

```bash
cd skills/retail-electricity-risk/instances/guangdong-retail-inversion-2026-11
PYTHONIOENCODING=utf-8 python make_demo.py && PYTHONIOENCODING=utf-8 python run.py --demo
```

- `python run.py --check-config`：只校验配置、打印规则来源表与警告（不产数据）。

- 全部 stdlib + 仓库引擎层 `tools/`（package/deviation/guarantee/portfolio/curves），确定性输出（同输入同结果），产物写 `out/`。

## 基准结果（demo 数据，全部 D 级合成）

- 复盘窗口 2025-12 .. 2026-11（12 个月），年实际电量约 1,214,499 MWh。
- **Track A 失败盘**（100% 固定价、无联动、无止损）：年度净 **−28,975,173 CNY**（−23.86 CNY/MWh），倒挂 8 个月，最深 2026-08（−76.50 CNY/MWh）。
- **Track B 对照盘**（签约即联动 60%）：年度净 −8,582,956 CNY（−7.07 CNY/MWh）。
- **Track C 止损盘**（止损线 0 + 联动触发价 430，2026-04 触发、滞后 1 个月、2026-05 起转联动 60%）：年度净 −9,816,699 CNY，较失败盘挽回 19,158,474 CNY。
- 最大亏损点：大工业（连续生产）× 2026-08（−3,926,443 CNY）；按客户群年度：大工业 −13.99M、一般工商业 −10.36M、中小零售用户 −4.63M CNY。
- **止损边界扫描**（216 组网格，仅 5 组不亏）：`批发成本较已实现路径再涨约 10% 后无任何不亏组合；存在不亏组合的最大涨幅 0%，最省联动的组合为止损线 20 CNY/MWh + 联动比例 95%（2026-01 起生效，年度净 +3,318,570 CNY）`。
- 情景对照（为什么当年没发现）：s1 下行（当年压测只测的方向）+11.35M、s2 中性（签约假设）+3.34M、s3 上行（没测）−69.30M、s4 尖峰上行（没测，现货最高 1,344 CNY/MWh，仍在 −50–1,800 限价内）−136.37M CNY。

三条轨道都是**对照情景**：Track A 量化倒挂损失，Track B/C 回答"当年如果有联动/止损会怎样"，不是历史事实。

## 场景设定（D 级合成，全部可改）

- 客户组合：大工业（连续生产）45%，固定 405 CNY/MWh，预测 σ 3%；一般工商业 35%，固定 410，σ 5%；中小零售用户 20%，固定 418，σ 6%。年预测电量 1,200,000 MWh。
- 批发：一份年约覆盖 70% @ 395 CNY/MWh；30% 现货敞口按当月现货价结算（偏差电量按实时价口径，广东 §3，B）。
- 已实现现货路径（年度基准）：388→402→375→392→455→470→505→545→640→600→520→490 CNY/MWh（全年均价约 481.8）。
- 偏差条款（合同约定，D 级假设）：免考带 ±3%、考核价 150 CNY/MWh；2026-02/08/09 三个月实际负荷超免考带。
- 担保：按 1595 号公式取大值 11,250,000 CNY（A），资金费率 1%/年；固定成本 1,500 CNY/天。
- 联动参数（对照盘/止损盘用）：传导系数 α=0.95、加价 36、下限 370、上限 750，目标联动比例 60%。
- 止损参数：止损线 0 CNY/MWh + 联动触发价 430 CNY/MWh（双触发条件），动作滞后 1 个月，动作清单见 `instance.json` `strategy.stop_loss.actions`。

## 口径与边界

- **月度电能量口径**：不含输配电价、政府性基金及附加、基本电费/需量电费、绿电溢价、容量补偿、辅助服务、坏账、用户流失、解约争议成本与税费。倒挂归因只在电能量口径内成立。
- **薄利背景**：广东 2026H1 售电公司平均度电收益约 0.0039 元/kWh、500 家样本中 298 家亏损（B/C）——几个百分点的批发涨幅就能吞掉全年利润，安全垫必须事前留，这就是为什么止损边界要扫而不是估。
- **止损只能减损**：扫描显示这套结构（α=0.95、覆盖 70%）在批发涨幅 ≥10% 时无任何（联动比例, 止损线）组合能不亏——涨出边界后靠的是提高传导系数（α→1）、提高覆盖或停止新增固定价电量，不是更晚的止损线。
- 联动不是开关，是剂量：α<1 时仍有 (1−α)×W 的敞口留在售电侧；联动下限要按成本反推，不能按市场价定（详见 `pitfalls.md`）。
- 本包是 D 级合成样板，不构成报价、投资或法律建议；不得把演示数据用于真实报价、签约或复盘归档。
