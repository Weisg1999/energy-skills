# 江苏售电零售 · 2027 样板实例

> 本目录是 `skills/retail-electricity-risk/instances/` 的第二个纵向切片：**江苏 + 一家售电公司 + 苏电交易〔2026〕11号（2027 年零售）**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示客户、价格、合同与计量数据均为 **D 级合成数据**，不代表任何真实售电公司、用户或交易结果。

## 1. 一条命令

```bash
# 配置校验 + 来源表 + 未核实项
python skills/retail-electricity-risk/instances/jiangsu-retail-2027/run.py --check-config

# 合成数据全流程：D-1 定价 → 月度封顶 → 情景/压力 → T+1 差异桥 → 复核表
python skills/retail-electricity-risk/instances/jiangsu-retail-2027/run.py --demo

# 真实数据（路径指向仓库外）
python skills/retail-electricity-risk/instances/jiangsu-retail-2027/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/retail-electricity-risk/instances/jiangsu-retail-2027/make_demo.py
```

## 3. 运行逻辑（从输入到封顶结算）

1. **配置校验**：六个块齐全；每个规则块有 `grade` + `source`；单位必须是 `CNY/MWh` 与 `MWh`；96 点与 15 分钟一致；客户群份额之和为 1；2026 年 1–8 月分摊表逐月自洽；年度零售窗口与“批发前 5 个工作日”日期关系可检查；套餐类型必须是 `pass_through_cap`。
2. **读 D-1**：单交易日、96 点无缺口、预测负荷非负、情景价格在 0–1,500 元/MWh 内；按 `price_reference_quantile` 对五个情景做**逐点加权分位**，得到计划参考价曲线。
3. **三层批发价**：`P_MT = 年度×0.5 + 月度×0.3 + 月内×0.2`；`P_wholesale,t = 70%×P_MT + 20%×P_DA + 10%×P_RT`（示例比例，配置可改）。现货只占传导价 30%，不是全部。
4. **参考价与封顶**：`P_ref = Σ_t max(年度, 月度, 月内, P_DA, P_RT) × Q_t / ΣQ_t`，按客户曲线加权；`P_cap = P_ref + F×P_wholesale + ΣK×P_allocation`。F 由购售双方约定，本包取 5%。
5. **一户一价**：按客户群曲线 `tilt` 拆分组合负荷；尖峰曲线 P_ref 更高、封顶更松，平坦曲线封顶更紧。组合平均封顶不能替代逐户测算。
6. **分摊**：以 2026-08 为基准月（P1=1.48、P2=5.34、P3=−0.11，合计 6.71 CNY/MWh）；传导系数 P1=0.8、P2=1.0、P3=0.5；未传导部分由售电公司吸收。2027 年按月公布，实际结算必须替换为当月值。
7. **情景与压力**：五个价格情景各算一次封顶前零售价、封顶价、扣减与净收益，得到期望净收益与 CVaR10；再按现货 ×0.8/1.0/1.2/1.5、F=0/0.05/0.10/0.20、浮动价 40/55/70、K 缩放 0/0.5/1.0、2026 年 1–8 月分摊做压力测试。
8. **T+1 差异桥**：把「计划净收益」与「实际净收益」拆成批发价差、参考价差、负荷量差、分摊价差、绿电环境价值、运营成本 6 项，残差应为 0；封顶影响作为单独诊断，不重复计入桥。
9. **复核表**：输出逐客户群封顶表、月度分摊参考表、情景尾部、压力表、差异桥、Top 5 偏差时段、合规清单与读法边界。

## 4. 合成演示的基准输出（2027-01-15）

| 项目 | 值 |
|---|---:|
| 组合预测电量 | 1,972.7 MWh |
| P_MT（年度/月度/月内加权） | 401.00 CNY/MWh |
| 批发均价 P_wholesale | 395.01 CNY/MWh |
| 参考价 P_ref | 428.52 CNY/MWh |
| 封顶前零售均价 | 456.48 CNY/MWh |
| 封顶均价 | 454.74 CNY/MWh |
| 加权封顶扣减 | 1.75 CNY/MWh |
| 触顶客户群 | 4 / 4 |
| 计划净收益 | 89,692 CNY（45.47 CNY/MWh） |
| 情景期望净收益 | 92,043 CNY |
| 情景 CVaR10 | 89,692 CNY |
| 实际净收益（T+1） | 93,280 CNY |
| 差异 | +3,588 CNY |
| 差异桥残差 | 0.00e+00 CNY |
| 封顶影响（诊断） | +0 CNY |

逐客户群看，封顶价从 451.90 到 456.51 CNY/MWh 不等：数据中心曲线最平坦（tilt=−0.60），P_ref 最低、封顶最紧，扣减 2.20；商业综合体曲线最尖峰（tilt=0.35），P_ref 最高、封顶最松，扣减 1.46。**“一户一价”不是一句口号，平坦负荷的封顶更紧，必须逐户算。**

演示日现货价格落在 286.88–466.87 CNY/MWh。现货 ×0.8、×1.2、×1.5 三档都不触顶，净收益回到 93,136 CNY（无扣减的理论上限）；只有 ×1.0 基准档触顶，扣掉 3,444 CNY。原因不是“现货越高越赚钱”，而是 P_ref 含日前/实时层、随现货 1:1 上行，P_wholesale 只有 30% 随现货，封顶反而放松。**这是传导型套餐的结构特征：售电公司赚的是浮动价与分摊 K 差，不是现货方向。**

## 6. 风格档与指纹

当前风格 `jiangsu-retail-2027-balanced-v1`：计划参考价取 0.5 分位；浮动价 55 CNY/MWh；F=0.05；分摊系数 P1=0.8、P2=1.0、P3=0.5；基准月 2026-08；现货压力 ×0.8/1.0/1.2/1.5；封顶系数 0/0.05/0.10/0.20；浮动价 40/55/70；分摊传导 0/0.5/1.0；复核表列 5 个最大偏差时段。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `3cfa9f5ae1b1`）。比较两个交易日的差异时，先看指纹是否相同：指纹不同，差异首先归因于风格；指纹相同，才归因于预测、执行或规则。

换风格的做法：复制 `instance.json` 为 `instance.aggressive.json`，改 `profile_id` 与参数，用本地路径运行，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；不依赖 `tools/` 里的函数，传导价、参考价、封顶与差异桥公式在本目录 `run.py` 内独立实现，便于单包审阅。
- **纳入**：2027 年江苏零售套餐的批发价传导、五层参考价、一户一价封顶、月度分摊与 K 系数、绿电能量/环境价值拆分、五情景与压力测试、T+1 差异桥、合规日期检查。
- **未纳入**：输配电价、政府性基金及附加、基本电费/需量电费、容量补偿、辅助服务、税费、坏账、用户流失、零售偏差考核、保函执行与信用评级；代表日不等于月度结算。
- **不是**：不是报价审批工具，不是交易中心结算的替代品，不是投资建议；D 级样本不能直接对外报价或签约。
- **封顶口径**：本包把 P_cap 作为月度标量、用代表日代理月度；实际必须用全月 96 点×天数、当月分摊值与逐户曲线。绿电封顶只作用于电能量传导部分、环境价值单独结算，属 D 级解释。
