# 广东售电零售 · 2026-11 样板实例

> 本目录是 `skills/retail-electricity-risk/instances/` 的第一个纵向切片：**一省（广东）+ 一个主体（售电公司）+ 一个规则版本**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示客户、价格、合同与计量数据均为 **D 级合成数据**，不代表任何真实售电公司、用户或交易结果。

## 1. 一条命令

```bash
# 配置校验 + 来源表 + 未核实项
python skills/retail-electricity-risk/instances/guangdong-retail-2026-11/run.py --check-config

# 合成数据全流程：D-1 定价与购电 → 情景/压力 → T+1 差异桥 → 复核表
python skills/retail-electricity-risk/instances/guangdong-retail-2026-11/run.py --demo

# 真实数据（路径指向仓库外）
python skills/retail-electricity-risk/instances/guangdong-retail-2026-11/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/retail-electricity-risk/instances/guangdong-retail-2026-11/make_demo.py
```

## 3. 运行逻辑（从输入到定价表）

1. **配置校验**：六个块齐全；每个规则块有 `grade` + `source`；单位必须是 `CNY/MWh` 与 `MWh`；96 点与 15 分钟一致；客户群份额之和为 1；联动套餐上下限合法；草案保函不得生效。
2. **读 D-1**：单交易日、96 点无缺口、预测负荷非负、情景价格在 −50–1,800 元/MWh 内；按 `price_reference_quantile` 对五个情景做**逐点加权分位**，得到参考价曲线。
3. **购电成本**：参考价按预测负荷加权得 `S_ref`；中长期覆盖 `c=75%` 锁价 `Pc=400`，加权采购成本 `W = c·Pc + (1−c)·S_ref`。
4. **套餐全成本**：`全成本 = W + 期望偏差 + 运营 + 担保资金 + 固定成本 + 风险缓冲 + 目标利润`。期望偏差按客户群 `σ`、合同免考带与考核价计算。
5. **建议价**：固定价套餐建议价 = 全成本；联动套餐建议加价 = 全成本 − `α·S_ref`，再按 `[floor, cap]` 裁剪；同时给出含/不含风险缓冲的保本现货价。
6. **情景与压力**：五个价格情景各算一次零售收入、购电成本、运营与固定成本，得到期望净边际与 CVaR10；再按现货 ×1.0/1.2/1.3/1.5 与预测误差 σ=2%/4%/6% 做压力测试。
7. **T+1 差异桥**：把「参考价口径计划净边际」与「实际价量口径实际净边际」的差，拆成零售收入量差/价差、现货购电量差/价差/量价交叉、合约成本差异、偏差考核、运营成本、担保资金成本 9 项，残差应为 0。
8. **复核表**：输出每个客户群的全成本缺口、情景尾部、压力表、差异桥、Top 5 偏差时段与读法边界。

## 4. 合成演示的基准输出（2026-11-18）

| 项目 | 值 |
|---|---:|
| 组合预测电量 | 2,880.0 MWh |
| 参考现货价 | 375.67 CNY/MWh |
| 加权采购成本 | 393.92 CNY/MWh |
| 当前加权零售价 | 414.43 CNY/MWh |
| 建议全成本价 | 418.14 CNY/MWh |
| 加权缺口 | +3.71 CNY/MWh |
| 计划净边际（参考价口径） | 37,070 CNY |
| 情景期望净边际 | 26,063 CNY |
| 情景 CVaR10 | −28,354 CNY |
| 现货净敞口 | 309.6 MWh |
| 组合保本现货涨幅 | +31.9% |
| 实际净边际（T+1 口径） | 19,898 CNY |
| 差异 | −17,172 CNY |
| 差异桥残差 | −1.75e-10 CNY |

分客户群看，工业固定价 405 低于全成本 418.60（缺口 13.60），数据中心 428 高于全成本 414.66（缺口 −13.34），联动套餐加价 65 低于建议 66.53（缺口 1.53）。**加权缺口只有 3.71，是因为数据中心在补贴工业客户**；这类交叉补贴在复盘中必须拆开，不能只看组合平均。

情景尾部为负同样是结构使然：五个情景等权，s5（均价 522）亏 28,354 CNY，s1（均价 306）赚 60,560 CNY。期望为正、CVaR 为负，说明这个组合赚的是"现货不上涨"的钱；一旦现货上行，联动套餐只传导 95%，剩余敞口会直接吃掉利润。

## 6. 风格档与指纹

当前风格 `guangdong-balanced-v1`：购电参考价取 0.5 分位；风险缓冲 8、目标利润 6 CNY/MWh；现货压力 ×1.0/1.2/1.3/1.5；偏差压力 σ=2%/4%/6%；复核表列 5 个最大偏差时段。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `d94867ef8197`）。比较两个交易日的差异时，先看指纹是否相同：指纹不同，差异首先归因于风格；指纹相同，才归因于预测、执行或规则。

换风格的做法：复制 `instance.json` 为 `instance.aggressive.json`，改 `profile_id` 与参数，用本地路径运行，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；不依赖 `tools/` 里的函数，定价与差异桥公式在本目录 `run.py` 内独立实现，便于单包审阅。
- **纳入**：电能量口径的零售套餐定价、中长期按预测负荷锁量、现货偏差购电、偏差考核（按合同）、履约保障资金成本、固定成本、五情景与压力测试、T+1 差异桥。
- **未纳入**：输配电价、政府性基金及附加、基本电费/需量电费、绿电溢价、容量补偿、辅助服务、坏账、用户流失、税金、保函执行与信用评级。
- **不是**：不是报价审批工具，不是交易中心结算的替代品，不是投资建议；D 级样本不能直接对外报价。
