# 上海独立数据中心需求响应 · 2026-11 样板实例

> 本目录是 `skills/virtual-power-plant/instances/` 的纵向切片：**一省（上海）+ 一主体（独立数据中心，聚合为用户侧 VPP 资源）+ 一个规则版本（沪经信运〔2025〕407号「1+5」体系，2025-06-23 发布，叠加上海现货连续结算试运行口径）**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，不对应任何真实数据中心、聚合商、合同或计量数据；规则值只取自 `knowledge/上海电力市场-2026-11.md` 与 `knowledge/虚拟电厂聚合调度与商业模式-2026-11.md` 中带级别标注的内容，模块没有的上海规则值一律 `null + 待核实`。本实例包是 D 级合成样板，不构成报价、投资或法律建议。
>
> 与 `shanghai-vpp-2026-11`（五类资源聚合商视角）不同，本包下沉到**数据中心单主体**：IT 批处理、制冷、UPS 备电、附属园区空调四条资源，全部资产参数为 D 级合成。

## 1. 一条命令

```bash
# 配置校验 + 来源表 + 未核实项
python skills/virtual-power-plant/instances/shanghai-datacenter-vpp-2026-11/run.py --check-config

# 合成数据全流程：5 同类日基线 → 申报 → 情景出清/CVaR → T+1 响应认定 → 差异桥 → 复核表
python skills/virtual-power-plant/instances/shanghai-datacenter-vpp-2026-11/run.py --demo

# 只申报、不做 T+1 复盘（省略 --t1-loads 与 --t1-event，产物只到情景与申报表）
python skills/virtual-power-plant/instances/shanghai-datacenter-vpp-2026-11/run.py \
  --history /path/to/history.csv --event /path/to/event.csv --out /path/to/out

# 真实数据（路径指向仓库外）
python skills/virtual-power-plant/instances/shanghai-datacenter-vpp-2026-11/run.py \
  --history /path/to/history.csv --event /path/to/event.csv \
  --t1-loads /path/to/t1_loads.csv --t1-event /path/to/t1_event.csv \
  --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/virtual-power-plant/instances/shanghai-datacenter-vpp-2026-11/make_demo.py
```

## 3. 运行逻辑（从输入到复核表）

1. **配置校验**：`meta` 八项 + 各规则块 `grade`/`source` 齐全；`meta.units.price` 必须 `CNY/kWh`；407 号目标、调用与运营商口径为 A/B-C 级事实，邀约时长、有效性门槛、封顶比例、实测比例为 D 级假设并逐条打印警告；官方单价与报价上限为 `null`（待核实），报价不做上限校验、只告警。
2. **读基线样本**：单资源字段齐全、每个样本日 96 点无缺口、至少 3 个样本日；取与事件日**同类日**（工作日/休息日）中最近 5 日。
3. **算基线**：调用 `virtual-power-plant/tools/cbl.py` 的 `customer_baseline`（对称 ±25% 筛选），按「最近 5 个同类日、剔除日电量偏离候选集均值约 ±25%、乘修正系数」的通用 CBL 口径逐点平均。VPP 基线为各资源基线之和。
4. **申报**：可调能力 = 额定 × 可调比例 × 可用率；申报量 = 可调能力 × 申报比例，向下取整到 0.1 MW；报价按风格档填写（D 级演示价）。
5. **情景出清**：逐情景判断报价是否不高于边际价；中标量 = min(申报量, 需求量)；毛收入 = 边际价 × 中标量 × 1000 × 事件时长；扣客户分成、变动成本与固定成本，得到期望净收益与 CVaR。
6. **T+1 认定**：响应量 = max(0, 基线 − 实际负荷)；响应率 = 响应量 / 中标量；低于 D 级演示门槛 50% 判无效、不计激励；超过申报值的部分按 1.2 倍封顶（D 级演示）；执行率低于 95% 时按合同额外让利 5 个百分点；每个资源按 `duration_h` 与电量上限复核（UPS 超窗口会在合规清单亮灯）。
7. **差异桥**：按「出清价差 → 中标量差 → 执行率差 → 超额封顶或无效扣减 → 客户分成与未达标补偿 → 运营成本」顺序逐项替换，残差应接近 0。
8. **合规清单**：报价上限（无官方值→warn）、申报不超能力、实测规模 ≥ 申报值 20%（D 级演示）、事件落在 D 级可调窗口、同一时段不重复参与 DR、响应率门槛、资源电量约束、PUE/制冷耦合提示。

## 4. 合成演示的基准输出（2026-07-14 14:00–15:00）

| 项目 | direct（制冷+UPS） | self（批处理+园区空调） |
|---|---:|---:|
| 可调能力 MW | 6.54 | 5.91 |
| 申报 MW | 5.50 | 4.70 |
| 报价 元/kWh（D 级演示） | 4.20 | 3.80 |
| 官方上限 | 待核实（null） | 待核实（null） |
| 客户分成 | 65.8% | 73.6% |
| 基线候选 / 保留 / 剔除日 | 制冷 5/5/0；UPS 5/5/0 | 批处理 5/4/1；园区空调 5/4/1 |
| T+1 响应量 MW | 4.19 | 5.70 |
| T+1 响应率 | 76.3% | 121.3% |
| 封顶后计量 MW | 4.19（未触顶） | 5.64（1.2 倍封顶） |

| 汇总项 | 值 |
|---|---:|
| 情景期望净收益 | 6,412 元 |
| 情景 CVaR80 | −3,000 元 |
| 计划净收益（执行率 95%） | 5,941 元 |
| 实际净收益 | 7,007 元 |
| 差异 | +1,066 元 |
| 差异桥残差 | 4.55e-12 元 |

**UPS 的 2.00 MW ≠ 4.05 MW 功率能力**：备电窗口 0.5 h（电量上限 2.25 MWh），事件前 0.5 h 放电 4.0 MW、后 0.5 h 归零，窗口平均只有 2.00 MW——功率能力乘事件时长会多算一倍电量。

**self 的 121.3% 响应率被 1.2 倍封顶**：实际响应 5.70 MW、中标 4.70 MW，只有 4.70 × 1.20 = 5.64 MW 计量，多出的 0.06 MW 不计激励；差异桥「超额封顶或无效扣减」−62 元就是这部分。

**direct 的 76.3% 触发未达标让利**：低于合同门槛 95%，客户分成从 65.8% 升到 70.8%，差异桥「客户分成与未达标补偿」−923 元。

**CVaR80 = −3,000 元是风格使然，不是算错**：情景 s1 边际价低于两类报价、都不中标，但固定成本 3,000 元照常发生。

**制冷基线被轻度异常日拉低**：07-08 制冷只降 15%，±25% 筛选不剔除，基线从 10.20 降到 9.89 MW，direct 响应少算 0.31 MW——±25% 不是万能筛，见 `pitfalls.md` 第 2 条。

## 6. 风格档与指纹

当前风格：直控（制冷+UPS）按可调能力 85% 申报、报价 4.2 元/kWh；自控（批处理+园区空调）按 80% 申报、报价 3.8 元/kWh；计划执行率 95%；CVaR 置信 80%。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `5fafc735b4c3`）。比较两次邀约的差异时，先看指纹是否相同：指纹不同，差异首先归因于风格；指纹相同，才归因于基线、执行或规则。

换风格的做法：复制 `instance.json` 为 `instance.aggressive.json`，改 `profile_id` 与参数，用 `--instance` 指向新文件，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；基线算法来自 `skills/virtual-power-plant/tools/cbl.py`（本包用对称 ±25% 默认行为，不改工具）。
- **纳入**：数据中心资产的聚合能力折算、通用 CBL 基线、申报、情景出清、CVaR、T+1 响应认定、超额封顶（D 级演示）、资源电量约束复核、客户分成、运营成本、差异桥、合规清单。
- **未纳入**：现货电能量（背景，`included=false`）、辅助服务、容量补偿、绿证、考核罚款（上海细则未核到）、任务迁移的 IT 排程优化、分钟级以下计量。
- **不是**：不是上海市虚拟电厂管理中心/交易中心的结算替代品，不是自动投标工具，不是对任何真实数据中心响应能力的承诺；407 号目标与调用记录是全市口径，不能当本包能力或收益。
- 真实数据放在仓库外，用 `--history/--event/--t1-loads/--t1-event/--out` 指向本地路径；仓库内只保留 D 级合成样例。
