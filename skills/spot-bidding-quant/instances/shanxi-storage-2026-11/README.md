# 山西独立储能 · 5 分钟现货样板实例

> 本目录是 `skills/spot-bidding-quant/instances/` 的第三个纵向切片：**一省（山西）+ 一主体（独立新型储能）+ 一个规则版本（现货 V16.0 + 实时 5 分钟出清 288 点/日）**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，不代表任何真实场站、真实报价或真实收益。

## 1. 一条命令

```bash

# 合成数据全流程：价格情景 → 价差申报 → 288 点情景出清 → T+1 两结算 → 差异桥 → 熔断压力测试

python skills/spot-bidding-quant/instances/shanxi-storage-2026-11/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```


## 3. 运行逻辑

1. **配置校验**：六个块齐全；每个规则块有 `grade` + `source`；**必须是 5 分钟 / 288 点**（96 点或 15 分钟直接报错）；申报与出清总区间必须为 0–1,500 元/MWh；煤电容量电价不得套到独立储能（`applicable_to_storage` 必须为 `false`，储能容量电价必须为空待核实）；熔断公告 ≤2 h、时长 ≤24 h；2025H1 日前 283 / 实时 281 元/MWh 与 1.34 厘价差须能对上。
2. **价差申报**：先按 5 个价格情景的 q50 取每小时段参考价，再按充放时段筛选求出充放电锚点；放电报价 = 充电锚点 / RTE + 退化成本 × (1 + 1/RTE) + 加价，充电报价 = 放电锚点 × RTE − 退化成本 × (1 + RTE) − 压价。**两条腿共用同一个日价差，避免低价情景只充电、高价情景只放电的假象。**
3. **能量平衡**：分位数逐时段取整后充放能量必然不闭合，按 RTE 对较大的一条腿做等比缩放；情景出清后再做一次环比缩放，保证每个情景都满足 `放电 = 充电 × RTE`。
4. **情景出清**：逐点比较情景价与申报价，放电腿价格 ≥ 报价才成交、充电腿价格 ≤ 报价才成交；扣退化与固定成本后按权重算期望净收益与 CVaR（尾部 10%）。
5. **T+1 两结算**：日前计划净出力按实际日前价，实际与计划的偏差按实际实时价，即 `Σ[计划净出力 × 日前价 + (实际净出力 − 计划净出力) × 实时价] × Δt`；退化按实际吞吐量计。
6. **差异桥**：4 个科目——日前价格偏差、日前计划量差、实时偏差价差、退化成本偏差；残差 < 1e-6 CNY，并列出量差影响最大的 5 个时段。
7. **熔断压力测试**：在配置窗口（默认 17:00–19:00）内把实际净出力按 D 级重算价（默认 450 元/MWh）重结，输出熔断冲击与压力情景净收益；**这不是结算规则，只是敏感性**。
8. **复核表**：把「计划（参考价）→ 实际（两结算）」与「价格偏差 / 量差 / 实时价差 / 退化」两条链分开写，避免把日前价差、实时尾价与执行偏差混为一谈。

## 4. 合成演示的基准输出

基准资产：100 MW / 200 MWh、可用 180 MWh、RTE 0.86、SOC 5%–95%；退化 18 元/MWh 吞吐，固定成本 20,000 元/日；交易日 2026-11-19（288 点）。

| 项目 | 值 |
|---|---:|
| 日参考价差（q50） | 563.9 元/MWh（政策门槛 280） |
| 充电锚点 / 放电锚点 | 86.7 / 650.6 元/MWh |
| 放电保本 / 充电保本 | 139.8 / 526.1 元/MWh |
| 申报放电价 / 充电价 | 159.8 / 511.1 元/MWh |
| 计划循环 | 1.59 次/日（上限 1.60） |
| 计划吞吐量 | 637.9 MWh |
| 充放切换次数 | 4 次 |
| 相邻时段净出力平均变化 | 4.47 MW |
| 参考价净收益 | 53,314 CNY |
| 情景期望净收益 | 52,025 CNY |
| CVaR（尾部 10%） | 44,933 CNY |
| 实际日前 / 实时加权价 | 367 / 375 元/MWh |
| 实际放电 / 充电 | 286.4 / 353.6 MWh |
| 实际现货收入 | 90,821 CNY |
| 单位放电收入 | 317 元/MWh |
| 实际退化 / 固定成本 | 11,520 / 20,000 CNY |
| 实际净收益 | 59,301 CNY |
| 差异桥差异 / 残差 | +5,987 CNY / -7.09e-11 |

情景表（价格情景 1→5）：净收益 55,451 / 56,427 / 53,314 / 49,998 / 44,933 CNY；情景 4、5 触发能量平衡缩放（`rebalanced = true`）。

**读法**：CVaR 落在最高价情景（5），不是最低价情景。价差报价下，高价情景的充电腿更容易不成交（申报价 511.1 低于部分时段价格），吞吐量被迫下降，收益反而最差。这说明独立储能在 5 分钟市场里怕的不是「价格低」，而是**低价时段没有、高价时段买不起**，策略上要把充电成交概率和放电价差一起看。

差异桥（按绝对值排序）：实时偏差价差 +15,669、日前计划量差 −11,077、日前价格偏差 +1,434、退化成本偏差 −39 CNY。量差集中在 19:30–19:50：计划放电 77.4 MW，实际为 0，单时段影响约 −4,200 CNY——这是执行/预测问题，不是价格问题。

熔断压力测试：17:00–19:00（2.0 h）按 450 元/MWh 重结，窗口内放电 105.6 MWh，基准收入 80,522 → 熔断收入 47,523，冲击 −32,999，压力情景净收益 26,302 CNY。

## 6. 风格档与指纹

当前风格 `shanxi-spread-v1`：价差报价；放电加价 20、充电压价 15 元/MWh；尖峰阈值 600 元/MWh 时放电加价 60；日循环上限 1.6；最小日价差 280 元/MWh；申报量与参考价均取 q50；CVaR 尾部 10%。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `a7fc6976c64e`）。换风格就换 `profile_id` 并保留旧文件与旧输出，便于比较「价差报价 vs 参考价加价」在 288 点市场里的成交结构与尾部风险差异。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；DP 调度复用 `skills/ems-dispatch/tools/dispatch.py`，CVaR 等复用 `skills/spot-bidding-quant/tools/desk.py`，均不修改内核。
- **纳入**：省内日前 + 实时电能量两结算、288 点充放电申报、退化与固定成本、熔断 D 级压力测试。
- **未纳入**：调峰/辅助服务、中长期曲线分解、省间外送、容量电价、库容租赁、税费与融资。
- **不是**：不是交易中心结算单，不是熔断重算方案，不是投资建议；实际结算以交易中心账单与 V16.0 原文为准。
- 真实数据放在仓库外，用 `--d1/--t1/--out` 指向本地路径；仓库内只保留 D 级合成样例。
