# 蒙西风光储联合申报 · 2026-11 样板实例

> 本目录是 `skills/spot-bidding-quant/instances/` 的一个纵向切片：**一省（蒙西独立电网）+ 一主体（风光储联合电站：风电 300 MW + 光伏 200 MW + 场内独立储能 100 MW/400 MWh，同一场站一个结算户头）+ 一个规则版本（现货正式运行 + 2026-02-14 修订版征求意见稿的储能条款）**。它专门演示蒙西风光储与其他组合最不一样的四件事：全电量单轨制下日前只是预出清、实际按实时价结算；征求意见稿要求"弃风弃光（富裕程度<0）时独立储能不得放电"、循环上限 1.5 次/日、最小连续 30 分钟（全部 C 级，未生效）；风、光、储共享并网点出口限额，储能能"回收"风光的限额弃电；储能/新型主体的充电结算口径才是联合 vs 分开收益的分水岭。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，储能条款为 **C 级征求意见稿口径（非正式规则）**，不代表任何真实场站、真实报价或真实收益；蒙西省级正式结算与考核条款以原文为准。本实例包是 D 级合成样板，不构成报价、投资或法律建议。

## 3. 运行逻辑

1. **配置校验**：八个规则块齐全（`spot` / `settlement` / `new_energy` / `storage_participation` / `frequency_regulation` / `capacity_compensation` / `deviation_assessment` / `market_context`），每块带 `grade` + `source`；288 点 / 5 分钟一致（蒙西实时 5 分钟滚动出清，不许复用 96 点骨架）；模型边界必须覆盖 2025 实绩 -48.66 至 1555.85；早期 40-550/600 只能留在历史字段、2026 草案 -50/1500 只能留在草案字段；储能参与块 `grade` 必须是 C（征求意见稿）；SOC 窗口必须落在草案允许的 0-10% / 90-100% 内；循环上限必须与草案一致（1.5）；进口限额必须等于储能功率（表后口径）。
2. **风光联合申报**：对每个时段取 5 个风光情景的 P50/P35 分位，向下取整到 0.1 MW，受共享出口限额约束，按 0 元/MWh 报价（D 级风格，不模拟出清拒绝）；申报电量同时是偏差考核基准。
3. **储能日内调度**：自写 SOC 网格动态规划（96 状态、terminal=cycle，与内核 `dispatch_day` 等价），外加两条蒙西草案约束：逐时段禁放掩码（计划按日前价 < 0 判定，D 级代理）与循环上限 1.5 次（用拉格朗日吞吐价二分 enforcement）；再按"最小连续 30 分钟"修复短时段并重算计划口径出力。
4. **储能报价**：放电保本 = 充电锚点/往返效率 + 退化×(1+1/效率)，加成 20（尖峰时段 60）元/MWh；充电保本 = 放电锚点×效率 − 退化×(1+效率)，减 15 元/MWh；逐点给出情景出清概率。
5. **五配对情景评估**：s1 大发深负价、s5 小发高价，风/光/价按同一编号配对；储能按计划执行，风光偏差经共享出口限额变成弃电或进口；扣运维（风 22 / 光 14 元/MWh）、固定成本 60,000 元/日与偏差考核后得情景净收益，按权重算期望与 CVaR（置信 80%）。
6. **策略选择**：只在"有储能且合规"的策略中取期望净收益最大（`compliant_only_selection=true`）；「禁放不执行」与「无储能」两行只是对照。
7. **T+1 结算重放**：实际按实时全电量结算（单轨制）；日前计划×日前价只作对照；禁放按实际价统计违规、不强改计划（D 级假设写进数据契约）。
8. **差异桥**：5 个科目——风光可用电量偏差（含出口限额弃电，按日前价）、实时价格效应（按实际净上网）、运维成本偏差、退化成本偏差、申报偏差考核；残差 < 1e-6 CNY。
9. **联合 vs 分开与敏感性**：分开口径 = 风光按同一限额独立上网（超限弃电不可回收）+ 独立储能（100 MW 进出口、同价充放电、同样受草案约束）；充电加成 0 / 180 元/MWh 两个口径与线性外推临界值；敏感性含实时价 ±15%、风光出力 ±10%、循环上限放开 2.5 次（仅对照）、组合压力。

## 4. 合成演示的基准输出

基准资产：风电 300 MW + 光伏 200 MW + 储能 100 MW/400 MWh（RTE 88%、SOC 5%-95%、初始 20%、退化 12 元/MWh 吞吐）；共享出口限额 280 MW、进口限额 100 MW；交易日 2026-11-18（288 点）。日前参考价夜间 ~205、早峰 ~350、午间深负价（最低 clip 到 -60）、晚峰 ~520 元/MWh；T+1 实时价含 51 个负价点（最低约 -30 元/MWh），晚峰最高约 540 元/MWh；s1 午间风光合计最大出力 311.9 MW，超过 280 MW 共享限额——弃电回收真实生效。

| 项目 | 值 |
|---|---:|
| 预测电量 | 风 3,401 + 光 1,328 = 4,729 MWh |
| 选中策略 | P50 申报 + 禁放执行（合规） |
| 风光联合申报电量 | 4,727.7 MWh（P50 分位，0 元/MWh 报价） |
| 储能计划 | 充 591.6 / 放 520.6 MWh，循环 1.39 次（上限 1.5，拉格朗日乘子 2.75，最小连续修复 1 段） |
| 储能报价 | 放电保本 −15.4（充电锚点 −36.1）、充电保本 438.9 元/MWh（放电锚点 524.3） |
| 情景期望净收益 | 989,871 CNY |
| CVaR（置信 80%） | 880,636 CNY |
| 情景期望弃电 / 偏差考核 | 8.0 MWh / −8,173 CNY |
| 实际风光可用电量 | 4,858.9 MWh |
| 实际上网电量 / 弃电 | 4,787.8 / 0.1 MWh |
| 实际捕获价 | 243 元/MWh |
| 实际偏差率 / 考核 | 2.78% / 0 CNY（±5% 免考核带内） |
| 实际净收益 | 1,007,018 CNY |
| 日前参考计划净收益 | 983,965 CNY（不用于结算） |
| 计划 → 实际差异 / 残差 | +23,052 CNY / −7.64e-10 |
| T+1 联合 − 分开（同价口径） | −227 CNY |
| 联合 vs 分开期望差额（加成 0 / 180） | −3,095 / +103,399 CNY |
| 分开充电加成临界值（线性外推） | ≈5 元/MWh |

四策略（五情景期望）：P50+禁放 **989,871**；P35+禁放 989,117；P50+禁放不执行 989,871（与禁放执行相同——禁放条款在本演示日不 binding，无约束最优本来就不在负价时段放电）；无储能基线 804,476（**储能联合价值 +185,395 CNY/日**，其中包含把风光限额弃电从 28.6 MWh 压到 8.0 MWh 的回收贡献）。

联合 vs 分开：同价口径下分开反而略优 −3,095 CNY——原因是分开风光在负价时段被出口限额弃电，而负价时段"弃电少上网"恰好少亏钱；一旦分开储能充电按含输配电价与附加的用户侧口径结算（加成 180 元/MWh，D 级占位），联合优势变成 +103,399 CNY。**充电结算口径未核到，才是这笔账的分水岭。**

差异桥（计划 983,965 → 实际 1,007,018）：风光电量偏差 +28,373、实时价格效应 −2,677、运维成本偏差 −2,644、退化 0、考核 0 CNY；残差 −7.64e-10。

**读法**：循环上限 1.5 次/日确实咬合（拉格朗日乘子 2.75 元/MWh 吞吐），放开到 2.5 次只多赚 480 CNY——约束咬合但边际价值不大；真正压住收益的是禁放（负价时段不能"先放后充腾容量"）与共享出口限额（晚峰放电价值被风光出力挤占）。换价格形态（早峰更尖、负价更深）后三者会重新洗牌，须重查。

## 6. 风格档与指纹

当前风格 `mengxi-windsolar-storage-joint-v1`：四策略比较 P50/P35 申报与禁放执行/不执行/无储能；申报价 0 元/MWh；禁放代理 = 现货价 < 0；循环上限 1.5 次；放电加成 20（尖峰 60）、充电减 15 元/MWh；CVaR 置信 80%；分开对照含充电加成 0/180 两口径。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `dd6b052ed176`）。换风格就换 `profile_id` 并保留旧文件与旧输出，便于比较「保守申报 vs 中性申报」「禁放执行 vs 不执行」「联合 vs 分开」的收入、考核与 CVaR 差异。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；`desk.weighted_cvar` / `desk.validate_public_dataset` 来自 `skills/spot-bidding-quant/tools/`，不修改内核。储能调度是本包自写的 SOC 网格 DP（`skills/ems-dispatch/tools/dispatch.py` 的等价实现 + 逐时段禁放与拉格朗日循环上限，内核的 `sell_price` 遮蔽无法表达"只禁放电、不禁充"）。
- **纳入**：实时全电量电能量结算（单轨制）、风光联合报量报价、储能日内调度（禁放代理、循环 1.5、最小连续 30 分钟、SOC 窗口）、共享出口限额与弃电回收、申报偏差 D 级考核、变动与固定运维、日前参考计划差异桥、联合 vs 分开对照与充电加成敏感性。
- **未纳入**：5 分钟内滚动决策、断面/爬坡/场站控制、中长期差价结算与结算参考点、机制电价差价（增量不适用）、调频辅助服务（仅记录 C 级口径）、绿证、省间外送、容量补偿、税费与融资。
- **不是**：不是交易中心结算单，不是正式考核结果，不是报价或投资建议；限价、考核、储能条款与结算顺序以省级正式规则和合同为准；2026 修订版储能条款全部是征求意见稿口径。
- 真实数据放在仓库外，用 `--d1/--t1/--out` 指向本地路径；仓库内只保留 D 级合成样例。
