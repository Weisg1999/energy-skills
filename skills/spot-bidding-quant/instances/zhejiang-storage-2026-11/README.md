# 浙江独立新型储能 · 5 分钟现货 + 授权合约样板实例

> 本目录是 `skills/spot-bidding-quant/instances/` 的实例包之一：**一省（浙江）+ 一主体（独立新型储能电站）+ 一个规则版本（现货 2025-08-07 转正式运行 + 5 分钟滚动出清 288 点/日 + 政府授权差价合约约 90% 电量）**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，不代表任何真实场站、真实报价或真实收益；限价 −200–1,200 元/MWh 为年报/征求意见稿口径（B/C），省级正式规则现行参数待核实。

## 1. 一条命令

```bash
# 配置校验 + 来源分级
python skills/spot-bidding-quant/instances/zhejiang-storage-2026-11/run.py --check-config

# 合成数据全流程：价格情景 → 价差申报 → 288 点情景出清 → T+1 两结算 → 差异桥 → 午间负价压力测试
python skills/spot-bidding-quant/instances/zhejiang-storage-2026-11/run.py --demo

# 真实数据（路径指向仓库外）
python skills/spot-bidding-quant/instances/zhejiang-storage-2026-11/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/spot-bidding-quant/instances/zhejiang-storage-2026-11/make_demo.py
```

Windows 控制台默认 GBK，所有 python 命令建议加 `PYTHONIOENCODING=utf-8` 前缀。

## 3. 运行逻辑

1. **配置校验**：六个规则块齐全；每个规则块有 `grade` + `source`（source 注明「浙江省级知识模块 §X」）；**必须是 5 分钟 / 288 点**（96 点或 15 分钟直接报错）；申报与出清总区间必须为 **−200–1,200 元/MWh** 且 `negative_price_allowed` 为真；授权差价合约覆盖率必须 ≈0.9 且储能覆盖为 `null`（未核实）；储能 `admission_conditions` 必须为 `null`；容量电价不得套给独立储能（`applicable_to_storage` 必须为 `false`、价格必须为空）；模块未给现货均价（`spot_average_price` 必须为 `null`）；2025 中长期期限结构必须为年度 412.39 > 总均价 390.73 > 月度 370.43；112 号后价差必须收窄；午间压力窗口必须对齐 5 分钟粒度、重算价必须落在 [−200, 0) 的负价区间。
2. **价差申报**：先按 5 个价格情景的 q50 取每时段参考价，再按充放时段筛选求出充放电锚点；放电报价 = 充电锚点 / RTE + 退化成本 × (1 + 1/RTE) + 加价，充电报价 = 放电锚点 × RTE − 退化成本 × (1 + RTE) − 压价。**两条腿共用同一个日价差，避免低价情景只充电、高价情景只放电的假象。**
3. **能量平衡**：分位数逐时段取整后充放能量必然不闭合，按 RTE 对较大的一条腿做等比缩放；情景出清后再做一次环比缩放，保证每个情景都满足 `放电 = 充电 × RTE`。
4. **情景出清**：逐点比较情景价与申报价，放电腿价格 ≥ 报价才成交、充电腿价格 ≤ 报价才成交；扣退化与固定成本后按权重算期望净收益与 CVaR（尾部 10%）。
5. **T+1 两结算**：日前计划净出力按实际日前价，实际与计划的偏差按实际实时价，即 `Σ[计划净出力 × 日前价 + (实际净出力 − 计划净出力) × 实时价] × Δt`；退化按实际吞吐量计。浙江授权合约双差价公式未核实，本表不含授权合约结算科目。
6. **差异桥**：4 个科目——日前价格偏差、日前计划量差、实时偏差价差、退化成本偏差；残差 < 1e-6 CNY，并列出量差影响最大的 5 个时段。
7. **午间负价压力测试**：在配置窗口（默认 11:00–15:00）内把实际净出力按 D 级重算价（默认 −200 元/MWh，限价下限）重结，输出负价冲击与压力情景净收益；**这不是结算规则，只是敏感性**。负价对充电腿是收入、对放电腿是损失。
8. **复核表**：把「计划（参考价）→ 实际（两结算）」与「价格偏差 / 量差 / 实时价差 / 退化」两条链分开写，避免把日前价差、实时尾价与执行偏差混为一谈。

## 4. 合成演示的基准输出

基准资产：100 MW / 200 MWh、可用 180 MWh、RTE 0.86、SOC 5%–95%；退化 18 元/MWh 吞吐，固定成本 20,000 元/日；交易日 2026-11-19（288 点）。价格形态为纯 D 级合成：夜谷 → 上午平段 → 午间深谷（情景 1 触及负价）→ 16:00 起爬坡 → 17:00–21:00 晚峰 → 23:00 回落。

| 项目 | 值 |
|---|---:|
| 情景价格区间 / 实际 RT 最低 | −117.6–974.9 / −46.8 元/MWh |
| 日参考价差（q50） | 770.1 元/MWh（政策门槛 280） |
| 充电锚点 / 放电锚点 | 38.8 / 808.9 元/MWh |
| 放电保本 / 充电保本 | 84.0 / 662.2 元/MWh |

| 计划循环 | 1.19 次/日（上限 1.20，对应「一充一放」为主） |
| 计划吞吐量 | 477.2 MWh |
| 充放切换次数 | 4 次 |
| 相邻时段净出力平均变化 | 2.89 MW |
| 参考价净收益 | 46,111 CNY |
| 情景期望净收益 | 45,742 CNY |
| CVaR（尾部 10%） | 41,492 CNY |
| 实际日前 / 实时加权价 | 342 / 326 元/MWh |

| 实际退化 / 固定成本 | 7,920 / 20,000 CNY |
| 实际净收益 | 38,534 CNY |
| 差异桥差异 / 残差 | −7,577 CNY / −7.37e-11 |

情景表（价格情景 1→5，均价 178.5→498.5 元/MWh）：净收益 48,873 / 49,122 / 46,111 / 43,114 / 41,492 CNY；情景 1、5 触发能量平衡缩放（`rebalanced = true`）。

**读法**：CVaR 落在最高价情景（5），不是最低价情景。价差报价的锚点来自 q50 参考价，整体价格水平上移时放电收入与充电成本同向上升，而循环上限 1.2 把吞吐量卡死、充电量（约 256 MWh）大于放电量（约 220 MWh），净收益随均价抬升反而收窄——浙江限价区间允许负价、午间谷深晚峰尖，储能怕的不是「绝对价格高」，而是**价差被压缩 + 吞吐被循环上限卡死**。均价最低的情景 1（午间触及负价）净收益反而最高：负价把充电成本打成了负收入。

差异桥（按科目）：日前计划量差 −13,273、实时偏差价差 +3,619、日前价格偏差 +1,409、退化成本偏差 +669 CNY。量差集中在 19:40–20:00：计划放电 59.0 MW，实际为 0，单时段影响约 −4,000 CNY——这是执行/预测问题，不是价格问题。

午间负价压力测试：11:00–15:00（4.0 h）按 −200 元/MWh 重结，窗口内充电 121.6 MWh、放电 0；基准窗口收入 −7,121 → 负价窗口收入 +24,311，冲击 **+31,432**，压力情景净收益 69,966 CNY。方向验证 pitfalls 第 3 条：负价对有充电头寸的储能是收入；若午间排了放电，冲击会反号。

## 6. 风格档与指纹

当前风格 `zhejiang-spread-v1`：价差报价；放电加价 20、充电压价 15 元/MWh；尖峰阈值 600 元/MWh 时放电加价 60；日循环上限 1.2（对应 112 号后「一充一放」为主，留少量第二循环余量）；最小日价差 280 元/MWh；申报量与参考价均取 q50；CVaR 尾部 10%。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `39d344878917`）。换风格就换 `profile_id` 并保留旧文件与旧输出，便于比较「价差报价 vs 参考价加价」在 288 点 + 负价区间市场里的成交结构与尾部风险差异。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；DP 调度复用 `skills/ems-dispatch/tools/dispatch.py`，CVaR 等复用 `skills/spot-bidding-quant/tools/desk.py`，均不修改内核。
- **纳入**：省内日前 + 实时电能量两结算、288 点充放电申报（含负价）、退化与固定成本、午间负价 D 级压力测试。
- **未纳入**：中长期曲线分解、授权差价合约头寸与双差价结算、零售、需求响应/AGC 收入、容量电价、库容租赁、税费与融资。
- **不是**：不是交易中心结算单，不是负价重算方案，不是投资建议；实际结算以交易中心账单与省级正式规则原文为准。
- 真实数据放在仓库外，用 `--d1/--t1/--out` 指向本地路径；仓库内只保留 D 级合成样例。
