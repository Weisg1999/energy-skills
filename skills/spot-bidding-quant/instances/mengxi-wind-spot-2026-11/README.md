# 蒙西风电现货 · 2026-11 样板实例

> 本目录是 `skills/spot-bidding-quant/instances/` 的第三个纵向切片：**一省（蒙西独立电网）+ 一主体（2025-06-01 后并网的集中式风电增量项目）+ 一个规则版本（内能源电力字〔2025〕84号现货正式运行，2026-02-14 修订版尚未生效）**。它专门演示蒙西与其他省最不一样的三件事：全电量单轨制下日前只是预出清、实际按实时价结算；负价时段弃风会连带丢掉按实际电量计价的 CfD 对冲；申报偏差超出 ±5% 免考核带会产生考核。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，不代表任何真实场站、真实报价或真实收益；蒙西省级正式结算与考核条款以原文为准。

## 1. 一条命令

```bash
# 配置校验 + 来源分级
python skills/spot-bidding-quant/instances/mengxi-wind-spot-2026-11/run.py --check-config

# 合成数据全流程：风/价配对情景 → 申报曲线 → 弃风决策 → 实时全电量结算 → CfD → 偏差考核 → 差异桥
python skills/spot-bidding-quant/instances/mengxi-wind-spot-2026-11/run.py --demo

# 真实数据（路径指向仓库外）
python skills/spot-bidding-quant/instances/mengxi-wind-spot-2026-11/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```

```bash
python skills/spot-bidding-quant/instances/mengxi-wind-spot-2026-11/make_demo.py
```

## 3. 运行逻辑

1. **配置校验**：八个规则块齐全（`spot` / `settlement` / `new_energy` / `negative_price` / `deviation_assessment` / `contract` / `cost` / `capacity_compensation`）；每块有 `grade` + `source`；96 点 / 15 分钟一致；模型边界必须覆盖 2025 实绩 -48.66 至 1555.85；早期 40-550/600 与 2026 草案 -50/1500 只能留在历史/草案字段；增量项目起点必须是 2025-06-01 且无机制电价；存量 282.9 元/MWh 不得用于增量；CfD 价格与合同块一致；风电不得有充电负荷。
2. **申报曲线**：对每个时段取 5 个风功率情景的 P50 或 P35 分位，向下取整到 0.1 MW，受装机与出口限额约束；报价为 0 元/MWh 的纯量申报。申报电量同时是偏差考核的比较基准。
3. **风/价配对情景**：s1 大风低价、s5 小风高价，按同一编号配对；每个情景逐点判断实时价是否低于弃风阈值，得到该情景的上网电量、弃风电量、捕获价、CfD 与偏差考核。风功率与价格不得独立抽样后随意拼配。
4. **全电量实时结算**：现货收入 = Σ 上网电力 × 实时价 × Δt；CfD = 合约比例 × 实际上网电量 ×（合约价 − 项目捕获价）；再扣运维、固定成本与偏差考核，得到情景净收益；按权重算期望与 CVaR（置信 80%）。
5. **偏差考核（D 级简化）**：以弃风前可用电量与申报电量比较，超出 ±5% 免考核带的部分 × 申报电量 × 30 元/MWh；±5% 来自现货 101 问口径，单价与可用电量口径为建模假设。
6. **日前参考计划**：按日前参考价 × 申报电量计算，只用于「计划 → 实际」差异桥；日前预出清不是结算依据，不能当成应收收入。
7. **T+1 结算与两结算对照**：实际按实时全电量结算；同时并列「日前计划 + 实时偏差」两结算，两者差额约等于申报电量 ×（日前价 − 实时价）×（1 − 合约比例），用于识别口径差异，不是套利空间。
8. **差异桥**：6 个科目——电量偏差（按日前价）、实时价格偏差（按实际电量）、CfD 电量效应、CfD 价格效应、运营成本偏差、申报偏差考核；残差 < 1e-6 CNY。
9. **敏感性与临界值**：实时价 ±15%、风功率 ±10%、合约比例 30%/90%、100% 弃风比例下阈值 -50/50、组合压力；另给弃风临界价、实时价与合约比例盈亏平衡点。

## 4. 合成演示的基准输出

基准资产：200 MW 风电、出口限额 200 MW；变动运维 25 元/MWh，固定成本 80,000 元/日；交易日 2026-11-18（96 点）。日前参考价均值 193.35 元/MWh；实时价含 16 个负价点（最低约 -40 元/MWh），晚峰最高约 450 元/MWh。

| 项目 | 值 |
|---|---:|
| 预测电量 | 3,130.0 MWh |
| 选中策略 | P50 申报 + 负价不停机（阈值 -60 元/MWh） |
| 申报电量 | 3,130.0 MWh（100.00% 预测） |
| 情景期望净收益 | 599,123 CNY |
| CVaR（置信 80%） | 533,573 CNY |
| 情景期望捕获价 | 190.03 元/MWh |
| 情景期望弃风 | 0.0 MWh |
| 情景期望偏差考核 | −6,387 CNY |
| 日前参考计划净收益 | 609,421 CNY |
| 实际可用电量 | 3,225.9 MWh |
| 实际上网电量 | 2,977.2 MWh |
| 实际弃风 | 248.7 MWh（16 个负价点，11–15 时弃风 70%） |
| 实际捕获价 | 197.35 元/MWh |
| 实际偏差率 / 偏差考核 | 3.10% / 0 CNY（在 ±5% 带内） |
| 实际净收益 | 580,749 CNY |
| 计划 → 实际差异 / 残差 | −28,672 CNY / −2.55e-11 |
| 两结算对照净收益 | 597,766 CNY（较实时全电量 +17,016） |
| 弃风临界价 | −49.59 元/MWh |

四策略（五情景期望）：P50+弃风 580,974；P35+弃风 580,419；P50+不停机 **599,123**；P65+不停机 599,001。差异主要来自「负价时弃不弃风」，而不是申报分位：P50 与 P65 的期望考核只差 122 CNY，但弃风策略少收约 1.8 万元。

差异桥（按绝对值）：电量偏差 −29,341、实时价格偏差 +11,912、CfD 电量效应 −7,890、CfD 价格效应 −7,147、运营成本偏差 +3,794、申报偏差考核 0 CNY。实际可用电量高于申报 3.10%，本在免考核带内，所以桥里没有考核损失；但情景 s1/s5 的偏差率约 18%，期望考核约 −6,387 CNY。

**读法**：负价 -40 元/MWh 看起来可以弃风止损，但弃掉 1 MWh 会同时失去约 0.6 ×（280 − 197）≈ 50 元/MWh 的 CfD 对冲，净损失反而更大。演示日的弃风临界价约 −49.59 元/MWh；只有实时价低于这条线，弃风才划算。这正是「负价不等于该弃风」。

## 6. 风格档与指纹

当前风格 `mengxi-wind-negative-aware-v1`：四策略比较 P50/P35 申报与负价弃风/不停机；申报价 0 元/MWh；弃风阈值 0 或 -60 元/MWh；CVaR 置信 80%。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `f04eecd9ecbe`）。换风格就换 `profile_id` 并保留旧文件与旧输出，便于比较「保守申报 vs 中性申报」「弃风 vs 不停机」的收入、考核与 CVaR 差异。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；`desk.weighted_cvar` 来自 `skills/spot-bidding-quant/tools/`，不修改内核。
- **纳入**：省内实时全电量电能量、负价弃风、按实际电量结算的金融 CfD、申报偏差 D 级考核、变动与固定运维、日前参考计划差异桥、两结算对照。
- **未纳入**：5 分钟内滚动决策、136 机制电价（增量不适用）、年度签约比例考核、辅助服务、绿证、省间外送、断面/爬坡/SOC 约束、税费与融资。
- **不是**：不是交易中心结算单，不是正式考核结果，不是报价或投资建议；限价、考核、CfD 与结算顺序以省级正式规则和合同为准。
- 真实数据放在仓库外，用 `--d1/--t1/--out` 指向本地路径；仓库内只保留 D 级合成样例。
