# 山东煤电/热电实例包（2026-11）

> 目录定位：`skills/spot-bidding-quant/instances/shandong-thermal-2026-11/` 是**实例层配置包**，不是知识模块，不改变 101 模块 / 13 分区计数。一个省 + 一类主体 + 一个规则版本；交易员只改 JSON 与 CSV，不改代码。

## 1. 这个包回答什么

同样是山东现货，储能包回答"电池怎么充放"，本包回答"**热电联产机组明天报多少、供热把最小出力顶到哪里、调频备用留多少**"。三个建模点与储能包不同：

| 建模点 | 储能包 | 本包 |
|---|---|---|
| 最小出力 | SOC 窗口约束 | 供热负荷 ÷ 热电比，可能高于 35% 最小技术出力 |
| 报价逻辑 | 参考价 + 加价 | 变动成本 + 加价，机组是成本型报价，不盯盘面价 |
| 辅助服务 | 未纳入 | 调频容量 + 里程，按 52 号上限与系数封顶 |
| 容量补偿 | 占位 | 市场化容量补偿占位（标准与供需系数待核实） |
| 负价行为 | 可以充电套利 | 供热最小出力下不能停机，负价仍可能亏损运行 |

## 3. 关键规则与来源

| 规则块 | 本包取值 | 级别 | 来源 |
|---|---|---|---|
| `spot` | 96 点 / 15 分钟；申报 −80～1300，出清 −100～1500 元/MWh | B/C | 山东省级现货现行限价；2026-08-28 下限草案未生效 |
| `thermal_participation` | 最小技术出力 35%；运行成本补偿 | A/B | 新版《山东电力市场规则（试行）》；省政府新闻办发布会 |
| `ancillary` | 调频里程价上限 0.015 元/kW·mile，系数上限 2 | A/B | 鲁监能市场规〔2026〕52号；2026-05-08 调整 |
| `capacity_compensation` | 有效容量 × 标准 × 供需系数；标准未填 | A | 鲁发改价格〔2025〕576号；1022号 |
| `negative_price` | 2025 年负价 >1500 h、触地板 13% | B/C | 山东省能源局/中国能源网 |

**没有写进生效字段的**：2026-08-28 的 −0.12/−0.14 元/kWh 下限草案、容量补偿具体标准、机组侧调频 K 值。草案放 `draft_2026_08_28`，待核实项放 `status`。

## 4. 资产与风格

示例资产是 350 MW 抽凝供热机组（D 级，不是真实项目）：

- 最小出力 122.5 MW；供热 240 MW_th、热电比 1.6 → 供热最小出力 150 MW；
- 变动成本 260 元/MWh；调频备用 20 MW；日里程 20 mile/kW；里程价 0.015 元/kW·mile；K 值 1.0（D 级假设）；
- 供热收益、燃料中长期、检修与两个细则考核**未纳入**。

风格档 `shandong-thermal-balanced-v1`：5 情景中位数量、增量报价加价 20 元/MWh；风格指纹 `8c7f9b6f5c49`。换风格就换 `profile_id`，保留旧文件便于横向比较。

## 5. 运行

```bash
cd skills/spot-bidding-quant/instances/shandong-thermal-2026-11

# 只校验配置，打印来源与未核实项
python run.py --check-config

# 用自带 D 级合成数据跑全流程
python run.py --demo

```

## 6. 演示结果（可复现）

| 指标 | 数值 |
|---|---:|
| 供热最小出力均值 | 150.0 MW |
| 申报上网电量（参考价口径） | 5,369.3 MWh |
| 调频日收入（D 级） | 6,000 CNY |
| 参考价口径净边际 | 296,155 CNY |
| 情景期望净边际 | 324,691 CNY |
| 情景 CVaR10 | −96,515 CNY |
| T+1 差异桥 | 计划 296,155 → 实际 344,127，差异 47,972，残差 3.6e−11 |

读法：低价情景下供热最小出力仍要运行，电能量边际为负是结构性的，不是算术错误；CVaR10 为负说明该风格在低价情景下无法避免亏损运行。

## 7. 配置校验

`run.py` 会拒绝：

- 缺 `meta` 必填项、缺 `rules`/`asset`/`policy`/`data_contract`；
- 任一规则块缺 `grade` 或 `source`；
- `points_per_day ≠ 24×60 / market_time_unit_min`；
- 限价不满足 `clear_floor ≤ declare_floor < declare_cap ≤ clear_cap`；
- `min_output_mw > power_mw`，或供热负荷推出的最小出力 > 额定功率；
- 调频备用 + 供热最小出力 > 额定功率；
- 里程价超过省级上限、K 值超过系数上限；
- 情景权重之和不为 1、情景列数与权重数不一致。

输入数据会拒绝：多交易日、缺时段、重复点、价格越界、出力超过额定功率、供热负荷为负。

## 8. 边界

- 本包是**价格接受者盘面复核**，不是市场出清仿真；实际出清、结算、考核以交易中心与调度机构正式结果为准。
- 容量补偿、运行成本补偿、两个细则考核未计入净边际；不要把本表数字当机组利润。
- 供热收益与燃料中长期另账；热电比、抽汽参数、最小出力必须按机组实际特性填写。
- 全部内置数据为 D 级合成，不对应任何真实机组、合同或计量数据。
