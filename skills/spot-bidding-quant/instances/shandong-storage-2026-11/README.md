# 山东独立储能 · 2026-11 样板实例

> 本目录是 `skills/spot-bidding-quant/instances/` 的第一个纵向切片：**一省（山东）+ 一主体（独立新型储能）+ 一个规则版本**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，不代表任何真实电站、真实报价或真实收益。

## 1. 一条命令

```bash
# 配置校验 + 来源表 + 未核实项
python skills/spot-bidding-quant/instances/shandong-storage-2026-11/run.py --check-config

# 合成数据全流程：D-1 申报 → 情景 CVaR → T+1 差异桥 → 复核表
python skills/spot-bidding-quant/instances/shandong-storage-2026-11/run.py --demo

# 真实数据（路径指向仓库外）
python skills/spot-bidding-quant/instances/shandong-storage-2026-11/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/spot-bidding-quant/instances/shandong-storage-2026-11/make_demo.py
```

## 3. 运行逻辑（从输入到申报表）

1. **配置校验**：六个块齐全；每个规则块有 `grade` + `source`；96 点与 15 分钟一致；限价满足 `clear_floor ≤ declare_floor < declare_cap ≤ clear_cap`；有效能量与 SOC 窗口一致。
2. **读 D-1**：单交易日、96 点无缺口、价格列齐全、权重和为 1。
3. **5 次 DP**：每个情景调用 `ems-dispatch/tools/dispatch.py` 的 `dispatch_day`，目标为「现货套利收益 − 退化成本」，`terminal="cycle"` 保证日末回到初始 SOC。
4. **分位合成申报**：申报量 = 各情景充放电功率的分位数；参考价 = 各情景价格的分位数；报价 = 参考价 + 风格加价（放电）或 − 压价（充电），并按省级申报限价裁剪。
5. **风格约束**：最小日价差不足则不出手；超过 `max_cycles_per_day` 则按比例缩放；分位混合导致 SOC 越界时逐段修剪并告警。
6. **情景清算**：价格接受者口径，放电报价 ≤ 情景价则中标、充电报价 ≥ 情景价则中标；计算现货边际、合约、退化、容量补偿、固定成本，得到期望净边际与 CVaR10。
7. **T+1 差异桥**：把「参考价口径计划边际」与「实际价量口径实际边际」的差，拆成放电量/价/交叉、充电量/价/交叉、退化、合约、容量、考核、分摊 11 项，残差应为 0。
8. **复核表**：输出最大差异科目、Top 5 量偏差时段、三个复核问题与次日动作。

| 项目 | 值 |

| 申报充电量 | 315.4 MWh |
| 等效循环 | 1.47 次 |
| 情景期望净边际 | 65,196 CNY |
| 情景 CVaR10 | −23,135 CNY |
| 计划边际（参考价口径） | 124,506 CNY |
| 实际边际（T+1 口径） | 26,981 CNY |
| 差异 | −97,524 CNY |
| 差异桥残差 | −2.91e-11 CNY |

**CVaR10 为负是风格使然，不是算错**：尖峰加价 50 元/MWh 让低价情景下只充电、不放电，两个低价情景各亏约 2 万元；这是用尾部亏损换高价情景的收益，复盘时要按风格解释，而不是当成预测误差。

## 6. 风格档与指纹

当前风格 `balanced-v1`：申报量与参考价均取 0.5 分位；放电加价 15、充电压价 10 CNY/MWh；参考价 ≥800 时放电加价改为 50；日循环上限 1.5；最小日价差 80 CNY/MWh。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `efa675d25571`）。比较两个交易日的差异时，先看指纹是否相同：指纹不同，差异首先归因于风格；指纹相同，才归因于预测、执行或规则。

换风格的做法：复制 `instance.json` 为 `instance.aggressive.json`，改 `profile_id` 与参数，用 `--instance` 指向新文件，保留旧文件与旧输出。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；调度内核来自 `skills/ems-dispatch/tools/dispatch.py`，通过绝对路径以独立模块名加载，不修改 EMS 技能。
- **纳入**：现货电能量、退化成本、固定成本、CfD 合约覆盖、容量补偿占位。
- **未纳入**：辅助服务（调频/备用）、中长期曲线分解、容量租赁、两个细则考核、实时市场二次结算、5 分钟调度指令跟踪。
- **不是**：不是实盘下单工具，不是交易中心结算的替代品，不是投资建议。
- 真实数据放在仓库外，用 `--d1/--t1/--out` 指向本地路径；仓库内只保留 D 级合成样例。
