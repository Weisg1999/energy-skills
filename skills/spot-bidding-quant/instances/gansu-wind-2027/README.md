# 甘肃风电 · 2027H1 机制电价样板实例

> 本目录是 `skills/spot-bidding-quant/instances/` 的第二个纵向切片：**一省（甘肃）+ 一主体（集中式风电场上网侧）+ 一个规则版本（现货 V3.2 + 2027 上半年风电机制电价 0.2440 元/kWh）**。配置改 `instance.json`，数据换 `data/*.csv`，运行 `run.py`，不改代码。
>
> 所有演示数据为 **D 级合成数据**，不代表任何真实场站、真实报价或真实收益。

## 1. 一条命令

```bash
# 配置校验 + 来源分级
python skills/spot-bidding-quant/instances/gansu-wind-2027/run.py --check-config

# 合成数据全流程：风功率情景 → 申报曲线 → 现货情景 → 机制差价 → 钓鱼法考核 → 差异桥
python skills/spot-bidding-quant/instances/gansu-wind-2027/run.py --demo

# 真实数据（路径指向仓库外）
python skills/spot-bidding-quant/instances/gansu-wind-2027/run.py \
  --d1 /path/to/d1.csv --t1 /path/to/t1.csv --out /path/to/out
```

合成数据可重新生成：

```bash
python skills/spot-bidding-quant/instances/gansu-wind-2027/make_demo.py
```

## 3. 运行逻辑

1. **配置校验**：六个块齐全；每个规则块有 `grade` + `source`；96 点 / 15 分钟一致；申报 40–500、出清 40–650 元/MWh 必须与 V3.2 一致（0–1000 旧口径只作为历史字段保留）；机制批次 0.3078 / 0.1954 / 0.2440 / 0.2447 元/kWh 折算后逐项核对；CfD 价格必须等于 2027H1 风电机制价 244.0 元/MWh；风电场不得计入 330 元/kW·年可靠容量补偿。
2. **申报曲线**：对每个时段取 5 个风功率情景的 35% 分位（约中心预测的 95%），向下取整到 0.1 MW，并受装机与出口限额约束；报价贴申报下限 40 元/MWh。**申报量只取风情景分位，情景收益只用价格情景，两套情景不交叉配对。**
3. **现货情景**：5 个价格情景逐点乘申报曲线，得到现货收入；机制差价 = 机制比例 ×（机制电价 × 申报电量 − 现货收入）；扣变动运维与固定成本后得情景净收益，按权重算期望与 CVaR（置信 80%）。
4. **T+1 双结算**：日前计划电量按实际日前价、实际与计划的偏差按实时价；实际捕获价 = 现货收入 / 实际电量；机制差价按实际电量口径重算。
5. **钓鱼法考核**：逐时段比较实际与「95% × 申报」，低于门槛的缺口 × 30 元/MWh（D 级简化）；同时输出日完成率与申报准确率。
6. **差异桥**：7 个科目——日前价格偏差、电能量量差、偏差价差、机制电量量差、机制收入让渡、钓鱼法考核、运营成本偏差；残差 < 1e-6 CNY。
7. **复核表**：把「计划（参考价）→ 实际」与「现货 → 机制 → 考核 → 成本」两条链分开写，避免把机制差价当成补贴或把考核当成主要损失。

## 4. 合成演示的基准输出

基准资产：200 MW 风电、出口限额 200 MW；变动运维 20 元/MWh，固定成本 100,000 元/日；交易日 2027-01-15（96 点）。风功率中心预测 2,556.6 MWh，实际 2,550.3 MWh。

| 项目 | 值 |
|---|---:|
| 申报电量（q=0.35） | 2,442.0 MWh（95.52% 预测） |
| 申报价 | 40 元/MWh（贴下限） |
| 参考捕获价（q=0.50） | 305 元/MWh |
| 计划现货收入 | 745,899 CNY |
| 计划机制差价 | −45,012 CNY |
| 计划运营成本 | 148,841 CNY |
| 计划净收益 | 552,046 CNY |
| 情景期望净收益 | 569,378 CNY |
| CVaR（置信 80%） | 406,856 CNY |
| 实际发电量 | 2,550.3 MWh |
| 日完成率 | 104.43% |
| 申报准确率 | 94.17% |
| 低于 95% 门槛时段 | 6 个（17:30–18:30 一带） |
| 钓鱼法考核（D 级） | 349 CNY |
| 实际捕获价 | 306 元/MWh |
| 实际净收益 | 581,869 CNY |
| 差异桥差异 / 残差 | +29,822 CNY / 1.46e-11 |

情景表（价格情景 1→5）：净收益 406,856 / 481,706 / 552,046 / 645,508 / 760,775 CNY；机制差价 +17,213 / −14,866 / −45,012 / −85,067 / −134,467 CNY。**低价情景机制补差、高价情景机制退款**，说明机制是双向差价而不是单向补贴。

差异桥（按绝对值排序的前三项）：电能量量差 +32,264、机制收入让渡 −10,462、机制电量量差 +7,926 CNY；钓鱼法考核仅 −349 CNY，真正代价是低价申报在高价时段少发的电量收入。

**读法**：日完成率超过 100% 仍出现 6 个时段低于门槛——钓鱼法按时段监测，不是按日平均。申报分位越保守，考核越少，但放弃的日前收入越多；本包把这两个效应分别放在「电能量量差」和「钓鱼法考核」两个科目里。

## 6. 风格档与指纹

当前风格 `gansu-wind-floor-v1`：申报价贴下限 40 元/MWh；申报量取风情景 35% 分位；参考价取 q50；CVaR 置信 80%。

`policy` 块规范化 JSON 的 SHA-1 前 12 位作为**风格指纹**写入复核表（当前 `c53f38d3aaa5`）。换风格就换 `profile_id` 并保留旧文件与旧输出，便于比较「保守申报 vs 中性申报」的考核与收入差异。

## 7. 依赖与边界

- **依赖**：仅 Python 标准库；`desk.weighted_cvar`、`desk.validate_public_dataset` 来自 `skills/spot-bidding-quant/tools/`，不修改内核。
- **纳入**：省内日前 + 实时电能量、136 机制差价（按项目捕获价近似）、钓鱼法 D 级考核、变动与固定运维。
- **未纳入**：中长期 24 时段曲线、D+2 日滚动、省间外送、辅助服务、绿证、税费与融资。
- **不是**：不是交易中心结算单，不是机制电价分配方案，不是投资建议；机制差价、考核与回收以正式结算为准。
- 真实数据放在仓库外，用 `--d1/--t1/--out` 指向本地路径；仓库内只保留 D 级合成样例。
